# 八 Agent 全能力审计

## 结论

18 份 Markdown 被视为创作规范与验收依据，不被执行。审计后将其归并为 31 项可追踪能力，每项均绑定：能力 ID、责任 Agent、来源文件、执行策略、校验器和必交付 artifact ID。

## 发现的现有缺口

1. 角色设计阶段仍读取已删除的“三视图”文件，导致五视图规范实际未注入。
2. 八阶段虽存在，但缺少统一的角色能力注册、交接契约和可复算的交付完整性门禁。
3. 音频阶段有实际 TTS/SFX/BGM 能力，但没有逐句输出语速、停顿、重音、呼吸和预计时长。
4. 合成阶段输出仍为 720×1280，与项目 1080×1920 竖屏母版基准冲突。
5. 宣发阶段未强制从已批准高光取材，也未把 AI 标识、版权和 KPI 纳入交付。
6. 既有最终状态只依赖视频质量证据，无法证明八 Agent 的全部交付均已批准。

## 冲突裁决

- “三视图”旧称统一升级为严格五视图：正面、正面四分之三、标准侧面、背面四分之三、背面。
- 竖屏默认 1080×1920/30fps；Bilibili 横屏编译为 1920×1080/24fps。单项目不混用。
- 竖屏普通镜头采用 1.5-4 秒的适配区间；高风险动作镜头采用 1.5-2.5 秒；情绪长镜头须单独批准。
- 竖屏冲突/反转间隔采用 15-30 秒，横屏采用 30-60 秒。
- 文档中的模型名称只是候选；实际视频模式必须与运行时供应商能力协商。

## 当前外部接口核验

- ElevenLabs Sound Effects 当前官方端点为 `POST /v1/sound-generation`。
- ElevenLabs Music 当前官方端点为 `POST /v1/music`，支持 prompt 或 composition plan，两者互斥。
- 所有密钥继续只从服务端环境或加密配置中心读取；研究过程没有提交任何付费生成任务。
