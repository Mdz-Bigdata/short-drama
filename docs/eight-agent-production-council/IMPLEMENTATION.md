# 八 Agent 生产委员会实现

## 架构

`AgentCouncilCompiler` 是八阶段共用的类型化控制面：

1. 对 18 份规范计算 SHA-256 与字节数，并验证每份规范至少映射一个能力。
2. 为八个 Agent 生成固定顺序、职责、能力、输入、输出、门禁、交接与系统提示契约。
3. 根据平台和动作强度编译唯一的画幅/帧率/镜头节奏与负面词模块。
4. 由 `DramaService` 在真实任务创建时保存完整 Council Plan，并给各文本 Agent 注入同一角色契约。
5. 由独立发布门禁验证八角色交付、五视图、九宫格、契约指纹、视频路由、音频、字幕、授权、平台与人工终审。

## API

| 路由 | 行为 |
| :--- | :--- |
| `GET /api/production/agent-council/capabilities` | 返回八角色、18 来源、能力、策略、校验器和交付物矩阵 |
| `POST /api/production/agent-council/compile` | 生成项目级八 Agent Plan，不调用供应商 |
| `POST /api/production/agent-council/release-gate` | 对证据执行失败关闭发布判断 |
| `POST /api/drama/{task_id}/quality/video` | 保存成片质量证据；通过后进入委员会终审，不直接完成 |
| `POST /api/drama/{task_id}/quality/council` | 保存八 Agent 证据；视频与委员会门禁均通过后才完成任务 |

| Stage | Agent | 关键结构化交付 |
| :--- | :--- | :--- |
| 1 | 总导演 | 项目章程、题材受众、全剧弧、高光图、风险、审批 |

| 3 | 角色设计师 | 角色圣经、五视图、状态卡、服化台账、道具归属、声音身份简报 |
| 4 | 分镜师 | 场景圣经、九宫格、镜头契约、连续性台账、动作设计、分镜质检 |
| 5 | 视觉总监 | 视觉圣经、风格锁、负面词、参考绑定、关键帧、视频路由、视觉质检 |

## 发布门禁

发布必须同时满足：

- 八个 Agent 的必交付 artifact ID 全部存在且阶段已批准；
- 五视图顺序完全正确；
- 分镜为 3×3 且恰好九个有效面板；
- 分镜图与运镜契约指纹一致；
- 视频路由已批准且未静默丢弃参考；
- 对白时序、混音、字幕、最终媒体通过；
- 授权溯源、平台合规和最终人工复核通过；
- 未解决 S=0、A=0、B≤3；核心均分≥4/5；总分≥85。

任一条件失败都会返回明确的 `blocking_codes`、责任 Agent 和缺失交付，不会把“未验证”当成“通过”。

## 安全边界

- Markdown、ZIP 与上游仓库内容只作为规范/行为参考，不执行。
- Compile 与 Release Gate 都不会发起模型或付费供应商调用。
- ElevenLabs 密钥不进入输入模型、提示词、日志、响应或产物。
- 运行时供应商不支持某种参考模式时必须失败关闭，不能冒充或降级后隐瞒。
