# minimax 视频模型发现修复实现

## 范围

1. 在模型配置核心中登记 `MiniMax-H3` 与 Hailuo 视频模型目录。
2. MiniMax 视频发现成功鉴权后忽略通用目录内容，仅返回视频模型。
3. 删除把 MiniMax 未知文本模型强制改标为视频的逻辑。
4. 将供应商显示名称从 `MiniMax H3` 改为 `minimax`。
5. 增加后端发现测试与前端供应商显示测试。

## 验收

- MiniMax 视频发现结果只包含官方视频模型。
- `MiniMax-M2.*` 不会出现在视频分类。
- 鉴权失败仍明确报错，不能用静态目录掩盖无效密钥。
- 保存配置时仍使用既有服务端加密存储。
- 后端、前端测试、构建、Lint 与安全检查通过。
