# 《系统实际下发提示词骨架》逐行对照

来源：ArcReel `docs/prompt-templates/系统实际下发提示词骨架.md`（按提交 62627982e 渲染）。

许可：ArcReel 为 AGPL-3.0。表里「新增」的固定句多为逐字照搬，「已有·原句相同」的句子也与骨架一致；哪些键逐字、哪些改写，以 `THIRD_PARTY_NOTICES.md` 2026-11-10 的条目为准。
这份表把骨架里的每一行对到本项目的提示词上，三种处理：

- **新增**：本项目原来没有，照骨架补进来。固定句放在 `backend/app/data/prompt/clip_skeleton.json`（视频）和 `backend/app/data/prompt/panel_still.json`（分镜），代码只负责拼装。
- **已有**：本项目原来就有同一条要求，写法是自己的，不重复写第二遍。表里给出本项目的原句和出处。
- **不适用**：骨架这一行依赖的数据或功能本项目没有，写明原因。

`〔…〕` 是骨架里的占位，对的是「这一栏的内容从哪来」；其余是固定句。

拼装代码：`backend/app/core/clip_skeleton.py`、`video_prompt_engine.py`、`slice_video.py`（视频）；`panel_still_prompt.py`（分镜）。
测试：`backend/tests/test_clip_skeleton.py`、`tests/test_panel_still_prompt.py`。

## 一、分镜提示词（逐格出图）

本项目的分镜格提示词（`panel_still_prompt.compile_panel_still`）原来就是「落笔 → 调色 → 收边」三段，对的是骨架 1.1 的中文写法。

### 1.1 中文写法

| 超字数按 L4→L1 降级 | 不适用 | 本项目只对备用供应商做一次截短（`ModelGateway._sanitize_prompt_for_agnes`：保留动作到【收边】之前，600 字以内），主路径不降级 |
| `makeup` 字段不渲染 | 不适用 | 说明性文字，无内容可移 |

写法上的出入（内容没少）：

- 六锁的身份、道具两项，骨架缺值时写「承接身份锚」「承接上一格」，本项目直接写出人名和道具名，后面接同一句固定要求；没有人物写「空镜，无人物」，没有道具写「无」。
- 服装缺值时骨架写「承接装备锚」，本项目没有「装备锚」这个说法，写「承接定妆照与上一格」。
- 光位、色板缺值时，本项目原来写「沿用本场建立镜」，现在两边都留：「沿用本场建立镜，承接上一格的主光方向与色温」。每场第一格没有上一格，写「沿用本场建立镜的主光方向与色温」「沿用本场建立镜与参考图的主色次色点缀色」；朝向写「以本格调度为准」。

### 1.2 英文标签写法（GPT-Image）

不适用：本项目没有 GPT-Image 出图通道，分镜格只发中文写法。这一节的内容与 1.1 逐项相同，只是换了英文标签；它独有的 `Preserve: face geometry, hairline, skin tone …` 一行，对应的要求在 1.1 的六锁和「不要身份漂移」里。

## 与骨架不同的地方（有意为之）

1. **「正脸特写」禁令和「优先中远景、侧后方、背影…」那一段默认不写。** 短剧要看清脸，这两句会把人物拍成背影和剪影。句子都在数据里，任务配置 `video_portrait_safe` 打开就写。
2. **真人演员镜头不写「均为原创虚构角色」和真人肖像那几项禁令。** 画面里就是真人演员，写了自相矛盾。
3. **引用写成「名字（参考图N）」**，不写 `@图片N`：本项目各模型通道统一用这个写法，发送时再按通道改。
4. **不写绝对秒数**（`0-4S`、`U1，0.5-4S`）：本项目按先后次序写拍点。
5. **表演锁第二句只在 8 秒及以上的镜头写**，短镜头只写第一句。
6. **「动作轴线」会出现两次**：运动契约里原有一句，Pa2 新增「空间坐标全程固定」一句。两句管的地方不同，都留着。

## 字数

视频片段提示词多出约 500 字固定句（一条 Seedance 对话镜头全文约 2100 字）。固定句不计入正文预算，也不会被压缩掉。分镜格提示词多出约 200 字。
