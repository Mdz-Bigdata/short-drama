# AI 导演：移植范围

用户的要求：把下列项目的 3D 导演台和 3D 建模能力融入本项目，做到自动建模、自动规划，并能用自然语言调整和优化；由模型优先推荐站位、机位、姿势、场景和空间调度。

## 怎么用

导演台右侧的 **AI 导演** 标签页：

| 区块 | 做什么 | 花费 |
| --- | --- | --- |
| 自动规划 | 模型读剧本，出 1 到 3 版完整调度，与规则方案比较并推荐一版；采用前舞台不变 | 每版 1 到 2 次文本调用 |
| 对话调整 | 用文字说要改什么，可限定只改选中对象或这一镜；每次改动可单独撤销 | 每条 1 到 3 次文本调用 |
| 自动优化 | 规则先修，模型再优化；评分变低的结果不保留 | 0 到 3 次文本调用 |
| 模型库 | 74 个内置白模，一键放上舞台 | 不调用模型 |
| 文字搭物体 | 文字或参考图变成一件可编辑的模型；名字正好是模型库里的东西就直接用库 | 0 或 1 次调用 |
| 文字搭场景 | 一段描述变成一组体块，优先用模型库 | 1 次文本调用 |
| 导出 GLB | 选中一件布景，下载 glTF 二进制文件 | 不调用模型 |

生成分镜时，每场也会先让模型定布景、站位和姿势（面板里的开关可以关）。站内助手和 MCP 客户端可以用同样的能力：`auto_plan_stage`、`adopt_stage_plan`、`build_stage_model`。

## 没有移植的

这些是 mangfufu/director-desk 等项目有、但不属于这次目标的能力。需要的话可以单独做：

- 物理（重力、碰撞、布娃娃）、粒子与形变、媒体表面、镜面
- FBX / OBJ 导入（现在只收 GLB）
- 人物站到物体上：本项目的舞台人物只有地面坐标，平台和楼梯只能做背景，模型也被这样告知
- 键盘操控录制走位、插件系统、命名版本历史（这里的撤销只保留最近 4 步）
- 让模型直接在 Blender 里写 Python 建模：这等于运行模型写的任意代码，所以模型只产出数据，由现有的 Blender 规格渲染

## 验证到什么程度

- 真实 Blender 渲染过组合模型，导出的 GLB 能被 Blender 导入。
- 浏览器里走通了规划、采用、对话、撤销、优化、模型库、文字搭物体、文字搭场景和 GLB 下载。
- **这些流程用的是本地假模型，答案是写死的。** 所以它们证明的是链路通畅，不是真实模型的规划质量。提示词还没有经过真实模型的调校。
