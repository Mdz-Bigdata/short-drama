# 多模型配置实现

## 数据流

1. 管理员加载供应商模型目录。
2. ElevenLabs 返回真实模型列表以及单独的 14 类能力目录。
3. 前端按能力筛选模型，复选结果跨分类累积并按模型 ID 去重。
4. 连接测试和保存请求一次发送全部 `selected_model_ids`。
5. 存储层把新选择合并到供应商配置，不替换此前保存项。
6. 已保存模型可单独启用、停用或删除；最后一项删除时清理供应商空配置和加密凭据容器。

ElevenLabs 返回 403 时代表目录 scope 或 IP 限制，允许使用版本化官方目录完成保存并返回未验证警告；401 无效/撤销 Key 和网络不可达不会在保存阶段回退。连接测试始终使用严格模式。

## 接口

- `POST /api/model-configurations/discover`：加载模型与服务能力目录。
- `POST /api/model-configurations/test`：严格验证全部选择。
- `POST /api/model-configurations`：批量合并保存。
- `PATCH /api/model-configurations/{configuration_id}/models/{entry_id}`：启停单项。
- `DELETE /api/model-configurations/{configuration_id}/models/{entry_id}`：删除单项。

删除操作要求管理员权限，写入不含秘密的审计事件，并在提交后重建运行时模型注册表。

## 界面行为

- “全部模型”显示供应商返回的完整模型集合。
- 能力按钮显示当前已加载目录中实际匹配的模型数。
- “全选当前分类”只追加当前可见模型，不清空其他能力下的选择。
- 独立服务显示说明，不提供虚假的复选框。
- 已保存模型列表不分页截断；使用独立纵向滚动区域显示全部条目，每项提供叉号删除。
- 标题同时显示“共 N 个 / 已启用 N 个”，避免把视口内可见数量误认为保存上限。
- 首页“模型”徽标通过后端绝对 API 地址读取 `global_status`；存在至少一个已启用模型时显示“已配置”，不再依赖当前任务的 `videoModel`。
- 保存、启用、停用或删除模型后，配置中心通过变更回调要求首页立即刷新状态；全部模型停用或删除后恢复“未配置”。
- 列表接口同时返回全部启用模型 ID 与每类默认模型；前端为空的任务模型字段会自动采用默认值，后端文本/图像/视频网关也会对空选择使用全局默认模型。
