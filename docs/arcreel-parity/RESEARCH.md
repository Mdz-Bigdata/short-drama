# ArcReel 能力对照：研究记录

## 目的

把 [ArcReel/ArcReel](https://github.com/ArcReel/ArcReel) 的全部能力融入本项目。ArcReel 以
AGPL-3.0 附加条款发布，本项目的既定做法（见 `THIRD_PARTY_NOTICES.md`）是**只参考行为，
不拷贝代码、提示词、Schema 与界面**：每项能力都按它的产品语义在本项目的架构里重新实现。

## 审阅对象

- 仓库：`https://github.com/ArcReel/ArcReel.git`
- 审阅提交：`066e7a505a0af17d31ee6c7a5629ac62ce88c166`（2026-10-12）
- 审阅方式：在隔离目录只读阅读 `PRODUCT.md`、`GLOSSARY.md`、`docs/adr/0001–0097`、
  `server/`、`lib/`、`frontend/src`、`website/docs`；未执行其中任何代码。
- 本项目此前已按同样方式移植了编剧引擎（分集账本、两段式创作、逐字台词、模型绑定时长、
  违约修复回路）与镜头运镜工作区，见 `docs/structured-screenwriting-engine/` 与
  `backend/app/core/camera_motion.py`。

## ArcReel 的能力版图（按产品语义归纳）

| 领域 | ArcReel 的行为 | 关键决策记录 |
|---|---|---|
| 源文件 | 一个项目可同时有多份**整本源文**（按显式顺序拼接后切集）与**逐集原文**（每个文件就是一集，排在播出顺序末尾）；源文件类型（小说 / 成品剧本）逐文件记录；账本记录每集原文来源：整本切出 / 自带原文 / 无原文 | ADR 0031、0036、0096、0097 |
| 分集账本 | 账本是分集的唯一真相；AI 分批规划、候选重规划并对比采纳、手工切分（切/拆/并/移边界）、重置规划、建集/移集/删集带影响预览 | ADR 0031、0032 |
| 剧本流水线 | 分镜内容规划 → 审核确认（指纹判定待审 / 已确认）→ 提示词编写只填待写项；违约草稿隔离与修复；保存“不劣化”校验 | ADR 0041、0080、0002 |
| 口播归属 | 一个视频单元只有一种口播（角色台词 / 旁白 / 无声），混合即退回规划；旁白交付为项目级设置（合成 TTS / 留给后期）；字幕草稿按阅读量机械切分计时 | ADR 0089、0040 |
| 资产 | 角色 / 场景 / 道具 / 商品；名字即身份，改名级联；合并与别名；角色衍生形象；资产图是生成的唯一参考，用户原图只喂资产图（商品除外） | ADR 0057、0072、0073、0034 |
| 参考图 | 目录、准入（未登记名或无资产图即阻断）、上传副本压缩、超限裁剪并告警 | ADR 0012 |
| 视频单元 | 生成模式创建后锁定（分镜图生视频 / 参考生视频）；`@[名]{台词}` 写法；请求事实一次求值；时长取不小于剧本时长的最小档位 | ADR 0055、0064、0086、0018 |
| 批量生成 | 持久化任务队列、按供应商 × 媒体类型并发、任务依赖、批次结果契约与下一步动作码 | ADR 0083、0043 |
| 批量视频准入 | 整批一起评估：放行 / 待确认（时长档位 + 费用）/ 受阻（零任务、零费用、逐单元原因；通过的单元标为“被整批扣住”）；报价 generate / reuse / blocked | ADR 0061 |
| 取消与重启 | 只能取消排队任务；重启后有供应商任务号的视频任务续查，其余标失败不重投（避免二次计费） | ADR 0006、0007 |
| 费用 | 供应商调用是计费单位；每模型声明式定价；项目级预估 + 实际；按币种分列从不合并；未定价即标注 | ADR 0009、0053、0076 |
| 供应商 | 多凭据手动激活；文本分简单 / 复杂档；按任务类型桶选模型；自定义供应商 + 声明式端点 + ComfyUI 端点；端点三种测试 | ADR 0016、0051、0054、0067、0081 |
| 剪辑交付 | 具名多条剪辑时间线（不是产物）、19 种转场、BGM 库响度归一、本地 ffmpeg 成片、剪映草稿（5.x / 6+ 两种文件）、素材审看接触表 | ADR 0090、0095 |
| 产物 | 产物清单是唯一真相；时效 current / stale / missing / blocked；版本历史；项目事件 SSE；工作流状态由服务端判定 | ADR 0062、0091、0085 |
| Agent | 嵌入式 Agent（会话、子代理、技能、记忆、沙箱）；外部 Agent 经 remote MCP | ADR 0003、0025–0030、0069、0074、0087 |
| 其他 | 36 个风格模版 / 风格参考图二选一；三种创作类型（旁白 / 剧情 / 广告）；zh / en / vi 全量 i18n；市场 | ADR 0023、0033、0078 |

## 本项目现状（审阅时）

- 已有：编剧引擎（见上）、镜头运镜工作区、分镜九宫格、五视图 / 设定集、空间调度与 3D 导演台、
  镜头衔接、风格锁、八 Agent 委员会、模型配置中心、工作流助手。
- 缺口：剧本文库里的文件不进入第 2 阶段（只能存一份 `script_content`）；没有批量准入；
  流水线不记录任何供应商调用费用；没有口播归属与字幕草稿；资产没有改名级联 / 合并；
  重启后供应商任务不续查；没有时间线 / 剪映草稿 / 嵌入式 Agent / 商品与广告模式 / i18n。

## 用户给出的场景

截图里的剧本文库有 `story.txt`（完整剧本）与 `episode_1..5.txt`（逐集剧情）。按 ArcReel 的语义，
前者是**整本源文**，后者是**逐集原文**；本项目此前把它们都当成只读参考资料。
