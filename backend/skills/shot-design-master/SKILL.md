## 铁律（优先级最高，覆盖一切）

1. **只写摄影机拍得到的、麦克风听得到的。** 禁止心理描写与括号暗示。「他很愤怒」→「下颌绷紧、鼻翼张开、指节发白」。
2. **每一次生成请求的时长必须 ≥ 4 秒，且 ≤ 所选视频模型的单次生成上限。** 超上限就拆镜，不要压缩内容；成片上只要 1.5 秒的短镜也按 4 秒下单、在剪辑台裁短，**绝不提交 `duration < 4`**——平台直接 400 拒，连废片都拿不到。三层时长口径与上限表见 [models-failures.md §1.1](references/models-failures.md)。
3. **一集必须拆成多个镜头。** 具体几个由戏剧节奏决定（地点变化、情绪转折、攻防回合、视线乒乓各自成镜），但绝不允许「一集一镜」。
4. **每镜只推进一个小动作，相邻两镜按「半拍」衔接。** 禁止从「发现」直接跳到「离开」；按 发现→反应→消化→决定→行动 逐镜拆，后一镜是前一镜动作完成到五到八成时的状态。
5. **第 2 镜起，每一镜都必须承接上一镜的最后一帧**，锁住六锚点：人物 / 空间 / 动作 / 情绪 / 道具 / 光影。
6. **锁 180° 轴线**，角色左右关系全场不翻转。
7. **禁止分身**：同一画面只保留单个对应人物，禁止外形着装完全一致的复制人、双胞胎效果。
8. **输出前自检**，依据本文件末尾的自检清单。自检是内部过程，不必展示。
9. **模板是词典，不是答案模板。** 本技能所有模板（八大镜头组合、五镜动作链、黄金 15 秒切片、题材提示词模板、站位公式、构图库）都是**取词词典**，禁止整表照抄。每次生成必须基于本次输入（人物性格 / 场景 / 影视参考 / 剧情兴趣点）做实质定制：**至少替换、改写或重组模板内容的 1/3**；同一题材连续两次调用，**镜头链、姿态分配、动作要点描述必须有明显不同（差异度 ≥ 30%）**。自检项：本次分镜与所引模板的差异度 ≥ 30%？同题材上一版与本版至少有 1–2 项明显不同？
10. **还原真实作品桥段时，禁止凭训练记忆发挥。** 用户要求「照着某某剧那场打戏来一版」时：① 若对该桥段有印象——先陈述「我对这个桥段的印象是 XYZ，对吗？」并**等用户确认或修正**，不得直接当作事实；② 若无可靠印象——直接说明并请用户逐招描述，**不要编**；③ **还原模式下一律不调用泛化模板**（题材模板 / 镜头组合模板 / 站位公式），以用户描述为唯一事实源。

## 提示词写作铁则（最高杠杆，直接决定成片率）

### 1. 词序即权重

**景别与运镜词必须放在句首。** AI 对构图指令「听而不闻」、总生成普通正面中景，根本原因是主体描述太长、把构图词的权重抢走了。

```text
✗ A handsome man in a black robe standing in the rain, close-up...
✓ Close-up shot of a handsome man in a black robe standing in the rain...
✗ 陈九站在祭坛边，火把照着他的脸，特写
✓ 特写，陈九站在祭坛边，火把照着他的脸
```

> **动作戏例外**：打戏采用「动作与反馈优先」的五段结构（① 动作与反馈 ② 镜头与运镜 ③ 光影氛围 ④ 音效提示 ⑤ 防崩后缀，见 [performance-action.md](references/performance-action.md) §3.11.5）。此时景别与运镜作为第 ② 块**紧随其后**，仍必须落在前两块之内，绝不允许沉到句尾。

### 2. 单帧单景别

同一条提示词里不要既写 `extreme wide shot` 又写 `close-up on eyes`，模型会构图混乱。**一个镜头只有一个景别、一个主角度。**

### 3. 英文运镜词的审核风险

裸写的英文运镜术语（`Dolly`、`Aerial`、`Crane`）可能被审核系统误判成人名或品牌名而拦截。
**中文提示词就用中文运镜词；英文提示词用完整短语**（`the camera pushes in`，而不是孤零零一个 `Dolly`）。

### 4. 景别 × 崩坏风险曲线

下面这条曲线**只针对拍人脸的镜头**：镜头越近、时长越长，人脸漂移越明显。

```text
远景 EWS  ██████████ 100% 安全（看不到表情）
全景 FS   ████████░░  80%
中景 MS   ██████░░░░  60%  ← 推荐主力景别
近景 CU   ████░░░░░░  40%  需要精修
特写 ECU  ██░░░░░░░░  20%  必须精修或真人驱动
```

**避免人脸特写连续堆叠。** 表情实在解决不了时的五种规避方案：

1. 低头 / 侧脸（手捂脸、转身）
2. 光影遮挡（逆光剪影、百叶窗、烟雾）
3. 道具遮挡（杯子、手机、书本、帽檐）
4. 切 insert 镜头（手部动作、环境细节）
5. 运动模糊（快速转头时自然模糊 1–2 帧）

**特写按「拍什么」分流，不按景别一刀切。** 上面 20% 那一档说的是人脸，不是所有特写：

| 特写类型 | 画面里有什么 | 打戏中的定位 |
|---|---|---|
| 人脸特写（Face ECU） | 完整五官占据画面主体 | **最高风险**，就是曲线上的 20% 一档：不得连续堆叠，每一条都必须精修或真人驱动 |
| 局部特写（Detail ECU） | 手部、兵器刃口、受击点、衣料撕裂处、脚下地面 | **打戏安全牌**：画面里没有完整人体，模型没有「人」可崩，可连用、可承接打击瞬间 |

崩的从来不是「近」，是**画面里有一整个人而模型猜不准他的五官和关节**。所以景别越近反而越安全——前提是切进去的那一块**不含人脸、不含完整肢体链**。

**高强度对抗镜（连续拳脚交接、奔跑、多人肢体缠斗）一律用局部特写暗示、侧面过肩、或快速甩镜（Whip Pan）规避**：打击瞬间交给手部/兵器/受击点的局部特写去承接，人脸只留给打完之后的静态反应镜。

### 5. 竖屏 9:16 修正

短剧是竖屏，横屏的景别直觉会失效：

| 横屏惯性 | 竖屏修正 |
|---|---|
| 中景够用 | **景别上移**：横屏的「中景」在竖屏要更近，面部占画面宽度 50–70% |
| 左右大全景 | 会被裁掉，改**纵向构图**；用前后景深走位替代左右走位 |
| 双人同框 | 竖屏窄易拥挤，**单人优先**，多用单人正反打 |
| 手部/道具横放 | 改**竖排**，纵向画面适合由下往上的动作 |
| 面部居中 | 面部落在**上 1/3 黄金区**；顶部 200px、底部 250px 安全区内不放关键信息 |

### 6. 黄金 15 秒切片模型

对应 H3 / Seedance 2.0 的 15 秒单镜上限，一条 15 秒视频按四段切：

| 时间 | 功能 | 镜头建议 |
|---|---|---|
| 0–3s | 交代场景与整体氛围 | 全景或中景静止 |
| 3–6s | 触发事件（只让一个道具或一个动作启动） | 中景慢推 |
| 6–9s | 角色反应（承接上一动作，表情轻微变化） | 近景或手部特写 |
| 9–12s | 情绪升级（只上升一级，不直接爆发） | 大特写慢推 |
| 12–15s | 行动或悬念（从上一镜自然收束） | 慢拉远或背影镜头 |

### 7. 五镜动作链

10 秒内拉满武打节奏：

```text
第一镜 全景 Establishing → 第二镜 中景 Charge → 第三镜 近景 Attack
→ 第四镜 特写 Impact → 第五镜 POV Reaction
```

第四镜的「特写」是**局部特写**（拳、兵器、受击点），不是人脸特写；人脸留到第五镜的反应镜，那一镜身体是静止的。

这里的「10 秒」是**成片剪辑时长**：五镜在成片上各占 1.5–2.5 秒，但**每一镜仍要单独按 ≥4 秒生成**，多出的素材在剪辑台裁掉。按 2 秒去下单，五条请求会被平台全部 400 拒。

### 8. 八大镜头组合模板

| 组合 | 景别链路 | 适用 |
|---|---|---|
| 开场建立组 | 全景 → 中景 → 特写 | 角色出场、开篇 |
| 情绪升级组 | 中景 → 近景 → 极近特写 | 崩溃、告白、内心独白 |
| 关系拉扯组 | 对切 → 手部特写 → 对方反应镜 | 谈判、争执、暧昧试探 |
| 悬疑窥视组 | 环境空镜 → 遮挡窥视 → 背影离场 | 暗中调查、跟踪 |
| 孤独氛围组 | 大远景 → 孤立背影 → 窗边侧脸 | 离别、深夜失落 |
| 动作节奏组 | 动感跟拍 → 低机位仰拍 → 动态模糊 | 追逐、逃亡 |
| 回忆插叙组 | 线索特写 → 失神凝视 → 逆光剪影闪回 | 转入回忆 |
| 结尾收束组 | 人物回眸 → 留白空镜 → 情绪收束点 | 收官、开放式结尾 |

**三条组合原则**：先定情绪再选镜头；围绕高潮爆发点安排前后景别起伏；**同一场景内不得出现超过两个连续的相同景别**——必须远近交替、正侧结合，刻意堆叠（如双特写制造窒息感）须在分镜表里注明意图。

景别链有方向性：`远→中→近` 是**推入**，天然带紧张感；`特写→近→远` 是**抽离**，适合收尾、回忆、释然。

## 四步工作流

### 第 1 步 · 定全片基调（每个项目只做一次）

产出一段「全局设定」，后续所有镜头都继承它，不得漂移：

```text
整体设定为{时间/地点/戏份类型}，{题材氛围}，
主色{主色}，辅色{辅色}，{动机光描述}，{光比}，{冷暖关系}。
```

> 示例：`整体设定为祭坛边柴堆引火区的夜戏，悬疑追查低照氛围，主色深青冷蓝灰，辅色琥珀橙与炭黑，动机硬光，8:1大光比，冷暖分离。`

同时锁定**场景圣经**与**角色不变量**，写法见 [blocking-lighting.md](references/blocking-lighting.md) 与 [continuity-consistency.md](references/continuity-consistency.md)。

### 第 2 步 · 绑定素材（有参考图/参考视频时必做）

用显式定义句把素材和角色/场景钉死，全片复用同一套代号：

```text
将 @图片1 中的{场景描述}定义为 <场景1>；
将 @图片2 中的{角色名}定义为 <主体1>，音色为{音色描述}；
将 @图片3 中的{角色名}定义为 <主体2>，音色为{音色描述}。
```

音色写法：`偏低沉厚、冷得无情绪的三十五岁男声` / `中低声区、偏冷带颗粒感的二十一岁女声`。
素材 token（`@图片N`/`@视频N`/`@音频N`）必须与平台界面显示的完全一致，不要翻译或改写。

### 第 3 步 · 拆镜

按铁律 3–6 拆分，每镜填满**八要素**：

| 要素 | 要求 |
|---|---|
| 镜号 | 本集内从 01 连续编号，形如 `E3S07` |
| 时长 | 分两栏写：**生成请求时长**（≥ 4 秒且 ≤ 模型上限）/ **成片剪辑时长**（1–3 秒，剪辑台裁出）。三层口径见 [models-failures.md §1.1](references/models-failures.md) |
| 景别 | 远景/全景/中景/中近景/近景/特写/大特写 |
| 机位与运镜 | 中文 + 英文双写，如 `低角度仰拍缓慢升起（low angle hero shot, tilt up）` |
| 起幅 → 落幅 | 明确写出首帧画面与末帧画面 |
| 画面动作与表演 | 可见动作 + 具象微表情，不少于 50 字 |
| 台词 | `{台词原文}` 花括号包裹，注明说话人、音色、语速情绪 |
| 声音 | 环境声层 + 动作音效 |

### 第 4 步 · 写提示词

按 [prompt-contracts.md](references/prompt-contracts.md) 选契约。**默认使用六段式 Full-Reference 契约**（见下），单镜快速出片可用精简单镜模板。

**目标模型是 MiniMax H3 时**，改用 [h3-native-contract.md](references/h3-native-contract.md) 的字段级硬契约：
先判定 `T2VA / I2VA / FL2VA / L2VA / Ref2VA` 五种模式之一，字段名（`integrated_multimodal_description`、
`overall_soundscape`、`non_diegetic_music`，或六段式的 `subject_definitions` 等）、`<Subject N>`/`<Picture N>`
标签、`(S1)` 说话人 ID、`<d>[语言] 台词</d>` 与 `[Shot N] At MM:SS.mmm` 记法**必须逐字保留英文原样**。

## 六段式 Full-Reference 契约（主力契约）

每段 15–30 秒视频的提示词不是一句话，而是一套结构化的六段式文档：

| 段落 | 内容 | 作用 |
|---|---|---|
| `subject_definitions` | 角色与场景的锁定描述 | 规定哪些图片负责什么，全片不得漂移 |
| `summary` | 整段剧情概述 | 一句话定调：什么人在什么地方发生了什么 |
| `retention_analysis` | 不变量约束 | 人物不变量 / 场景不变量 / 风格不变量 / 绝对禁止项 |
| `detailed_description` | 逐镜头详细描述 | 机位、运镜、表演、对白、情绪节奏 |
| `overall_soundscape` | 环境声设计 | 雨声/脚步/环境底噪/对白/呼吸等声音层 |
| `non_diegetic_music` | 配乐设计 | BGM 进出点、情绪匹配、乐器选择 |

填空模板与整段范例见 [prompt-contracts.md](references/prompt-contracts.md)。

### 单镜写法骨架（`detailed_description` 内每一镜）

```text
镜头{N}：{运镜中文}（{运镜英文}），
起幅：{首帧画面} → 落幅：{末帧画面}，
{主体}{可见动作，含身体细节}，{具象微表情}；
{光色方案}，动机光源为{光源}，{光的走向与打亮部位}，暗部保留{材质细节}，光比{X:1}；
{环境元素与物理反馈}。
<{环境声层1}，{环境声层2}，{动作音效}>。
```

有台词时，在动作之后接：

```text
用{音色描述}，{语速与情绪}说道 {台词原文}
```

## 时长与切镜

单镜时长上限由**所选视频模型**决定（下表是**生成请求时长**，即可填进 `duration` 的区间），超限必须拆镜：

| 模型 | 单镜上限 | 备注 |
|---|---|---|
| MiniMax H3 / 海螺系 | 15 秒 | 下限 4 秒 |
| Seedance 2.0 | 15 秒 | |
| Seedance 2.5 | 30 秒 | 超长模式另计 |
| 未登记模型 | 10 秒 | 保守值，宁短勿超 |

**三层时长口径（一句话）**：能填进请求的只有**生成请求时长**（≥ 4 秒且 ≤ 上限）；提示词内部排的是**动作单元 2–4 秒**（🟢 低危动作可到 5 秒）；成片上看到的 **1–3 秒短镜是从 4 秒素材里裁出来的，永不作为请求参数**。完整对照表见 [models-failures.md §1.1](references/models-failures.md)。

成片剪辑时长参考：建立镜 3–4 秒；叙事中景 2–3 秒；情绪特写 2–3 秒；台词镜按每 10 字约 2 秒估；强调/奇观镜 3–5 秒；转场镜 1–2 秒；高风险动作镜 1.5–2.5 秒。**这一行的数字一个都不填进请求**，一律按 4 秒起下单再裁。

## 收尾串（每条视频提示词的结尾必带）

**收尾串归口：全片只有三串，本章是第一串的权威定义处。** 本章两块（质量锚点 + 稳定性与负面约束）合起来即三串里的**画质锚点串**，适用面是**全片每一镜**，挂在提示词最末。另两串不在本章定义：**一致性串**（承接句 + 跨镜断裂负面词，第 2 镜起每一镜）见 [continuity-consistency.md](references/continuity-consistency.md) §一；**打戏防崩坏后缀**（仅打戏镜，`24fps` 就写死在这一串里）见 [performance-action.md](references/performance-action.md) §3.13。三串语义不重叠，同一镜可以同时叠挂；归口表、挂载顺序与完整机理见 [shot-grammar.md](references/shot-grammar.md)〈收尾串归口〉，本章不复述。

**禁止另造第四串**：新增的收尾约束一律并进语义最近的那一串。**多起一串就会崩**——末尾多一遍「不变形 / 光影统一」这类同义约束，模型把重复当强调、权重整体后移，句首的景别与运镜词被压到「听而不闻」，画面退回默认的正面中景。

**质量锚点**（按题材增删，风格词全片保持一致）：

```text
电影胶片质感，变形宽银幕镜头，{色彩分级}，{光质}动机光源，暗部保留细节，
35mm胶片颗粒，自然运动模糊，高清，细节丰富，电影质感，{光比}，{饱和度}，画面铺满无黑边
```

**稳定性与负面约束**：

```text
人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿；
保持无字幕，避免生成任何文字或字幕，不要生成水印，不要生成 Logo；
视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，
同一画面中仅保留单个对应人物，不出现人物重复复刻。
```

分模块负面词见 [models-failures.md](references/models-failures.md)。

## 万能组合公式

**出图（单帧）**

```text
镜头景别 + 构图方式 + 人物描述 + 环境光线 + 画质参数
```

**站位（多人同框）**

```text
场景类型 + 角色站位方式 + 轴线关系 + 镜头景别 + 镜头运动 + 情绪目标 + 适用场景
```

> 一套画面**优先只搭 1 种景别 + 1 种构图**。叠加过多镜头词汇会导致画面错乱、人物畸形。

**一句话锦囊**

```text
远景定场 → 中景叙事 → 近景带入 → 特写爆情绪
黄金光 + 逆光轮廓 + 三分法构图 = 80 分起步
色调统一 + 动态元素 + 好转场 = 质感翻倍
```

## 动作戏铁则（AI 最不擅长的场景）

扩散模型逐帧去噪，位移越大越猜不准——**运动幅度越大越容易崩**。不要让模型挑战高速动作，
要**重新设计动作本身**：

```text
[降速设计] + [单动作单镜] + [暗示代替展示] + [特效加分] + [声音补位]
```

**打击感五件套（一次打击必写全五类，缺一类力量感就塌）**——打击感 ≠ 光效：

```text
① 蓄力势能：重心下压、肌肉紧绷、关节蓄力、身体扭转
② 接触冲击：环形冲击波、火花、冲击帧、画面短震
③ 受击反馈：头部猛甩、身体弓形后弹、手臂上扬、步伐擦地
④ 环境破坏：碎石飞溅、尘土炸开、地面裂纹、断木横飞
⑤ 镜头反馈：撞击瞬间镜头剧烈震动、1 帧白闪冲击帧、速度线爆发（慢动作仅限终结击）
```

**约束单位是一次打击（跨出招—受击—环境三镜链），不是一镜。** 五类必须在同一次打击里全部出现，但不得挤进同一镜——
出招镜担①、受击镜担②③、环境镜担④、⑤优先后期做。
**挤进同一镜会崩**：等于让模型在一段位移里演完蓄力、命中、飞退、碎石，运动幅度直接顶穿 ≤ 4 的上限，肢体糊成一团。
**⑤ 里的慢动作不是每击都给**：中间回合只留震动 + 冲击帧 + 速度线，`0.25x / slow motion` 仅在终结击命中后的 0.5 秒使用——
全程慢放会让观众读到"没有力量"，这与下方铁则「慢动作只用在最后一击」是同一条规矩。

**光效是叠加项，不是替代项**：缺五件套时光效再多也没有打击感；五件套齐了之后，后期再叠命中闪光 + 三层音效，临场感才满。

**戏剧层先于技术层**：写打戏前先过七原则——Clarity 清晰（最高优先级）、Geography 场景几何、
Stakes 赌注、Motivation 动机、Choreography 编排、Vulnerability 脆弱、Consequences 后果。
观众看不懂在打什么，招式再炫也是废片。

- **运动幅度 ≤ 4**（🟡 中等风险降到 4，🟢 低危 2–3；「决不超过 7」是旧版残留，已废止）；所有动作场景写 `slow motion, cinematic slow motion`，不要写 `fast action`。
- **24fps 是全片唯一交付帧率**，它已经写死在防崩坏后缀里，逐镜提示词不得改写、不得删除。`60fps` 只是**素材帧率**，
  仅在这一镜确实要升格时才出现，且必须写成完整短语 `shot at 60fps for slow-motion, delivered at 24fps`。
  **`24fps` 与 `60fps` 裸写在同一串里会崩**：两个孤立的帧率数字对模型是两个互斥的时间基，采样时在二者之间摇摆，
  输出忽快忽慢的变速段落、动作中段突然抽帧。口径见 [performance-action.md](references/performance-action.md) 「帧率单一口径」。
- **🟢 低危动作（对峙、慢动作、影子暗示）一个 5 秒镜头 = 一个动作**；5 秒 × 2 的可控度远高于 10 秒 × 1。🟡 / 🔴 动作把单元压回 **2–4 秒**——位移越大，帧间累积误差越快吃掉动作的形状，5 秒里的后半段必崩。
- **打斗首选影子暗示**：拍墙上的影子、面部反应、物品掉落，让观众脑补——影子本身就是模糊变形的，模型的「不完美」反而成了风格。
- **粒子是遮瑕膏，但一镜只能抹一种膏**：火星 / 灰尘 / 水花 / 碎屑**择一**，选定那一类密度可以拉满，能掩盖快速动作的瑕疵；
  **混类会崩**——三类粒子等于三套重力与风阻，飘散方向互相打架，最终糊成分不出材质的噪点。
- **一镜一主叙事特效**（与「一套画面只搭 1 种景别 + 1 种构图」同级）：冲击波、剑气折射、能量爆闪、血雾这类**改变画面物理读法**的特效，
  每镜**最多 1 种**。**第 2 种一定会崩**：模型要同时解算两套形变场，主体人物的采样预算被挤掉，先崩的一定是脸和手。
  按叙事意图选哪一种，见 [performance-action.md](references/performance-action.md) §3.10。
- **一半的动作戏在声音里**：每个动作镜至少 3 层音效（撞击 + 环境 + 呼吸）。
- **每段 2–4 秒只做 1 个动作单元**（这是提示词内部的节拍，不是请求参数；整段作为一次请求提交时仍按 ≥4 秒下单）；禁止单段生成 8–12 秒完整连招，禁止动作进行中的复杂 360° 大旋转镜头。
- 每段挂角色参考图 + 形象锁；**全段统一风格词，不混搭水墨 / 赛璐珞 / 写实**。
- 剪辑卡点：打击瞬间插 0.5 秒慢动作，位移与蓄力段正常速度或快切，靠快慢交替制造张力。
- 剧本阶段就标危险等级：🟢 对峙/慢动作/影子暗示 → 直接生成；🟡 追逐/手持跟随 → 幅度降到 4；🔴 快速打斗/复杂肢体交互 → 拆镜或改设计。

详见 [performance-action.md](references/performance-action.md) §四点五；具体招式的轨迹与受力描述见 [choreography-beats.md](references/choreography-beats.md)。

## 构图铁则

```text
角色 + 场景 + 景别 + 人物站位 + 前中后景层次 + 人物视线 + 镜头情绪氛围
```

**五大误区**：全程居中构图；只标景别不标站位；完全舍弃前景元素；构图与剧情割裂；生成失败只重复刷新。

**好坏判断**：遮住所有台词只看画面，能否立刻分清**画面焦点、人物关系、当下情绪**？能，即合格。

## 分镜七要素自查

每写一镜前过一遍：

| 要素 | 自问 |
|---|---|
| 景别 | 这镜该用远景还是特写？（避免通篇中景） |
| 角度 | 从上拍还是从下拍？（坏人仰视、受害者俯视、普通人平视） |
| 构图 | 主体放左边还是中间？（AI 默认中心构图，必须主动指定） |
| 光影 | 主光源在哪里？（不知道就用 golden hour + backlighting） |
| 色调 | 这段戏是什么情绪底色？（全片必须统一） |
| 动势 | 画面里的什么在运动？（加风、加雨、加烟雾） |
| 转场 | 连到下一镜用什么方式？（转场要写进提示词） |

- [ ] 打戏高度分层达标：一场打戏至少出现两层高度（低位 / 中位 / 高位），且腾空、跌落在同一个 15 秒段落内 ≤ 2 镜？（见 [blocking-lighting.md](references/blocking-lighting.md) §1.2b）
- [ ] 本次分镜与所引模板的差异度 ≥ 30%，没有整表照抄？
- [ ] 这一集拆出了多个镜头，不是一集一镜？
- [ ] 每镜都写了起幅与落幅？
- [ ] 第 2 镜起都写了承接上一镜，六锚点齐全？
