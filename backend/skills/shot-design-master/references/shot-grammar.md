# 镜头语法词典

写每一镜时，从这四张表里各取一项，拼成镜头描述。中英文双写能显著提高模型的执行率。

---

## 一、景别

| 景别 | 英文 | 画面占比 | 叙事用途 | 适用情绪 | 提示词写法 |
|---|---|---|---|---|---|
| 大远景 | Extreme Wide Shot / EWS | 人物占画面 < 1/10 | 交代地理、渺小感 | 孤独、宿命、史诗 | `大远景，人物在画面中占极小比例，环境主导` |
| 远景 | Wide Shot / WS | 全身 + 大量环境 | 建立场景 | 客观、疏离 | `远景全身入画，交代空间关系` |
| 全景 | Full Shot / FS | 全身顶天立地 | 展示体态与调度 | 亮相、对峙 | `全景，人物全身入画，头顶与脚下留少量余量` |
| 中景 | Medium Shot / MS | 腰部以上 | 推进动作与对话 | 常规叙事 | `中景，腰部以上入画` |
| 中近景 | Medium Close-Up / MCU | 胸部以上 | 对话主力景别 | 交流、试探 | `中近景，胸部以上入画` |
| 近景 | Close-Up / CU | 肩部以上 | 捕捉表情 | 情绪转折 | `近景，肩部以上入画，面部占主导` |
| 特写 | Close-up | 整张脸 | 情绪爆点 | 震惊、崩溃、决断 | `特写，面部充满画面` |
| 大特写 | Big Close-up / BCU | 眼睛/嘴/手/道具 | 强调细节 | 悬念、暗示 | `大特写，只保留{眼睛/指节/刀刃}在画面中` |
| 中远景 / 中全景 | Medium Long Shot / MLS | 膝盖以上 | 兼顾肢体语言与中等背景 | 交涉、试探、群像 | `中远景，膝盖以上入画` |
| 极特写 | Extreme Close-up / ECU | 单只眼球/唇/泪珠/指尖 | 放大微观质感 | 崩溃、恐惧、顿悟 | `极特写，只保留{瞳孔/颤抖的嘴唇}` |
| 侧脸特写 | Profile Close-Up | 纯侧面面部 | 克制、深思、隐藏内心 | 隐忍、孤独、心碎 | `侧脸特写，红着眼眶忍住不落泪` |
| 眼部特写 | Eye Close-Up | 瞳孔与眨眼 | 情感博弈的终极武器 | 惊恐、杀意、动心 | `眼部特写，瞳孔放大，视线锁住门口` |
| 嘴部特写 | Mouth Close-Up | 咬唇、嘴角抽动 | 无声抗议 | 隐忍、不甘 | `嘴部特写，下唇轻颤，嘴唇抿紧` |
| 手部特写 | Close-up of Hands | 指关节、递物、颤抖 | 用手讲潜台词 | 紧张、犹豫、诀别 | `手部特写，指节攥紧发白` |
| 局部特写 / 道具特写 | Detail Shot | 线索物件、信件、纹样 | 投放线索与伏笔 | 悬疑、揭示 | `局部特写，茶几上唯一亮着的手机屏幕` |
| 背影 | Back Shot | 只见背部 | 隐去表情、留白 | 孤独离开、决绝 | `背影，人物沿长街走远` |
| 过肩 | Over the Shoulder / OTS | 肩后看对方 | 锁死轴线的对话视角 | 对峙、心虚 | `过肩镜头，前景为{A}肩背虚化` |
| 双人 | Two-Shot | 两人同框 | 关系与地位博弈 | 暧昧、僵持、和解 | `双人中景，两人同框，距离紧绷` |
| 主观 | POV | 第一人称视线 | 绝对代入 | 恐惧、受击、窥探 | `主观视角（POV），画面即{角色}所见` |
| 空镜 | Insert / Cutaway | 无人物的环境或物件 | 转场、留白、节奏调剂 | 余韵、时间流逝 | `空镜，雨水沿屋檐滴落` |

> **英文术语以下方完整版景别主表（附：完整词典 §1.1）为唯一权威，速查版仅作检索用。** 两版冲突时一律按完整版取词，不得另写英文别名——分镜表与九宫格字段取到互斥英文，同一个中文景别会在不同镜生成两种取景。

**用法**：一场戏由 远→近 推进情绪；反过来（近→远）表示情绪释放或抽离。

## 二、机位与角度

| 角度 | 英文 | 心理效果 | 提示词写法 |
|---|---|---|---|
| 平视 | Eye Level | 中立、平等 | `平视机位，与人物视线等高` |
| 仰拍 | Low Angle | 高大、压迫、英雄感 | `低角度仰拍（low angle hero shot）` |
| 极端仰拍 | Worm's Eye | 神性、威胁 | `贴地极低角度仰拍（worm's eye）` |
| 俯拍 | High Angle | 弱小、被审视 | `高角度俯拍（high angle）` |
| 顶拍 | Top Down / Bird's Eye | 上帝视角、宿命 | `正顶俯拍（bird's eye view）` |
| 斜角 | Dutch Angle | 失衡、疯狂、危险 | `荷兰角倾斜构图（dutch angle）` |
| 过肩 | Over the Shoulder / OTS | 对话关系、代入 | `过肩镜头，前景为{A}的肩背虚化` |
| 主观 | POV | 代入、窥视 | `主观视角（POV），画面即{角色}所见` |
| 背身 | Back Shot | 悬念、离别 | `背身跟拍，只见背影` |

## 三、运镜词典

| 运镜 | 英文 | 适用情绪 | 提示词写法 |
|---|---|---|---|
| 固定 | Static / Locked Off | 冷静、审视、压抑 | `固定机位，画面静止` |
| 推 | Dolly In / Push In | 情绪聚焦、逼近真相 | `缓慢推近（slow dolly in）` |
| 快推 | Snap Push | 震惊爆点 | `快速推近（snap push in）` |
| 拉 | Dolly Out / Pull Back | 释然、抽离、孤独 | `缓慢拉远（slow dolly out）` |
| 摇 | Pan | 环视、跟随视线 | `水平摇镜（pan left/right）` |
| 俯仰摇 | Tilt | 展示高度、由局部到全貌 | `向上摇起（tilt up）` / `向下俯摇（tilt down）` |
| 移 / 横移 | Trucking / Lateral Dolly | 并行、旁观 | `摄影机横移（trucking shot, lateral dolly）` |
| 跟 | Follow / Tracking | 代入、紧迫 | `跟拍（tracking shot）` |
| 升降 | Crane / Jib | 气势、揭示 | `摇臂升起（crane up）` |
| 环绕 | Orbit / Arc | 强调、仪式感 | `环绕运镜（orbit shot）` |
| 手持 | Handheld | 真实、紧张、混乱 | `手持跟拍，轻微晃动（handheld）` |
| 变焦 | Zoom | 突兀强调 | `快速变焦（crash zoom）` |
| 希区柯克变焦 | Dolly Zoom / Vertigo | 眩晕、认知崩塌 | `希区柯克变焦（dolly zoom, vertigo effect）` |
| 长焦压缩 | Long Lens Compression | 压迫、距离被压扁 | `长焦压缩（long lens compression, 200mm telephoto）` |
| 甩镜 | Whip Pan | 转场、节奏加速 | `甩镜转场（whip pan）` |

**组合写法**：`低角度仰拍缓慢升起（low angle hero shot, tilt up, worm's eye）`

## 四、焦段与景深

| 焦段 | 特征 | 情绪 | 提示词 |
|---|---|---|---|
| 广角 16–35mm | 透视夸张、空间放大 | 不安、荒诞、压迫 | `广角镜头，透视夸张` |
| 标准 40–55mm | 接近人眼 | 客观、写实 | `标准镜头，自然透视` |
| 中长焦 85mm | 人像、背景虚化 | 亲密、聚焦 | `85mm 人像镜头，背景虚化` |
| 长焦 135–200mm | 空间压缩 | 窥视、宿命、距离感被压扁 | `200mm 长焦，空间压缩` |
| 微距 | 极浅景深 | 细节、暗示 | `微距特写，极浅景深` |

景深写法：`浅景深，背景奶油虚化` / `深景深，前中后景全部清晰`

## 五、构图法则

| 法则 | 用途 | 提示词 |
|---|---|---|
| 三分法 | 通用平衡 | `三分法构图，主体位于右三分线` |
| 中心构图 | 权威、对称、仪式 | `中心构图，主体居正中` |
| 对称构图 | 秩序、庄严、压迫 | `严格对称构图` |
| 框中框 | 困境、窥视 | `框中框构图，透过{门框/窗棂}拍摄` |
| 前景遮挡 | 层次、偷窥感 | `前景以{虚化元素}遮挡画面边缘` |
| 引导线 | 视线牵引 | `{长街/廊柱}形成引导线指向主体` |
| 留白 | 孤独、余韵 | `大面积留白，主体偏置一角` |
| 视线方向 | 关系与预期 | `主体视线朝向画面{左/右}侧，前方留出视线空间` |
| 纵深层次 | 空间真实感 | `前景{元素}、中景{主体}、后景{元素}三层纵深` |

## 五点四、动势：让静止画面有运动感

单帧是静止的，但可以有「刚发生」或「即将发生」的感觉。加风、加雨、加烟雾，动感立刻拉满。

| 手法 | 提示词 |
|---|---|
| 定格动作瞬间 | `action shot, mid-jump, hair and clothes frozen mid-motion` |
| 飘动的衣物与头发 | `hair blowing in wind, clothes fluttering, dynamic movement` |
| 粒子 / 烟雾 / 雨雪 | `particles floating in air, dust motes lit by sunlight` |
| 前景运动模糊 | `motion blur on passing car in foreground, character stationary` |
| 人物动势线 | `dynamic pose, body twisted, sense of imminent action` |
| 镜头推进感 | `dolly zoom effect, dramatic compression` |
| 手持晃动感 | `handheld camera style, slight motion blur, realistic` |
| 轨道平移感 | `tracking shot feeling, horizontal motion lines` |

## 五点五、转场：镜与镜之间的标点

模型不会自动生成转场动画，但**分镜提示词必须在转场处写清楚**，拼接成片时才对得上。

| 转场 | 用途 | 提示词 |
|---|---|---|
| 叠化 Dissolve | 时间流逝、回忆 | `dissolve transition, fading from scene to scene, dreamy atmosphere` |
| 匹配剪接 Match Cut | 形状/颜色/动作匹配（月亮→盘子→硬币） | `match cut transition, circular shapes connecting scenes` |
| 甩镜头 Whip Pan | 快节奏切换 | `whip pan transition, motion blur between scenes, fast pace` |
| 淡入 Fade In | 开场 | `fade in from black, opening scene emerges slowly` |
| 淡出 Fade Out | 收尾 | `fade to black, ending` |
| 遮挡转场 Wipe | 手掌/门板/衣服挡住镜头再移开 | `wipe transition, object passes in front of camera, scene change` |

## 五点六、60 套标准化构图（按叙事目的选，不要随机生成）

**万能构图公式（5 个维度缺一不可）**

```text
角色 + 场景 + 景别 + 人物站位 + 前中后景层次 + 人物视线 + 镜头情绪氛围
```

> 示例：`白发少女 伫立 秋日古巷左三分线，前景飘落枯黄树叶虚化遮挡，中景少女半身侧身回望，巷尾古建筑形成纵深透视，少女目光望向画面右侧空旷巷口，整体构图孤寂伤感，柔和秋日柔光电影质感`

**另一套写作顺序（出图更稳）**

```text
人物 + 动作 + 景别机位 + 构图 + 场景 + 光线氛围 + 画面风格
```

**万能替换模板**

```text
【时间与地点】，一名/两名【人物身份与外形】正在【具体动作】，人物位于画面【位置】，
使用【景别】、【机位】、【构图方式】，前景出现【前景元素】，背景为【环境细节】，
采用【光线方式】和【主色调】，营造【具体情绪】，画面呈现【风格】，
人物数量保持一致，服装和发型保持统一，动作自然，面部清晰。
```

### 构图五大误区

1. **全程统一居中构图** —— 居中只适合审判、反派登场；全部居中像证件照，失去叙事层次。
2. **只标注景别、忽略人物站位** —— 景别只控制距离；人物放在边缘/高处/低位才是情绪核心。
3. **完全舍弃前景元素** —— 门框、雨幕、树枝、栏杆是电影质感核心，无前景则扁平廉价。
4. **构图与剧情割裂** —— 对峙镜不做左右分隔、离别镜不留大面积留白，画面与情绪脱节。
5. **生成失败只重复刷新** —— 先排查人物位置、景深层次、视线留白，而不是单纯重绘。

### 构图好坏的快速判断

> 遮住所有文字台词，只看画面，能否立刻分清**画面焦点、人物关系、当下情绪**？能，即为合格镜头。

### 构图创作固定流程

1. 确定本镜头核心叙事目的（对峙 / 离别 / 悬疑 / 高光）
2. 匹配对应景别（远景 / 特写 / 中景）
3. 规划人物画面站位
4. 增加前中后景分层元素
5. 标注人物视线与留白方向
6. 补充光影、氛围关键词

### 三条细节铁则

- 一个画面只保留**一个核心事件**。
- 动作要写出**方向**。
- 约束词不要写得太笼统。

## 五点七、30 组可直接复制的景别与构图模板

**万能组合公式**

```text
镜头景别 + 构图方式 + 人物描述 + 环境光线 + 画质参数
```

> 例：`大远景 + 引导线构图，冰蓝色古风长裙女主，银白古风发饰，云海城堡仙境，清晨柔光，电影感呼吸运镜，35mm胶片颗粒，皮肤毛孔与细小绒毛可见，发丝边缘清晰不粘连，浅景深，氛围感史诗画质`

**使用规则（很重要）**

1. 一套画面**优先只搭 1 种景别 + 1 种构图**；叠加过多镜头词汇会导致画面错乱、人物畸形。
2. 情绪镜头优先特写/大特写；宏大剧情用远景/大远景；对手戏固定用过肩镜头。
3. 清冷仙侠风搭留白、负空间构图；霸气角色用低角度、三角稳定构图。
4. 提示词末尾**不在本文件另定义画质词串**——统一挂 [SKILL.md](../SKILL.md)〈收尾串〉章的**画质锚点串**。`8K` / `4K` / `超清` / `masterpiece` / `极致画质` 这类泛化词一律禁用：它们不携带可执行的光线、材质与运动信息，却占着提示词尾部的注意力，把权重从景别与构图词上抽走（禁用词全表见 [models-failures.md](models-failures.md) §2.7）。

**收尾串归口：全片只有三串，禁止另造第四串**

| 串名 | 权威定义处 | 适用面 | 挂载位置 |
|---|---|---|---|
| 画质锚点串 | [SKILL.md](../SKILL.md)〈收尾串〉章 | **全片每一镜** | 提示词最末 |
| 一致性串（承接句 + 跨镜断裂负面词） | [continuity-consistency.md](continuity-consistency.md) §一 | **第 2 镜起每一镜** | 承接句在最前，负面词接在画质锚点串之后 |
| 打戏防崩坏后缀 | [performance-action.md](performance-action.md) §3.13 | **仅打戏镜** | 叠在前两串之后 |

三串语义不重叠，同一镜可以同时叠挂；**新增约束时只能并入语义最近的那一串，不得新起第四串**。

**为什么第四串会崩：** 尾部串一多，「不变形」「光影统一」「动作连贯」这类同类约束会在末尾重复三四遍。模型把重复当强调，权重整体后移，前半段的景别、机位、运镜、动作指令被压低——表现就是 6.7 里那条最常见的翻车：**构图指令听而不闻，画面退回正面中景**。本文件的模板串只负责景别、构图、人物、光线四段，收尾一律交给上表三串。

>
> 1. **词序即权重**——景别与运镜词必须放在提示词最前面。AI 对构图指令“听而不闻”、总生成普通正面中景，根本原因是主体描述过长抢走了构图词的权重。把 `A handsome man, close-up...` 改写为 `Close-up shot of a handsome man...`。
> 2. **单帧单景别**——同一条提示词里不要既写 `extreme wide shot` 又写 `close-up on eyes`，AI 会产生构图混乱。一个镜头只有一个景别、一个主角度。
> 3. **英文运镜词的审核风险**——裸写的英文运镜术语（如 `Dolly`、`Aerial`、`Crane`）可能被审核系统误判为人名/品牌名而触发违规拦截。**中文提示词使用中文运镜词，英文提示词使用完整短语**（见运镜表「Seedance 安全写法」列）。

| 特写 | `Close-up` | 聚焦面部 | 放大表情与眼神，产生强烈情绪穿透力 | 崩溃、告白、震惊错愕 | `Close-up on face, shallow depth of field, camera holds perfectly still` |
| 大特写 | `Big Close-up` / `BCU` | 额头到下巴的局部面部 | 更强的视觉逼近感 | 压迫、屏息、临界爆发 | `Big close-up, forehead to chin, 135mm telephoto lens` |
| 极特写 | `Extreme Close-up` / `ECU` | 单只眼球 / 发抖的嘴唇 / 泪珠 / 瞳孔 / 指尖 / 水滴 | 放大情绪、展现微观质感，制造深层悬念或心理震颤 | 崩溃痛哭、恐惧、顿悟 | `Extreme close-up on trembling lips, sweat rolling down temple` |
| 侧脸特写 | `Profile Close-up` | 纯侧面面部 | 表现克制、深思、忧郁或隐藏内心 | 隐忍、孤独、心碎、嫉妒酸涩 | `Profile close-up, side profile, red eyes, restrained tears` |
| 眼部特写 | `Eye Close-up` / `ECU of Eyes` | 瞳孔、眨眼、眼神聚焦变化 | 传达惊恐、震撼或情感博弈的终极武器 | 惊恐、杀意、动心 | `Eye close-up, pupils dilated, gaze locking onto the door` |
| 嘴部特写 | `Mouth Close-up` | 咬唇、嘴角抽动、微微张开 | 表达隐忍、无奈、不甘或无声抗议 | 隐忍、不甘、欲言又止 | `Mouth close-up, lower lip trembling, lips pressed tightly` |
| 手部特写 | `Close-up of Hands` | 紧握的指关节、递送物件、颤抖的手指 | 用手的“表情”讲述潜台词 | 极度紧张、犹豫、嫉妒、诀别 | `Close-up of hands, clenched fingers, white knuckles` |
| 局部 / 道具特写 | `Detail Shot` | 关键线索物品、信件、服装花纹 | 提醒观众注意细节，投放线索 | 悬疑、揭示、伏笔 | `Detail shot, lit phone screen on the coffee table, the only bright object in the scene` |
| 背影 | `Back View` / `Back Shot` / `Behind Shot` | 只展示背部 | 隐去表情，用背部线条与方向制造距离感与留白 | 孤独离开、静默等待、决绝 | `Back shot, character walking away down the long street` |
| 过肩镜头 | `Over-the-Shoulder` / `OTS` | 一人肩后看另一人，前景为虚化肩膀/后脑 | 对话场景视角切换，提供空间方位感、锁死轴线 | 对峙、心虚、关系拉扯 | `Over-the-shoulder shot (OTS), looking from behind foreground character's shoulder at the target` |
| 双人镜头 | `Two-Shot` | 两人同框 | 展现人物关系与地位博弈 | 暧昧、僵持、和解 | `Two-shot, both characters framed together, tense distance` |
| 主观视角 | `Point of View` / `POV Shot` | 角色第一人称视线 | 最高级沉浸体验，绝对代入与紧迫感 | 恐惧、受击、窥探 | `POV shot, first-person point of view, looking through the eyes of the character` |
| 客观视角 | `Objective Shot` / `Third-person View` | 旁观者中立机位 | 保持理性叙事距离，不带主观情绪 | 冷静、审视、纪实 | `Objective shot, third-person view, static camera` |
| 低角度全景 | `Low-angle Full Shot` | 贴近地面拍全身 | 拉长身材，塑造英雄气概、威严 | 强势登场、绝境反击 | `Low-angle Full Shot, camera near ground level looking up` |
| 高角度全景 | `High-angle Full Shot` | 高机位向下拍全身 | 展现宏大空间中的孤立无援与弱小 | 挫败、绝望、被压制 | `High-angle Full Shot looking down at the small figure` |
| 俯视全景 | `Overhead Wide Shot` / `High-angle Wide Shot` | 高空向下俯瞰的广阔画面 | 客观审视、地图感、全局把握 | 命运感、冷酷 | `Overhead wide shot, top-down geometry of the courtyard` |
| 仰视全景 | `Worm's-eye Wide Shot` | 极低角度向天空拍全景 | 夸张几何透视，表现巨大空间挤压 | 压迫、巨物恐惧 | `Worm's-eye wide shot, towering architecture looming above` |

### 1.3 景别 × AI 崩坏风险（决定该不该用这个景别）

```
表情自然度 vs 景别关系：

远景(ELS)  ██████████ 100% 安全（看不到表情）
全景(LS)   ████████░░  80% 安全
中景(MS)   ██████░░░░  60% 安全 ← 推荐主力景别
近景(CU)   ████░░░░░░  40% 需要精修
特写(ECU)  ██░░░░░░░░  20% 必须精修或真人驱动
```

- 镜头越近、时长越长，人脸漂移越明显；避免人脸特写连续堆叠。
- 表情实在解决不了时的替代方案：角色低头/侧脸（手捂脸、转身）、光影遮挡（逆光剪影、百叶窗、烟雾）、道具遮挡（杯子、手机、书本、帽檐）、切 insert 镜头（手部动作、环境细节）、运动模糊（快速转头时自然模糊 1–2 帧）。
- **特写按「拍什么」分流，不按景别一刀切**：上面 20% 那一档说的是**人脸特写（Face ECU）**——完整五官占画面主体，必须精修或真人驱动、不得连续堆叠；**局部特写（Detail ECU）**——手部、兵器刃口、受击点、衣料撕裂处、脚下地面——画面里没有完整人体，模型没有「人」可猜错五官与关节，是打戏安全牌，可连用、可承接打击瞬间。分流全表与判定口径以 [SKILL.md](../SKILL.md)〈景别 × 崩坏风险曲线〉为准，本表不复述。
- 高强度对抗镜（连续拳脚交接、奔跑、多人肢体缠斗）必须用**局部特写暗示、侧面过肩镜头、或快速运动转场（Whip Pan）**平滑规避：打击瞬间交给手部/兵器/受击点的局部特写承接，人脸只留给打完之后身体已静止的反应镜——在肢体仍在交接时切人脸特写，模型要同时猜五官与高速关节，出来就是五官漂移加肢体粘连。

### 1.4 竖屏 9:16 景别修正

| 横屏惯性 | 竖屏修正 |
|---|---|
| 中景够用 | **景别上移**：横屏的“中景”在竖屏要更近（怼脸感），人物面部占画面宽度 50–70% |
| 左右大全景 | 被裁切，改**纵向构图**；人物前后景深走位替代左右走位 |
| 双人同框 | 竖屏窄易拥挤，**单人优先**，多用单人正反打 |
| 手部/道具横放 | 改**竖排**，纵向画面适合手部由下往上的动作 |
| 面部居中 | 面部落在**上 1/3 黄金区**；顶部安全区约 200px、底部安全区约 250px 内不放关键信息 |

### 1.5 景别组合套路（单镜决定表达，组合决定节奏）

**八大经典镜头组合模板**

| 组合名 | 景别链路 | 作用 | 适用 |
|---|---|---|---|
| 开场建立组 | 全景 → 中景 → 特写 | 由大入小，先交代空间再锁定人物 | 角色出场、新剧本开篇 |
| 情绪升级组 | 平视/中景 → 近景 → 极近特写 | 视距层层压迫，把崩溃推到观众眼前 | 内心独白、崩溃、深情告白 |
| 关系拉扯组 | 对切镜头 → 手部特写 → 对方反应镜 | 用潜台词揭示语言之下的博弈 | 商务谈判、争执、暧昧试探 |
| 悬疑窥视组 | 环境空镜 → 遮挡窥视 → 背影离场 | 构建悬念，加深未知压迫 | 暗中调查、跟踪尾随 |
| 孤独氛围组 | 大远景环境 → 孤立背影 → 窗边侧脸 | 空旷 + 背部无防备 + 凝望侧影 | 离别、深夜失落、低潮期 |
| 动作节奏组 | 动感跟拍 → 低机位仰拍 → 动态模糊 | 力量与速度瞬间拉满 | 生死追逐、仓库逃亡 |
| 回忆插叙组 | 静物/线索特写 → 主角失神凝视 → 逆光剪影闪回 | 由道具切入眼神，转入回忆 | 叙述旧事、深情回望 |
| 结尾收束组 | 人物回眸 → 大面积留白空镜 → 情绪收束点 | 悠长余味，留白给观众 | 收官、伏笔、开放式结尾 |

**三条黄金组合原则**

1. 先定情绪，再选镜头。
2. 先有主次，再排节奏——确定哪一个是高潮爆发点（通常是特写或 Dutch 视角），围绕它安排前后景别起伏。
3. 同类镜头别连续堆叠——避免连续三个尺寸完全一致的单人中景，必须远近交替、正侧结合。

**黄金 15 秒时间轴切片模型（对应 minimax H3 / seedance 2.0 单条上限）**

```
⏰ 0s ──────────────── 3s ─────────────── 7s ────────────── 11s ────────────── 15s
   │  [第一切片：全景段]  │  [第二切片：中景段]  │ [第三切片：特写段]  │ [第四切片：收尾段]  │
   ▼                     ▼                     ▼                    ▼                    ▼
 交代场景与整体氛围    主角登场，启动动作    动作细节，情绪传递   动作收尾，悬念拉远/转场
```

| 时间 | 功能 | 连续性重点 | 镜头建议 |
|---|---|---|---|
| 0-3s | 建立场景和人物关系 | 锁定空间、人物左右、道具位置 | 全景或中景静止 |
| 3-6s | 触发事件 | 只让一个道具或一个动作启动 | 中景慢推 |
| 6-9s | 角色反应 | 承接上一动作，表情轻微变化 | 近景或手部特写 |
| 9-12s | 情绪升级 | 情绪只上升一级，不直接爆发 | 大特写慢推 |
| 12-15s | 行动或悬念 | 动作从上一镜自然收束 | 慢拉远或背影镜头 |

**五镜动作链（10 秒内拉满武打节奏）**

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  第一镜 (全景) │ ──▶ │  第二镜 (中景) │ ──▶ │  第三镜 (近景) │ ──▶ │  第四镜 (特写) │ ──▶ │  第五镜 (POV)  │
│  Establishing│     │    Charge    │     │    Attack    │     │    Impact    │     │   Reaction   │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

| 镜号 | 景别与时长 | 目的 | 画面 |
|---|---|---|---|
| 1 | 全景对峙 2–3s | 展示相对站位、体型差距、场景氛围 | 大雨竹林中两名剑客斗笠低垂，按剑对视 |
| 2 | 中景前冲 1.5s | 展示爆发速度与前冲身法 | 低角度摄像机前冲，踏地起尘，泥水飞溅 |
| 3 | 近景交锋 1.5–2s | 展示招式帅气度与动作线条 | 单人挥刀切入画面，刀锋拉出半月形白色刀光气浪 |
| 4 | 特写重击 1s（取**局部特写**：拳锋/刀刃/受击点，不切完整人脸，见 §1.3 特写分流） | 传递极致力量与物理重量 | 拳/刀砸在脸上，下巴挤压形变，汗水雨水飞散 |
| 5 | POV 受击 2s | 增强代入感与情绪张力 | 第一人称视线模糊、镜头强震，看向上方收拳的胜者 |

**“出招-受击”三镜拆分法**（AI 多人肢体高频互动穿模率高达 90%，必须在剪辑层拆分）

- 镜号 1（出招镜，中景/特写，2s）：A 重心下沉，重拳朝摄影机方向轰出，出拳瞬间极速 Whip Zoom。生成难度低（单人动作，不会穿模）。
- 镜号 2（受击镜，近景/特写，1.5s）：B 侧脸受重击，脸部物理压缩形变，头猛偏，水珠飞溅。
- 镜号 3（环境负反馈镜，远景/全景，2s）：B 身体弧线后倒飞、砸地滑行、尘土扬起、货架崩落。
- 拼接节奏 2s → 1s → 2s，配合击中瞬间**一帧白屏闪烁（冲击帧）**与爆裂撞击音效。

## 二、机位与角度词典（Camera Angles）

### 2.1 角度主表

| 斜仰视 | `Oblique Low Angle Shot` | 孤胆对峙、局势危急、决心坚定 | 决战前、单挑 | `Oblique low angle shot, determined stance` |

| 前侧 45° | `Front Three-quarter View` | 最适合展现五官立体线条与轮廓美 | 人物美拍、登场 | `Front three-quarter view, 85mm portrait lens` |
| 后侧 45° | `Rear Three-quarter View` | 探视角色的神秘感 | 即将转头的前置镜头 | `Rear three-quarter view before the turn` |
| 45 度角 | `45-degree Angle Shot` | 富纵深透视，背景引导线自然收缩于焦点 | 走廊、街道纵深 | `45-degree angle shot, converging leading lines` |

### 2.2 角度 = 权力关系（空间象征站位法）

| 关系 | 机位处理 | 写法 |
|---|---|---|
| 强权者 | 站立于高台，**仰拍** | `low angle, hard shadows, black gold tone` |
| 被动者 | 位于低处，**俯拍** | `high angle looking down, oppressive framing` |
| 平等 | 平视、等高眼线 | `eye-level, matched eyeline height` |
| 仪式/庄重 | 正面居中构图 + 缓慢直线推镜 | `symmetrical composition, slow dolly in` |
| 压迫/被困 | 狭窄空间 + 顶光 | `narrow hallway, strong vertical lines, low ceiling, character framed tightly between walls, oppressive composition, cold overhead light` |

```
                │                         │
  摄影机机位 1  🎥                        🎥  摄影机机位 2
  (A 在左, B 在右)                         (过肩视角 A -> B)
─────────────────────────────────────────────────────────────────
  [禁止越轴区]  ─────────────────────────────────────────────────
  摄影机机位 3  ❌ 🎥 (越轴机位：左右位置瞬间对调，造成穿帮)
```

三条硬约束（每个镜头提示词都要带）：

```text
A is positioned on the left side of the frame, facing and striking towards the right; B is on the right side of the frame, facing left in a defensive posture.
```

```text
Character A remains on screen left, Character B remains on screen right, the table stays between them, preserving left-right relationship and 180-degree rule
```

```text
角色A始终在画面左侧，角色B始终在画面右侧，桌子位于两人中间，保持左右关系和180度轴线
```

- **过肩镜头（OTS）定向**：把 OTS 当作安全过渡镜，锁死轴线。
- **后期镜像翻转兜底**：动作方向完美但位置越轴时，直接在剪辑软件中水平镜像翻转。
- 机位自检：对话是否遵守轴线规则；正反打视线方向是否对应；角色左右关系是否被随意反转；高低机位是否服务于权力关系；**机位变化是否有动机，不像随机生成**。

## 三、运镜词典（Camera Movement）

### 3.1 Level 1 基础运镜（覆盖 80% 需求）

| 中文运镜 | 英文提示词 | 运动轨迹 | 心理效果 / 适用情绪 | Seedance 安全写法 |
|---|---|---|---|---|
| 推镜头 | `Dolly In` / `Push In` / `Camera Moving Closer` | 机位前后物理移动，稳步靠近 | 建立亲密感、累积紧张、把情绪推向高潮 | ⚠️ CN: `推轨推进` / EN: `dolly tracking shot` |
| 慢推 | `Slow Push In` / `Slow Dolly In` | 极缓靠近 | 润物无声锁定面部，细微心理转折、情绪压抑 | ✅ 安全 |
| 拉镜头 | `Dolly Out` / `Pull Out` / `Camera Moving Away` | 机位后退 | 揭示孤立、释怀、离场、真相显露 | ✅ `Pull Out` 安全 |
| 慢拉远 | `Slow Pull Out` / `Slow Dolly Out` | 极缓后移 | 身影渐渐孤立，悲伤、回忆、空虚 | ✅ 安全 |
| 摇镜头（水平） | `Panning Shot` / `Pan Left/Right` | 机位不动，水平转动 | 追踪横向移动、展现广阔环境、慢摇揭示 | ⚠️ CN: `水平摇摄` / EN: `pan shot` |
| 摇镜头（垂直） | `Tilting Shot` / `Tilt Up/Down` | 机位不动，垂直转动 | 仰拍强化力量感，俯拍表现脆弱 | ✅ 安全 |
| 移镜头 / 横移 | `Tracking Shot` / `Trucking Shot` / `Truck Left/Right` / `Lateral Tracking Shot` | 机位左右横向平行移动 | 展示并列元素、扫视街道、并排前行 | ✅ 安全 |
| 纵移 | `Forward-backward Tracking` | 沿纵深线前后平移 | 走廊、通道、前后错落人物 | ✅ 安全 |
| 跟镜头 | `Follow Shot` / `Tracking Follow` / `Camera Following Character` | 同步跟随角色轨迹（前跟/后跟/侧跟） | 保持主体焦点 + 传递速度感 | ✅ 安全 |
| 升镜头 | `Crane Up` / `Boom Up` / `Camera Rising` / `Pedestal Up` | 机位垂直上升 | 宏大揭示，从特写过渡到远景 | ⚠️ CN: `摇臂升降` / EN: `crane shot` / `jib shot` |
| 降镜头 | `Crane Down` / `Boom Down` / `Camera Lowering` / `Pedestal Down` | 机位垂直下降 | 逐渐逼近，视线从高空滑落回地面细节 | ⚠️ 同上；`Pedestal Up/Down` ✅ 安全 |
| 环绕镜头 | `Orbit Shot` / `360-degree Orbit` / `Arc Shot` | 以主体为圆心弧形移动 | 展示主体全貌、仪式感、三维空间层次 | ⚠️ CN: `环绕`/`弧形环绕` / EN: `orbital camera movement` / `arc shot`；**动作进行中一律禁用**，只许用在动作已被冻结的瞬间，或主体两步内无第二人、无遮挡的非接触单人镜——见 [performance-action.md](performance-action.md) 附 §3.1 动作戏总原则 |
| 旋转镜头 | `Rotating Camera` / `Roll Shot` | 沿光轴旋转 | 精神恍惚、时空扭曲、奇幻魔法 | ✅ 安全 |
| 变焦推进 | `Zoom In` | 焦距变化，机位不动，背景透视不变 | 快速聚焦、突发凝视 | ✅ 安全 |
| 变焦拉远 | `Zoom Out` | 视野拉宽 | 拉开心理距离，宏大悲伤 | ✅ 安全 |
| 快速推进 | `Fast Zoom In` / `Snap Push` / `Crash Zoom` | 一秒内视距猛烈拉近 | 震惊、觉察、意外、危险警告 | ✅ 安全 |
| 快速拉远 | `Fast Zoom Out` / `Snap Pull Back` | 视距急速后撤 | 被突如其来的危机或包围圈震撼 | ✅ 安全 |
| 甩镜头 | `Whip Pan` / `Swish Pan` | 极高速掠过形成横向模糊 | 空间转场、紧张节奏 | ✅ 安全 |
| 固定镜头 | `Static Shot` / `locked-off tripod shot` | 机位不动 | 客观记录、冷静叙事、静止凝视 | ✅ 安全 |
| 手持 | `Handheld` / `Handheld Shake` | 细微不规则颠簸 | 纪实粗粝感、混乱、崩溃 | ✅ 安全 |
| 希区柯克变焦 | `Hitchcock zoom` / `Dolly Zoom` / `Zolly` | 机身后移同时光学前变焦，主体大小不变、背景扭曲 | 眩晕、空间扭曲、极度惶恐、顿悟 | ✅ CN: `希区柯克变焦` / `滑动变焦` |
| 无人机俯冲 | `Drone Dive` | 高空极速垂直俯冲 | 宏大战斗、开场 | ⚠️ 中文写「无人机俯冲」 |
| 长镜头 | `Long Take` / `Sequence Shot` / `Continuous Single Shot` | 时空不间断 | 客观真实感、沉浸感 | ✅ 安全 |

### 3.8 运动强度修饰词（防「糊动 motion mush」）

| 等级 | 中文修饰词 | English Modifiers | 适用场景 |
|------|-----------|------------------|---------|
| ⚡ 极强 | 猛烈、暴烈、爆裂、猛冲 | violent, explosive, slamming, bursting | 爆炸/撞击/格斗 |
| 🔥 强烈 | 剧烈、迅猛、急速、用力 | dramatic, vigorous, rapid, forceful | 追逐/运动/情绪高潮 |
| ⚡ 突然 | 突然、骤然、猛然、戛然 | sudden, abrupt, snapping, jolting | 惊吓/转变/闪回 |
| 🌊 中等 | 稳步、从容、自然、轻快 | steady, confident, natural, brisk | 叙事推进/日常动作 |
| 🍃 轻柔 | 缓缓、温柔、轻柔、丝滑 | gentle, soft, smooth, delicate | 浪漫/舒缓/ASMR |
| 🪨 渐进 | 渐渐、逐步、缓慢、不知不觉 | gradual, slowly, imperceptibly, easing | 日出/情绪渐变/暗场 |

用法要点：

- 每个动作都应携带强度修饰词——`人物猛然转身` 而非 `人物转身`。
- 强度修饰词应与运镜节奏一致——剧烈动作配快速运镜，轻柔动作配缓慢运镜。
- 避免矛盾组合——`缓慢爆裂` / `gentle slamming` 会让模型困惑。

```
# ❌ 模糊（容易糊动）
人物走过去。镜头跟随。

# ✅ 明确（运动清晰）
人物猛然起身大步流星冲向出口。手持跟拍急速追踪。
```

### 3.9 运镜失效急救（镜头指令不生效时）

| 症状 | 根因 | 修法 |
|---|---|---|
| dolly zoom 生成了静止画面、orbit 变成简单摇镜 | 裸英文运镜词触发内容安全误判 | 换 Seedance 安全写法：`推轨推进` / `dolly tracking shot` |
| 运镜完全被忽略 | 运镜指令埋在长提示词深处失去注意力权重 | 把运镜移到一句话概述之后，或每个时间戳片段的**首元素** |
| 镜头朝非预期方向漂移 | 运镜与场景几何冲突（360° 环绕需要主体周围有空间） | 确认镜头路径在描述空间中物理可行；压缩冗余描述 |
| 运镜把光源/色调也改了 | 光影参数混在运动层 | 加约束：`运镜不改变光源方向或色调基准` |
| 动作糊、方向不明 | 运镜写成泛词 `镜头跟随` | 用 Level 1 + Level 2：`快速手持跟拍`；每个明确动作留足 2–3 秒 |
| 仍不生效 | — | 用视频参考绑定：`@视频N仅参考运镜轨迹` |

运镜连续性自检：推、拉、摇、移、跟、升降、旋转是否与情绪一致；追逐/奔跑/紧张戏是否用合适运动增强节奏；**静态戏是否避免无意义晃动**；镜头运动方向是否与角色运动方向协调；是否存在镜头无故漂移、变焦抽搐、背景拉扯。

## 四、焦段与景深（Lens & Depth of Field）

> 视频大模型底层是三维物理模拟器，对具体的毫米数（mm）极度敏感。写 `14mm ultra-wide lens` 远比写"广角镜头"更能激发正确的空间透视。
>
> **核心规律：焦距越短 → 空间越夸张 → 主体越膨胀；焦距越长 → 空间越压缩 → 背景越贴近。**

### 4.1 焦段主表

| 焦段 | 视觉特征 / 物理效果 | 心理暗示 | 典型创作场景 |
|------|----------|----------|-------------|
| **14mm Ultra-wide** | 强烈桶形畸变，边缘物体被拉伸 | 压迫、窒息、巨物恐惧 | 末日废土仰拍巨型机甲；幽闭室内被困角色；建筑内部仰拍穹顶 |
| **24mm Wide** | 适度广角、自然空间感 | 开放、客观 | 环境建置、街景、SnorriCam |
| **24-35mm / 35mm Standard Wide** | 接近人眼略广，自然空间延伸 | 叙事、纪实 | 建置镜头、街头纪实、多人对话全景、Steadicam 跟拍 |
| **50mm Standard** | 零畸变，最接近人眼 | 平实、真实、亲切 | 日常对话；平实叙事；纪录片采访 |
| **85mm Portrait** | 轻度压缩，柔美散景 | 温柔、亲密、浪漫 | 人像特写；情感戏；`cinematic depth of field, blurred bokeh background, 85mm f/1.8 lens effect` |
| **135mm Telephoto** | 极致空间压缩，奶油般背景虚化 (Creamy Bokeh) | 孤立、聚焦微观 | 面部汗滴微表情、颤抖嘴唇 |
| **200mm+ Super Telephoto** | 极致背景压缩，背景快速填满画面 | 窥视感、监视感、幽闭追击 | 远距离偷拍感、长焦压迫跟随 |
| **Fisheye 鱼眼** | 极度球面畸变 | 偷窥感、心理扭曲 | `鱼眼镜头透过[形状]窥视` / `Fisheye lens peering through [shape]`；滑板视角、喜剧 |
| **Macro 微距** | 极近距离划过物体表面 | material 质感放大 | 微距扫过 `Macro Sweeping`：突出材质细节或微小刻字 |

**焦段提示词范例（可直接粘贴）**

```
# 14mm 巨物压迫
14mm ultra-wide lens, extreme low angle, towering mecha looming above, barrel distortion stretching the edges

# 135mm 微表情特写
135mm telephoto lens, shallow depth of field with creamy bokeh, extreme close-up on trembling lips, sweat rolling down temple

# 50mm 平实叙事
50mm standard lens, eye-level medium shot, natural perspective, couple walking through autumn park
```

### 4.2 焦点控制与景深

| 中文 | 英文 | 效果 |
|------|------|------|
| 浅景深 | `Shallow Depth of Field` | 背景模糊，主体突出（背景越复杂人物边缘越易崩，非重点背景一律虚化） |
| 深焦 | `Deep Focus` | 前中后景全部锐利 |
| 焦点转换 | `Rack Focus` / `Focus Transition` | 焦点在前后景间平滑转移，转换观众第一视线重心 |
| 反向焦点折返 | `Reverse Rack Focus` | 焦点从背景人物拉回近处前景人脸的细微表情 |
| 景深漂移 | `Depth of Field Drift` | 焦点在不同深度的线索道具间闪烁转移 |
| 景深切换 | `Depth of Field Shift` | 从大景深全局转为极浅景深，锁定局部重点 |
| 散景 | `Bokeh` | 柔和圆形背景虚化光斑 |
| 分屈光镜 | `Split Diopter` | 两个平面同时对焦 |

**Rack Focus 速度修饰**

| 修饰 | 英文 | 效果 | 场景 |
|------|------|------|------|
| 缓焦转移 | `Slow rack focus` | 从容的视觉引导 | 回忆、发现、渐悟 |
| 急焦切换 | `Snap focus` / `Whip focus` | 瞬间跳焦，视觉冲击 | 惊吓、突然发现威胁 |
| 呼吸焦点 | `Breathing focus` | 焦点微微前后游移 | 紧张等待、不安情绪 |

```
# 经典前→后焦转
Rack focus from the dripping gun barrel in foreground to the villain's face emerging from shadows in background

# 后→前焦转（揭示型）
Focus shifts from blurred foreground, slowly resolving to reveal a bloody handprint on the glass

# 急焦切换（惊吓型）
Snap focus from peaceful landscape to a figure standing inches from camera

# 长焦 + 缓焦（戏剧化最强）
135mm telephoto, shallow DOF, slow rack focus from wilting flower in foreground to woman's tear-streaked face in background, creamy bokeh transition
```

### 4.3 微表情联动表（表情场景 → 焦段 × 景别 × 运镜）

| 表情场景 | 推荐焦段 | 推荐景别 | 运镜 | 辅助手法 |
|----------|----------|----------|------|----------|
| 内心挣扎（渐进弧线） | 135mm | ECU 极致特写 | 极缓推进 | 呼吸焦点 + 手持微晃 |
| 情绪压制（角色在忍） | 85mm | CU 特写 | 固定机位 | 浅景深 + 前景虚化 |
| 情绪渐变（从 A 到 B） | 85-135mm | CU→ECU | 缓慢推进 | Rack Focus 焦点转移 |
| 情绪爆发前夕 | 135mm | ECU 极致特写 | 静止 | 呼吸焦点 + 拉长时间 |
| 无声对峙 | 85mm | CU 特写（双人交替） | 固定 或 极慢环绕 | 浅景深正反打 |
| 告别/释然 | 85mm | CU→MS（缓慢拉远） | 缓慢后拉 | 景深渐深，空间感展开 |

```
# 内心挣扎 × 极缓推进
135mm telephoto lens, handheld with natural breathing sway, extreme close-up slowly pushing toward the face, breathing focus gently drifting, shallow depth of field isolating the subject

# 情绪压制 × 固定机位
85mm portrait lens, locked-off tripod shot, close-up on face, shallow depth of field with blurred foreground element, camera holds perfectly still letting micro-expressions carry the narrative

# 告别 × 缓慢后拉
85mm portrait lens, slow dolly pull-back from close-up to medium shot, depth of field gradually deepening to reveal the surrounding space
```

焦点连续性自检：焦点是否落在当前叙事主体上；焦点转移是否有明确叙事目的；背景虚化是否遮蔽了关键信息；同一场景景深风格是否稳定；是否出现人物脸部失焦、关键道具失焦。

## 五、构图法则（Composition）

> 拒绝 AI 默认的「平视 + 中景 + 居中」，通过景别与构图（三分法、引导线、对角线）控制信息量、引导观众视线。

### 5.1 构图主表

| 构图法 | 英文提示词 | 视觉心理 | 适用情节 / 情绪 | 可直接粘贴的写法 |
|---|---|---|---|---|
| 三分法（偏心） | `rule of thirds off-center composition, dynamic side perspective` | 经典稳定，避免大面积居中的呆板 | 通用主力构图、动作侧向透视 | `rule of thirds off-center composition, dynamic side perspective` |
| 中心 / 黄金分割构图 | `centered composition` | 主角固定在画面中心或黄金分割点，配角在左右前后形成视觉平衡 | 核心镜头站位、主角登场 | `主角位于画面中心，配角在左右形成视觉平衡，中远景建立空间` |
| 对称构图 | `symmetrical composition` / `Mirror Symmetry` / `Strict symmetrical centered composition` | 仪式感、压迫感、肃穆与几何隐喻 | 对峙、审判、仪式、宫廷 | `symmetrical composition, cold hard light, tense distance` |
| 框中框 | 门窗取景 / `foreground: blurred door frame` | 增加层次，用门框/窗框封锁包围人物，形成无形边界 | 严厉质问、阻拦离去、窗边心事 | `foreground: blurred door frame, middle ground: main character standing near the table, background: soft city lights through the window, layered cinematic depth` |
| 前景遮挡 | `foreground obstruction` / `Foreground Occlusion` | 用道具或次要角色作前景，制造窥探悬念与隐秘情绪 | 悬疑、窥视、嫉妒、跟踪 | `foreground obstruction, hidden clue, low-key lighting` |
| 前中后景层次 | `layered cinematic depth` | 前景道具 + 中景主角 + 背景环境，三层纵深 | 通用防「贴纸塑料感」 | `前景是虚化的门框，中景是主角站在桌边，背景是窗外柔和城市灯光，形成电影感空间层次` |
| 引导线 | `leading lines` / `long leading lines` | 纵深线条制造压迫感、目的地感与未知恐惧 | 长廊尽头、巷道纵深、逃离动线 | `leading lines, motion direction, handheld camera` |
| 留白 / 负空间 | `negative space` / `large negative space` | 保留情绪余味，强化孤独与疏离 | 分手、告别、结尾收束 | `negative space, emotional distance, muted colors` ／ `large negative space, distant small light, lonely blue tone` |
| 暗部负空间 | 画面大量负空间（暗部占 70%+） | 用黑暗制造不安 | 惊悚、潜伏、心理暗涌 | `画面大量负空间（暗部占70%+），[微弱环境异响]` |
| 极简构图 | 大量留白 | 意境感 | 文艺、水墨、治愈 | `大面积留白，山水意境` |
| 满构图 | — | 信息量大、压迫感 | 群像、市集、混乱 | `dense frame, information-rich composition` |
| 压迫构图 | `oppressive framing` | 人物被墙面紧紧夹住 | 崩溃、被困、无出口感 | `narrow hallway, strong vertical lines, low ceiling, character framed tightly between walls, oppressive composition, cold overhead light` |
| 三角形构图 | — | 主角在中景，两配角在前景与背景形成三角稳定 | 打斗、对峙、三人关系 | `主角在中景，两名配角分居前景与背景，形成三角形稳定构图` |
| 冲突对峙构图 | — | 两组阵营分立左右，中间留出「张力空间」 | 决战、谈判破裂 | `两方阵营分立画面左右，中间留白作为张力空间，由全景切中景沿中轴线缓慢推进` |
| 镜像 / 映像 | `Mirror Symmetry` | 借镜子、水面、刀光的映像交代双重线索 | 面对自我、掩藏秘密 | `reflection in the mirror revealing the hidden truth` |
| 分屏 | `Split Screen` | 一屏多格，同时展示异地动作 | 悬疑、平行叙事 | `Split screen, two locations at the same moment` |
| 画中画 | `Picture-in-picture` | 主画面含监视框/通话画面 | 多信息源 | `Picture-in-picture, video call inset` |
| 视线留白（对白空间） | — | 角色位于三分线，视线方向一侧留空 | 对白、凝望 | `角色位于画面左三分线，右侧留对白负空间` |

### 5.2 视线方向与空间锚定

构图层只管一条**轴线纪律**：

| 规则 | 写法 |
|---|---|
| 视线轴一致 | 角色 A 看向右侧，角色 B 看向左侧，切忌翻转；正反打时眼线高度与方向必须匹配 |

> **可粘贴的中英锁定句见 [blocking-lighting.md](blocking-lighting.md) §2.2「左右站位锁定语句」**——通用左右锁、视线匹配剪辑、出入场方向、正反打连续、镜头轴线一致等逐镜可复制模板都在那里，本节不再复制一份。

### 5.3 八种角色站位法（构图的调度层）

> **站位法正文见 [blocking-lighting.md](blocking-lighting.md) §1.1「八种基础站位法（行业通用底座）」**——核心镜头 / 对话切换 / 三角关系 / 空间象征 / 运动固定 / 对称仪式 / 冲突对峙 / 前后中景层次八法的定义与调度建议以那一份为准（含「三角关系站位是构图法、打戏景别仍按五镜动作链递进」的口径）。本节只提醒：站位定下来之后，回到 §5.1 挑构图形态、回到 §5.2 锁轴线方向。

### 5.4 竖屏 9:16 构图规范

```
竖屏画面分区（1080×1920）：
┌─────────────┐  ← 顶部安全区（避开平台 UI/头像）约 200px
│   ░░░░░░░   │
│             │
│   人物主体   │  ← 人物面部建议落在上 1/3 黄金区
│  (上1/3区)   │
│             │
│             │
│   躯干/动作  │  ← 中部留给身体动作
│             │
│   ▓▓▓▓▓▓▓   │  ← 字幕区（底部上方，避免压在最底）
│  字幕安全区  │
└─────────────┘  ← 底部安全区（避开点赞/评论 UI）约 250px
```

- ❌ 避免：横屏拍完裁成竖屏（构图被破坏、人物被切）。
- ✅ 使用：从分镜阶段就按 9:16 设计构图。

### 5.5 构图冲突矩阵（组装提示词时必须交叉检查）

| 冲突对 A | 冲突对 B | 为什么冲突 | 解决方案 |
|---|---|---|---|
| 手持晃动 / Handheld | 绝对对称构图 | 运镜与构图逻辑矛盾 | 对称构图强制用三脚架/云台 |
| Slow Motion 慢镜头 | Speed Ramp 变速 | 同一时间切片内不可同时慢和加速 | 分时间切片使用，不在同段重叠 |
| `extreme wide shot` | `close-up on eyes` | 单帧内景别自相矛盾 | 一条提示词只能有一个景别 |

构图连续性自检：人物在画面中的位置是否稳定表达关系；留白、对称、压迫感、孤立感等构图意图是否延续；画面重心是否清晰；多人构图是否能区分主次；竖屏短剧是否始终考虑手机观看中心区域。

## 六、一句话镜头描述公式

### 6.1 上位公式（三条源公式，按用途取一）

**A. 万能八模块公式（图片/视频通用主力）**

```text
提示词 = [主体] + [主体动作] + [场景/环境] + [光影/色调] + [运镜动作及约束] + [视觉风格] + [画质修饰] + [稳定性约束]
```

**B. 官方顺序公式（即梦 / Seedance）**

```text
主体（Subject）+ 动作/事件（Action）+ 场景与环境（Setting）+ 视觉风格（Visual Style）+ 镜头运动（Camera）+ 音效/对话（Audio）
```

**C. 情绪特写公式（人物近景/特写专用）**

```text
[景别/镜头] + [人物身份与外观一致性] + [情绪阶段] + [面部表情细节] + [眼神] + [嘴部/下颌] + [身体反应] + [动作节奏] + [光影氛围] + [稳定性约束]
```

**D. 连续性公式（第 2 镜及以后必须叠加）**

```text
[镜头编号] + [承接上一镜状态] + [同一人物与服装] + [同一空间与站位] + [上一镜动作的延续] + [本镜只推进一个小动作] + [情绪连续] + [光影连续] + [镜头运动] + [稳定性约束]
```

### 6.2 一句话镜头描述公式（本词典的合成骨架）

> 把五张牌按「镜头三件套前置 → 主体 → 环境 → 光影 → 运镜 → 风格 → 约束」串成一句。**景别 + 角度 + 焦段永远在句首**。

```text
[景别] + [机位角度] + [焦段] ，[主体与一致性锚点] + [强度修饰 + 动作] ，[场景/环境与前中后景] ，[构图法则] ，[光源方向 + 色温 + 色调] ，[运镜动作 + 速度修饰 + 情绪修饰] ，[视觉风格 + 画质修饰] ，[稳定性与连续性约束]
```

**中文一句话模板（可直接粘贴）**

```text
[景别][机位角度]，[焦段]，[角色固定外貌句]在[场景]中[强度修饰词][动作]，[前景/中景/背景层次]，[构图法则]，[光源方向与色温]，[色调氛围]，[运镜+速度修饰+情绪修饰]，[视觉风格]，[画质修饰]，保持同一张脸、同一服装、同一场景、同一光向，动作连续，道具连续，不要跳切，不要跳轴，不要更换背景，不要闪烁
```

**英文一句话模板（可直接粘贴）**

```text
[Shot size] [camera angle], [lens mm], [character consistency phrase] [intensity modifier + action] in [location], [foreground/middle/background layers], [composition rule], [light direction and color temperature], [color mood], [camera movement + speed modifier + mood modifier], [visual style], [quality anchors], consistent face, matching action, prop continuity, no jump cut, no axis flip, no changing background, no flickering
```

**极简三段速写版（赶工时用）**

```text
[景别+角度+焦段] + [谁在哪里做什么（带强度词）] + [运镜+光影+约束]
```

```text
# 5 结尾留白
大远景，高角度俯视，200mm 长焦压缩，女主背影独自走向长街尽头，前景是雨幕，背景是散景霓虹，大面积负空间与留白，远处小光源，冷蓝孤独色调，极缓慢拉远并轻微升镜，`slow pull-back, small lonely figure`，2.39:1 宽银幕，胶片颗粒，保持同一服装与发型，不要跳切
```

### 6.6 出词前自检（八条）

1. 景别、运镜词是否在提示词最前面？（否则 AI 会退回默认正面中景）
2. 单帧内是否只有一个景别、一个主角度？
3. 每个动作是否都带了强度修饰词？运镜速度与动作强度是否一致？
4. 运镜是否一次不超过 2–3 个动作？镜头路径在该空间中是否物理可行？
5. 英文运镜词是否已换成 Seedance 安全写法（`推轨推进` / `dolly tracking shot`）？
6. 角色左右位置、视线方向是否与上一镜一致（180 度轴线）？
7. 是否加了「运镜不改变光源方向或色调基准」？
8. 情绪是否写成了可观察的面部肌肉与肢体，而不是 `very sad` / `angry` 这类抽象词？

### 6.7 常见翻车与急救

| 翻车现象 | 急救法 |
|---|---|
| AI 对构图指令「听而不闻」，总生成普通正面中景 | 主体描述过长抢走了构图词权重——**把景别和运镜词移动到提示词最前面**：`A handsome man, close-up...` → `Close-up shot of a handsome man...` |
| 镜头总是中景 | 把 `extreme close-up / close-up / low-angle` 放在提示词开头 |
| 一条提示词里写了「走路、打架、然后哭泣」 | 避免一镜到底，拆分为多个分镜片段分别生成 |
| 多人肢体交互穿模（`two people shaking hands` 长出第三只手） | 改用**正反打过肩镜头**分别拍摄，分镜拆解避开交接瞬间 |
| 单帧构图混乱 | 光线与景别在单帧中必须统一，不要既写 `extreme wide shot` 又写 `close-up on eyes` |
| 背景复杂导致人物边缘崩坏 | 非重点背景一律 `shallow depth of field` 虚化 |
| 跨镜头色调漂移 | 同一剧集风格词（如 `Teal and orange movie style, photorealistic`）必须完全一致 |
