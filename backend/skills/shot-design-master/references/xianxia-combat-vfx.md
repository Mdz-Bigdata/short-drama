# 玄幻打斗：能量形态、特效尺度与收束协议

## 一、三轮攻守骨架与打戏颗粒度

玄幻打戏最常见的六种病：推拿发软(动作像按摩)、相持僵化(架着刀推来推去)、单向挨揍(对手是沙包)、
爆心瞬移(炸完坑败者在坑边凭空出现)、贴脸堆叠(最后一秒两人脸贴脸)、主客倒挂(反派特效拉满、主角挥一根光条)。
对应的规矩：

- **三轮攻守**：一段 15–30 秒的打戏分三轮——对手先强势压制并至少命中一次 → 贴身搏杀、双方互换一次重击 →
  对手放大招逼入绝境、主角绝境反杀。对手必须有正向的致命输出，不能只挨打。
- **颗粒度**：以 2–3 秒的整秒区间为节拍，每个区间 = 1 个机位景别 + 1 个瞬发的核心攻防 + 1 个即时受力回执；
  单区间不堆第二个动作。
- **动词铁律**：禁用长时状态动词(僵持、对峙着、持续压制)，全部改成瞬发瞬收的动词(崩、贯、撕、劈开、震飞)。
- **反杀视觉反超**：主角反杀要留足 4–5 秒，分三段——破缚蓄压前摇(能量向心压缩成炽白光核) → 有宏观物理厚度的立体巨刃 →
  横推碾压落点，顺路斩碎对手的造物。主角的终结技在体积、厚度、亮度上必须明显压过对手的大招。

## 二、能量四态：先定形，再有光

禁写"一团光芒""强烈能量束"这类无轮廓描述。任何能量先归入四态之一，再写颜色与材质：

| 态 | 形 | 写法要点 |
|---|---|---|
| 附着态 | 咬在兵器或肢体表面 | 刃口最亮、剑脊走主流、电弧顺金属纹理螺旋攀附；挥斩时延展、收势时回缩贴刃 |
| 脱体态 | 离开载体独立飞行的实体 | 有明确几何截面(半月、月牙薄刃、光锥)，厚度扁平，边缘带飞白或锯齿，飞行留痕 |
| 聚集态 | 万剑、法阵群流 | 先钉单体规格再写集合；按三维鱼群组织(前部错层锋线 / 中部穿插补位 / 后部追入回填)；**摄影机留在群外** |
| 气场态 | 蓄力与位移的流向尾流 | 静止时能量向心汇聚翻涌；极速位移时衣摆与真气被风压倒拽成锥形拖尾，身体前端出现透明音爆锥 |

每种特效按三层写：硬质能量体(光刃 / 电柱 / 火核) + 写意层(水墨飞白、符文、羽刃) + 流体层(雾、烟、沙、浪、碎石)，
并给出三者的大致占比。剑气类偏写意层，火、冰、土类偏流体层，雷与圣光类偏硬质层。
属性与质感成对写死：水墨剑气 = 泼墨飞白 + 墨滴；紫电刀 = 浓稠墨流 + 暗红血纹 + 紫色锯齿电弧；
赤红枪 = 熔岩翻涌 + 金色螺旋符文 + 前端白色激波；玄冰 = 幽蓝冰晶 + 白霜雾 + 六边冰裂纹；
虚空 = 吞光的纯黑裂隙 + 紫色余烬 + 金色扭曲纹。

**色彩对冲**：严禁同色相撞(蓝剑打蓝雾、黑焰打黑夜)。暖色能量砸在冷色环境或冷色防御上，冷色能量撕裂暖调光尘；
主冲击色、敌人主体色、场景基底色三者两两可辨。

## 三、尺度四件套：大招必须量得出来

凡大招、法阵、巨兽、范围毁灭，拒绝"巨大""恐怖"这类空词，配齐四件：

1. **画框占比**：特效占画面几分之几(占半幅、占七成、遮蔽八成天穹)。
2. **宏观量级**：宽达上百米、纵深数百米、数百丈巨刃。
3. **参照物阶梯**：与已知大小的东西同框——人 → 古建 / 残柱 → 山岳 → 云海天地 → 军阵。
4. **人物位置与占比**：人物在画框哪一层、占多大(千分之一如微尘)。

大招镜头另写清：占据哪块画面、是否冲出画框、前景小物的虚化比例尺、背景巨物被压过的破坏、此刻机位与焦段、
环境的永久性破坏结果，然后**接一个急拉大远景或阶梯拉远做二次证明**，否则尺度只是说说。

- 万剑归宗：全部是正常三尺窄刃飞剑，剑尖朝前；分高位俯冲、左右包抄、中央 S 形主路、低空掠行多路；禁止扁平剑板或单把巨剑充数。
- 法阵：至少三层同心圆环，相邻两层反向、不同速旋转；内中外三色分层；生命周期是阵眼先亮 → 阵纹如裂纹向外蔓延 →
  整体脉动一次 → 节点放出剑流或雷印。
- 召唤巨兽 / 法相护体：正面低仰角，人物在前景正下方只占 3–5%，巨兽在正后方占上方七八成，头穿云层、巨爪悬在人物头顶前方。
- 法天象地(自身巨化)：法相即主体(约七成)，尺度靠环境参照——山峰只到膝盖、城池如积木、飞禽如飞蚁。

## 四、近景对招三件事

远景看奇观，近景看杀意；没有近景对招的打戏等于只有爆炸没有枪战。

- **节奏三模式**：三轻一重(刷刷刷—砰) / 左右交替加速(打击间隔越来越短) / 封—破—杀(两次格挡卸力 → 一次崩防 → 一次贯穿)。
- **招式序列化**：禁"以极快速度激烈对攻"；写成看得见的链——攻方哪只手什么招打哪里，守方怎么挡、挡开后暴露什么，下一招从哪里进。
- **防守三态**：完整态(架势严密、从容卸力) → 崩防态(格挡臂被弹开，0.3–0.5 秒绝对真空) → 狼狈过渡态(侧身闪、后仰躲、
  单臂仓促下拍、碎步后退)。崩防与狼狈是反杀或重创的铺垫，不是可跳过的过渡。
- 轻击泛起透明空气涟漪，重击撕出沉闷音爆环，大招炸开环形冲击波；直线穿刺带子弹状气穴，弧线扫斩带月牙气刃，垂直劈落带向两侧翻涌的气帘。

## 五、收束协议：一段打戏只能用四种方式结束

爆心不能瞬移，最后一秒不能贴脸。每段打戏的最后 2–3 秒从四种里选一种写死空间逻辑：

| 协议 | 写法 |
|---|---|
| A 遗物定场 | 败者消失于爆心，留下兵器 / 碎甲 / 焦痕作为空间锚点，镜头落在遗物上 |
| B 物理抛飞隔离 | 败者沿冲击方向被抛出画框或砸进远处建筑，与胜者拉开可见距离 |
| C 光粒解构 | 败者在冲击中由外向内解构成光粒 / 灰烬随风散去，先形后光再无 |
| D 战意永动硬切 | 打不完：两人反向错车背向出画，或单人刀光冲镜硬切，停在下一击之前 |

Seedance 2.5 写法：整数秒时间戳分段；不嵌套大分镜；清洗元指令与代码符号；音频与排除项写成自然句。
