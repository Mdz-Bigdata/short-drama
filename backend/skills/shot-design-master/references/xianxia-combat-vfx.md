# 玄幻打斗：能量形态、特效尺度与收束协议

## 一、三轮攻守骨架与打戏颗粒度

玄幻打戏最常见的六种病：推拿发软(动作像按摩)、相持僵化(架着刀推来推去)、单向挨揍(对手是沙包)、
爆心瞬移(炸完坑败者在坑边凭空出现)、贴脸堆叠(最后一秒两人脸贴脸)、主客倒挂(反派特效拉满、主角挥一根光条)。
对应的规矩：

- **三轮攻守**：一段 15–30 秒的打戏分三轮——对手先强势压制并至少命中一次 → 贴身搏杀、双方互换一次重击 →
  对手放大招逼入绝境、主角绝境反杀。对手必须有正向的致命输出，不能只挨打。
- **颗粒度**：以 2–3 秒的整秒区间为节拍，每个区间 = 1 个机位景别 + 1 个瞬发的核心攻防 + 1 个即时受力回执；
  单区间不堆第二个动作。
- **动词铁律**：禁用长时状态动词(僵持、对峙着、持续压制)，全部改成瞬发瞬收的动词(崩、贯、撕、劈开、震飞)。
- **反杀视觉反超**：主角反杀要留足 4–5 秒，分三段——破缚蓄压前摇(能量向心压缩成炽白光核) → 有宏观物理厚度的立体巨刃 →
  横推碾压落点，顺路斩碎对手的造物。主角的终结技在体积、厚度、亮度上必须明显压过对手的大招。

## 二、能量四态：先定形，再有光

禁写"一团光芒""强烈能量束"这类无轮廓描述。任何能量先归入四态之一，再写颜色与材质：

| 态 | 形 | 写法要点 |
|---|---|---|
| 附着态 | 咬在兵器或肢体表面 | 刃口最亮、剑脊走主流、电弧顺金属纹理螺旋攀附；挥斩时延展、收势时回缩贴刃 |
| 脱体态 | 离开载体独立飞行的实体 | 有明确几何截面(半月、月牙薄刃、光锥)，厚度扁平，边缘带飞白或锯齿，飞行留痕 |
| 聚集态 | 万剑、法阵群流 | 先钉单体规格再写集合；按三维鱼群组织(前部错层锋线 / 中部穿插补位 / 后部追入回填)；**摄影机留在群外** |
| 气场态 | 蓄力与位移的流向尾流 | 静止时能量向心汇聚翻涌；极速位移时衣摆与真气被风压倒拽成锥形拖尾，身体前端出现透明音爆锥 |

每种特效按三层写：硬质能量体(光刃 / 电柱 / 火核) + 写意层(水墨飞白、符文、羽刃) + 流体层(雾、烟、沙、浪、碎石)，
并给出三者的大致占比。剑气类偏写意层，火、冰、土类偏流体层，雷与圣光类偏硬质层。
属性与质感成对写死：水墨剑气 = 泼墨飞白 + 墨滴；紫电刀 = 浓稠墨流 + 暗红血纹 + 紫色锯齿电弧；
赤红枪 = 熔岩翻涌 + 金色螺旋符文 + 前端白色激波；玄冰 = 幽蓝冰晶 + 白霜雾 + 六边冰裂纹；
虚空 = 吞光的纯黑裂隙 + 紫色余烬 + 金色扭曲纹。

**按质感挑写法**：术法换名字、换颜色，写法只看它落在哪种质感上——
流体(水、藤、烟雾)写形态动词(扩散、缠绕、涌起、翻卷、攀爬)和被它带起的碎屑，不写速度；
几何(结界、阵法、幻术)写图案结构(同心主环副环、六角纹、对称、逐层旋转)，阵纹贴地或贴身，跟人站的位置咬住，不写速度；
动能(拳劲、腿风、刀意)以动态模糊、几道残影、速度线和弧形气浪为主，特效本体只占一点，写明快门感；
碎块(土岩、羽刃、碎屑)写数量、从哪来、往哪飞、飞多远，有方向的粒子前端密、尾端疏。
受击的人另写一句：身体怎么后仰、脚下滑出多远、衣摆被掀向哪边；特效砸过去对面纹丝不动，是最常见的破绽。

**色彩对冲**：严禁同色相撞(蓝剑打蓝雾、黑焰打黑夜)。暖色能量砸在冷色环境或冷色防御上，冷色能量撕裂暖调光尘；
主冲击色、敌人主体色、场景基底色三者两两可辨。

## 三、尺度四件套：大招必须量得出来

凡大招、法阵、巨兽、范围毁灭，拒绝"巨大""恐怖"这类空词，配齐四件：

1. **画框占比**：特效占画面几分之几(占半幅、占七成、遮蔽八成天穹)。
2. **宏观量级**：宽达上百米、纵深数百米、数百丈巨刃。
3. **参照物阶梯**：与已知大小的东西同框——人 → 古建 / 残柱 → 山岳 → 云海天地 → 军阵。
4. **人物位置与占比**：人物在画框哪一层、占多大(千分之一如微尘)。

大招镜头另写清：占据哪块画面、是否冲出画框、前景小物的虚化比例尺、背景巨物被压过的破坏、此刻机位与焦段、
环境的永久性破坏结果，然后**接一个急拉大远景或阶梯拉远做二次证明**，否则尺度只是说说。

- 万剑归宗：全部是正常三尺窄刃飞剑，剑尖朝前；分高位俯冲、左右包抄、中央 S 形主路、低空掠行多路；禁止扁平剑板或单把巨剑充数。
- 法阵：至少三层同心圆环，相邻两层反向、不同速旋转；内中外三色分层；生命周期是阵眼先亮 → 阵纹如裂纹向外蔓延 →
  整体脉动一次 → 节点放出剑流或雷印。
- 召唤巨兽 / 法相护体：正面低仰角，人物在前景正下方只占 3–5%，巨兽在正后方占上方七八成，头穿云层、巨爪悬在人物头顶前方。
- 法天象地(自身巨化)：法相即主体(约七成)，尺度靠环境参照——山峰只到膝盖、城池如积木、飞禽如飞蚁。

## 四、近景对招三件事

远景看奇观，近景看杀意；没有近景对招的打戏等于只有爆炸没有枪战。

- **节奏三模式**：三轻一重(刷刷刷—砰) / 左右交替加速(打击间隔越来越短) / 封—破—杀(两次格挡卸力 → 一次崩防 → 一次贯穿)。
- **招式序列化**：禁"以极快速度激烈对攻"；写成看得见的链——攻方哪只手什么招打哪里，守方怎么挡、挡开后暴露什么，下一招从哪里进。
- **防守三态**：完整态(架势严密、从容卸力) → 崩防态(格挡臂被弹开，0.3–0.5 秒绝对真空) → 狼狈过渡态(侧身闪、后仰躲、
  单臂仓促下拍、碎步后退)。崩防与狼狈是反杀或重创的铺垫，不是可跳过的过渡。
- 轻击泛起透明空气涟漪，重击撕出沉闷音爆环，大招炸开环形冲击波；直线穿刺带子弹状气穴，弧线扫斩带月牙气刃，垂直劈落带向两侧翻涌的气帘。

## 五、收束协议：一段打戏只能用四种方式结束

爆心不能瞬移，最后一秒不能贴脸。每段打戏的最后 2–3 秒从四种里选一种写死空间逻辑：

| 协议 | 写法 |
|---|---|
| A 遗物定场 | 败者消失于爆心，留下兵器 / 碎甲 / 焦痕作为空间锚点，镜头落在遗物上 |
| B 物理抛飞隔离 | 败者沿冲击方向被抛出画框或砸进远处建筑，与胜者拉开可见距离 |
| C 光粒解构 | 败者在冲击中由外向内解构成光粒 / 灰烬随风散去，先形后光再无 |
| D 战意永动硬切 | 打不完：两人反向错车背向出画，或单人刀光冲镜硬切，停在下一击之前 |

Seedance 2.5 写法：整数秒时间戳分段；不嵌套大分镜；清洗元指令与代码符号；音频与排除项写成自然句。

## 六、特效镜头：四拍时序、特效光与制作规格

- **四拍时序**：蓄力 → 释放 → 作用 → 余波。蓄力时能量向施法者或兵器收拢，环境先有反应(衣摆、尘土、水面、烛火向内吸或向外推)；
  释放一瞬成形，形状按能量四态写；作用时接触点最亮，受力的人、物和地面同时形变；余波 1–2 秒：冲击环扩散、碎屑落下、
  光由亮转暗，留下余烬或残余电弧。一段视频里四拍按整秒写时间，蓄力不超过全长的三分之一。
- **特效就是光源**：释放与作用那两拍，特效的颜色照在朝向它的脸、兵器、衣褶和地面那一侧，阴影背向特效；余波时光随特效变暗，
  回到本场的底光。分镜锁的是本场底光，特效光是叠在上面的临时光，不算改光。
- **一镜一个主特效**：同一镜只让一种主特效占视觉中心，其他的只留附着态或余波；主特效不盖住人物的脸和接触点，脸至少一侧清楚。
- **颜色归属**：每个角色一种固定的特效主色，全剧不换；对立双方主色一冷一暖，配合上文的色彩对冲。
- **大制作感要看得见**：硬质能量体、写意层、流体层三层同时在画面里；环境至少两种受力反应(地面龟裂、碎石悬浮、树叶尘土朝同一方向倒、
  水面炸起、灯火同时偏倒、瓦片震落)；粒子与烟尘分前中后景，有纵深；大招之后接一个拉远或俯瞰证明尺度；焦痕、冰霜、断裂物留在后面的镜头里。
- **只写看得见的**：不写「绚丽特效」「炫酷光效」「强大能量」这类空词，写形状、颜色、材质、方向和尺寸。

## 七、非打斗奇观：渡劫、突破、御剑、阵法、法宝、结界、召唤、炼丹

- **渡劫雷劫**：云层先压低、旋成漩涡、中心发亮(预兆) → 雷柱垂直劈落，柱身白芯外裹分叉电弧 → 人物以护体光或法宝硬扛，
  脚下焦黑龟裂、四周碎石弹开 → 一道比一道粗。第一道雷用大远景定尺度，之后近景给人物承受：咬牙、衣袍焦破、皮肤上电纹游走。
- **突破境界**：灵气化作可见的光丝光点从四周向人物汇聚，丹田或眉心一点亮起，随即一圈光环向外推开，气浪吹动周围衣物与灯火；
  突破后留一个持续的新细节(瞳中一闪、周身淡光、发丝无风自动)，之后的镜头保持。
- **御剑飞行**：剑横在脚下、与人等长或略长，剑光贴着剑身；衣袍与头发向后拖成锥形，脚下与身后拖出光痕；俯视镜里要有云层、山脊或城池在下方作比例；
  起飞与落地各有一次气流冲击，尘土向外推开。
- **阵法开启**：沿用上文法阵的三层同心环；阵纹从阵眼沿地面刻槽蔓延，像熔金流进沟里；光从地面向上打亮人物的下巴和衣摆；阵成时整体脉动一次，升起光幕。
- **法宝祭出与认主**：法宝离手悬浮 → 放大或展开 → 外围亮起属性光晕(质感按上文的属性配对)；认主时一滴血落在法宝上沿纹路渗开，法宝一亮，光芒收回内敛。
- **结界护罩**：半透明的球面或穹顶，表面有六边形或符文网格；受击处一圈涟漪向外扩散、由亮转暗；破碎时裂纹先蔓延，再整片碎成光片落下。
- **召唤与法相**：比例沿用上文召唤巨兽与法相的写法；先有影子或轮廓在云雾里显形，再亮起眼睛或纹路，最后整体凝实。
- **炼丹与丹火**：炉口火焰的颜色按品级写死，炉身纹路随火势明灭；丹成时一道光柱冲天，丹香化成可见的彩雾。
- **丹雷与出炉异象**：高品丹将成时天上落下丹雷，细而密，围着丹炉打，炉身被打得发亮却不碎；炉盖被顶开一线，丹药带着一圈丹纹光晕飞出、悬在半空自转，
  丹香化成彩霞或灵兽虚影盘旋一圈后散去，周围的人被香气冲得一怔。炼废时炉内一声闷响，黑烟从炉盖缝里喷出，炉身裂纹一亮，炼丹的人被反震得后退。

## 八、武侠的内力外放：克制、写实、靠环境显力

武侠不是仙侠：内力、掌风、剑气不画成发光的能量体，剧本写明剑气发光时才发光。力量感来自物理反应：

- **掌风**：一圈被压缩的透明空气波纹，尘土、落叶、水花、烛火被吹开；受掌的人衣服先贴身、再向后鼓起。
- **剑气刀气**：刃口一线寒光或残影；劈开的方向上竹叶齐断、水面劈出一道沟、石砖留下切痕。
- **内力相拼**：两人脚下的地面下陷或石板碎裂，周围器物震颤移位，衣袍鼓荡，额角青筋与汗。
- **轻功**：每个落脚点都有物理回执(瓦片下沉轻响、水面一圈涟漪、竹梢压弯又弹回)，不飘、不悬停。
- **重击**：受击的身体先形变再位移，兵器相交时火星沿刃口飞溅，背后的器物被撞碎，声音与画面同时到。

特效占比低：以环境反应和身体反应为主，光效只在刃口与接触点一闪。
