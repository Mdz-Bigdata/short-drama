# 高速打斗与割草运镜手册

> 来源：公众号「细雪芒出」(孟令卿) 2026-09《Seedance万能高速打斗运镜Skill手册》
> (https://mp.weixin.qq.com/s/S4d11k2bhOJ7KQOIfQR9pA)。按本项目重写：`martial-arts` 管招式与打点设计，
> `fight-prompt-director` 管速度档与强度曲线，本文只管**镜头怎么跟着打**——机位公式、速度档位词、命中与尾帧处理。
> 写 Seedance 打戏提示词时与它们同时生效。

## 一、核心原则

高速打斗最常见的失败是"人在动、镜头在发呆"。镜头的任务不是拍完动作，而是跟随速度、制造速度、放大速度，只服务三件事：
让观众看清动作轨迹；强化攻击方向与力量；用镜头速度制造压迫感。

一句话：**镜头贴着动作轨迹走，跟着攻击方向转，在命中点短暂停，在结尾留下下一击的空间。**
一镜到底、不硬切：输出写成一段连续的中文描述，少用分镜序号，否则模型会自己切镜。

## 二、十个机位公式(单挑)

| 节拍 | 机位 + 运镜 | 要点 |
|---|---|---|
| 起手冲刺 | 低机位仰拍 + FS 全景 + 快速前推 | 压低地平线让人显得更快；前景碎石草叶掠过；FOV 略拉宽 |
| 高速错位 | ORBIT 绕交错点半圈 + 焦点切换 | 环绕是围绕"交错点"转，焦点先锁进攻者再切闪避者 |
| 腿法轨迹 | TRACK 贴地横移 + 轻微上摇 | 镜头高度低于膝盖，踢击瞬间上摇带出腿风草屑 |
| 腾空动作 | 低机位仰拍起跳点 + TILT-U 急速上摇 | 镜头略滞后于动作，强化滞空与旋转幅度 |
| 命中瞬间 | CU 落点 + WHIP 跟碰触 + 0.15 s 凝滞锐化 | 碎屑悬停，然后轻微震动并恢复运动 |
| 被震飞 | PULL 急速后拉至 MS | 后拉要展示被打出去的距离与方向，人物边缘带拖影 |
| 追击连招 | DOLLY 贴进攻者身侧同速平移 | 仰拍与平视间快速切换，每次攻击镜头轻微前弹 |
| 对手反击 | 从进攻者身后快速推出 + PAN 转向威胁 + PUSH 逼近 | 反击时注意力必须立刻转到威胁点 |
| 高空压制 | 低机位仰拍升至高点 + 垂直下摇跟随下砸 | 画面重心随攻击快速下沉，地面冲击波外炸 |
| 尾帧前摇 | MCU 锁低姿态蓄力 + PULL gentle 缓慢后拉 | 停在"下一击马上开始"，不停在摆 pose；背景敌人仍在倒飞 |

## 三、割草专章(群敌清场)

与单挑的差别：镜头要同时交代**主角推进路线**和**敌人成片倒下**，一镜扫过去观众要感到战场在被清空。

| 节拍 | 写法 |
|---|---|
| 入场破阵 | 低机位广角 FS 沿冲锋路线横扫怪群，DOLLY swift 贴身前推，前景敌人掠过画边、后方接连失衡倒地 |
| 范围横扫 | WHIP 沿攻击弧线横向扫过，高度贴腰线，连续掠过三到五名敌人被击飞的瞬间，落点短暂凝滞后立刻接下一段 |
| 穿透连斩 | TRACK 跟拍直线突进，焦点锁死进攻者，背景敌人依次倒飞出画，每次命中镜头轻微前弹 |
| AOE 爆发 | 命中瞬间 CU 锁冲击中心，随即 PULL 急速后拉至 FS，环形冲击波外扩、四周敌人同步倒飞，shock 0.3 s 后稳住 |
| 割草尾帧 | MCU 锁收招低姿态，PULL gentle 拉至 FS 露出满地倒伏与烟尘，停在下一波涌入前的安静压迫 |

## 四、速度档位词(写进运镜句)

| 档位 | 用于 | 写法 |
|---|---|---|
| swift | 冲刺、闪避、连击、贴地移动、穿阵 | `DOLLY swift` 紧贴人物运动方向跟拍，前景快速划过，背景横向运动模糊 |
| whip | 踢击轨迹、转身、命中、方向突变、范围横扫 | `WHIP` 甩镜沿弧线扫过，落点瞬间轻微凝滞，边缘动态拖影 |
| gentle | 结尾压迫、蓄力、展示战场、割草收束 | `PULL gentle` 缓慢后拉，焦点锁前景角色，背景逐渐展开 |
| shock | 重击、爆发、砸地、能量碰撞、AOE | 命中瞬间 `shock` 震动 0.3 s，碎石草屑沿冲击方向扩散 |

景别搭配：起手对冲 FS → 贴地移动 MS 低机位 → 命中 CU → 腾空仰拍 MS → 连招侧移 MS → 反击反向 FS/CU →
破阵广角 FS 横扫 → AOE CU→FS 后拉 → 尾帧 MCU。

## 五、拼接公式(一段打戏一条 prompt)

1. 一镜到底 + 不硬切；
2. 选 1 个起手机位；
3. 选 1–2 个过程运镜(连招 / 错位 / 割草横扫)；
4. 选 1 个命中处理(凝滞 / 震动 / 后拉)；
5. 选 1 个尾帧(蓄力后拉)；
6. 补材质：前景草叶、碎石、拖影、运动模糊、冲击波。

6–8 秒的单挑通常是：起手前推 → 环绕错位 → 贴身连招 → CU 命中凝滞 + shock → 急拉展示倒飞 → MCU 蓄力缓拉。
割草则是：广角横扫破阵 → TRACK 穿阵 → WHIP 弧线横扫 → AOE 后拉 + shock → 缓拉露出清场。
把主角、对手、武器、场景材质换成本剧的资产锁即可；与 `camera-move-library` 的"一镜一主运镜"不冲突——这里的
多段运镜是一镜到底里按节拍顺序接力，每个节拍仍只有一种运镜。

口诀：低机位冲，贴地跟；环绕错，甩镜追；特写打，震动停；后拉开，尾帧续。割草加：广角扫，穿阵跟；弧线掠，后拉清。
