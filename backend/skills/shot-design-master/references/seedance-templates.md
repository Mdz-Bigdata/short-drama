# Seedance 短剧提示词模板库（2.0 / 2.5）

> 目标模型是 **Seedance 2.0 或 2.5** 时，本文件是分镜表与逐镜提示词的取词词典。
>
> **权威顺序**：
> - Seedance 2.5 的任务路由、参数分离、素材职责、`【未采用素材】`、首尾帧角色句 → 以 `backend/skills/sd25-pe/SKILL.md` 为准。
> - Seedance 2.0 的引用语法、三段论、强制兜底包 → 以 `backend/skills/seedance2-prompt-optimizer/SKILL.md`（sd2-pe）为准。
> - 时长上限、素材限额、请求协议红线 → 以 [models-failures.md §1.1/§1.3/§1.4](models-failures.md) 为准。
> - 本文件只补「短剧怎么写才出片」这一层工艺，不重新定义任务路由。
>
> 2.5 模板中 `【生成目标】【参考素材职责】【未采用素材】【对白账本】【事件脚本】【保持一致】` 与 `backend/app/core/sd25_compiler.py` 的输出标签**同名同序**；
> `【主体与关系】`（来自 `sd25-pe` 的人写模板）以及 `【镜头】【声音】` 是本文件的**人工扩展段**，编译器不会生成，需要机器编译时把这三段内容并入 `goal`。
> 编译器的 `【事件脚本】【保持一致】` 是固定句，逐镜细节写在 `goal`；不要把 §9.1 手写正文整体当 `goal` 提交，否则会得到重复的这两段。
>
> **外部依据（2026-09-18 实读）**：字节官方《Seedance 2.5 提示词指南》全文转载、
> 三份 Seedance 2.0 实战指南（时间轴万字指南、多镜头指南、速成）与两份 2.5 进阶/六步法、Seedance 2.5 白模实战（含官方测试集案例）、
> AI 短剧「四重一致性 / 七锁」连续性方法、分镜出图「锚点＋变量」两层法、漫剧分镜实战模板。
> 下文凡与项目内 skill 口径不一致处，均**显式标注两种口径**，不静默改写合约。
>
> **完整范例入口**：同一场戏（航班换座，3 镜）的分镜表 + 静帧 + 2.5 三条 + 2.0 三条，见 §16 模板 I。

## 0. 先选版本：能力与语法差异（写之前必须看）

**两版不是同一套提示词换个模型名就能跑。** 下表每一行写错都会直接掉片。

| 维度 | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 单镜时长 | 4–15 秒（Ark 网关钳制 `max(4,min(15,int(d)))`，越界 400） | 4–30 秒；另有 30–180 秒超长模式需显式选择 |
| 素材上限 | 图 ≤ 9（单张 < 30MB）、视频 ≤ 3（总时长 2–15s，单条 < 50MB，480p–720p）、音频 ≤ 3（总时长 ≤ 15s，单条 < 15MB）；**混合总数 ≤ 12**。单文件大小 / 分辨率 / 时长为社区实测口径（§15「Seedance 2.0 速成」），models-failures §1.3 只保证 9/3/3 分项数量 | 图 ≤ 30（≤ 4K）、视频 ≤ 10、音频 ≤ 10、**合计 ≤ 50**；单条视频/音频 [1.8, 30.2]s，各自总时长 ≤ 30 秒。**不要把 2.0 的 12 文件规则套到 2.5** |
| 仅音频输入 | **不支持**：参考链路必须至少有一张图或一段视频 | 支持仅传音频 |
| 真人脸素材 | **不接受含写实真人脸部的上传素材**（图/视频都会被拦），短剧要用风格化或授权形象 | 按平台当前审核口径 |
| 最高分辨率 | 2K | 480p / 720p 档（以端点配置为准） |
| 时间表达 | 项目合约 `sd2-pe` 要求只用 `镜头1 / 镜头2`；三份实战指南则用秒数时间轴。**折中写法见 §7.6** | 允许数字时间段（用户给出时保留，连续不重叠）；没给就用不带数字的「阶段」 |
| 主体标记 | `<主体N>@图片N`，或先 `将@图片N中的[2-3个稳定静态特征]定义为<主体N>` | 裸角色名（`<>` 留给音效），逐条 `沈昭雪对应@图片1，只采用…` |
| 参数位置 | 顶层字段 `resolution / duration / ratio / watermark`，**`style_caption` 非空** | 全部留在工具配置区，正文不写；首帧/编辑/延长任务的画幅还会被输入自动锁定 |
| 兜底负向包 | **默认必挂**：画质包 + 稳定包 + 水印/Logo；多人必挂双胞胎兜底 | **不自动挂**；只写本条真实存在的风险，`【保持一致】` 通常 3–8 条 |
| 未采用素材 | 不强制 | **强制** `【未采用素材】` 逐个列号 |
| 首尾帧 | 第一段里写 `@图片N 作为首帧约束 / 尾帧约束` | 必须独立精确角色句 `@图片1作为首帧。`，不得弱化为「构图参考」 |
| 编辑/延长句式 | `严格编辑 @视频1，…` / `向后延长 @视频1，…`，**禁止写「参考@视频1」**（会被误判为参考任务） | `【编辑目标】编辑@视频1，只把…`；画幅不符或非续写的时长变化 → 不是编辑，按生成处理并加一句 `请注意这不是视频编辑。`；明确续写 → 走延长（§9.7），不加该句 |
| 风格锚位置 | 走顶层 `style_caption`，正文尾串只留稳定锚 + 兜底锚，**两处不重复写** | 写在正文的视觉描述句里，正文不出现任何接口参数 |
| 人脸参考 | 大头照 + 全身照；**禁用三视图/多视图**（触发 ID 漂移与双胞胎） | 多视角可用，但要逐图写职责并声明「共同定义同一实体、只有一个」 |

**本文件用到的项目术语（首次出现前先看）**

| 术语 | 含义 |
|---|---|
| 层① | 生成请求时长，即填进 `duration` 的数，≥ 4 且不超过模型上限（2.0 = 15，2.5 = 30）。出处：models-failures §1.1 |
| 层② | 动作单元时长，即提示词内一个时间段承载的动作，2–4 秒 |
| 层③ | 成片剪辑时长，由剪辑台从层①素材里裁出，常规 1–3 秒，**永不作为请求参数**。把层③的 1.5 秒填进 `duration` 会直接 400 |
| 🟢 / 🟡 / 🔴 | 动作危险分级。🟢 低危是对峙、慢动作、影子暗示，动作单元可放宽到 5 秒；🟡 和 🔴 压回 2–4 秒 |
| 白模 | 只有灰色几何体或人偶的预演视频，只提供走位、机位和节奏，不提供长相，详见 §11 |
| 半拍 | 前一镜动作完成到五到八成的那一刻，后一镜从这里起笔 |
| 动机光源 | 画面里能看见或能推断来源的那盏灯（烛台、窗、阅读灯） |
| 光比 | 亮面与暗面的亮度比，如 4:1 |
| Ark 网关 | 本项目调用 Seedance 的接口层 |
| 路径 A / B | 2.0 的一段式 / 三段论，见 §10.2 和 §10.3 |
| 合并下单 | 把分镜表里相邻 2–3 行写进同一条请求 |

**选型建议（短剧）**：对白戏、情绪戏、需要 15 秒以上一镜到底、需要精确首尾帧 → 用 2.5；
已经跑通 2.0 工作流、单镜 ≤ 15 秒、素材少于 12 份 → 2.0 更省成本。同一集**不要混用两版语法**。

## 1. 两版共通的硬规则

1. **一次请求只做一件事**：生成 / 编辑 / 延长三选一。「先改再续」拆成有序两步。
2. **参数不进正文的那部分**（分辨率、画幅、总时长、帧率、声音开关、seed、档位）两版一致；2.0 的 `style_caption` 是唯一例外，且只在顶层。用户已写出的事件时间段是创作内容，不算参数（§8.1「规格句的两种口径」）。
3. **一镜一景别、一主运镜**。推拉摇移叠加 = 构图崩。
4. **景别与运镜词前置**。主体描述太长会把构图词的权重吃掉，成片退化成「普通正面中景」。
5. **只写拍得到、听得到的**。「他很愤怒」→「下颌绷紧、指节发白、呼吸变浅」。
6. **每份素材一个职责，并写明不采用什么**。素材编号一旦定下全剧不改号。
7. **符号体系**：音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`。用了 `<>` 写音效，2.5 的角色名就不要再用尖括号。
8. **台词预算 3–5 字/秒**，停顿、听、呼吸都算在内。6 秒镜 ≈ 18–30 字。装不下就减字，不要加速。
9. **单次生成 ≥ 4 秒**。成片只要 1.5 秒的动作镜也按 4 秒下单再裁，`duration < 4` 平台直接 400。
10. **短剧节奏**：每镜 4–8 秒（指**生成请求时长**，层①（见 §0 术语表）；成片剪辑时长见 §2「时长」栏），一场戏 3–6 镜。切镜靠分镜表逐镜下单，不靠一条提示词写「切到」。
    **例外**：2.0 路径 B 三段论与 2.5 多阶段时间轴允许在**一条 ≤ 模型上限的请求**里写 2–3 个「镜头N」段（详见 §7.6 / §10.3）；
    分镜表一行仍对应一次请求，需要合并时在分镜表「模式」栏注明「合并下单」，并保证合并后总时长 ≤ 上限（2.0 = 15，2.5 = 30）。

### 素材硬限速查

| 项 | 2.0 | 2.5 |
|---|---|---|
| 混合文件总数 | ≤ 12 | 分项计：图 30 / 视频 10 / 音频 10，合计 ≤ 50 |
| 单图 | < 30MB（社区口径：§15「Seedance 2.0 速成」） | < 30MB，比例 0.4–2.5，宽高 300–6000px，30 图工作流建议 ≤ 4K |
| 单段视频 | 总时长 2–15s，单条 < 50MB，480p–720p（社区口径） | 名义 2–30s（容差 1.8–30.2s），≤ 200MB，480p–4K，24–60fps |
| 单段音频 | 总时长 ≤ 15s，单条 < 15MB（社区口径） | ≤ 30s，≤ 15MB，wav/mp3 |
| 延长 | 按 2.0 网关口径 | 源片 ≤ 30s，单次新增 4–30s，延长后结果 ≤ 60s |
| 稳定区间 | 参考人物 > 4 先分组生图；推荐只用 4–5 份素材 | 静态图主体 1–8；视频/音频驱动主体 1–5，单段 5–10s；编辑源片 ≤ 20s 为宜，编辑参考图 1–5 张（6–8 降稳定） |

### 全剧固定素材编号约定

```text
@图片1  主角A 大头照（五官，无表情）        @图片2  主角A 全身照（妆造/服装）
@图片3  主角B 大头照                        @图片4  主角B 全身照
@图片5  场景一 空间与光线                   @图片6  场景二 空间与光线
@图片7  关键道具                            @图片8+ 首帧 / 尾帧 / 阶段关键帧
@视频1  动作或运镜参考（不带身份）          @音频1  主角A 音色   @音频2  主角B 音色
```

上传顺序必须与编号一致，否则职责整体错位。2.0 里**重要素材前置**：越需要精准参考的（人脸大头照）写得越靠前。

## 2. 模板 A｜分镜表（版本无关，逐镜提示词的上游）

分镜表是给人和调度看的中间产物，**不提交给模型**。每一行对应一次生成请求。

| 字段 | 填写要求 |
|---|---|
| 镜号 | `E3S07-01` 集-场-镜，全剧唯一 |
| 时长 | 两栏：**生成请求时长**（层①：≥4，≤ 模型上限）/ **成片剪辑时长**（层③：常规 1–3 秒，转场/打击慢动作可到 0.5 秒，高风险动作镜 1.5–3 秒；带台词的对白镜按 3–5 字/秒预算放宽到刚好装下台词；均由剪辑台从层①素材裁出，永不作为请求参数，见 models-failures §1.1） |
| 模式 | `文生` / `首帧` / `首尾帧` / `多图参考` / `全模态` / `延长` / `编辑` |
| 景别 | 远景/全景/中景/中近/近景/特写，**一镜只填一个** |
| 机位 | 平视/仰拍/俯拍/越肩/主观 + 高度（齐胸、齐膝、贴地） |
| 运镜 | 一个主运镜，按 §3 标准句式展开 |
| 人物 | 在场的人，数量写死 |
| 起幅 → 落幅 | 首帧画面 + 末帧画面，两端都要能被看见 |
| 动作 | 一个可被拍到的主动词 |
| 表演 | 1–3 条可见线索（视线、呼吸、指节、肩线、吞咽） |
| 台词 | 说话人 + `{原文}` + 语气；无台词写「无」 |
| 音效 | `<>` 内来源明确的声音 |
| 光位 | 主光方向 + 色温 + 光比 |
| 轴线 | 谁在画面左、谁在右、面向哪，**全场不翻转** |
| 六锚点 | 人物/空间/动作/情绪/道具/光影 的承接项 |
| 调度 | 每个主体与关键道具的「景别 + 画面位置 + 朝向 + 静止/位移」，坐标记 (u, v)，见 §5.1 |
| 静帧 | 本镜是否先出分镜图；出图后该图作为下一步首帧，并作为下一镜的「上一镜成图」 |
| 素材 | 本镜激活的编号；2.5 还要写未激活编号 |

### 填写示例（祠堂对峙，3 镜）

| 镜号 | 生成/成片 | 模式 | 景别 | 机位 | 运镜 | 起幅 → 落幅 | 动作 | 台词 |
|---|---|---|---|---|---|---|---|---|
| S03-01 | 6 / 3 | 多图参考 | 中景 | 平视齐胸 | 缓慢推近 | 供桌两侧双人中景 → 沈昭雪中近景 | 她把玉牌按上供桌 | 沈昭雪 `{这块牌，是你亲手给我的。}` |
| S03-02 | 5 / 2 | 首帧 | 中近 | 越肩（过沈昭雪右肩） | 固定 | 越肩看裴无咎中近 → 同构图 | 他垂眼看玉牌，不接 | 裴无咎 `{我不记得了。}` |
| S03-03 | 7 / 3 | 首尾帧 | 全景 | 平视齐腰 | 横移左至右 | 双人全景，沈昭雪右手仍压在玉牌上 → 沈昭雪已出画左缘，裴无咎独自立于供桌内侧、视线落在留在桌面正中的玉牌上 | 她收回手，转身走出画面左缘 | 无 |

**拆镜判据**：地点变化、情绪转折、攻防回合、视线乒乓，各自成镜。
**半拍衔接**：后一镜从前一镜动作完成到五到八成时起笔，禁止从「发现」直接跳到「离开」。

## 3. 模板 B｜标准运镜（两版通用句式）

```text
<运镜名> + 作用主体 + 起始位置或状态 + 运动方向 + 到达位置或状态
```

只写术语名等于没有约束。小众术语保留名称并展开为可观察结果：

```text
<术语> + 作用主体 + 画面变化 + 前景/背景关系 + 方向或速度
```

### 短剧常用运镜库

| 运镜 | 短剧用途 | 必须写清 | 常见翻车 |
|---|---|---|---|
| 缓慢推近 | 施压、进入内心、台词前静默 | 推向谁、从什么景别到什么景别 | 推到人脸特写导致五官漂移——中近景收住 |
| 缓慢拉远 | 孤立主体、收束、揭示环境 | 拉开后画面里新出现什么 | 拉远时凭空长出人物或家具 |
| 横移 | 交代两人关系、隔断感 | 移动方向、经过的前景遮挡物 | 越过轴线导致左右对调 |
| 跟拍 | 走戏、离开、追赶 | 跟谁、机位在其前/后/侧、距离是否恒定 | 跟丢或人物越走越小 |
| 越肩正反打 | 对白戏主力 | 过谁的肩、听者肩部占幅、两镜眼线高度一致 | 反打时轴线翻转，两人同时看向同一侧 |
| 固定机位 | 让表演说话的情绪长镜 | 构图与景别不变，只有人物在动 | 正文混入运镜词，模型自作主张开始漂 |
| 手持呼吸感 | 争吵、慌乱、纪实感 | 跟谁、晃动幅度（轻微/明显） | 写成剧烈晃动导致糊帧 |
| 环绕 | 揭示关系、关键道具 | 绕谁、顺/逆时针、绕多少度 | 绕圈时背景空间自相矛盾 |
| 低角度仰拍 | 权势、压迫、反派登场 | 机位高度（贴地/齐膝）、仰角作用对象 | 仰拍配俯视光，光位与机位打架 |
| 高位俯拍 | 无助、全局关系 | 高度与俯角、地面关系 | 俯拍参考图被当成机位，破坏运镜 |
| 移焦 | 前后景反转（前景手机 → 后景人脸） | 焦点从谁转到谁，两者清晰度如何变化 | 只写「移焦」，模型两个都清楚 |
| 希区柯克变焦 | 惊觉、真相冲击 | 主体大小不变、背景如何压缩或拉伸 | 主体跟着一起变形 |
| 急摇 | 转场、视线乒乓 | 摇的方向、起止对象、结束构图 | 摇完落到空镜 |
| 升降 | 开场建立、结尾抽离 | 升降方向与终点景别 | 中途切换成平移 |
| 一镜到底 | 长对峙、跟随进入新空间 | 镜头连续经过的主体、空间与事件顺序 | 只写术语不给路线 = 没约束 |
| 主观视角 | 偷看、监视、第一人称 | 视线属于谁、身体运动如何影响画面 | 同时出现该角色的正面镜头 |
| 航拍视角 | 开场建立、地点转换 | 高度、俯角、飞行方向、终点落到谁或哪栋建筑 | 只写「航拍」，结果落点是空镜，或凭空多出建筑 |
| FPV 穿越 | 追逐、闯入新空间 | 穿越路线依次经过的物体、速度变化、终点构图 | 路线没写，镜头原地乱晃 |
| 子弹时间 | 打戏高光、险些命中 | 冻结的是谁的哪个姿态、镜头绕多少度、环境粒子是否同步凝滞 | 主体跟着镜头一起转或变形。这类镜必须先降速再写（§6 铁律 1） |
| 回弹变速 | 出拳、拔剑、转身亮相 | 在哪个动作节点加速、在哪个节点减速或回弹、最终停留状态 | 只写「变速」，变速点落在无关动作上。写时间戳规定频率无效（§7.2） |

**转场只用三种**：切（默认）、叠化（时间流逝或回忆）、匹配剪辑（形状或动作相似）。一集不超过 3 处非「切」转场。需要在模型内完成的转场走 §9.11。

**组合上限**：一条视频最多 2 个运镜组合（1 主运镜 + 至多 1 修饰），第 3 个叠加一律删掉，详见 §6 铁律 2。

**2.0 补充**：一镜只允许 1 种主运镜，运镜写在分镜四要素的第一位；运镜可整体锚定到 `@视频1`（"运镜参考 @视频1 的中景推拉与轻微摇移"）。
**2.5 补充**：运镜句写进 `【镜头】`；若同时给了白模视频，白模是唯一镜头参考，正文不再另写运镜词。

### 竖屏（9:16）构图

- 主体眼睛落在画面上三分之一，头顶留白不超过一成。
- 双人**不要并排**：用越肩、前后景深或一近一远——并排在竖屏里两人都被切。
- 关键道具进画时先给一个近景交代，之后才允许它在别的镜头里出现。

## 4. 模板 C｜对白与情绪戏（版本无关，短剧的命根子）

短剧 70% 的镜头是两个人说话。按反应链写，比堆微表情有效：

```text
刺激 → 理解停顿 → 第一个不受控反应 → 选择后的回应 → 残留情绪 → 下一拍
```

- 关键情绪拍点往往是**台词之后的反应**，不是台词本身。给听者镜头时间。
- 眼泪要积累：呼吸变化 → 眼眶湿润 → 眨眼节奏改变 → 指定的那一拍才落下一滴。开场满脸泪是废片。
- **情绪转折模板**（出自 `sd25-pe`「情绪与可观察表现」，把上面的反应链落成可填空的四句）：

  ```text
  整体情绪从<A>转为<B>。
  发生<触发事件>后，<主体>先出现<即时可观察反应>。
  随后，<眼神/眉头/嘴角/呼吸/视线/手部>逐渐<变化>。
  最终，<主体>以<外在表现>表达<B>。
  ```

  单次转折只选 2–4 个最明确的表现；多次转折按触发事件分阶段，每阶段套一次本模板。
- 一拍只给 1–3 条可见线索。逐条排列眉毛、眼睑、鼻翼、嘴角会演成机器人。
- **因果揭示镜**：先让观众看清触发原因，再给人物反应；两者离得远就用一次明确的视线或镜头转移建立关系。
- 假装受伤 / 险些受伤的戏，要写出**未受伤的可观察状态**（皮肤、衣物、道具完整），否则会被画成真伤。
- `不要两人同框` 时，连肩膀、剪影、镜面反射、前景虚化里的另一人都要排除。
- 台词语种要写明（英语台词至少写「使用英语」）；用户没指定时**不要**擅自补普通话或方言口音。
- 2.0 额外：多音字/生僻字易读错，可替换为同音常用字（「螭龙山」→「吃龙山」）并在交付说明里披露。
- 2.0 额外：台词语种统一，避免中英混用（专有名词除外）；小语种写 `用日语说道 {…}`。含旁白的成片片尾可能有截断杂音，后期用音量包络线淡出。

### 4.1 台词、旁白、独白要分开写

三者的口型与声源完全不同，混写会出现「旁白响着但人物在动嘴」这类废片：

| 类型 | 记法 | 必须写清 |
|---|---|---|
| 对白 | `<角色>（正面／侧面／背身）…（<音色>，<语气>，<语速>）：{原文}` | 说话人、画内、音色语气语速、口型与台词同步 |
| 旁白 | `旁白（画外，不出镜）：{原文}` | 明确非画内人物发声；画面中**没有人做口型** |
| 独白 | `<角色>内心独白（画外音，人物自然闭口不做口型）：{原文}` | 必须点明人物闭口，否则会被演成对白 |

**语气标注写在台词前的括号里**，与台词原文分离：

```text
（温柔急切音，语气焦急恳求，语速稍快）：{周女士，经济舱那位和您换座位的孕妇，突然大出血了。}
```

**逐镜台词行的标准写法**（正反打戏直接套）：

```text
<时间段>：正反打<角色A>近景，<角色A>（正面）<身体动作>，<面部线索>，
（<音色>，<语气>，<语速>）：{<台词原文>}；<角色B>自然闭口聆听，反应发生在台词落下之后。
音效：<环境层与动作音效>。
```

填写示例：

```text
00:00.000–00:06.000：正反打空乘近景，空乘（正面）身体微倾、单手扶住座椅靠背，眉心收紧，
（温柔急切音，语气焦急恳求，语速稍快）：{周女士，经济舱那位和您换座位的孕妇，突然大出血了。}；
周女士背身入画占左前景三成，闻声后肩线一顿，尚未回头。
音效：<机舱轻微气流声，远处推车轮轴声>。
```

本段 6 秒、台词 22 字 ≈ 3.7 字/秒，落在 §1 规则 8 的 3–5 字/秒预算内；若只给 4 秒，台词要减到 ≤ 20 字（如「周女士，和您换座的孕妇突然大出血了。」）。

**同一条提示词里，未说话的人一定要写明「自然闭口聆听」**——这是 2.5 原生音频最容易出错的地方。

## 5. 模板 D｜一镜两段交付：静帧提示词（落笔 / 调色 / 收边）

短剧逐镜的正确产物**不是一条提示词，而是两条**：

```text
静帧提示词（图模型，产出本镜分镜图）  →  该图作为 @图片N 首帧  →  视频提示词（Seedance 2.0/2.5）
```

静帧先把身份、构图、方位、光色一次性钉死，视频提示词就只负责「让它动起来」，
人脸漂移、服装跳变、左右对调这三类废片绝大多数在这一步被挡住。

静帧提示词固定三段：**【落笔】**（画面内容与方位）、**【调色】**（影调与光）、**【收边】**（画幅完整性与禁止项）。
三段字数比例约 `600 : 160 : 100`，总量控制在约 800–1300 字（三段按比例相加约 860 字，§5.3 示例约 800 字，属下限）；超过 1300 字后置信度开始稀释。

### 5.1 【落笔】七件套

按固定顺序写，缺一件即判未写完：

| # | 件 | 内容 |
|---|---|---|
| 1 | 参考图清单 | `图1 <角色A>定妆照、图2 <角色B>定妆照、图3 道具<X>、图4 <场地>、图5 特效<Y>、图6 上一镜成图` |
| 2 | 服装来源 | `<角色A>、<角色B>本镜没有单独戏服，服装分别以图1、图2 定妆照为准` |
| 3 | 逐图职责 | 每类图写死「只取什么、不取什么」，见下方职责矩阵 |
| 4 | 媒介与规格 | `电影分镜视频静帧，单张完整画面，竖屏 9:16` |
| 5 | 本镜表演 | 承接上一镜的**半拍**动作 + 面部可见线索（眼、唇、喉、眉、肩） |
| 6 | 相对方位 | 象限词 + 归一化坐标 (u, v) + 相对上一镜的增量 + 与对手距离 + 光带关系 + 肩线高低 |
| 7 | 调度行 | 每个主体与关键道具各一条：`「<名>」<景别><画面位置>、<朝向>、<运动状态>`；末尾一条背景声明 |

#### 参考图职责矩阵（照抄这套「只取 / 不取」）

| 图类 | 只取 | 不取 |
|---|---|---|
| 定妆照 | 脸型骨相、五官、发型发色、体型比例 | 背景与光线 |
| 道具图 | 形制、材质、磨损 | 人物与场景 |
| 场地图 | 结构、陈设、材质（光线以本镜自拍为准） | 人物 |
| 特效图 | 形态、色彩、强度 | 人物与场景 |
| 上一镜成图 | 影调与色板 | 人物、构图与版式 |

**「上一镜成图」是跨镜一致性的主力手段**：它只交接影调色板，不交接构图，
所以既能锁住全场颜色，又不会把上一镜的机位复制过来。第 2 镜起每镜都应该挂。

#### 方位坐标约定（全项目统一，写进每一镜）

```text
u：画面横向归一化坐标，0 = 画面左缘，1 = 画面右缘
v：画面纵向归一化坐标，0 = 画面上缘，1 = 画面下缘
景深：近 / 中 / 远 单独写一档，不与 u、v 混用
增量：只在与上一镜有变化时写，格式 `u 由 0.35 移到 0.28`
象限词：画左 / 画右 / 中央偏左 / 中央偏右 —— 坐标是给人对齐的，象限词是给模型读的，两者都要写
```

> 这套语义必须在项目内统一并原样写进模板。**不要**从别家产品的截图反推坐标含义，
> 各家 (u, v) 的轴向与零点约定不同，数值跨产品照搬必错位。

### 5.4 静帧与视频的接口

1. 静帧出图验收通过后，把它作为下一步的 `@图片N`，在 2.5 里写独立角色句 `@图片N作为首帧。`，
   在 2.0 里写 `@图片N 作为首帧约束`。
2. **视频提示词里不要重复描述长相与构图**——首帧已经钉死了，重描是漂移的主要来源；
   视频正文只写动作、运镜、对白、声音和不变量。
3. 静帧的【调色】段不必原样搬进视频提示词，只保留「光向 + 光比 + 影调档」一句即可。
4. 本镜静帧同时作为**下一镜的「上一镜成图」参考图**，形成影调链。

### 5.5 轻量版：一层不变，一层变

不需要落笔/调色/收边那么重时，用这套更轻的标签版。核心心法只有一句：**一层不变，一层变**。

```text
🔒 固定锚点（每镜逐字复制，一字不改）
   角色锚点：角色卡原文        风格锚点：画风、媒介、色板、光影
   场景锚点：同一场戏的环境、光线方向、色温、关键道具位置

🎬 镜头变量（每镜只改这里）
   景别 / 机位与构图 / 角色的动作与表情
```

**铁律：一次只改一个变量。** 改得越多，模型自由发挥空间越大，角色漂得越远。

**角色卡公式**（「角色卡原文」里该有什么）：`角色名 + 年龄/身份 + 发型发色 + 五官 + 服装配饰 + 体型 + 气质 + 画风`
（+ 固定 seed，仅出图模型）；另写 1–2 个**每镜必现的视觉锚点**（耳钉/伤疤/异色瞳），
这也是 §12.1 人物锁「人物 DNA」的固定项写法。

```text
【风格】<画风、色调、光照、描边、比例>，逐字不变。      ← 同一题材全集共用一套风格锁定词，每镜末尾可加「全程统一画风」
【角色】<角色卡原文>，逐字不变。
【场景】<地点、光线方向、关键道具位置>，逐字不变。
【镜头】<景别>，<机位>，<构图>，<角色可见动作与表情>。      ← 只有这一段在变
【连贯】与上一镜同一场戏：<角色在画面的左右位置>、<面朝方向>、<光线方向>、<关键道具位置>与上一镜保持一致。
【负面】不要文字、对话框、水印、多余手指、<本镜真实存在的其他风险>。
```

**连贯声明是替「场记」提醒的那句话**——你不写，模型就真的不记得。第 2 镜起每条都要写，
且必须写出四件事：角色左右位置、面朝方向、光线方向、关键道具位置。

### 5.6 三个方向锁

角色是同一个人，剪在一起还是别扭，问题通常出在方向上：

| 锁 | 内容 |
|---|---|
| 视线方向 | A 朝右看 B，整场就朝右；切到 B 时 B 应当朝左。两人对望，方向相对 |
| 光线方向 | 前一镜光从左来，同一场戏别让光跑到右边，否则像换了时间 |
| 道具位置 | 道具在画右，不管全景还是特写都得在对应位置，不能这镜在左、下镜在右 |

这就是影视的轴线规则——你只是用文字替模型把机位守在轴线同一侧。

### 5.7 静帧的三个高频坑

1. **别让出图模型画台词和对话框**。文字几乎必乱码。画面只放动作与表情，台词、气泡、音效字留到剪辑台加。
2. **别堆空泛词**。「8K、史诗感、电影级、超高清」堆一串没有意义，不如写清「光从哪来、角色看哪、手在干嘛」。
3. **脸还在漂？两招**：① 把角色卡那张干净的正面全身定妆图当参考图每镜都上传，并写明「与参考图为同一角色、同一服装」；
   ② 一次只改一个变量。

### 5.8 分镜故事板选型（先判断这场戏最难控的是什么）

| 最难控的是 | 用哪种故事板 | 关键检查 |
|---|---|---|
| 走位 | 调度故事板：每一步从哪出发、到哪结束 | 几格能否连成一条明确行动路线 |
| 攻防 | 动作故事板：谁先动、谁反应、结果是什么 | 攻击有没有准备动作、闪避有没有重心变化、跳跃有没有起落点 |
| 单个高难动作 | 动作拆解板：一个动作分成多个姿态 | 中间姿态接不接得上 |
| 信息推进 | 叙事故事板：对话、误会、发现线索 | 每格问一句「这一镜让观众新知道了什么」 |
| 节奏 | 导演轨道板：镜头/动作/情绪三条轨道对齐 | 悬念是不是来得太早、关键物件是不是没看清就切走 |
| 空间与遮挡 | 3D 白模板（见 §11） | 白模人物**不是**外貌参考，别拿它当角色图 |
| 大场景方位 | 场景概览（鸟瞰草图） | 角色逃进侧巷后能不能顺路到达目标点 |
| 室内功能分区 | 场景规划图 | 同一间屋子别第一场药柜在左、第二场跑到门后 |
| 同一地点多机位 | 场景固定图（多角度） | 切机位时会不会「换了房间」 |

**分镜生成后，先逐格过五问**，再开始做视频：人物一致吗？空间连续吗？动作能接上吗？
道具状态对吗（没拿到的有没有提前出现在手里、已损坏的有没有突然复原）？镜头有目的吗？

## 6. 运镜五条铁律（两版都适用，本项目强制）

1. **动作写慢、写连续**。别写「跳舞」，写「缓慢转身、轻轻抬手」；高爆发动作（狂奔、大跳、翻滚）先降速再写。
2. **运镜写稳、写简单**。一条视频**最多 2 个运镜组合**：1 个主运镜 + 至多 1 个修饰（如「缓慢推近 + 轻微手持呼吸感」），
   第 3 个叠加一律删掉。
3. **稳定约束**：`画面流畅稳定、无抖动无闪烁`——**2.0 默认必挂**在正文结尾（§10.6 运镜稳定串）；
   **2.5 不作为固定尾串**，仅在本镜存在对应真实风险（手持晃动、快速运镜）且按 §9.8 条件表命中时写入 `【保持一致】`。
4. **角色约束**：`面部稳定不变形，五官清晰，服装一致`——**2.0 有人物必挂**；
   **2.5 同上**，只在推到近景拍脸、换装/复制风险真实存在时按 §9.8 逐条写，不作为固定尾串。
5. **模糊词换精确词**。

| 模糊写法 | 换成 |
|---|---|
| `move` / 镜头动一下 | `3 秒平滑推近（smooth 3-second dolly forward）` |
| 好看 / 高级感 | `治愈清新暖光` 或 `低饱和青橙分级、暗部保留细节` |
| 跳舞 | `缓慢转身、轻轻抬手，手腕停在肩高` |
| 快速跑过去 | `小碎步快走，上半身前倾约十五度` |
| 情绪激动 | `呼吸变快、指节发白、下颌绷紧` |
| 打光好 | `侧逆光，主光自画右四十五度，光比 4:1` |
| 气氛紧张 | `环境声压低，只留呼吸与衣料摩擦，人物停止动作一拍` |

> **两种口径与决策规则**：`sd2-pe` 把画质包/稳定包列为 2.0 默认兜底，第 3、4 条在 2.0 里照挂；
> `sd25-pe` 第 8 条禁止「自动添加用户未要求的画质包、稳定包……或其他通用负向约束」，「本项目要求」不等于「用户要求」，
> 项目编译器 `sd25_compiler.py` 的 2.5 `【保持一致】` 也只输出「保持人物身份与数量、服装、身体拓扑……同一主体不重复、不分裂」而不含这两串。
> 因此：**2.0 → 默认挂；2.5 → 不挂固定串，按 §9.8 条件表逐条写本镜真实存在的风险**。

## 7. 模板 E｜时间轴与节奏（两版通用方法论）

### 7.1 时间轴 ≠ 分镜

两者是**独立的两个维度**，可以叠加也可以单用：

| | 分镜 | 时间轴 |
|---|---|---|
| 回答 | 看什么 | 什么时候看 |
| 管的是 | 空间：景别、机位、构图、切镜 | 时间：起止秒数、持续时长、节奏 |
| 只写这一维的后果 | 节奏由模型自行分配，常见「A 占 12 秒、BC 没了」 | 画面构图由模型自由发挥 |

两者结合才是完整的一段：`第几秒 + 用什么景别 + 拍什么`。

### 7.2 三种时间控制模式

| 模式 | 写法 | 何时用 |
|---|---|---|
| **精确时间锚点** | `0-5秒：…` `5-10秒：…` | 强控制：卡点、必须在第 N 秒反转、品牌露出、延长片段的精确编排 |
| **画面编号** | `画面1：…` `画面2：…` | 中控制：知道内容顺序，但不确定每段该多长 |
| **动作流** | 用「然后 / 此时 / 紧接着 / 最后」串联 | 弱控制：一镜到底、情绪向慢节奏、单一连续动作 |

上表三种模式出自 2.0 社区时间轴指南。**官方三形态补充（2.5）**——官方《Seedance 2.5 提示词指南》把时间戳分成三种写法，前一种即上表的精确锚点，后两种是上表没有的：

1. **时间区间** `0-3秒：…`（同上表「精确时间锚点」）。
2. **明确时间点** `第5秒，镜头快速向左横移并完成转场`——用于卡准切点或转场，只标一个时刻，不给区间。
3. **相对时间** `她把玉牌按上桌面 2 秒后，裴无咎才抬眼`——用于因果反应镜（§4「先看清触发原因再给反应」），不必换算成绝对秒数。

三者都是**事件预算**，不是帧级剪辑点；**不要用时间戳规定频率**（如「一秒内完成三次动作」「每 0.5 秒眨一次眼」），频率类需求改写成可见动作序列或交给剪辑台。

**动作流的连接词本身就是节奏指令**：

| 连接词 | 暗示 | 模型倾向 |
|---|---|---|
| 突然 / 瞬间 / 猛地 | 极快，几乎无间隔 | 分配极短时间，动作迅猛 |
| 然后 / 随后 / 接着 | 自然过渡 | 分配适中时间 |
| 缓缓 / 慢慢 / 逐渐 | 慢速展开 | 分配较多时间，动作舒展 |
| 最后 / 最终 | 进入末段 | 知道要收尾 |

一镜到底**不要**切时间段——切了就有「断裂感」，用动作流反而更稳。

### 7.3 切几段：段数有上下限

| 视频时长 | 最少 | 最多 | 建议 |
|---|---|---|---|
| 4–6 秒 | 1（单一连续动作可不分段） | 3（6 秒 × 每段 2 秒） | 1–2 |
| 8 秒 | 2 | 4 | 3–4 |
| 10 秒 | 3 | 5 | 3–4 |
| 15 秒 | 3 | 6 | 4–5 |

上表出自 Seedance 2.0 时间轴指南，止于 15 秒。**30 秒（2.5）**：来源表没有这一行；2.5 官方与 `sd25-pe` 只要求按「阶段」组织、每阶段一个主要状态变化并写清结束状态，**不给固定段数上限**（`sd25-pe`：不要给出未经验证的最大时间段数量，事件过密时减少阶段而不是继续细分）。短剧实践可参考 §7.9 的五阶段，但那是叙事分配，不是段数硬限。

**4–6 秒行的口径说明**：来源表写 4–6 秒切 2–3 段。本项目按 models-failures §1.1 的动作单元下限 2 秒（层②）收紧：4 秒最多 2 段，6 秒最多 3 段。
**先判断要不要分段**：单机位、单一连续动作的 4–8 秒镜默认不分段。2.5 用【事件脚本】的开始时 / 主要事件 / 结束时；2.0 走 §10.2 路径 A 一段式，或用动作流连接词（§7.2）。
只有镜内有两个以上可分的事件，或用户要求卡点，才按本表分段。2.0 的 `镜头N` 等于一次分镜：同机位连续动作不要拆成两个 `镜头N`；确实要拆，第二段必须写明「承接镜头1、同一机位不切镜」。

- **下界**：每段太长就失去了控制意义。
- **上界**：承载动作的单段下限为 **2 秒**（见 models-failures §1.1 层②「动作单元 2–4 秒」，短于 2 秒会糊动或整段被跳过；🟢 低危动作可到 5 秒），且一段只装「一个镜头 + 一个反应」。
- **不要等分**：核心情节可以占一半以上时长，开场与收尾快速带过。
- **首段做建立、末段做收束**，中间才是叙事区。

### 7.4 每段写什么：四层结构

```text
镜头层（摄影机在做什么）＋ 主体层（画面里是谁）＋ 动作层（在做什么）＋ 氛围层（光影、情绪、环境声）
```

**四层不必每层都写**，按内容类型取舍：

| 内容类型 | 强化 | 弱化 |
|---|---|---|
| 氛围向（情绪铺垫、空镜） | 氛围层 | 动作层（只留光影移动、布料轻摆） |
| 动作向（打斗、追逐、快切） | 镜头层 + 动作层 | 氛围层（动作本身就是氛围） |
| 对话向（短剧主力） | 动作层里的台词与听者反应 | 镜头与氛围作辅助 |

**声音是隐藏的第五层**：用时间轴时一定要写声音，因为时间轴天然适合声画同步——
台词 `{}`、音效 `<>`、音乐 `()` 都可以绑到具体时刻。

### 7.5 时间密度：一秒该写多少字

| 档位 | 密度 | 适用 |
|---|---|---|
| 低密度 | 每秒约 5–8 字 | 情绪铺垫、空镜、留白；只写静态细节与光影 |
| 中密度 | 每秒约 8–15 字 | 短剧叙事主力：有镜头运动、有明确角色行为 |
| 高密度 | 每秒约 15–25 字 | 快切、打斗、卡点蒙太奇 |

**密度失控的三个警示信号**：

1. 单段描写超过 80 字，但只有 2–3 秒 → 删到 50 字以内，问「这 2 秒最重要的一个画面是什么」。
2. 总提示词超过 400 字却没有分段 → 模型会把全部内容当「一坨」，前半段堆积、后半段空白。
3. 相邻两段字数差超过 3 倍 → 重新平衡，把前段的次要信息挪到后段。

### 7.6 Seedance 2.0 的两种口径（重要）

| 口径 | 来源 | 说法 |
|---|---|---|
| A | 项目内 `sd2-pe` 合约 | 2.0 对精确时间支持不稳定，**只用 `镜头1 / 镜头2`，禁止绝对秒数** |
| B | 三份 2.0 实战指南 | 时间轴是 2.0 多镜头的核心写法，13–15 秒**强烈建议**用时间戳 |

两边都不能当耳旁风。**2.0 默认口径 = A（`sd2-pe`）**：分镜只用 `镜头1 / 镜头2`，正文不出现秒数。
下面的折中写法——保留镜头序号做主结构，把秒数作为时间预算写在括号里——**不符合 `sd2-pe` 的强制约束**（「镜头顺序优先于绝对时间，不要写 `0–3s` 等绝对秒数」），
只是两种解析方式都能读懂的例外写法：

```text
镜头1（0–5秒）：…
Cut to 镜头2（5–10秒）：…
Cut to 镜头3（10–15秒）：…
```

**决策规则**：默认（用户未要求卡点）按口径 A 交付，不写秒数；**仅在用户明确要求卡点 / 时间预算时**才用上面的折中写法，
并在交付说明里披露「已按用户要求写入秒数，偏离 `sd2-pe` 口径；2.0 对精确时间支持不稳定」。
2.0 走 `sd2-pe` 优化器时，它会把括号内的秒数当「绝对秒数」病灶报回——这是预期行为，不是要回头删掉用户要求的卡点；需要严格遵守 `sd2-pe` 时，删掉括号即可。
**不要**在同一条提示词里混用两套时间语义。另外：2.0 每 4–5 秒只安排一个主动作，塞多了容易出黑帧或直接失败。

### 7.7 段间过渡与留白

初级写法段段独立，高级写法在**上一段末尾或下一段开头植入过渡线索**：

| 过渡 | 做法 |
|---|---|
| 视觉过渡 | 前段收在某个视觉元素（推进到纯白），后段从同一元素开始 |
| 动作过渡 | 前段的动作延续到后段（推门 → 手仍保持推门姿势） |
| 声音过渡 | 前段作为背景暗示出现的声音，在后段成为主导（远处汽笛 → 站台汽笛） |

**留白区间**（仅适用于 §7.2 精确时间锚点模式的普通段；毫秒模式 §7.10、白模时间轴 §11 和 2.5 阶段句一律连续覆盖、不留白）：
精确锚点模式下可以故意留 1–2 秒空白（如 0–3 秒、5–8 秒），
模型会自行做过渡处理，衔接往往比逐秒塞满更自然。留白 **≤ 2 秒**（与 §14 一致），超过即有脑补风险。

### 7.8 时间轴的两个高阶用法

**分段绑定不同素材**——同一条提示词里，不同时间段可以引用不同参考（下例为 **2.5 写法**，编号按 §1 全剧固定约定：@图片8 首帧、@图片6 场景二、@图片9 临时占用为风格参考）：

```text
@图片8作为首帧。
该首帧定义开场时角色在街道上的位置、姿态、场景和镜头方向。
0-5秒：画面从@图片8定义的首帧自然开始，角色沿街道向前行走，运镜参考@视频1的正面跟拍，不采用@视频1中的人物与场景。
5-10秒：角色进入一扇门，室内场景参考@图片6，动作参考@视频2中的转身回望。
10-15秒：画面切换为@图片9的插画风格，角色继续行走但画面变成手绘感。
```

**首帧角色句独立成句，写在时间段之前**，不得弱化成「作为首帧画面」并与动作压在同一句（§0 / §9.2）。
**2.0 改写**：段头改为 `镜头1 / 镜头2 / 镜头3`（不写秒数，§10.1），首帧句改为第一段里的 `@图片8 作为首帧约束`（§10.4）；用户明确要求卡点时才按 §7.6 的 `镜头1（0–5秒）` 折中式。

**延长任务的时间轴是相对新增部分的**：写「1-4秒」指新增区间的第 1–4 秒，
不是原片 + 延长的总时间轴。这是做「连续剧式」逐段推进最省事的写法。

### 7.9 短剧节奏模版

**30 秒（2.5）五阶段**：

```text
0–5秒   开场：建立人物、场景与氛围（一个可见的钩子）
5–12秒  推进：人物开始行动，冲突正式发生
12–20秒 展示：核心信息／关键道具／关键对白
20–26秒 高潮：情绪或视觉的明确变化
26–30秒 收尾：一个明确的结束画面，留可承接的下一集钩子
```

**15 秒情绪弧线**：转折点放在 **60%–80% 的位置**（即第 9–12 秒）。
转折太早后面填不满，太晚观众来不及感受。

**动作密集脉冲（8 秒）**：每段 2 秒、每段换一种机位；
**第一段要「静」**（对峙、风声、落叶）——前面越静，后面爆发感越强；
**最后一段要「慢」**（缓缓回落、渐暗）——给高速打斗一个有重量的句号。

**每段收尾都要给「结束定格」**：写明这一段结束时画面停在哪，下一段才好承接。
**运镜位置**（时间轴分段内）：**段首**写景别 + 主运镜名（与 §1 规则 4「景别与运镜词前置」、§10.3 四要素顺序一致），
**段尾**只写该段的运镜到达状态 / 结束定格；不要把运镜动词埋在动作句中间。
（2.5 社区进阶指南的「运镜写段尾」指的是到达状态，不是运镜名；本文件统一按上述口径。）

### 7.10 毫秒级时间轴：能写，但要知道它管什么

需要台词起止、撞击落点、卡点或正反打切点精确对齐时，用毫秒记法：

```text
标准式：00:00.000–00:04.000：<内容>
短式：  0.000–4.000秒：<内容>
短剧常用：0.0–2.4秒（一位小数已足够，除非要对音乐卡点）
```

**每段带一个功能标签**，读起来就是一张拍摄日程：

```text
【0.0–2.4秒】｜正常行走｜<画面与动作>
【2.4–4.6秒】｜突然失去平衡｜<画面与动作>
【4.6–6.8秒】｜手机运动分析特写｜<画面与动作>
```

**能力边界（必须先认）**：官方写明时间戳**只能分配事件节奏，做不到帧级精准剪辑**。
所以毫秒写法的真实作用是两条：① 把「谁在第几秒说话、谁在第几秒落地」的**意图**说清楚，
提高对齐概率；② 给剪辑台一个明确的目标时刻。**最终对齐仍然发生在剪辑台**，不要向客户承诺逐帧。

用毫秒的四条纪律：

1. 只给**关键时刻**上毫秒：台词起止、撞击/落地、卡点、正反打切点；其余段落用一位小数或整数。
2. **前段结束时刻 = 后段开始时刻**，连续不重叠，覆盖到片尾。
3. 承载可见动作的单段不短于 **2 秒**（models-failures §1.1 层②动作单元下限，与 §7.3 一致；🟢 低危动作可到 5 秒）。
   毫秒记法只用来标注台词起止、撞击落点、切点这类**时刻**，不用来切出短于 2 秒的动作段；
   按 `sd25-pe` 口径时间段是事件预算，不承诺 0.5 秒以内的精度，最终对齐在剪辑台完成。
   0.3 秒是视频编辑的输出时长容差（§13），与分段无关。
4. 毫秒段落里**不要塞两个动作**。越精确的时间，越只能装一件事。

## 8. 模板 F｜两种实拍级逐镜骨架

§9／§10 的契约管的是「素材职责与任务路由」，这一节管的是**正文怎么排版**。
下面两套骨架都是实拍级短剧验证过的写法，按戏的类型二选一。

### 8.1 骨架一｜多道具实拍级（强控制）

适合：道具多、有物理事件（失手、掉落、碰撞）、需要逐段特写拆解、时间精度要求高的镜头。

```text
【基本规格】
风格：<电影级写实 + 时尚广告 + 都市街拍>｜运动质感：<运动流畅自然>｜
表演基调：<前半段意外与慌张，后半段逐渐掌控局面>｜台词语言：<用户指定的语种与口音／地区变体，如「使用英语」；用户未指定或无台词则删去本项，不擅自补>。
（总时长、画幅、分辨率、帧率只写在【工具配置】，不进正文——见下文「规格句的两种口径」）

【固定道具】
1. <道具一：形制、颜色、材质、数量>；
2. <道具二：形制、颜色、材质、数量>；
3. <道具三>；
4. <手持物或服饰>；
5. <屏幕内容等特殊素材：以上传的@图片N为准，不属于人物固定造型>。

【场景设计】
<地点、时间、光线、路面材质、背景建筑与人流密度>；<不要出现的时代或风格元素>。

【摄影语言】
使用<50mm／85mm／微距>镜头交替：正常行走段采用<低机位平稳跟拍>；
失手瞬间<快速推进>；运动分析段<高速摄影质感、主体锁定、背景轻微虚化>。

【完整分镜与时间轴】
【0.0–2.4秒】｜<段落功能>｜<镜头：景别 + 主运镜>；<主体动作>；<道具状态与归属>；<结束定格>。
【2.4–4.6秒】｜<段落功能>｜<镜头：景别 + 主运镜>；<承接上段的结束状态>；<一个主要动作>；<结束定格>。
【4.6–6.8秒】｜<道具特写>｜<镜头：景别 + 主运镜>；<该道具的运动轨迹、姿态与画面占比>；<结束定格>。
……
【<末段>】｜<收束>｜<最终画面状态>。

【全局约束】
保持<人物身份、五官、发型、服装、体型比例>与<道具数量、归属、外形>稳定；
<人物在冻结或慢速段仍保持自然呼吸、衣料与发丝的轻微运动>。
<2.0：追加 `面部稳定不变形，五官清晰，服装一致；画面流畅稳定、无抖动无闪烁`；2.5：不追加固定串，按 §9.8 条件表写本镜真实风险>
```

**规格句的两种口径**（这条容易出事）：

- 用户截图来源的原骨架把 `总时长约N秒｜比例｜fps` 写在正文首行当定调句；**本项目不采用**这一口径，正文首行只保留风格 / 运动质感 / 表演基调 / 台词语言的定调句（台词语言是创作内容不是接口参数，与 §4「台词语种要写明」一致）。
- **2.5**：时长、画幅、分辨率、帧率、seed、档位、声音开关一律只在【工具配置】（`sd25-pe` 参数分离；`sd25_compiler` 也把 `parameters` 与正文分开携带），
  正文用事件密度体现节奏，不写「生成一段 N 秒视频」。
- **2.0**：同样不进正文，只进顶层字段 `duration / ratio / resolution`。
- 用户已经写出的**事件时间段**（`0–3秒：…`）属于创作内容予以保留；与接口时长冲突时改用不带数字的「阶段」组织，
  **不按顶层字段反向改写正文数字**，也不据接口时长新造时间段（`sd25-pe` 长视频与时间段规则；2.0 正文仍按 §7.6 默认不写秒数）。
- **帧率一律不进正文**（Seedance 2.5 官方帧锚为 24fps、97–721 帧覆盖 4–30 秒，不要写 30fps）：打戏镜的 `24fps` 只出现在 [performance-action.md](performance-action.md)「帧率单一口径」规定的防崩后缀里，
  正文不得另写任何 fps 数字（写「运动流畅自然」这类可观察词代替）——两个孤立的帧率数字会造成变速抽帧。

**道具清单要编号**，并写死数量与归属——「一部橙色三摄手机」「一个带木盖的外带咖啡杯」这种写法，
比「一些随身物品」稳定一个数量级。屏幕内容、招牌文字这类必须精确的元素，
按 §9.12 的边界做成图片素材上传，不要让模型原生生成。

### 8.2 骨架二｜固定机位对白（弱运镜、强表演）

适合：一镜到底的对白戏、办公室/客厅/车内的情绪戏、喜剧节奏、口播感内容。

```text
【整体设定】
<横屏/竖屏>真人质感<题材>短片，<风格>。（时长与比例只在【工具配置】，不写「生成一段约 N 秒视频」）
固定<正面/侧面>机位，<中景偏半身>构图，全程不推拉、不摇移、不切镜。
画面是<核心环境与前景物>：<可见细节与保持项>。

【附件人物】
<素材 token>作为形象参考，保持相同的脸、发型、服装和身体比例。
真人皮肤质感，<柔和正面光>，表演<略带夸张但保持真人可信感>。

【动作与对白】
0–3秒：<动作>，<面部线索>，（<语气>）：{<台词>}。
3–5秒：<承接上段>，<一个新动作>，<可见反应>。
5–8秒：<动作升级>，（<语气变化>）：{<台词>}。
8–12秒：<行为失控或情势反转>，<环境反馈>。
12–15秒：<收束事件>，<最终画面状态>。

【声音】
保留<角色人声、对白、动作音效、环境声>；对白口型准确，声音清晰。
全程<无字幕、无背景音乐>。

【全局约束】
固定<正面单镜头>，背景保持<静止清晰>，<关键区域>位置固定。
角色全程保持<同一张脸、相同发型、服装和身体比例>；
表情变化连贯：<怀疑 → 发现 → 震惊 → 生气 → 失控 → 惊恐>。
手部动作清晰自然，避免额外手指、肢体变形、人物换脸、物体穿帮、图标复制或融化；
<特殊效果的安全边界，例如：爆炸采用无伤亡、无血腥的夸张喜剧效果>。
```

两个值得抄的细节：

1. **情绪变化链写成一行**：`怀疑 → 发现秘密 → 震惊 → 生气 → 失控 → 惊恐`。
   比在每段里零散写情绪词更能让模型看出整条弧线，也方便你检查有没有跳拍。
2. **素材 token 原样保留**：平台界面显示 `{{Mixed 1}}` 就写 `{{Mixed 1}}`，显示 `@图片1` 就写 `@图片1`。
   `sd25-pe` 的素材引用保真规则要求不翻译、不改号——两种写法都合法，但**同一条提示词里只用一种**（2.0 只认 `@图片N` 形态，见 §11.7）。

### 8.3 两种骨架怎么选

| 这场戏的难点 | 用哪套 |
|---|---|
| 道具多、有掉落碰撞、需要逐个特写拆解 | 骨架一 |
| 时间精度要求高（卡点、撞击帧、正反打切点） | 骨架一 + §7.10 毫秒时间轴 |
| 一镜到底的对白、情绪递进、喜剧节奏 | 骨架二 |
| 人物少、运镜几乎不动、靠表演和台词推进 | 骨架二 |
| 既要多道具又要长对白 | 拆成两镜，别在一条提示词里同时要精确物理和长台词 |

两套骨架都只是**正文排版**：素材职责、`【未采用素材】`、首尾帧角色句、任务路由，
仍然按 §9（2.5）或 §10（2.0）的契约执行。
**用 2.0 时**，骨架一的 `【0.0–2.4秒】` 与骨架二的 `0–3秒：` 段头一律换成 `镜头N：`（§10.1 红线；毫秒 / 秒数只保留在分镜表和剪辑说明，不进正文），
用户明确要求卡点的例外按 §7.6 处理。

## 9. Seedance 2.5 契约

### 9.1 逐镜标准提示词（主力）

`【生成目标】【参考素材职责】【未采用素材】【对白账本】【事件脚本】【保持一致】` 与 `sd25_compiler` 的输出标签同名同序；`【主体与关系】【镜头】【声音】` 是人工扩展段（编译器不生成，机器编译时并入 `goal`；编译器的【事件脚本】【保持一致】为固定句，逐镜细节写进 `goal`）。**删掉用不到的段落，不要留空占位**（`【未采用素材】` 除外：按 §1 全剧固定上传 @图片1–8、@视频1、@音频1–2 时，任何单镜都有未激活编号，只要集合非空就必须保留并逐个列号——`sd25_compiler` 在生成 / 编辑 / 延长三类任务里都会输出这一段）。

```text
【生成目标】
<景别>+<运镜>，<谁>在<哪里><做什么>；本镜承担<建立/施压/揭示/反转/收束>。

【参考素材职责】
@图片1用于<角色A>的五官、发型和<服装>，不采用图片背景与构图。
@图片5用于<场景>的空间布局、陈设和光线方向，不采用图中人物。
@图片7用于<道具>的结构、材质和颜色，不采用素材背景。
@音频1用于<角色A>的音色、语速和情绪，不覆盖本条台词文字。

【未采用素材】
@图片6、@视频1未参与本镜，不用于人物、场景、道具、动作、镜头或声音。

【主体与关系】（人工扩展段）
本镜共<N>人：<角色A>、<角色B>。
<角色A>始终在<稳定物>的<内/外侧>，面向<方向>；<角色B>在<另一侧>，两人隔着<稳定物>。
全场只有一件<道具>，开始时在<谁>的<哪只手>。

【镜头】（人工扩展段）
<景别>，<机位高度与角度>，<一个主运镜>：作用于<主体>，从<起始状态>向<方向>运动，到达<结束状态>。
起幅：<首帧画面> → 落幅：<末帧画面>。

【对白账本】
<角色A>用<音色/语速/情绪>说：{<台词原文>}；<角色B>自然闭口聆听。

【事件脚本】
开始时：<人物位置、道具归属、场景与光线的可观察状态>。
主要事件：<一个连续动作>；<1–3 条可见表演线索>；触发原因先被看清，人物反应随后发生。
结束时：<人物位置、道具归属、运动趋势与声音状态>——该状态原样充当下一镜的开始状态。

【声音】（人工扩展段）
<环境层>，<动作音效层>；<是否有音乐>。

【保持一致】
保持<人物身份与服装>、<道具数量与归属>、<空间内外站位与轴线>、<光向>和<说话人关系>稳定；
同一主体全程是一个连续对象，不重复、不分裂。
```

> 2.5 不追加固定稳定串（`面部稳定不变形…无抖动无闪烁` 是 2.0 的兜底包，见 §6 铁律 3、4 的两种口径）；
> `【保持一致】` 按 §9.8 条件表逐条写本镜真实存在的风险，与 `sd25_compiler` 的输出一致。

#### 【对白账本】的四种写法

§4.1 的对白 / 旁白 / 独白三分法，落到 2.5 的【对白账本】是下面四种句式（句首的「画内 / 画外 / 旁白」与 `Sd25DialogueEntry.position` 同值）：

```text
画内对白：画内的<角色A>使用<语言>，音色参考@音频1，以<表达方式>说：{…}；其他人物自然闭口聆听。
多人对话（按先后逐条写，一条一人一音频）：
  第一句：画内的<角色A>使用<语言>，音色参考@音频1，以<表达方式>说：{…}；<角色B>自然闭口聆听。
  第二句（<角色A>话音落下并出现<可见反应>之后）：画内的<角色B>使用<语言>，音色参考@音频2，以<表达方式>说：{…}；<角色A>自然闭口聆听。
旁白：旁白（画外，不出镜），音色参考@音频N，以<表达方式>说：{…}；画面中所有人物自然闭口、不做口型。
独白：画外的<角色A>内心独白，以<表达方式>说：{…}；画面中的<角色A>自然闭口、不做口型，其他人物自然闭口。
```

多人对话填写示例（祠堂对峙合成一镜，6 秒，两句合计 16 字，约 2.7 字/秒，不超 §1 规则 8 的上限，余量留给听者反应）：

```text
【对白账本】
第一句：画内的沈昭雪使用普通话，音色参考@音频1，以压低声音、语速偏慢、尾音收紧的方式说：{这块牌，是你亲手给我的。}；裴无咎自然闭口聆听。
第二句（沈昭雪话音落下、裴无咎垂眼看向玉牌之后）：画内的裴无咎使用普通话，音色参考@音频2，以语气平直、语速偏慢的方式说：{我不记得了。}；沈昭雪自然闭口聆听。
```

1. **编译器字段映射**：对白对应 `position=画内`；独白对应 `position=画外`，并在 `goal` 里补「<角色A>自然闭口不做口型」（编译器的账本句尾固定是「其他人物自然闭口聆听」，不含说话人本人）；旁白对应 `position=旁白`。
2. **台词原文 `{}` 全条只出现一次**，放在【对白账本】。【事件脚本】和时间轴段里只写「说出对白账本第 N 句，自 X 秒起、至 Y 秒落下」，不再贴 `{}` 原文——同一句贴两遍，模型有概率说两遍。
3. 正文不得出现「同上」「不重复」这类给人看的说明。

#### 填写示例（S03-01，多图参考，6 秒）

```text
【生成目标】
中景缓慢推近，沈昭雪在祠堂供桌外侧把玉牌按上桌面并直视裴无咎；本镜承担施压与关系翻转。

【参考素材职责】
@图片1用于沈昭雪的五官与低髻，@图片2用于她的月白斗篷与妆造，两张共同定义同一个人物，不采用图片背景与构图。
```

### 9.5 全模态（图 + 视频 + 音频）

短剧最强的一档：**图定身份、视频定动作与运镜、音频定音色**。三者职责严格切开——

**四条纪律**：

1. **动作视频只借维度**：动作、运镜、节奏、时序中选需要的写清楚，其余明确「不采用」。
   视频已经把动作给准了就只声明继承哪些维度，不要再逐动作复述——复述会与素材本身打架。
2. **音色与台词分离**：台词内容以文字为准，音频只给音色、口音、语速、情绪；要复用音频台词才明说。
3. **语言写明**，不擅自补口音。
4. **稳定性**：视频/音频驱动的主体 1–5 个，单段参考 5–10 秒，视频与音频各自总时长 ≤ 30 秒。

#### 向前延长（补前情）

向前延长是**独立模板**，不是在向后延长模板上追加一句：边界方向相反（延长片段的**最后一个画面**衔接原视频**首帧**），照抄向后模板会同时出现「承接尾帧」与「首帧作为结束状态」两个互相矛盾的方向。先描述原视频开始之前发生的内容，再把原视频首帧写成延长片段的明确结束状态：

```text
@视频1是需要向前延长的原视频。

向前延长@视频1。在原视频开始之前，<前置动作、事件、镜头或声音>。

延长片段的最后一个画面自然衔接@视频1的首帧：保持<主体姿态与朝向>、<道具位置>、<背景与空间关系>、<机位与构图>、<光线>、<声音状态>和<运动趋势>一致。

延长过程中保持人物身份与服装、关键道具、背景布局、摄影轴线和原有声音环境连续。
同一主体始终是一个连续对象，不重复、不分裂；人物外形与物体部件数量保持稳定。
只属于原视频后续的角色、道具或特效不得提前出现。

【未采用素材】
@图片N、@视频N、@音频N未参与本镜，不用于人物、场景、道具、动作、镜头或声音。
```

只写「随后承接原视频」会让模型提前引入后续人物、道具或特效，或到达目标状态后再次改变画面，所以末句的「不得提前出现」不能省。

方向从上下文判断不出来时（只说「延长」「续写」），**先问一次**放在原片之前还是之后，不要猜。
源片 ≤ 30 秒，单次新增 4–30 秒，延长后结果 ≤ 60 秒。

#### 填写示例（只把红色信封换成玉牌，visual 范围）

`@视频1` 是 S03-03 的成片（7 秒，无台词），供桌上的道具被误生成为红色信封；画幅与时长不变，属于真编辑，不加消歧句。

```text

编辑@视频1，只把供桌正中的红色信封修改为@图片7中的青白玉牌。

【编辑对象与范围】

【时间线继承】
玉牌继承红色信封每次出现、运动、遮挡和离开的时点、路径与速度变化：开场被沈昭雪右手压住，她收回手后留在供桌正中，直到片尾不再移动；
其他动作、镜头、口型和事件顺序保持原样。

【未采用素材】
@图片1、@图片2、@图片3、@图片4、@图片5、@图片6、@图片8、@图片9、@音频1、@音频2未参与本任务，不用于人物、场景、道具、动作、镜头或声音。
```

「先改再续」时（§1 规则 1）先跑本条编辑，拿到改好的成片后再把它作为新的 `@视频1` 走上面的向后延长，两步不合并。

- **范围句必写一条**：只换道具却不写 visual 范围句，原声轨可能被整体重生成；只改声音不写 audio 范围句，画面会被重绘。
- **闭环句另一种取值**：要删掉未点名主体时（`sd25_compiler` 的 `edit_scope_closure=delete_unspecified`），闭环句改为
  `除以上明确保留对象外，删除@视频1中的其他可见主体；不新增未指定对象。`——两种闭环二选一，不能都不写。
- **稳定建议**：编辑母版 @视频1 尽量 ≤ 20 秒，目标素材参考图 1–5 张（6–8 张会降低稳定性，models-failures §1.5）；超出仍可提交但要标注风险。

**路由闸门**（与 `sd25-pe` 的画幅与时长兼容性闸门一致，三选一顺序：先判编辑，再判延长，其余才是生成）：

- 目标画幅与原视频不同 → **不是编辑**，按普通生成处理，并在【生成目标】的目标句后紧跟一句 `请注意这不是视频编辑。`；
- 目标时长与原视频相差超过约 0.3 秒 → **不是编辑**：用户明确要求向前/向后续写的按本节「向后延长 / 向前延长」处理（**不加**消歧句），
  其他时长变化按普通生成处理并加消歧句；
- 只有画幅与基本时长一致（或均未指定）**且**用户要求修改原片中的明确对象/区域/声音时才是编辑。

`请注意这不是视频编辑。` 仅在上述规格冲突进入生成时添加；真编辑、视频延长、首帧/首尾帧任务和没有规格冲突的普通生成都不加。

### 9.8 `【保持一致】` 里写什么

限制是用来**收敛已经写清楚的内容**，不是补救没写清楚的内容。先消除自相矛盾，再按下表筛，通常 3–8 条：

| 类别 | 只有满足这个条件才写 |
|---|---|
| 身份稳定 | 有已命名人物，且存在变脸、换装、复制、人数变化的可能 |
| 结构稳定 | 有关键道具，存在变形、数量漂移、归属漂移的可能 |
| 物理正确 | 有打斗、追逐、抛接、喷洒或多人换位 |
| 摄影正确 | 多人同框或有明确左右关系 |
| 文字与品牌 | 明确要求无字幕、无品牌，或画面中会出现文字载体 |
| 声音边界 | 有对白或指定音效，存在被音乐盖住或错位的可能 |

**2.5 不要**自动添加画质包、稳定包、水印、Logo、分身约束——那是 2.0 的规则。

### 9.9 编辑的另外两种形态

除 §9.7 的主体替换外，官方还给了通用编辑与背景替换两种写法。

**通用编辑（改光、改属性、改一小块）**：

```text
【编辑目标】
编辑@视频1，在<全片或明确时间段>对<画面对象、区域或声音类别>进行<增加、移除、替换或调整>。

【原视频职责】
@视频1是唯一编辑母版，负责<人物、场景、动作、构图、镜头、遮挡关系、声音和事件顺序>。

【目标素材职责】
@图片1或@音频1用于<目标对象或声音的指定属性>。

【编辑对象与范围】
只处理<对象、区域、时间段或声音类别>，全片目标对象数量为<数量>。
除以上明确修改对象外，@视频1中其他可见人物、道具和背景元素保持原样，不参与替换或删除。

【时间线继承】
<目标对象或属性>沿用<原对象>每次出现、运动、遮挡和离开的时点与时长；其他人物动作、镜头运动、镜头切换和事件顺序保持@视频1。

【保持内容】
保持@视频1中的<不应变化的画面、动作、声音和时间关系>。

【未采用素材】
@图片N、@视频N、@音频N未参与本镜，不用于人物、场景、道具、动作、镜头或声音。
```

范围闭环句（局部修改 / 删除未指定主体，二选一，见 §9.7）**每条编辑 Prompt 都不能省**——缺闭环时未点名的人物、道具、背景会被随意改动，是编辑任务的主要废片来源。

> 示例：`编辑@视频1，只在4-7秒把画面右侧墙面的冷蓝色灯光调整为暖橙色灯光。除以上明确修改对象外，@视频1中其他可见人物、道具和背景元素保持原样，不参与替换或删除。`
> 并补一句 `人物肤色随环境光自然变化`——只改光时，被照对象的连带变化要说清楚，否则会出现人物「浮」在新光里。

**背景替换**（短剧换景省搭景钱的主力）：

```text

【目标素材职责】

【编辑对象与范围】

【时间线继承】
人物动作与遮挡关系保持@视频1。除以上明确修改对象或区域外，@视频1中的其他人物、道具、场景内容、
镜头运动、镜头切换和事件顺序保持原样。

【未采用素材】
@图片N、@视频N、@音频N未参与本镜，不用于人物、场景、道具、动作、镜头或声音。
```

**声音编辑**：

```text

在@视频1尾部，<主体或前景物>通过<动作>触发转场。
镜头<运动方向和速度变化>，画面中的<形状、材质、光线或空间>逐渐变化为@视频2开头的<对应元素>。
转场结束时自然到达@视频2的开头构图，并保持<主体位置、镜头方向和运动趋势>连续。
声音从<前段声音>平滑过渡到<后段声音>。
```

五种转场各自要写清的东西：俯冲/折返（镜头方向、速度、何时进入下一场景）、人物旋转（姿态、旋转方向、服装或背景如何连续变化）、
前景遮挡（遮挡物何时覆盖全屏、遮挡后的构图）、物体变形（前后物体的形状、材质、变形过程）、推拉或焦点变化（镜头运动、焦点对象、前后空间的连续关系）。

### 9.12 能力边界（九条，写之前先认清）

1. 时间戳只能分配事件节奏，**不是帧级剪辑点**。
2. 视频编辑能提高关键事件与原片对齐的概率，但**不保证逐帧重合**。
3. 多素材的重点是**正确选择和组合**，不是让 50 份素材同时出现在画面里。
4. 必须完全准确的字幕、公式、标牌、产品参数，**做成图片素材上传**，别让模型原生生成。
5. 视频编辑锁画幅与基本时长，输出可能有约 0.3 秒差异。
6. 首帧/首尾帧以首帧画幅锁比例；首尾比例不同会让尾帧拉伸。
7. 视频延长锁画幅；延长片段音量可能与原片有轻微差异。
8. 一键成片中，图片顺序或人物对应关系重要时必须显式指定。
9. 无缝转场追求视觉与声音连续，**不代表两段原片能逐像素不变**。

**省钱铁律**：新场景先用 **4–8 秒**验证画面方向，风格对了再出 30 秒。

### 10.1 语法红线（违反直接掉片）

| 红线 | 正确写法 |

### 10.4 首帧 / 首尾帧（2.0 写法）

2.0 没有 2.5 的精确角色句，帧约束写在**第一段的主体定义之后**：

```text
@图片8 作为首帧约束；@图片9 作为尾帧约束。
画面从首帧构图自然开始，经<一个连续动作>到达尾帧构图，中途不换机位、不切镜。
```

多人或多图时，**必须显式写清谁在左、谁在右、谁是首帧**——方位/帧位映射不明是 2.0 四类关键歧义之一，
宁可停下来问一次，也不要让模型自己分配。

### 10.5 多图参考与全模态（2.0 写法）

```text
<主体1> 的面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）；

```

- 同一主体多素材：`将 @图片1 中的[…]、@图片2 中的[…] 定义为 <主体1>`。
- 音色还原不佳时，在提示词里补一句细致音色描述，并让台词风格贴近参考音频语气。
- 多人正面动态镜头：**强方位约束 + 固定机位 + 双胞胎兜底**三件套同时上，否则必穿模跳脸。

### 10.8 时长策略与超 15 秒拼接

| 时长 | 适合 | 写法 |
|---|---|---|
| 4–8 秒 | 单动作、单转场、产品/道具展示 | 聚焦 1–2 个核心画面，可以不分段 |
| 9–12 秒 | 一个完整小场景 | 分 2–3 段 |
| 13–15 秒 | 完整叙事 | 强烈建议分段（默认 `镜头1 / 镜头2 / 镜头3`；用户要求卡点时按 §7.6 的折中写法并披露） |
| > 15 秒 | 一整场戏 | **分段生成 + 视频延长拼接** |

拼接流程：生成第 1 段（≤15 秒）→ 把成片上传为 `@视频1` → 第 2 段写 `向后延长@视频1，…`。
**每段必须写衔接点：上一段的结尾状态 = 下一段的开头状态**，否则接缝处会跳。

### 10.10 七个高频报错与修法

| 症状 | 修法 |
|---|---|
| 跨镜头人脸变了 | 每次都上传同一张脸图作 `@图片1` 并显式引用；别靠文字描述长相 |
| 黑帧或生成失败 | 每 4–5 秒只留一个主动作；分辨率从 2K 降到 720p；长时间轴拆短 |
| 提示词被审核拦截 | 减少显式人脸文字描述，改用 `@图片` 参考；避免真人姓名与「写实人像」同现 |
| 音画不同步 | 先关音频只生成画面，再二次补音；长对话拆成短句 |
| 手指扭曲 | 加目标手势参考图；一条提示里别安排多个同时进行的手部动作 |
| 成片有塑料感 | 删掉泛化的「电影感」，换成具体材质、真实光照、镜头型号 |
| 画面文字乱码 | 不要指望模型渲染屏幕文字与招牌，后期加 |

> 同一套提示词结构连续失败 3 次以上，通常是**复杂度过高**，不是平台故障。
> 先简化到能出片，再逐步把元素加回来。

### 10.11 2.0 的合规与素材边界

- **不接受含写实真人脸部的上传素材**（图片与视频都会被拦）。短剧要么用风格化形象，要么用已获授权的素材。
- 审核偏严，人脸相关尤其容易触发过滤；被拦时先减少人脸文字描述再重试。
- 不支持 LoRA，特定视觉只能靠提示词与参考图逼近。
- 商用授权条款尚不明朗（曾有版权方向字节发出停止侵权函）。涉及可识别角色或真人肖像的客户交付，
  **发布前先确认授权边界**——这条与提示词写法无关，但比提示词更能决定项目能不能交。

## 11. 模板 G｜白模驱动的资产替换（变量化模板）

白模（预演动画 / 灰模 / 空镜调度片）跑通动作与运镜后，用正式资产图把人、道具、环境一次性换上。
这是短剧动作戏与多人调度戏最省成本的路径：动作只演一次，形象可以反复换。

### 11.1 先定路由：这是生成，不是编辑

**白模视频是参考素材，主任务仍是「视频生成」。** 常见写法陷阱：

| 写法 | 后果 |
|---|---|
| ✗ 「编辑{{Video 1}}，把白模人物替换为…」 | 被路由成视频编辑，画幅与时长被白模锁死，资产替换退化成局部修图 |
| ✓ 「{{Video 1}}是白模参考，仅提供…；<粗粒度：保持其中<几何体>的轨迹并对应<角色A>｜细粒度：将其中的<白模主体>重渲染为<角色A>>」 | 正确进入生成，画幅与时长可自由设置 |

目标画幅或总时长与白模不同时（**最常见：白模 16:9 预览 → 成片 9:16**），
按 `sd25-pe` 在【生成目标】的目标句后紧跟一句 `请注意这不是视频编辑。`——这是路由消歧声明，不是画面负向约束。

先判白模粒度（决定模板走哪一支）：

- **粗粒度**：简单几何体只提供动作路径、站位、进出场、机位、运镜、切镜、光影节奏 → 每个几何体必须单独映射。
- **细粒度**：结构、动作、场景已完整，只换形象与材质 → 保持原结构、动作、空间与镜头。

**白模承载的五类信息**（写职责句时逐类对照，漏一类模型就自行发挥一类）：

| 类 | 白模提供什么 | 职责句要写到 |
|---|---|---|
| 动线 | 谁从哪到哪、停在哪 | 人物轨迹、前后关系、相对距离、进出场 |
| 运镜 | 机位起止与路径 | 机位与摄影机运动 |
| 光照 | 光源变化的时点与方向 | 光影变化节奏 |
| 切镜 | 切点位置与数量 | 切镜时点，只保留白模已有切点 |
| 声音 | 动作音效/台词的时点 | 声音时序 |

**核心动词按粒度分**（与 `sd25_compiler` 的输出一致）：粗粒度句式用「保持白模的…」（几何体只对应到角色，不「重渲染」），
细粒度用「将…重渲染为…」。官方测试集口径：**粗粒度当前更稳，官方推荐优先**，能用粗粒度就不用细粒度。

| `blockout_granularity` | `blockout_granularity`（`coarse` / `fine`） |
| `standin_has_limbs` | `blockout_standin_limbs` |
| `characters[].image` | `assets[]`，`role="character"`，**`required=true`** |
| `props[].image` | `assets[]`，`role="prop"`，**`required=true`** |
| `environments[].image` | `assets[]`，`role="scene"`，**`required=true`**（俯拍图另加 `overhead_view=true`，该声明只对已采用素材输出） |
| 未采用编号 | `assets[].required` 默认 `false`；凡本镜要激活的角色/道具/环境图必须显式 `required=true`，否则编译器的 `_used_refs` 只认锚定引用（首尾帧/关键帧/源视频/九宫格/白模/对白音频）与 `required=true` 的素材，会把它们整体列入 `【未采用素材】`（实测按旧表填 `@图片1(character)`、`@图片5(scene)` 不设 required → `UNUSED=['@图片1','@图片5']`） |
| `story_one_line` + `story_summary` | `goal` |
| 阶段关键帧（如有） | `keyframe_refs` + `keyframe_stage_ends` |
| `duration_seconds` / `aspect_ratio` | `parameters`（编译器按任务自动摘除被锁定项） |

### 11.7 2.0 的写法差异

同一套变量在 2.0 下渲染成三段论：第一段做主体定义与白模声明，第二段用 `镜头1 / 镜头2`（**不要秒数**）
承载 `segments`，第三段挂风格与兜底包；`visual_style` 走顶层 `style_caption`，正文不重复。
白模仍写成参考（`参考 @视频1 的相机轨迹、人物动作与光影变化`），不要写成 `严格编辑 @视频1`。
2.0 的 `ref_style` 固定为 `@图片N / @视频N / @音频N`（`sd2-pe` 统一标准，Ark 适配器也按此桥接）；`{{Video 1}}` / `@Video 1` 只用于 2.5，在 2.0 里等同裸写、没有语义标识。

### 11.8 先判断：这个镜头值不值得上白模

**看素材**——适合白模的镜头：5–10 秒、单一连续镜头、一个清晰主体、没有严重运动模糊、运镜中等且可预测、遮挡少。
走秀、转身、简单舞蹈、产品演示最好用；快切、甩镜、复杂手部编排、超快运动最容易让结构判断失准。

**看收益**：

| 值得上 | 可以不上 |
|---|---|
| 人物必须沿固定路线穿过特定空间 | 简单固定机位、人物只有小幅动作 |
| 多人需要在指定位置会面或停下 | 只要「大致正确」、不在乎精确路径 |
| 多机位切换有明确顺序和时长 | 4 秒以下的短镜（搭白模比多抽几次还慢） |
| 环绕、跟拍这类路径需要避开遮挡 | — |

白模不消灭抽卡，它把最贵的那种抽卡——**成片返工**——换成生成之前几乎不要钱的路径调整。

**三层分工**要记牢，缺哪层模型就自己瞎补哪层：

```text
骨架层：白模管运动、几何、构图、运镜
身份层：角色图管长相、体型、服装
场景与风格层：提示词管环境、光影、材质
```

### 11.9 五条实战硬规则

1. **映射是承重墙**。白模里每个几何体都要单独认领（「高圆柱体对应讲解员、长方体对应移动展车」）。
   漏一个，模型自己瞎分配；多人场景尤其要写死「视频里的人物2 对应 图片1 里的女工程师」。
2. **替身尽量别带四肢和翅膀**。官方口径是优先用关系清楚的简单几何体；替身若带四肢，
   **必须**写出完整分段的肢体力学（身体前倾角度、步幅、重心、布料动态），否则四肢僵化。
   官方测试集里那组「一副骨架四个世界」之所以成立，正是因为每段都把肢体力学写清了。
3. **正文一个运镜词、景别词都不要写**。「镜头右摇」「推近」「切到特写」「中景」一旦出现，文字运镜与白模运镜会成为
   两套竞争指令。实测把正文压到极简、只强调「@视频1 是唯一镜头与调度参考」，服从度最高。
   运镜跑偏时第一件事不是改白模，而是检查正文里有没有残留镜头语言。
4. **高位俯拍参考图要单独声明**。场景图里若有俯拍角度，必须写明它只补充屋顶排列、道路宽度等空间结构，
   **不提供机位、不改变白模运镜**，否则整段会被带成俯拍。
5. **细粒度白模导出前先清场**：隐藏轨迹线、坐标轴、控制器、相机锥体——模型不认识这些是制作标记，
   会当成画面内容渲进去。

> 第二、三、四条在本项目的 `sd25_compiler.py` 里有对应实现：
> `blockout_standin_limbs` 在缺少分段动作序列（正文无 `0-5秒` 类区间）时告警，正文出现运镜词或景别词时告警，
> `Sd25Asset.overhead_view=true` 自动补上「只补充空间结构与布局……不提供机位，不改变运镜」的声明。
> **第一条（逐几何体映射）编译器不校验**：`Sd25CompileRequest` 没有 `blockout_marker` 字段，编译器既不核对角色数与几何体数，
> 也不生成逐几何体映射句，只输出一句固定的「逐个几何体映射到输入已声明的最终人物或道具」——映射必须人工写进 `goal` 的【主体映射】。

### 11.10 白模从哪来（按门槛从低到高）

| 路径 | 做法 | 坑 |
|---|---|---|
| 预演台（一张场景图起步） | 传 1–3 张带空间结构的正面/斜角场景图生成 3D 白模，加方块人、设机位、画走位轨迹、录制导出 | 纯俯视图会让白模塌陷；**动作片段与路径片段必须等长**（30fps×30 秒 = 900 帧，指预演台导出片段的帧数，不是 Seedance 的输出帧率），否则人跑 30 秒、空间只移动 4 秒；自动机位参数要检查俯仰角 |
| **AI 草稿反推**（最反直觉、最省事） | 先用文字随便生成一段视频，不求画质，只求站位、走位方向与运镜大致对，把它当粗粒度白模参考重新生成 | 多花一次草稿积分，换来第二次生成的调度完全可控 |
| 图生 3D 手搭 | A-pose 角色图 → Tripo / Meshy 出模并绑骨 → Blender K 走位与相机动画 | 门槛最高，但路径最可控 |
| 引擎物理 | 重力、碰撞、流体这类模型算不准的，先在三维里做「物理正确但很丑」的 block-out，模型只当渲染滤镜 | 业内叫混合渲染：动作合理性交给引擎，观感交给模型 |

## 12. 模板 H｜连续性：第 2 镜起的六锚点（版本无关）

| 锚点 | 写法 |
|---|---|
| 人物 | 身份、五官、发型、服装、配饰、伤痕全程不变 |
| 空间 | 布局、光源数量与方向、关键陈设位置不变 |
| 动作 | 本镜起幅 = 上镜落幅，动作完成度衔接在五到八成处 |
| 情绪 | 上一镜的残留情绪带进本镜，不做情绪瞬切 |
| 道具 | 数量、归属、手别；交接后原持有人不再持有 |
| 光影 | 主光方向、色温、光比不跳变 |

**轴线要每镜复述**：分段生成时每条提示词是独立请求，模型看不到上一条里的轴线声明，
不复述第二镜就会左右对调（上一镜自左向右的动作，下一镜从右边回来）。

### 12.1 七锁系统（一集开工前先建资产锁）

六锚点是逐镜的检查项，七锁是**整集的资产层**。开拍前先把不会变的东西写死，再进镜头。

| 锁 | 锁什么 | 写法要点 |
|---|---|---|
| Character 人物锁 | 脸型、五官、年龄、发型发色、身材比例 | 写一段「人物 DNA」，固定信息与可变信息分开 |
| Costume 服装锁 | 服装、配饰、妆容 | 与人物锁分开写，换装戏才好管理 |
| Scene 场景锁 | 建筑结构、门窗位置、道路方向、家具与灯位 | 写「场景 DNA」，不可变项与可变项分开 |
| Prop 道具锁 | 外形、材质、颜色、尺寸、磨损 | **编号管理**：`PROP-01 沈家旧白玉佩` |
| Direction 方向锁 | 银幕方向、视线方向、光线方向 | 左→右跑的人，下一镜别变右→左 |
| Action 动作锁 | 起点、过程、终点 | 逐镜记 Action State，见 §12.2 |
| Emotion 情绪锁 | 情绪起点与残留 | 上镜情绪不瞬切 |

**人物 DNA 的固定 / 可变二分**（这是关键，不分开就会锁死表演）：

```text
固定：脸型、五官、年龄、发型、服装、饰品、身材比例
可变：表情、眼神、姿势、动作、情绪、衣服是否被雨水打湿
原则：人物身份固定，人物状态变化
```

**场景 DNA 同理**：不可变是建筑、道路、门、桥、房屋位置；可变是雨量、烟雾、灯光、火焰、门是否打开。
这样场景可以持续变化，但不会变成另一个地方。

**道具不是只有「有／没有」**，要记三件事：**在哪里 + 谁拿着 + 什么状态**。
写成道具状态表：`镜01 腰间 → 镜05 右手握住 → 镜07 放回腰间 → 镜20 被夺走 → 镜21 在对手手中`。

### 12.2 把 50 镜当成 50 个状态

不要理解成 `镜01 → 镜02 → …`，而要理解成 `状态01 → 状态02 → …`：
站立 → 听见声音 → 回头 → 发现来人 → 握紧玉佩 → 拔剑 → 冲刺 → 闪避 → 对峙。

每镜生成前记一张**镜头状态卡**，末行就是下一镜的起点：

```text
人物位置：画面中央偏左        身体方向：面向画面右侧
头部方向：朝向后方            左手：靠近腰间        右手：握住剑柄
视线：锁定来人                道具：玉佩位于腰间左侧
情绪：警觉                    环境：暴雨            景别：中景
结束状态：右脚向前迈出半步   ← 下一镜从这里开始
```

**动作三段式**：任何动作都拆成 `准备 → 执行 → 结束`，分别落在相邻的镜头里。
拔剑＝手移向剑柄／握住并拔出／完全出鞘进入攻击姿态。
**一镜只给一个核心动作**——「转身、拔剑、跑步、跳跃、旋转、挥剑，同时镜头环绕推进」是典型的提示词过载。

### 12.3 分段生产与检查点

**不要 50 镜一次性生成**，按 5–8 镜一个连续段落推进，每段结束设一个连续性检查点：

- 人物：脸、发型、服装是否一致？
- 场景：建筑位置、道路方向是否一致？
- 道具：数量、归属、状态是否对得上？
- 动作：本段最后一镜是否接得上下一段第一镜？

**检查不过就不要继续生成下一镜**，先修。整集用一张总表管理：

| 镜号 | 人物状态 | 场景状态 | 道具状态 | 动作状态 | 结束状态 |
|---|---|---|---|---|---|
| 01 | 站立 | 宅门前 | 腰间 | 静止 | 听见声音 |
| 02 | 警觉 | 宅门前 | 腰间 | 抬头 | 准备回头 |
| 03 | 回头 | 宅门前 | 腰间 | 转头 | 看向身后 |

### 12.4 逐镜连续性提示词块（第 2 镜起粘贴）

```text
【人物锁】固定使用同一人物 DNA，不改变脸型、五官、年龄、发型、服装、身材比例。
【场景锁】固定使用上一镜相同场景，不改变建筑结构、道路方向和主要空间关系。
【道具锁】固定使用相同道具，保持外形、材质、颜色、尺寸和当前状态一致。
【上一镜结束状态】<原样抄上一镜状态卡的末行>。
【本镜动作】从上一镜结束动作自然继续，人物首先<…>，随后<…>，最终<…>。
【身体状态】身体方向<…>，头部方向<…>，视线方向<…>，双手状态<…>，脚步状态<…>。
【镜头】景别<…>，机位<…>，镜头从<…>向<…>移动。
【情绪】从<…>变化为<…>。
【本镜结束状态】人物<…>，道具<…>，视线<…>，身体方向<…>。
【连续性】与上一镜无缝衔接，人物身份、脸型、发型、服装、道具、场景结构、空间方向保持一致，
不发生变脸、换装、道具消失、建筑变化、人物瞬移和动作跳跃。
```

用 2.5 时把这一块折进 `【主体与关系】` 与 `【保持一致】`；用 2.0 时放在三段论的第一段与第三段。

## 13. 交付格式：正文与配置分离

```text
【静帧提示词】
（如本镜先出分镜图：§5.2 或 §5.5 的完整正文）

【提示词正文】
（§9 / §10 / §11 任一契约的完整正文；§8 骨架只是其排版）
```

| 任务 | 会被输入自动锁定的参数（2.5） |
|---|---|
| 视频编辑 | 画幅与基本时长（输出可能有约 0.3 秒差） |
| 首帧 / 首尾帧生成 | 画幅由首帧图锁定；时长可设 |
| 视频延长 | 画幅锁定；延长时长可设 |

### 拆镜与时长

| 目标长度 | 模型 | 切法 |
|---|---|---|
| 22 秒 | 2.5（cap 30） | `[22]` 不拆 |
| 22 秒 | 2.0（cap 15） | `[11, 11]` 均分 |
| 40 秒 | 2.5（cap 30） | `[20, 20]`——不是 `[30, 10]`，均分更稳，避免 10 秒段内容密度崩塌 |

**2.5 超 30 秒的承接方式二选一**。① 向后延长：源片不超过 30 秒、单次新增 4–30 秒、结果不超过 60 秒，按 §9.7 写。
② 独立生成第二段：先出第二段起幅静帧（§5），它等于第一段落幅，再走 §9.2 首帧模式。两种都必须复述轴线与光向（§12）。

成片只要 1.5–2.5 秒的高风险动作镜：**按 4 秒下单生成，剪辑台裁出**，不要把 1.5 提交给 `duration`。
