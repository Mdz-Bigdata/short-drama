# Seedance 2.5 中文手册补充：提示词公式、续写与转场用语

> 来源：飞书《【即梦】Seedance 2.5 使用手册》(bytedance.larkoffice.com/wiki/RXh5ww6EqighMdkVTMccm2d4n7e，中文版，2026-09-21 修订，2026-10-15 读取)。
> 时长与素材上限以 `seedance-2-5-video-director/references/capabilities-and-limits.md`(英文版快照)为准，
> 本次核对中文版数字一致：输出 4–30 秒(97–721 帧)；单次最多 30 张图、10 段视频合计 ≤30 秒、10 段音频合计 ≤30 秒；
> 视频延长要求底片 ≤30 秒、单次延长 4–30 秒、套娃累计至 60 秒；超长视频模式最长 180 秒。
> 本文只收中文版里能直接写进本项目提示词的公式与固定说法，用本项目的话整理。

## 一、四种提示词公式

| 场景 | 公式 |
|---|---|
| 基础 | 素材描述 + 一句话概述 + 具体情节描述 + 全局补充（结尾） |
| 30 秒长视频 | 总述一句 + 【多模态参考层】 + 【全局设定】 + 【时间戳剧本分镜】 |
| 超长视频 | 全局参数（时长、画幅，开头再强调一次） + 素材描述 + 一句话概述 + 分时间段情节 + 全局补充 |
| 续写/延长 | 引用原视频 + 延长方向与秒数 + 衔接约束 + 新增区间的动作或场景 |

各部分写法：

- **素材描述**：按上传顺序编号，逐个写用途（人物 / 音色 / 动作 / 场景）。全文可以多次 @ 同一素材，越多越准。
- **一句话概述**：主体 + 地点 + 事件 + 题材或风格 + 特殊运镜。
- **具体情节**：按时间段或故事线写。每段含 ➕ 正向（画面内容、运镜、动作、台词、音效）与 ➖ 反向（不要字幕、不要 BGM 等）。
- **全局补充**：结尾再强调一遍贯穿全片的东西——机位、环境特征、整体声音氛围、光影——以及全片都不要出现的元素。

## 二、30 秒长视频的三个模块

1. **多模态参考层**：基于上传的[素材类型]，严格保持 @图N 的人物面孔一致，保持 @图M 的构图/空间关系一致，锁定人物站位。
2. **全局设定（世界观 + 防崩坏）**：基础环境与质感（时间、地点、氛围，强调真实物理质感） + 视觉风格（写实/二次元、景深、打光）
   + 镜头语言（景别视角与整体运镜） + 人物造型 + 表演核心（成片最想强调的东西） + **禁止项**。
3. **时间戳剧本分镜**：`[00:00 - 00:06] 镜头一：【运镜名】` 下分「情感潜台词 / 音频设计 / 动作与物理指令」三行。
   时间戳精确到秒（甚至 0.1 秒）时，动作在指定时刻发生的稳定性最好。

## 三、人物造型细分公式（真人与动画通用）

| 项 | 公式 |
|---|---|
| 发型 | 发色 + 头发状态与质感 + 发型名称 + 与环境的互动（被风吹、凌乱） |
| 服装 | 版型剪裁 + 颜色 + 服装名称 + 面料与新旧 + 穿法细节 |
| 眼神 | 眼神形容 + 目光传达的信息或比喻 + 透出的底层情绪 |
| 体型气质 | 骨架与肩部特征 + 构图或镜头要求 + 动作与视线 + 整体氛围词 |

故事主体部分已写了构图、镜头、动作时，体型气质一项只保留骨架与氛围词，避免两处描述打架。

## 四、续写与延长的固定说法

- 必须出现方向词之一：向前延长 / 向后延长 / 延续 / 续写，并写明延长秒数。
- **一镜到底式延长**加：要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。
- **带切镜或转场的延长**加：需要在切镜处使用"<转场名>"转场（禁止生硬切镜、禁止物体凭空出现），要求必须自然切换场景，
  并写明前后景别（如"由战士的近景自然切换为游侠的中景"）。
- 延长的提示词只作用于新增区间，原视频部分保持不变。

## 五、中文转场用语

| 转场 | 一句话写法 | 适用 |
|---|---|---|
| 淡入淡出 | 画面 A 逐渐暗至全黑（或全白），画面 B 从黑暗中慢慢浮现 | 开头、结尾、时间流逝 |
| 叠化 | A 缓慢变透明的同时 B 逐渐显现，重叠 1–2 秒 | 回忆、梦境、抒情过渡 |
| 白闪 / 黑闪 | 瞬间闪白（或闪黑）一下，极速切入下一画面 | 卡重音、紧张刺激 |
| 擦除 | B 像推拉门从一侧平滑推进，把 A 完全盖住 | 复古风格、明显换地点 |
| 遮罩 | 镜头推进被某物完全挡黑，穿过黑暗后已是新场景 | 空间跨越 |
| 相似物 | 上一镜最后一帧与下一镜第一帧形状/轮廓/颜色相近，无缝变过去 | 蒙太奇 |
| 动作 | 用相似动作（柔和）或冲突动作（有力）衔接两镜 | 动作戏、变装 |
| 水墨 | A 像浓墨滴入清水般晕开消失，B 从散开的墨迹中浮现 | 古风、人文、回忆 |

每种都要补同一句约束："禁止生硬切镜、禁止物体凭空出现，要求必须自然切换场景"。

## 六、其他可直接用的说法

- **干净底片**：要画面不被乱加字幕和配乐，写"纯净视频，无字幕，无背景音乐"。
- **去 BGM 留人声**："去除 @视频1 的背景音乐，只保留人物对白与环境音，画面与字幕保持不变"。
- **多宫格分镜参考**：先声明"@图1 为完整分镜脚本，共 N 个连续镜头，每格代表一个完整镜头，而非单独的人物或场景"，
  再逐个映射角色/道具/场景参考，最后逐镜写景别、运镜和动作。推荐简约线稿或火柴人分镜图。
- **多人同框**：每个人物单独 @ 一张参考图并写清身份，写"身份清晰不串脸、数量准确、主次分明"，防"双胞胎脸"。
- **局部编辑**：`[标注工具与位置] + [修改对象] + [变成什么] + [生效时间段]`，如"将红框内的羊替换成一匹棕色的马，
  动作轨迹与原片一致，仅在第 7–15 秒期间"。
