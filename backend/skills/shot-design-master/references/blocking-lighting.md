# 站位、场景圣经与光色

多人同框时，**先定站位，再定光，最后才写动作**。站位决定谁是主体、谁是压迫者；光决定情绪；两者定了，画面就不会散。

---

## 一、站位公式

每条公式都给「站位含义 + 可复制提示词」。花括号 `{}` 为替换位。

> **本章编号只有一条序列**：`0` 九字段模板 → `1`–`5` 站位公式（`5` 为派生站位）→ `6`–`11` 派生与扩展条目。`6`/`7` 按人数细分（双人 / 三人以上），`8` 是覆盖面最广的分类总表（`1`–`5` 均可在其中找到对应行），`9`–`11` 补充空间、一致性与整段模板。第四章灯光的 `4.1`–`4.4` 是灯光章自己的编号，与本章的 `4.` 递进站位无关。

### 0. 九字段站位模板（多人同框首选）

多人镜头统一用这套 `【字段】` 结构填写，比一句话公式更稳、也更容易被下游解析。

```text
【场景】{地点}对峙场景，{站位公式名}
【主角】（角色描述），{主角站位与气场}
【副手】（角色描述），{相对主角的位置}
【随从】（角色描述），{排列方式}
【环境】（详细描述场景环境与氛围）
【光影】（光源位置、光线特征、明暗对比）
【机位】{景别与角度}，突出{强调对象}，层次分明
【风格】电影级CG渲染，史诗国风，8K超高清
【氛围】（氛围描述），戏剧张力强，视觉震撼
```

三套站位对应的字段取值：

| 字段 | 中心聚焦 | 双方对峙 | 三角包围 |
|---|---|---|---|
| 场景 | `{地点}对峙场景，半包围弧形站位` | `{地点}对峙场景，双方左右对称站位` | `{地点}`（古代闺房 / 朝堂大殿 / 仙境洞府 / 江湖厅堂） |
| 主角/主体 | 居中站立，气场强大 | 正对对方，气场强大 | 三人围坐或对峙，中心人物位于画面中心，光线聚焦 |
| 副手 | 左右对称，配合主角 | 位于主角身侧，辅助气势 | —（用「站位」字段代替） |
| 随从 | 半包围排列，衬托主角 | 左右对称排列，人数递减 | — |
| 站位 | — | — | 三角半包围站位，左右及侧前方两人，视线均看向中心人物 |
| 动作 | — | — | 三人正在（议事/对峙/论道/商谈），气氛（紧张/肃穆/深沉） |
| 光影 | 中心光源聚焦主角，周围渐暗 | 主光源聚焦对峙中心，四周暗化 | 戏剧性光影，中心人物重点补光，明暗对比强烈 |
| 机位 | 正面中景，突出主角，层次分明 | 正面中景/全景，突出对峙空间与人物关系 | — |
| 构图 | — | — | 稳定构图，中心突出，三角构图增强张力 |

**通用使用要点**

| 维度 | 要求 |
|---|---|
| 核心 | 主角始终处于画面视觉中心（对峙式则为双方对称、突出对峙张力） |
| 对称 | 左右人物对称排列，增强稳定感 |
| 景深 | 通过前中后景深强化空间层次；对峙式利用纵深增强压迫感 |
| 光影 | 主光源聚焦核心，四周渐暗 |
| 氛围 | 根据剧情选择合适的环境氛围 |
| 情绪 | 通过人物表情与姿态传递情绪 / 冲突感 |
| 细节 | 服饰、道具需符合时代背景与身份 |

**四类场景取值参考**

| 站位 | 可用场景 |
|---|---|
| 中心聚焦 | 庭院对峙、朝堂对峙、云海宗门、江湖门派 |
| 双方对峙 | 市井街头对峙、金銮朝堂对峙、云海仙山对峙、江湖林地对峙 |
| 三角包围 | 闺房三人围坐议事、朝堂三方君臣对峙、仙洞三位修士论道、江湖厅堂高手会谈 |

**三角包围的适用场景细分**

- 室内：议事、对峙、密谈、传承、质问
- 朝堂：君臣对峙、权谋博弈、审判定夺
- 仙侠：论道、比试、传功、天机预言
- 江湖：商议、结盟、谈判、恩怨化解

### 1. 中心聚焦站位

**站位含义**：主角居中，左右配角对称站位，后方随从半包围排布，形成层次感和聚焦感。

**适用**：对话、立场展示、气场营造。

```text
中心聚焦站位，主角居中，左右配角对称站位，后方随从半包围排布，形成层次感和聚焦感。
场景风格为{风格关键词}，氛围{氛围关键词}，画面清晰，构图对称，戏剧感强。
```

> 示例：`中心聚焦站位，主角居中，左右配角对称站位，后方随从半包围排布，形成层次感和聚焦感。场景风格为古风日常，氛围温馨，画面清晰，构图对称，戏剧感强。`

**要点**：主角始终在画面视觉中心；左右配角对称平衡画面；后方群演半包围增强层次与聚焦。

### 2. 三角包围站位

**站位含义**：关键人物位于画面中心，周围三方人物形成三角半包围结构，视线全部投向中心人物，突出中心，增强戏剧张力。

**适用**：对话、冲突、审讯、谈判、决策等需要强化主角的场景。

```text
三角包围站位，关键人物位于画面中心，周围三方人物形成三角半包围结构，
视线全部投向中心人物，突出中心，增强戏剧张力。
场景风格：{古风日常/权谋朝堂/仙侠玄幻/江湖武侠}，氛围：{温馨/紧张/神秘/肃杀}，
光影：{自然光/烛光/仙光/光影对比}，画面构图：中景/近景，高清，电影质感。
```

### 3. 双方对峙站位

**站位含义**：画面左右两大阵营分别站开，中间留出对峙空隙；双方主角各自出列靠前，目光对视。

**适用**：对峙、谈判破裂、开战前、摊牌。

```text
双方对峙站位，画面左右两大阵营分别，中间留出对峙空隙。
双方主角各自阵营靠前，目光对视，气氛紧张，随从/副手身后站开。
场景为{古风日常/权谋朝堂/仙侠玄幻/江湖武侠}，环境氛围{市井街头/朝堂之上/云海之巅/江湖客栈外}，
光影cinematic，高清电影质感。
```

**要点**：双方阵营对称站位突出对立冲突感；主角向前一步强化戏剧张力；中间留出空隙营造对峙氛围。

### 4. 递进站位（四种阵型）

| 阵型 | 站位含义 | 可复制提示词 |

| 豪门家眷列队 | 身份由后到前逐级抬高，主角站最靠前 C 位，仆从后排依次退后，体现尊卑层级 | `古风豪门府邸庭院，家眷与仆从梯队递进站位，核心主角站画面靠前中心，随仆从向后逐层靠后排布，人物错落，前后拉开距离，午后柔和自然光，古风叙事镜头，8K 超清，AI 原生影像` |
| 门派弟子梯队 | 掌门在前，弟子分两列向后逐层退后，突出掌门核心地位 | `古风山门广场，掌门站画面靠前中心，弟子分成左右两列向后梯队式排布，人物前后拉开层次，山间漫射柔光，仙侠氛围感，8K 超清，AI 原生影像` |

### 5. 派生站位（由上述公式推导）

| 场景 | 站位写法 |
|---|---|
| 二人对话正反打 | `双人中景，{A}立于画面左侧、{B}立于画面右侧，两人视线在画面中线相交；正反打全程保持 {A} 在左 {B} 在右，不翻转` |
| 审讯 | `三角包围站位，被审者居中偏低（坐/跪），审问者立于其斜前方两侧俯视，第三人守门位于画面深处，视线全部投向被审者` |
| 一对多压迫 | `主体居中靠后且画面占比偏小，四周人物半包围向内挤压，前景以肩背虚化遮挡形成框中框，强化被围困感` |
| 群像亮相 | `中心聚焦站位 + 递进站位叠加，核心三人站前排一字排开，其余人物向后两侧梯队散开，前后拉开纵深` |

### 6. 两人站位六式（双人戏首选）

> 不同站位传递不同关系与情绪。先定关系，再定站位。

| 站位 | 含义 | 适用场景 |
|---|---|---|
| 1 正面相对 | 面对面站立，情感对峙或深入交流 | 争吵、告白、谈判、对话 |
| 2 并排站立 | 并肩站立，关系亲密或目标一致 | 伙伴关系、共同面对挑战、亲密互动 |
| 3 错位站立 | 一前一后，突出层次与主次关系 | 保护、跟随、隐秘关系、权力对比 |
| 4 侧身对话 | 侧身面向对方，更自然的交流感 | 日常对话、情感沟通、温馨场景 |
| 5 背对背站立 | 背对背，表现矛盾、决裂或防备 | 争执后冷战、立场对立、防备心理 |
| 6 镜像站位 | 对称站位，视觉平衡，关系平等 | 平等对话、谈判、相互理解 |

**拍摄小贴士**

- 根据剧情选择合适站位，强化角色关系与情绪表达。
- 注意人物间距与镜头构图，避免拥挤或空洞。
- 结合光线、角度与环境，提升画面层次与氛围感。

### 7. 三人及以上站位八式

**四条核心原则**

| 原则 | 要求 |
|---|---|
| 关系清晰 | 通过站位体现人物关系，主次分明，层次清晰 |
| 视觉平衡 | 构图稳定，疏密有致，避免呆板，保持动态感 |
| 情绪统一 | 站位与情绪、剧情基调保持一致，强化氛围 |
| 动线引导 | 利用站位引导视线，聚焦关键人物或冲突点 |

**八种经典站位形式**

| 形式 | 特点 | 适用 |
|---|---|---|
| 三角形站位 | 稳定有力，层次分明 | 表现权力、情感的制衡 |
| 一字横排站位 | 简洁大气，气场强大 | 展示团体气势或对立 |
| 梯形站位 | 错落有致，立体感强 | 表现层级或阵营关系 |
| 圆形 / 半圆形站位 | 亲密包围，氛围感强 | 家庭、团队或亲密关系 |
| 分组对立站位 | 冲突感强，对立明确 | 表现矛盾、谈判、对抗 |
| 前中后纵深站位 | 纵深感强，空间层次丰富 | 表现复杂关系或悬念 |
| 交错站位 | 灵活生动，避免呆板 | 日常互动或剧情推进 |
| 中心突出站位 | 突出主角，聚焦视线 | 强调核心人物或主题 |

**站位与镜头的配合**

| 镜头 | 配合建议 |
|---|---|
| 全景镜头 | 使用对称或梯形站位，增强画面稳定感 |
| 中景镜头 | 使用三角形或交错站位，突出人物关系 |
| 近景镜头 | 围绕核心人物布局，弱化背景干扰 |
| 运动镜头 | 预留动线空间，便于推、拉、移、跟拍 |

**四条注意事项**

- 避免所有人站在同一水平线上，显得呆板。
- 注意人物间距，避免拥挤或过于分散。
- 避免背对镜头或遮挡关键人物面部。
- 结合光影方向，增强立体感和戏剧效果。

> 好的站位，是故事的无声语言，也是情绪的视觉表达。

### 8. 八大固定站位法（覆盖 99% 人物关系）

**通用站位公式**

```text
场景类型 + 角色站位方式 + 轴线关系 + 镜头景别 + 镜头运动 + 情绪目标 + 适用场景
```

> 例：`双人对话场景 + 左右固定站位 + 保持对话轴线同侧 + 中近景正反打 + 轻微推镜 + 强调眼神交流和情绪变化 + 适合采访/谈判/情感戏`

| 站位法 | 做法 | 适用 | 镜头调度 |
|---|---|---|---|
| 1 核心镜头站位 | 主角永远在画面中心或黄金分割点；配角在其左右前后形成视觉平衡；静态场景用三角形或对称站位 | 对话、宴会、集体场景 | 远景建立空间 → 中景强化关系 → 近景突出情绪，缓慢推拉或小幅平移 |
| 2 对话切换站位 | 主角固定在左或右，与对话对象成「镜像站位」；保持 90° 或略侧身，换镜时眼线一致；眼线方向与肩膀转向统一 | 一对一或多人对话 | 正反打、肩上镜头、中近景切换 |
| 3 三角关系站位 | 关键动作留在画面安全框内；配角不遮挡主角；用「前中后三层站位」 | 打斗、追逐、舞蹈 | **景别按动作链递进（全景建立 → 中景交手 → 近景/局部特写打击 → 全景交代结果），禁止全程中景**；摄影机可小幅弧形滑移，不跨越主关系轴 |
| 4 空间象征站位 | 高位象征权力、低位象征从属；心理距离对应空间距离；正式用对称、冲突用非对称 | 权力场景、情绪冲突 | 仰拍高位人物、俯拍低位人物、缓慢推进 |
| 5 运动固定站位 | 用标记点固定关键位置，角色移动路线固定，保证多镜切换位置一致 | 空间移动的多镜头场景 | 跟拍、侧拍、前跟、后跟，运动方向保持一致 |
| 6 对称仪式站位 | 主角固定在中轴线上，配角左右对称，人数、距离、姿态尽量对称 | 婚礼、会议、审判、发布会、正式登场 | 正面镜头、居中构图、缓慢推镜或静态 |
| 7 冲突对峙站位 | 两组角色固定左右，中间预留空白「张力空间」；主角站队伍前方 | 争吵、谈判、帮派对峙、审讯、决战前 | 远景建立阵势 → 中景加强压迫 → 沿中轴缓慢推进 |
| 8 前后中景层次站位 | 前景放辅助人物或遮挡元素，中景放主角，背景放次要人物或环境 | 情绪戏、悬念铺垫、空间展示 | 纵深推镜、横向平移、景深变化 |

> 「三角关系站位」是**构图法**（主体 + 两个前后景配角构成三角），不是景别规定——打戏用它锁定人物在空间里的三角关系，景别仍按 performance-action.md §3.5 五镜动作链走。全程钉死中景，观众既看不清打击点落在哪，也读不出胜负进程，一场打戏会摊平成一段无重音的乱动。

**第 4 / 6 / 8 式的可复制提示词**（其余五式的模板见本章 `1.`–`5.` 与附录「公式 1–7」）

```text
空间象征站位（上表第 4 式）
主角站在高处象征权力，配角低处或远处象征从属，通过高低位、距离远近、对称/非对称等
站位表达权力、关系或情绪。
场景风格为{权谋朝堂/仙侠宗门/江湖门派}，氛围{紧张/肃杀/神秘}，光影{硬光/侧光/逆光}。

对称仪式站位（上表第 6 式）
主角居中，左右配角对称排列，画面构图以中轴线为核心，营造庄重、正式、秩序感强的视觉效果。
场景风格为{婚礼/会议/审判/家族仪式}，氛围{庄重/肃穆/正式}，光影{柔和自然光/烛光}。

前后中景层次站位（上表第 8 式）
画面建立前景、中景、背景的纵深轴线，前景安排辅助人物或遮挡元素，中景放置主角，
背景安排次要人物或环境人物，镜头沿空间纵深缓慢推进或横向平移，强化层次感、空间感和氛围感。
场景风格为{古风庭院/仙侠洞府/江湖客栈}，氛围{神秘/悬疑/唯美}，光影{侧光/逆光/柔光}。
```

### 9. Z 轴舞台：从「贴纸」到「立体」

新手习惯用「左边有什么、右边有什么」描述站位——在 AI 眼里那是一张二维平面图，人物与背景分离，这就是**摆拍感**的来源。必须强制把画面分成**前景 / 中景 / 后景**三层。

```text
✗ 两个人站在房间里，左边是男主，右边是女主。
✓ 前景是虚化的男主肩膀（占据画面左下角），中景是站在3米外的女主，后景是纵深向外的走廊。
   女主位于画面正中心偏右。
```

**坐标要用几何语言**，不要用模糊的「面对面」：

```text
男主位于画面左三分之一处，女主位于右三分之一处，两人中间隔着宽大的办公桌。
过肩镜头，焦点在女主脸上，男主肩膀虚化占据画面底部。女主直视镜头（看向男主）。
```

**用站位打心理战**

| 关系 | 写法 |
|---|---|
| 上下位不对等 | `男主站立低头注视（中景），女主瘫坐在地板上抬头仰望（仰视特写）` |
| 疏离 | `两人站在画面两端，中间是大面积的空地毯。通过超广角强调巨大的空间隔阂` |
| 亲密 | `两人站在画面中心，额头几乎相触。通过滑动变焦或微距镜头强调呼吸交错的距离感` |
| 群像（三人以上） | **倒三角站位**：`前景中心是反派BOSS（坐姿，占主导），后景左右两侧分别是保镖和秘书（站立，偏向两侧），形成稳定的三角构图` |

> 三人以上切勿让 AI 排成一排；群众场面也不能像做团体操一样整齐排列。

**动态站位**：静态站位定完后，要告诉 AI 镜头怎么动来改变空间关系。
`镜头缓慢右移。画面从两人的中景开始，随着镜头右移，前景的遮挡物逐渐挡住男主，画面最后只剩女主一人，暗示决裂。`

### 10. 站位一致性三解法（防止人物乱跑）

| 解法 | 写法 |
|---|---|
| 锚点道具 | `女主一直站在打开的冰箱门后面，只露出半张脸。男主一直坐在客厅的沙发上` |
| 参考图锁位 | `@图1 作为首帧参考图。图1中人物站位保持不变，图1中的女主在左，图1中的男主在右。生成后续动作时，必须保持这个左右站位关系` |
| 角色记忆卡 | 在分镜表里定义：`男主在任何双人场景中默认在右侧（观众视角），女主默认在左侧`，再通过反打切换，避免 AI 随机生成 |

### 11. 三大经典场景整段模板

**霸总对峙 —— 强调「权力的距离」**

## 二、180° 轴线与越轴防治

1. 一场戏开拍前先定**关系轴线**：两个角色之间的连线即为轴线，所有机位只能在轴线的同一侧取景。
2. 一旦定下 `{A}在画面左、{B}在画面右`，本场所有镜头（含特写、过肩、反打）都必须维持该左右关系。
3. 提示词中显式写死：`{A}始终位于画面左侧，{B}始终位于画面右侧，正反打遵守180度轴线，左右关系不翻转`。
4. 必须换边时，插入一个**过轴镜头**：跟拍越过轴线、或先给一个中立正面镜（人物正对镜头）再换边。
5. 负面词固定挂：`axis flip, broken eyeline, mirrored blocking, screen direction reversal`。

**五类轴线提示词（直接抄用）**

| 轴线 | 提示词 |
|---|---|
| 180° 运动轴线 | `保持180度轴线一致。摄像机始终位于动作线同一侧拍摄，角色A在画面左侧，角色B在画面右侧，两人对话时保持空间位置关系不翻转` |
| 视线轴线 | `保持视线轴线一致，角色A看向右侧，角色B看向左侧，形成呼应关系。视线方向与被看物体/人物位置对应` |
| 对话轴线（正反打） | `双人对话使用正反打镜头，过肩拍摄。角色A的镜头从右后方越过角色B的肩膀，角色B的镜头从左后方越过角色A的肩膀。保持视线匹配` |
| 角色位置轴线 | `群体场景中保持角色相对位置。主角站在中央，配角A在左侧，配角B在右侧，镜头切换时三人位置保持不变` |
| 镜头运动轴线 | `明确角色A起点、终点、转折点和经过位置，镜头推轨从近到远，始终朝同一方向移动，镜头跟随角色时保持与角色运动方向一致，避免镜头运动与角色运动方向冲突` |

## 三、场景圣经（Scene Bible）

同一场戏的所有镜头共享一份场景圣经，写一次、全场继承，避免背景随机发挥。

```text
【场景圣经 · {场景名}】
空间布局：{进门方向 / 主要陈设及其相对位置 / 景深纵向层次}
人物左右站位：{A}恒定画面{左/右}，{B}恒定画面{左/右}，{C}位于{前景/中景/背景}{方位}
关键道具位置：{道具1}在{位置}（由{角色}的{左/右}手持有），{道具2}在{位置}，全场不移动
主光方向与色温：主光自{方向}射入，{硬光/柔光}，色温{冷/暖}，{K值或色名}
前中后景层次：前景{元素}，中景{元素}，后景{元素}
恒定不变项：{墙面材质 / 地面状态 / 天气 / 时间 / 光源数量}
可破坏元素（打戏必填，文戏删除本行）：{元素}允许{破坏形态}，破坏后不复原，该状态即新的恒定不变项；未列入者一律不许变
```

后续每一镜只写「本镜与场景圣经的差异」，不重述整个空间。

## 四、灯光

### 4.1 动机光源（Motivated Light）

每一处光都要有画面内的来源：火把、烛台、窗、灯管、屏幕、月光、车灯。提示词写法：

```text
唯一动机光源为{光源}，{颜色}光自{方向}打亮{被照部位}，
{未被照亮的部位}沉入{暗部色调}但保留{材质}细节，光比{X:1}
```

> 示例：`唯一动机光源为火把与窜起的祭火，琥珀橙火光自下而上打亮 <主体1> 下半张脸与袍摆，人物上半张脸与背景祭坛沉入深青冷蓝暗部但保留石质纹理细节，光比8:1`

### 4.2 光质与光比

| 参数 | 取值 | 情绪含义 | 提示词 |
|---|---|---|---|
| 硬光 | 边缘锐利、阴影分明 | 冷峻、对抗、审判 | `硬光，硬质投影，边缘锐利` |
| 柔光 | 过渡平滑 | 温情、回忆、脆弱 | `柔光，漫射光，过渡柔和` |
| 低光比 2:1 | 明暗接近 | 日常、平静 | `低光比 2:1，暗部通透` |
| 中光比 4:1 | 有立体感 | 常规叙事 | `中光比 4:1` |
| 大光比 8:1 | 半张脸沉入黑 | 危险、悬疑、反派 | `8:1大光比，暗部保留细节` |
| 极端剪影 | 只余轮廓 | 神秘、未揭晓身份 | `逆光剪影，仅保留轮廓边光` |

### 4.3 光位

| 光位 | 效果 | 提示词 |
|---|---|---|
| 顺光 | 平、无戏剧性 | `正面顺光，面部均匀` |
| 侧光 / 伦勃朗光 | 立体、内心挣扎 | `45度侧光，颊部三角形亮区（Rembrandt lighting）` |
| 逆光 / 边光 | 轮廓分离、神性或危险 | `逆光边光勾出发丝与肩线轮廓（rim light）` |
| 顶光 | 眼窝成阴影、压抑 | `顶光直下，眼窝落入阴影` |
| 底光 | 反常、恐怖、恶意 | `底光自下而上打亮下半张脸` |
| 三点布光 | 标准人物光 | `主光+辅光+轮廓光三点布光` |

### 4.4 一句话光色模板

```text
{方案名}，主色{主色}，辅色{辅色}，动机光源为{光源}，{光质}，光比{X:1}，{冷暖关系}，暗部保留{材质}细节
```

> 示例：`方案E低照度青调，主色深青冷蓝灰，辅色琥珀橙与炭黑，动机硬光，8:1大光比，冷暖分离，暗部保留石质纹理细节`

## 五、色彩

1. **主色 / 辅色制**：每个项目只定一组主色 + 一到两个辅色，全片不换。
2. **冷暖分离**：人物用暖（琥珀橙 / 肤色暖调），环境用冷（深青 / 冷蓝灰），靠色温差把人从背景里拔出来。
3. **青橙分级（teal & orange）**：短剧最通用的电影感分级，暗部压青、肤色提橙。
4. **低饱和**：写实题材统一 `低饱和`，避免 AI 默认的高饱和塑料感。
5. 常用题材配色：

| 题材 | 主色 | 辅色 | 分级 |
|---|---|---|---|
| 古装权谋 | 深青冷蓝灰 | 琥珀橙、炭黑 | 青橙分级、低饱和 |
| 都市悬疑 | 冷蓝、水泥灰 | 霓虹品红、钠灯黄 | 高对比、暗部压青 |
| 甜宠 | 暖米白、浅粉 | 奶茶棕 | 高明度、低对比 |
| 仙侠 | 月白、雾青 | 流光金 | 柔漫射、高光晕 |
| 民俗惊悚 | 暗红、墨绿 | 惨白烛光 | 高饱和撞色、大光比 |

### 1.0 演员调度三要素（写任何站位前必填）

> AI 视频模型在多人场景中极易出现视线错乱、面部朝向错误。必须在每个画面描述中明确以下三项：

| 要素 | 含义 | 提示词写法 |
|------|------|-----------|
| **① 站位** | 角色在画面中的空间位置 | `角色A位于画面左侧 / 舞台中央 / 门口` |
| **② 面部朝向** | 脸面向谁或面向哪个方向 | `面部朝向角色B / 面部转向镜头 / 面部朝向门口方向` |
| **③ 视线焦点** | 眼神看向哪里 + 情绪修饰 | `视线温柔地聚焦于角色B的脸 / 视线惊恐地扫视前方` |

**常用视线情绪修饰词：**

| 类别 | 词库 |
|------|------|
| 柔情类 | 温柔凝视 / 深情注视 / 充满爱意地聚焦 |
| 冲突类 | 轻蔑俯视 / 愤怒直视 / 不敢对视地低头 |
| 惊变类 | 惊恐扫视 / 失魂落魄地寻找 / 难以置信地望向 |

| ❌ 模糊写法 | ✅ 具体化写法 |
|------------|-------------|
| `OTS过肩镜头` | `过肩近景，从角色A背后拍摄，焦点在角色B脸上` |

| `低角度仰拍` | `从门口内侧低角度拍摄，角色占据画面上方` |
| `特写` | `特写，从角色A左前方45°角拍摄，焦点锁定眼部` |

### 1.1 八种基础站位法（行业通用底座）

| 序号 | 站位法 | 定义 | 调度建议 |
|:---|:---|:---|:---|
| 1 | **核心镜头站位** | 主角固定在画面中心或黄金分割点上，配角在其左、右、前、后形成视觉平衡 | 中远景建立空间；注意 **180 度运动轴线**与**视线轴线**一致，A 看右、B 看左，切忌翻转 |
| 2 | **对话切换站位** | 双人对话时使用「镜像站位」或「90 度倾斜侧身站位」 | 正反打（Shot-Reverse Shot）过肩拍摄，眼线高度与方向必须匹配 |
| 3 | **三角关系站位** | 主角在中景，两个配角在前景和背景形成三角形稳定构图 | 文戏可整镜中景；打戏景别按 performance-action.md §3.5 五镜动作链递进，不得全程钉死中景。摄像机可做小幅度弧形滑移，但不可跨越关系轴 |
| 4 | **空间象征站位** | 通过物理高低、远近表达权力或心理状态 | 强权者站立于高台（仰拍），被动者位于低处（俯拍），镜头轴线保持在同侧 |
| 5 | **运动固定站位** | 多镜头场景中，明确标记角色移动的起点、转折点和终点 | 镜头跟随方向与角色运动方向完全一致（前跟/后跟/侧跟），避免视线轴错乱 |
| 6 | **对称仪式站位** | 沿中轴线将角色左右对称排列，体现正式、庄重、秩序 | 正面居中构图，缓慢直线推镜（Dolly In） |
| 7 | **冲突对峙站位** | 将两组阵营分立左右两侧，中间留出空白区域作为「张力空间」 | 由全景（交代阵势）切换到中景，沿中轴线缓慢推进 |
| 8 | **前后中景层次站位** | 利用道具或次要角色作前景遮挡，中景放主角，背景是环境 | 镜头横向平移，通过景深变化（Rack Focus / 焦点转移）转移焦点 |

### 1.2 七大可复制站位公式

> 每条公式给出：**站位含义 → 站位图 → 中文可复制模板（带 `{}` 槽位）→ 英文可复制模板 → 运镜与景别建议 → 常见崩坏**。
> 三个通用槽位含义固定：`{场景风格}` = 场景类型 + 美术风格（如「夜晚高层公寓客厅，电影感写实」）；`{氛围}` = 情绪氛围词（如「安静紧张」）；`{光影}` = 光色一句话（见第五节 5.0，可直接整段粘贴）。

#### 公式 1｜中心聚焦站位（Center Focus Blocking）

**站位含义**：主角固定在画面中心或黄金分割点上，配角在其左、右、前、后形成视觉平衡。全部视线、线条、光斑指向主角，观众第一眼只会看主角。用于**强者登场、宣判式台词、高光时刻、单人情绪爆点**。

```
             [配角C 背景]
                  │
 [配角A 左] ──  ★主角（中心/黄金分割点）  ── [配角B 右]
                  │
             [配角D 前景虚化背影]
```

**中文可复制模板：**

```text
电影感{场景风格}，中心聚焦站位：主角站在画面正中（或右三分线交点），身体正对镜头，面部朝向镜头略偏，视线平直不闪躲；配角A在画面左侧后半步，配角B在画面右侧后半步，两人身体均向内侧倾斜、面部朝向主角，视线聚焦在主角脸上；前景放一名配角的虚化背影做遮挡，背景保留一名远处配角形成第三层。{光影}。{氛围}。中景转近景缓慢推进，加强主角的支配感。浅景深，主角面部为唯一清晰焦点，保持同一空间布局、同一光源方向，不要更换背景，不要人物站位不清，不要画面杂乱
```

**English:**

```text
cinematic {scene style}, center-focus blocking, the protagonist standing dead center on the golden-section point facing camera, secondary characters half a step behind on screen left and screen right, both angled inward with faces and eyelines locked onto the protagonist, a blurred foreground shoulder in the near plane and a distant figure in the background forming three depth layers, {lighting}, {mood}, slow push-in from medium shot to medium close-up, shallow depth of field with the protagonist's face as the only sharp focus, consistent location, same room layout, same lighting direction, no random objects, no cluttered composition
```

| 项 | 建议 |
|---|---|
| 景别/运镜 | 全景建置 → 中景 → 近景慢推（Push In）；或缓慢直线推镜（Dolly In） |
| 焦段 | 50mm 平实叙事 / 85mm 人像压缩背景 |
| 光位 | 主光正侧前 45°，背后加边缘光把主角从背景剥离 |
| 常见崩坏 | 配角与主角争焦点 → 配角必须写「虚化、背身、面部朝向主角」；主角漂移离开中轴 → 加 `主体居中构图占画面 70%` |

#### 公式 2｜三角包围站位（Triangle Encirclement Blocking）

**站位含义**：主角在中景，两个配角分置前景与背景形成三角形稳定构图；三点不共线，画面天然有纵深且不会塌成一条平线。多用于**打斗、对峙、三人关系（三角恋/审问/围堵）**。三角形是最稳定的多人构图，也是 AI 最不容易糊人的多人排布。

```
        [配角B 背景 · 虚化]
              ╱   ╲
        ★主角（中景 · 清晰）
              ╲
        [配角A 前景 · 大虚化背影/肩部]
```

**中文可复制模板：**

```text
电影感{场景风格}，三角包围站位：主角位于中景画面中央偏左，全身清晰，面部朝向前景的配角A；配角A位于右侧前景，只保留虚化的肩背轮廓，形成前景遮挡；配角B位于左后方背景，身形较小且轻度虚化，面部朝向主角，视线冷淡地锁住主角。三人构成稳定三角形，不在同一条水平线上。{光影}。{氛围}。中景为主，摄影机做小幅度弧形滑移（弧形环绕），不跨越关系轴；焦点转移从前景配角A拉回主角面部。前中后三层景深清晰，保持同一空间布局、同一光源方向，不要人物重叠，不要肢体交叠，不要更换背景
```

**English:**

```text
cinematic {scene style}, triangle encirclement blocking, the protagonist in the middle ground slightly left of center in sharp focus facing the foreground character, character A as a heavily blurred shoulder and back in the near foreground creating natural framing, character B smaller and softly defocused in the left background with eyeline locked on the protagonist, the three positions forming a stable triangle never aligned on one horizontal line, {lighting}, {mood}, medium shot with a subtle arc shot slide that never crosses the relationship axis, rack focus pulling from the foreground shoulder back to the protagonist's face, clear foreground-middle-background separation, consistent location, no overlapping limbs, no changing background
```

| 项 | 建议 |
|---|---|
| 景别/运镜 | 文戏对峙可整镜中景；打戏时中景只是三角构图的锚定镜，整段景别仍按 performance-action.md §3.5 五镜动作链换。弧形环绕小幅滑移 + 焦点转移（Rack Focus） |
| 防穿模 | 多人走位错开前后景深，避免肢体重叠区；不要写「双人接触瞬间同框」 |
| 常见崩坏 | 三人挤成一排 → 强制写「不在同一条水平线上」+ 前景/中景/背景各一人 |

> 模板里的「中景为主」只约束**本镜内部**的取景，不是整场的景别配额——当配额用，一段打戏就会写成同一个中景的五次微调，每镜信息量相同，剪起来像没剪过。

#### 公式 3｜双方对峙站位（Standoff Blocking）

**站位含义**：将两组阵营分立左右两侧，中间留出空白区域作为「**张力空间**」。空白越大，压力越大；两侧人数、高度、色彩形成对比，一眼读出实力差。用于**决战对峙、逼宫、当众撕破脸、谈判破裂**。

```
  [阵营A：主+2随从]        ← 张力空间（留白） →        [阵营B：主+2随从]
        画面左侧                 中轴线                      画面右侧
        视线向右                                            视线向左
```

**中文可复制模板：**

```text
电影感{场景风格}，双方对峙站位：角色A率两名随从站在画面左侧三分之一区域，面部朝向右侧，视线愤怒直视对方；角色B率两名随从站在画面右侧三分之一区域，面部朝向左侧，视线轻蔑地俯视对方；画面正中留出大面积空白作为张力空间，地面线条/走道/长桌沿中轴延伸，把两侧对称切开。A 始终在画面左侧，B 始终在画面右侧，保持左右关系和 180 度轴线。{光影}。{氛围}。先用宽幅全景交代阵势，再沿中轴线缓慢推进到中景。保持同一空间布局、同一光源方向、同一站位，不要跳轴，不要左右翻转，不要人物站位不清
```

**English:**

```text
cinematic {scene style}, standoff blocking, character A with two followers occupying the left third of the frame facing screen right, character B with two followers occupying the right third facing screen left, a large empty tension space held in the dead center of the frame, floor lines or a long table running along the central axis splitting the two camps symmetrically, character A remains on screen left and character B remains on screen right preserving the left-right relationship and the 180-degree rule, {lighting}, {mood}, opening wide shot establishing the formation then a slow dolly push along the central axis into a medium shot, same location, same screen direction, no axis flip, no mirrored composition
```

| 项 | 建议 |
|---|---|
| 景别/运镜 | 宽幅全景（交代阵势）→ 中景（沿中轴慢推）→ 正反打近景 |
| 配套光色 | 冷暖对撞：一侧冷蓝、一侧暖橙，强化人物的冲突与博弈 |
| 场景 | 办公室、客厅、走廊、审讯室、顶层办公室、酒店走廊、竹林/庭院 |
| 常见崩坏 | 张力空间被 AI 填满杂物 → 加 `画面正中保持空白，不要随机增加物体` |

#### 公式 4｜递进站位（Hierarchy / Echelon Blocking）

**站位含义**：角色按**身份、权力、战力**沿画面纵深或横向依次排开，退后半步 = 低半级，一个画面读完整个权力序列。核心手法是「前后中景层次站位 + 空间象征站位 + 群像关系镜头」的合体：前排清晰、后排逐层虚化，用**大气透视**（雾/尘/景深）制造层级。共四个变体。

**通用递进站位骨架（先填这一句，再选变体）：**

```text
递进站位：{核心人物}位于画面{位置}最前排且完全清晰，{第二级}退后半步分列其左右、轻度虚化，{第三级}再退一层、身形更小且明显虚化，{最末级}贴{墙/廊柱/远景}只留轮廓；层级越低身位越靠后、画面占比越小、清晰度越低；所有人面部朝向{核心人物}，只有{核心人物}面向镜头方向。
```

---

**变体 4A｜豪门家眷列队**

**站位含义**：家主居中最前，正妻/长子分立其左右后半步，妾室/庶子再退一层，仆从贴墙成排只留轮廓。对称仪式站位打底，用「退后半步」量化尊卑。用于**祠堂认亲、遗产宣读、当众羞辱、认祖归宗**。

```text
电影感{场景风格}，豪门家眷列队递进站位：家主坐/立于画面正中最前，正对镜头，完全清晰；正妻在其右后半步、长子在其左后半步，身体微向内倾，面部朝向家主；妾室与庶子再退一层站在两侧后方，轻度虚化；仆从沿两侧墙面成排站立，只保留深色轮廓不见五官；沿中轴线严格左右对称，人物按辈分依次后退，身位高低直接对应地位高低。{光影}。{氛围}。正面居中构图，缓慢直线推镜到家主面部近景。保持同一空间布局、同一光源方向，不要增删人物，不要人物站位不清，不要画面杂乱
```

---

**变体 4B｜门派弟子梯队**

**站位含义**：掌门居高台或最前中轴，长老左右分列低一阶，内门弟子在其后排成三角梯队向纵深延展，外门弟子最远、被雾气吞没。用「物理高度 + 纵深层数」双重表达门第。用于**门派大会、逐出师门、开宗立派、集体请命**。

```text
电影感{场景风格}，门派弟子梯队递进站位：掌门站在高台最前端中轴，低机位仰拍使其在画面上方，衣袍完整清晰；两位长老低一级台阶分列左右，面部朝向掌门；内门弟子在台阶下排成向后延展的三角梯队，前排清晰、越往后越小；外门弟子在最远处只剩成排的深色剪影，被薄雾与体积光吞没。全体面部朝向掌门，只有掌门面向镜头方向。{光影}。{氛围}。从弟子队列后方低角度仰拍向掌门，缓慢摇臂升起揭示整个梯队规模。长焦压缩纵深，大气透视分离每一层，保持同一空间布局、同一光源方向，不要人物穿模，不要队列错乱
```

---

**变体 4C｜主角护卫随行**

**站位含义**：主角在中景中轴略偏一侧，护卫呈**雁行 V 形**排在其后半步与两侧后方，前景可放一名护卫的虚化背影做遮挡。主角是唯一清晰的面孔，护卫是会移动的画框。用于**强势登场、走廊行进、进场包场、押解**。

```text
电影感{场景风格}，主角护卫随行递进站位：主角走在画面中央略偏右，全身清晰，面部朝向镜头方向，步伐匀速；两名护卫在其左后方与右后方各半步，呈雁行 V 形展开，身体略侧、面部朝向前方警戒；再后方两名护卫身形更小并轻度虚化；画面最前景放一名护卫的深色虚化背影作为遮挡框。主角始终是画面中唯一清晰的面孔。{光影}。{氛围}。镜头在主角前方后退跟拍（引导后退跟拍），保持主角在画面中央不漂移；或低角度跟踪仰拍强化压迫。走位幅度控制在中等，避免角色与墙体过近，保持同一空间布局、同一光源方向，不要肢体重叠，不要人物瞬移
```

---

**变体 4D｜队伍行军列队**

**站位含义**：队伍沿纵深方向朝镜头推进，前排清晰、后排逐层雾化直到只剩剪影；旗帜、长枪、马匹形成重复的节奏线。用长焦压缩把队伍「压厚」，人数感靠层数而不是靠数人头。用于**大军压境、送葬队伍、迎亲、出征、集体逃难**。

```text
电影感{场景风格}，队伍行军列队递进站位：队伍沿画面纵深从背景向镜头方向推进，为首者在最前排画面中央、面部清晰可辨；第二排两人略后退分列左右；后续队列逐排后移、逐排缩小、逐排被尘土与薄雾吞没，最远端只剩连续的深色剪影；旗帜与长兵器在纵向上形成重复排列的节奏线。{光影}。{氛围}。长焦镜头压缩纵深使队伍显得更密更厚，摄影机低机位固定或极缓后退；大气透视分离每一层。保持同一行进方向（从画面{左/右}向{右/左}），保持同一空间布局、同一光源方向，不要队形穿插，不要人物穿模，不要方向反转
```

| 递进站位共用要点 | 说明 |
|---|---|
| 层级量化 | 「退后半步 / 低一级台阶 / 再退一层」——必须写出可执行的物理位移，不写「地位较低」 |
| 清晰度阶梯 | 前排清晰 → 中层轻度虚化 → 后层明显虚化 → 最远只剩剪影 |
| 分离手段 | 景深 + 大气透视（薄雾/尘土）+ 明暗（后排压暗） |
| 焦段 | 长焦（135mm/200mm）压缩纵深，把队伍压厚 |
| 风险 | 多人同框是 AI 高风险区——后排一律写「剪影/虚化/只见轮廓」，不写五官 |

#### 公式 5｜二人对话正反打站位（Shot-Reverse-Shot Blocking · 派生）

**站位含义**：由「对话切换站位法」派生。双人对话使用镜像站位或 90 度倾斜侧身站位，靠过肩正反打交替推进；A 永远在左、B 永远在右，眼线高度与方向必须匹配，全场不许翻面。这是短剧里出现频率最高、也是最容易翻车的站位。

```
      A（画面左，面朝右）   ──[茶几/长桌]──   B（画面右，面朝左）
                            轴线
       🎥机位1(OTS 越过A肩看B)      🎥机位2(OTS 越过B肩看A)   ← 二者必须同侧
```

**中文可复制模板（建立镜 + 正打 + 反打，三条一起用）：**

```text
【建立镜｜双人全景】
电影感{场景风格}，二人对话站位：角色A始终在画面左侧，角色B始终在画面右侧，{道具}位于两人中间，两人身体呈 90 度侧身相对，面部朝向对方，视线互相锁定，保持左右关系和 180 度轴线。{光影}。{氛围}。中景静止，先固定空间和人物关系。保持同一空间布局、同一光源方向，不要跳轴

【正打｜过肩看B】
过肩近景，从角色A右肩后方拍摄，焦点在角色B脸上；角色A的肩背作为左侧前景虚化遮挡，角色B在画面右侧，面部朝向左侧的A，视线{视线情绪}地直视A。{光影}。85mm 浅景深柔化背景。眼线高度与上一镜匹配，保持轴线不变，不要左右翻转

【反打｜过肩看A】
过肩近景，从角色B左肩后方拍摄，焦点在角色A脸上；角色B的肩背作为右侧前景虚化遮挡，角色A在画面左侧，面部朝向右侧的B，视线{视线情绪}。{光影}。眼线高度与正打镜严格对应，遵守 180 度轴线，角色A仍在画面左侧，不要跳轴，不要视线错位
```

**English（对话连续性硬约束句，逐镜追加）：**

```text
shot-reverse-shot continuity, keep the 180-degree rule, Character A remains on screen left, Character B remains on screen right, consistent eyelines, no axis flip
```

**双人对峙表情模板（可直接拼在上面模板后面）：**

```text
medium close-up, over-the-shoulder composition, [角色A] facing [角色B], tense silence, [角色A表情细节], avoiding or holding eye contact, fingers slowly clenching, cold side lighting, shallow depth of field, cinematic drama, consistent face, no extra hands, no distorted faces, no flickering
```

| 项 | 建议 |
|---|---|
| 景别节奏 | 双人全景（定关系）→ OTS 近景 A→B → OTS 近景 B→A → 单人特写（情绪爆点） |
| 光位 | 正反打两侧的主光方向必须一致：A 的主光来自画面左上，B 的主光也来自画面左上（同一物理光源） |
| 竖屏调整 | 9:16 双人同框易拥挤，多用单人正反打；景别整体上移（横屏中景 = 竖屏近景） |
| 常见崩坏 | 反打时两人同时在左 / 同时朝同一方向 → 每镜必写「角色A在画面左侧、面部朝向右侧」 |

#### 公式 6｜审讯站位（Interrogation Blocking · 派生）

**站位含义**：由「空间象征站位 + 冲突对峙站位」派生。被审者被固定在低处、封闭、被光切割的位置；审问者站立于其上方或绕行走动，可离画。权力差用**高低机位 + 光的所有权**（谁在光里、谁在暗里）表达，而不是靠台词。用于**密室审问、逼供、当众质问、心理施压**。

```
        [审问者 · 站立 · 逆光剪影 · 可绕行离画]
                    ↓ 俯拍
        ═══════[ 桌 ]═══════
        [被审者 · 坐 · 顶光/局部光锁定 · 仰拍看向上方]
```

**中文可复制模板：**

```text
电影感{场景风格}（审讯室/密室/顶层办公室），审讯站位：被审者坐在画面中央偏下、面向镜头，双手放在桌面上，视线被迫向上抬；审问者站在画面右侧靠前，只保留深色的半身逆光剪影，面部隐入暗处，身体朝向被审者。桌面把画面横向切开，两人分处上下两个权力层。被审者用略俯拍机位显得渺小，审问者用略仰拍机位显得高大，机位始终保持在轴线同侧。{光影}（推荐：顶光单点照亮被审者面部，百叶窗把光切成条纹落在桌面与墙上，其余大面积留黑）。{氛围}：安静、压迫、无出口感。中景切近景缓慢推进，加强心理压力。保持同一空间布局、同一光源方向，不要增加旁观者，不要更换背景，不要画面杂乱
```

**English:**

```text
cinematic interrogation room, {scene style}, the interrogated character seated lower-center facing camera with hands on the table and eyeline forced upward, the interrogator standing on screen right in the near plane rendered as a dark backlit silhouette with the face lost in shadow, the table cutting the frame horizontally into two power layers, slight high angle on the seated character and slight low angle on the standing one with the camera staying on the same side of the axis, cold hard overhead key light isolating the seated face, venetian blind shadow stripes across the table and wall, large areas of pure black elsewhere, low-key lighting, tense oppressive silence, slow push-in from medium shot to close-up, consistent location, same lighting direction, no extra bystanders, no cluttered composition
```

| 项 | 建议 |
|---|---|
| 关键光 | 百叶窗光影（秩序感与心理压迫）+ 局部打光（聚光只照亮手/证物）+ 暗部留黑 |
| 关键道具 | 未签字的合同/照片/手机——用冷硬台灯单独打亮，成为画面唯一的亮物 |
| 情绪配套 | 压抑愤怒：眉头紧锁、下颌绷紧、指节发白、目光死死盯住对方 |
| 常见崩坏 | 两人都被打亮 → 必须写明「审问者面部隐入暗处」，光的所有权只给一个人 |

#### 公式 7｜群像站位（Ensemble Blocking · 派生）

**站位含义**：由「群像关系镜头」派生——宽幅全景下安排主次、高低、聚散站位，一眼传达阵营和话语权。规则只有三条：**分组、分层、分光**。用于**决战对峙、圆桌会议、复杂的团队冲突、宴会、秘密聚会**。

```
   ┌ 主阵营（左，3人，聚拢，暖光）┐   留白   ┌ 对立阵营（右，4人，散开，冷光）┐
   │  ★核心（略前、最亮、最清晰）│           │  ★对手（略前、逆光剪影）      │
   │  次级（后半步，轻虚化）      │           │  次级（后半步）                │
   └ 边缘者（贴画框，只留轮廓）  ┘           └ 边缘者（暗部隐没）            ┘
```

**中文可复制模板：**

```text
电影感{场景风格}，群像关系站位：画面左侧为主阵营三人紧密聚拢，核心人物略靠前、亮度最高、最清晰，两名次级人物退后半步轻度虚化；画面右侧为对立阵营四人松散排开，对手核心略靠前呈半逆光剪影；两组之间保留明显的空白距离作为张力空间；边缘人物贴近画框只保留深色轮廓，不刻画五官。人物按重要度分配画面占比与清晰度：主 > 次 > 群。{光影}（推荐：左侧暖光、右侧冷光，冷暖对撞区分阵营；夜戏可用夜色群像——多人局部隐没在极有限的暗光中）。{氛围}。宽幅全景固定或极缓慢推进，先交代阵营与话语权，再切入核心人物近景。保持同一空间布局、同一光源方向、同一站位，不要增删人物，不要人物重叠穿模，不要每张脸都清晰
```

**English:**

```text
cinematic wide ensemble shot, {scene style}, three allies clustered tightly on screen left with the leader slightly forward, brightest and sharpest while the two secondary figures stand half a step back softly defocused, four opponents spread loosely on screen right with their leader slightly forward as a half-backlit silhouette, a clear empty gap held between the two groups as tension space, peripheral figures reduced to dark outlines at the frame edges with no facial detail, screen area and sharpness allocated by narrative importance, warm key on the left group and cold key on the right group separating the factions, {mood}, locked wide shot or extremely slow push-in establishing the power hierarchy before cutting to a close-up, consistent location, same lighting direction, no added or removed characters, no overlapping bodies
```

| 项 | 建议 |
|---|---|
| 三条铁律 | ①分组（左右/前后成组）②分层（前中后三层清晰度递减）③分光（阵营用冷暖或明暗区分） |
| AI 安全 | 边缘与后排人物一律「剪影/轮廓/虚化」，不刻画五官——多人同框脸崩率最高 |
| 常见崩坏 | 人数漂移 → 提示词写死人数「左侧三人、右侧四人」并加负面词 `不要增删人物` |

#### 公式 7 附｜1vN 群斗：对手 ≠ 群演

**边界裁决**：上表的剪影/虚化规则适用于**群像亮相与背景人物**（用来压住多人同框的脸崩率）；**1vN 打戏中的对手不适用**——对手是叙事主体，必须逐个可辨。把「后排一律剪影」套到 1v4 的四个对手身上，观众追不出谁被打倒了、还剩几个，打戏的进程感直接归零。

**每个对手四维独立**（1v4 就要四套，没有一个是凑数的）：

| 维度 | 要求 |
|---|---|
| 兵器 | 四人四器（单刀 / 双刺 / 长枪 / 袖箭），不重样 |
| 体型 | 高瘦 / 壮硕 / 矮壮 / 灵巧，剪影就能分辨 |
| 气质与服色 | 服装主色差异要大，配一句气质定语（阴鸷 / 憨勇 / 谨慎 / 狂躁） |
| **攻击线类型** | 每种兵器给一条独立的画面线条走向：单刀＝斜线、双斧＝垂直线、长枪＝直线、双截棍＝弧线、暗器＝多向散射 |

**攻击线类型是构图信息**：它决定这一镜的主线条方向，直接和 shot-grammar.md §5.1 构图主表衔接——四个对手同时进攻时，四条线**不能同向**，否则线条互相叠加，画面糊成一团，谁在打谁读不出来。

**同框上限**：打戏对手同框 **≤ 3 人**，其余用画外音、景深虚化、或分镜错开出场（与「同框人数上限 ≤5」的群像规则不冲突，取更严者）。

**双人对练**：每一镜写全 A（主动）与 B（被动）两个角色及两人的距离与朝向（已在 performance-action.md §3.0，此处不重复）。

### 1.2b 高度分层（Y 轴，打戏专用）

站位不只有前中后（Z 轴），还有高低（Y 轴）。只写 Z 轴，打戏会摊成一张平面地图——所有人贴着同一条地平线滑来滑去，没有立体感。**一场打戏至少要出现两层高度**：

| 层 | 内容 | 典型镜头 |
|---|---|---|
| 低位层 | 地面低桩、扫堂、跪撑、贴地滑行、倒地视角 | 贴地机位 / 低角度仰拍 |
| 中位层 | 贴身缠斗、拳掌肘膝交换 | 平视中景 / 过肩 |
| 高位层 | 腾空、踩墙、居高下劈、跃过障碍 | 仰拍 / 俯拍 |

**写法**：把高度写进站位句——`A 沉马位于画面左侧下三分之一，B 自右上方腾空下劈`。

**与 Z 轴同时用**：同一画面里前景低位 + 中景中位 + 背景高位，是最快拉开打戏空间感的做法。

**上限**：腾空 / 跌落一个 15 秒段落最多 **2 镜**——人物离地后画面里没有任何接触点可以参照，跨镜位置漂移率极高（见 performance-action.md §3.0）。

---

### 1.3 竖屏 9:16 站位改写规则

| 横屏习惯 | 竖屏改写 |
|---|---|
| 左右大全景交代阵势 | 弃用；改**纵向构图**，用纵深层次代替横向排开 |
| 左右走位 | 改**纵向调度**：人物前后景深走位 |
| 双人同框中景 | 改**单人正反打**（竖屏窄，双人同框易拥挤） |
| 中景 | 景别整体上移，横屏的「中景」在竖屏要更近（怼脸感），人物占画面 70% |
| 手部/道具 | 特写竖排，适合手部由下往上的动作 |
| 通用 | 从分镜阶段就按 9:16 设计构图，禁止横屏拍完裁竖屏 |

## 二、180 度轴线与越轴防治

### 2.1 基本规则

```
定义: 两个角色对话时，摄像机始终在连线的同一侧

正确:
  角色A ←→ 角色B
  ─────────────── 轴线
  📷 📷 📷（所有机位在同一侧）

错误:
  角色A ←→ 角色B
  📷            📷（跳轴，观众空间感混乱）
```

**动作戏专用图示：**

```
【动作拍摄 180 度轴线规约】
             [角色 A] ───────────────── [角色 B]  (轴线 Axis)
                │                         │
  摄影机机位 1  🎥                        🎥  摄影机机位 2
  (A 在左, B 在右)                         (过肩视角 A -> B)
─────────────────────────────────────────────────────────────────
  [禁止越轴区]  ─────────────────────────────────────────────────
  摄影机机位 3  ❌ 🎥 (越轴机位：左右位置瞬间对调，造成穿帮)
```

**越轴痛点**：AI 视频每个镜头是独立渲染的，大模型极易发生越轴——上一镜 A 在左、B 在右，下一镜突然变成 A 在右、B 在左，剪辑时方向感完全颠倒。

---

### 2.2 左右站位锁定语句（逐镜粘贴）

| 用途 | 中文锁定句 | English |
|---|---|---|
| 通用左右锁 | `角色A始终在画面左侧，角色B始终在画面右侧，桌子位于两人中间，保持左右关系和180度轴线` | `Character A remains on screen left, Character B remains on screen right, the table stays between them, preserving left-right relationship and 180-degree rule` |
| 动作戏硬锚定 | `A 位于画面左侧，面向右侧出击；B 位于画面右侧，面向左侧做防御姿态` | `A is positioned on the left side of the frame, facing and striking towards the right; B is on the right side of the frame, facing left in a defensive posture.` |
| OTS 安全过渡 | `过肩镜头，从画面左前景 A 的左肩后方看向站在右侧的 B` | `Over-the-shoulder shot, looking from behind A's left shoulder on the left foreground at B who is standing on the right.` |
| 正反打连续 | `正反打连续，遵守180度轴线，角色A始终在画面左侧，角色B始终在画面右侧，视线方向一致，不要跳轴` | `shot-reverse-shot continuity, keep the 180-degree rule, Character A remains on screen left, Character B remains on screen right, consistent eyelines, no axis flip` |
| 视线匹配剪辑 | `视线匹配，上一镜角色看向画面右侧，下一镜揭示画面右侧的对象，保持空间方向一致` | `eyeline match, the character looks toward screen right in the previous shot, the next shot reveals the object located on screen right, preserving spatial direction` |
| 出入场方向 | `背景左侧有清晰出口，角色运动方向从画面右侧到左侧，行动路径可见，不要阻断动线` | `clear exit door in the background left, character movement direction from screen right to screen left, visible pathway, no blocked movement path` |
| 镜头轴线一致 | `人物站位不变，镜头轴线不变，光线不变` | `preserve camera axis, obey the 180-degree rule, consistent eyeline, consistent screen direction, no axis flip, no random camera angle change` |

---

### 2.3 AI 生成中的轴线控制方法

```
方法:
  - 在Prompt中明确指定拍摄方向
    "shot from the left side of the character"
    "over-the-shoulder shot from behind character A"
  - 使用ControlNet Pose指定人物朝向
  - 用参考构图图指定摄像机位置
  - 建立场景的Top-Down视图标注摄像机位
```

补充三条工程手段：

1. **屏幕左右固定锚定**：每一个动作镜头的提示词里明确标注角色的左右相对方位。
2. **过肩镜头（OTS）定向**：利用过肩视角作为安全过渡镜，锁死轴线。
3. **后期镜像翻转兜底**：如果 AI 生成的动作方向完美但位置越轴，直接在后期剪辑软件（Premiere / CapCut）中水平镜像翻转视频，简单高效地拉回 180 度轴线。

---

### 2.4 允许跳轴的情况

```
- 运动镜头平滑过轴（摄像机从一侧移到另一侧）
- 插入中性镜头（正面/俯视）后换侧
- 混乱/迷失场景（有意制造空间混乱感）
- 快切蒙太奇（节奏快到观众来不及感知）
```

---

### 2.5 轴线自检

- [ ] **防越轴检测**：检查相邻镜头中，角色 A 与 B 的左右屏幕相对位置是否恒定，发生越轴的镜头在后期执行水平镜像翻转。
- [ ] 对话场景是否遵守基本轴线规则；正反打中人物视线方向是否对应。
- [ ] 角色左右关系是否不被随意反转。
- [ ] 左右站位、视线方向、出入场方向是否符合轴线逻辑。
- [ ] 高低机位是否服务于权力关系或情绪；机位变化是否有动机，不像随机生成。
- [ ] 镜头切换后人物位置、物体位置是否对得上。

## 三、场景圣经（Scene Bible）

### 3.0 场景设计四层结构

| 层级 | 作用 | 需要写清楚什么 |
|---|---|---|
| 剧情功能 | 决定这场戏为什么发生在这里 | 告白、对峙、揭露、逃离、崩溃、反转 |
| 空间关系 | 决定人物怎么站、怎么移动 | 左右关系、距离、遮挡、出入口、视线方向 |
| 情绪氛围 | 决定观众感受到什么 | 压迫、孤独、暧昧、危险、温暖、衰败 |
| 视觉细节 | 决定画面是否可信和稳定 | 光源、色温、家具、道具、材质、背景层次 |

**核心方法：先定场景功能，再定空间布局；先找光，再定构图；道具要参与叙事；背景要稳定、简洁、有层次。**

**通用场景设计公式（中文）：**

```text
[场景类型] + [剧情功能] + [空间布局] + [人物站位] + [关键道具] + [光源方向] + [色调氛围] + [材质细节] + [背景层次] + [镜头景别] + [稳定性约束]
```

**通用场景设计公式（英文）：**

```text
[scene type], [dramatic function], [spatial layout], [character blocking], [key props], [lighting direction], [color mood], [material details], [background depth], [shot type], [stability constraints]
```

---

### 3.1 场景圣经六要素（①–⑤ 全场必填，⑥ 打戏场次必填）

| 要素 | 必须写死的内容 | 继承方式 |
|---|---|---|
| **① 空间布局** | 左/右/中/前景/背景各是什么，家具位置，出入口在哪 | 整场不变，逐镜复制 |
| **② 人物左右站位** | A 在左还是右、离什么家具最近、两人之间隔着什么 | 与 180 度轴线绑定 |
| **③ 关键道具位置** | 名称 + 归属 + 精确位置（如「茶几右上角」）+ 状态（亮屏/半杯） | 道具连续性锚点 |
| **④ 主光方向与色温** | 光从画面哪一侧进来、几度角、什么色温、室内还有什么实体光源 | 光影连续性锚点 |
| **⑤ 前中后景层次** | 前景是什么遮挡、中景是谁、背景是什么（且虚化） | 景深与纵深锚点 |

**第⑥要素 · 可破坏元素清单（打戏场景必填）**

打戏场景的场景圣经必须多填一项：**哪些元素允许被打坏、坏成什么样**。不预先声明，只剩两条错路——要么把合法破坏判成穿帮回滚重生成，要么把破坏词硬塞进提示词，与自己的负面串 `不要家具变化 / 不要道具变化` 正面相消，最后地面裂纹和断木一个都没出来。

```text
可破坏元素：{木箱/货架/立柱/玻璃隔断/地面青砖/积水/挂灯}
破坏形态：{碎裂横飞/蛛网状裂纹/整排倒塌/炸散/熄灭}
```

三条规则：

1. **破坏是合法的背景变化**，不算穿帮——它是打击力度的表达（见 performance-action.md 附 §3.3「反滑步 / 物理阻尼词库」§环境互动）。
2. **破坏单向不可逆**：坏了就不能复原，与「伤痕单向恶化」同一逻辑。柱子第 5 镜裂了，第 9 镜不许完好。
3. **破坏后的新状态立即成为新的恒定态**：写进该镜的落幅 / `end_state` / 连续性交接字段，后续镜以新状态为准锁定。

> 未列入可破坏清单的元素，仍然受「不要家具变化、不要道具变化」的负面串约束。

### 3.3 已填样例（权威样板，照此密度写）

## 四、灯光

> 氛围感的关键，不是亮，而是**光线关系**。写光的顺序固定为：**动机 → 方向 → 软硬 → 光比 → 冷暖 → 大气**。

### 4.1 动机光源（Motivated Light）

**定义**：画面里每一束光都要能指认出它的物理来源——窗、台灯、烛火、屏幕、霓虹、车灯、火光。写出实体光源，AI 才会把光和阴影算对；只写「电影感灯光」会得到平光。

| 场景类型 | 动机光源词库 |
|----------|--------|
| **室内** | 台灯侧光 / 窗户进光 / 烛光闪烁 / 屏幕冷光 |
| **都市/夜景** | 霓虹灯漫射 / 玻璃幕墙反射 / 车灯流光 / 防空警报红光 |
| **自然/写实** | 黄金时刻侧逆光 / 阴天漫射天光 / 月光冷辉 / 火焰跳动暖光 |
| **灾难/动作** | 暴雨逆光 / 爆炸橙红火光 / 核爆白光 / 闪电侧光 |
| **奇幻/仙侠** | 灵力自发光 / 法阵光环 / 仙雾透光 / 月华清辉 |
| **科幻** | 飞船引擎尾焰光 / 能量球蓝白光 / 全息投影散射 |

**写法对照：**

| ❌ 无动机 | ✅ 有动机 |
|---|---|
| `电影感灯光，氛围很好` | `主光来自右侧落地窗外的冷蓝月光，沙发后方一盏暖色台灯作为室内辅助光` |
| `脸被照亮` | `台灯的暖光从左下方打亮下颌与颈部，右半张脸落入阴影` |
| `很亮的房间` | `desk lamp as the only light source`（书房只有一盏台灯，其余留黑） |

### 4.2 硬光 / 柔光

| 类型 | 视觉特征 | 情绪含义 | 中文提示词 | English |
|---|---|---|---|---|
| **硬光** | 阴影边缘锐利、明暗交界清楚、皮肤纹理放大 | 冷酷、审问、权力、危险 | `硬质冷光，锐利阴影，明暗边界清晰` | `cold hard light, hard shadows, sharp shadow cutoff` |
| **柔光** | 阴影边缘弥散、过渡柔和、皮肤温润 | 温情、暧昧、回忆、脆弱 | `柔和的散射光包裹面部，皮肤呈现温润质感` | `soft diffused light wrapping the face, soft shadow falloff` |
| **均匀柔光（高调）** | 整体明亮、几乎无硬影 | 清新、甜宠、喜剧、广告 | `均匀柔光，极少硬影，高调打光` | `soft even fill lighting with no hard shadows` |
| **单点雕刻（低调）** | 单一光源把脸从黑暗中「刻」出来 | 悬疑、惊悚、黑化 | `低调打光，单点光源雕刻面部，大面积暗部` | `low-key single-source lighting carving face from darkness` |

### 4.3 光比（Lighting Ratio）

> 光比 = 亮部与暗部的强度比。**光比是短剧「电影感」最省钱的开关**：同样的场景，把光比从 2:1 拉到 8:1，立刻从电视剧变成电影。

| 光比 | 观感 | 适用 | 中文提示词 | English |
|---|---|---|---|---|
| **2:1 小光比** | 明暗差极小，柔和干净 | 甜宠、喜剧、广告、高调打光 | `小光比，柔和均匀，暗部仍有充分细节` | `low lighting ratio, soft even fill, no hard shadows, bright open shadows` |
| **4:1 标准戏剧光比** | 有立体感但不压抑 | 常规对话、都市情感、日常叙事 | `标准戏剧光比，主光侧前 45°，柔和补光保留暗部细节` | `45-degree key light with soft fill, moderate contrast, shadow detail retained` |
| **8:1 大光比** | 暗部大面积吃掉细节，只留亮部 | 对峙、审讯、复仇、悬疑、黑化 | `8:1 大光比，高反差，主光单侧，暗部深黑几乎无细节，主动大面积留黑` | `8:1 high lighting ratio, high contrast, dominant shadows, deep crushed blacks, low-key lighting` |
| **16:1 极限/剪影** | 主体几乎只剩轮廓 | 诀别、宿命对决、隐藏身份出场 | `逆光中面部细节隐入暗处，仅轮廓线可辨` | `strong backlight (contre-jour) creating a dramatic silhouette` |

> **一句话规则**：文戏 4:1，冲突 8:1，命运时刻 16:1。同一场戏内光比可以随情绪递进抬升，但主光**方向**不许变。

### 4.4 冷暖分离（Warm / Cool Separation）

**定义**：同一画面里同时存在冷色温与暖色温两个光源，用色温差把人物、阵营、内外空间切开。这是短剧对峙戏最高效的一招——**冷暖对撞镜头：画面中同时出现冷蓝色温与暖橙色温，强化人物的冲突与博弈**（适配激烈争执、心理博弈、关键转场时刻）。

| 分离方式 | 写法 | 用途 |
|---|---|---|
| **内外分离** | 窗外冷蓝月光 / 室内暖色台灯 | 家庭、深夜谈判、被隔绝感 |
| **阵营分离** | 左侧人物暖光、右侧人物冷光 | 群像站位、双方对峙 |
| **正邪分离** | 主角面部暖侧光，反派半张脸落入冷蓝 | 反转、身份揭露 |
| **时空分离** | 回忆段暖黄柔光，现实段冷灰硬光 | 闪回、梦境 |

**可复制句：**

```text
冷暖分离：主光为来自画面右侧窗外的冷蓝月光（冷侧），画面左后方一盏暖色台灯提供暖侧轮廓，人物左脸落在暖光里、右脸落在冷光里，冷暖交界线正好切过鼻梁
```

```text
cold blue moonlight from the right window as the cool key, a warm practical table lamp on the left rear providing warm rim, the warm-cool boundary falling across the bridge of the nose, teal shadows and orange highlights
```

### 4.8 光影三层结构（大制作提示词的核心技巧）

**第一层 — 光源层**（是什么光、从哪来）见 4.1 动机光源表。

**第二层 — 光行为层**（光如何与材质/大气互动）：

| 效果 | 描述 |
|------|------|
| 薄雾柔化高光 | 光线穿过雾气被柔化 |
| 强化阴影对比 | 雾层加深暗部 |
| 丁达尔效应/god rays | 光束在尘埃/雾中可见 |
| 体积光穿透 | 光柱穿过空间 |
| 烟尘散射光线 | 粒子折射光 |
| 玻璃折射彩虹光斑 | 棱镜效果 |
| 金属反射高光 | 锐利金属反光 |
| 雨水折射霓虹 | 湿面彩色反射 |
| 次表面散射(SSS) | 皮肤/玉石透光效果 |

**第三层 — 色调层**（整体冷暖和对比）见第五节 5.4 色调公式表。

**三层结构使用模板：**

```text
光影：[光源词1]+[光源词2]（光源层），
[光行为词1]+[光行为词2]（光行为层），
[色调公式]（色调层）。
```

**示例：**

```text
光影：自然柔光+皮肤真实质感(光源层)，浅景深前景虚化(光行为层)，自然色温(色调层)。
```

### 4.11 光影连续性锁（跨镜头必加）

**根因**：光影参数被写进了运动层（I2V）而不是锁在视觉锚点（关键帧）里；运镜提示词无意中重新定义了光源。

**四条修复规则：**

1. 多镜项目使用**关键帧优先**：所有光影写进 Stage 1（T2I 定帧），Stage 2（I2V 运动层）里一个光影词都不写。

   > **例外：事件性光效允许写进运动层。** 命中闪光（impact flash）、兵器碰撞火花、能量爆发、雷光闪照属于**由动作触发的瞬时光事件**，只能写在运动层——定帧是静止的一格，闪光在定帧里根本无处发生。三条限制：①只作**瞬时叠加**（1–3 帧），②**不改变主光方向与全场色温基准**，③一镜只允许一种（与「一镜一主特效」一致）。除此之外，Stage 2 仍然一个常规光影词都不写。

2. 在连续性圣经里把光源位置与颜色写成不变量：`主光始终来自画面左上方30°、色温5600K暖白`。
3. 全片使用同一胶片/渲染引擎锚定词，写进圣经。
4. 显式追加约束：`运镜不改变光源方向或色调基准`。

**Stage 1 关键帧模板的光影段（原文）：**

```text
【光影与材质】
[光源方向、色温、软硬]，[大气效果]，[材质锚定词]，[胶片/渲染引擎]。
[将全部光影细节集中在此处，不放入 Stage 2。]
```

**Stage 2 运动层的连续性保护段（原文）：**

```text
【连续性保护】
保持@图片1中的[角色身份/服装/道具/场景地理/光照方向/色调]不变。
不要引入@图片1中不存在的人物、道具或场景元素。
光影不因运镜变化而改变基调——摄影机移动时光源保持空间固定。
```

**逐镜光影一致约束词：**

```text
same lighting direction, same color temperature, consistent shadows, same time of day, same weather, consistent exposure, no lighting shift, no color shift
```

```text
同一光源方向，同一色温，阴影一致，同一时间，同一天气，曝光一致，不要光线突变，不要色调突变
```

## 五、色彩

### 5.0 主色 / 辅色 指定法

> 全片、全场、全镜三级色彩都必须显式**指定主色与辅色**，不写「色彩很美」。主色决定观众的情绪基调，辅色只负责在画面里制造 5%–20% 的对抗与呼吸。

| 层级 | 主色（Dominant） | 辅色（Accent） | 判定规则 |
|---|---|---|---|
| **全片** | 一个不变的底调（如冷蓝灰） | 一个不变的强调色（如血红） | 全片主色调是否稳定 |
| **全场** | 场景圣经里的色调层公式 | 关键道具/服装色 | 同一场景色调统一 |
| **单镜** | 画面占比最大的色块 | 最亮/最饱和的那一点 | 辅色必须落在叙事重点上 |

**主辅色写法模板：**

```text
主色：{主色}占据画面{占比}的背景与环境；辅色：{辅色}只出现在{承载叙事的物体}上，成为画面中唯一高饱和的点。
```

```text
dominant {color} covering the environment and background, accent {color} appearing only on {narrative object} as the single most saturated point in the frame
```

**样例（道具即辅色）：**

| 道具 | 叙事功能 | 场景提示词 |
|---|---|---|
| 手机 | 消息、背叛、真相 | `lit phone screen on the coffee table, the only bright object in the scene` |
| 戒指 | 婚姻、承诺、背叛 | `silver ring catching a small highlight, placed near the edge of the table` |
| 合同 | 权力、交易、威胁 | `unsigned contract folder on the desk, sharply lit by a cold desk lamp` |
| 旧照片 | 回忆、秘密、亲情 | `old photo partly hidden under a book, warm nostalgic light` |
| 水杯 | 紧张、沉默、破裂 | `half-filled glass cup, slight reflection, placed between two characters` |
| 门 | 逃离、拒绝、边界 | `closed door in the background, clear exit line, symbolic separation` |
| 雨伞 | 分别、保护、疏离 | `black umbrella leaning near the entrance, wet floor reflection` |
| 镜子 | 自我审视、真相分裂 | `mirror reflection showing the character's hidden expression` |

### 5.1 青橙分级（Teal and Orange）

**定义**：冷色调阴影与暖色调高光对立，极具工业级商业大片质感；也是**动作格斗的黄金配色**。原理与冷暖分离同源——把肤色留在橙侧，把环境推到青侧，人物自动从背景里跳出来。

```text
Teal and Orange color grading, high contrast cinema grading, warm highlights and cool cyan shadows, cinematic blockbuster look
```


### 5.2 色温（Color Temperature）

> 色温是**场景圣经的硬字段**，必须落到具体写法上，并全场不变。写法参考：`色温5600K暖白`。

| 光源 | 常用写法 | 观感 | 用途 |
|---|---|---|---|
| 烛火 / 火光 | 极低色温暖橙 | 亲密、怀旧、危险跳动 | 深夜谈心、古风夜戏 |
| 钨丝灯 / 暖色台灯 | 低色温暖黄（约 3200K） | 家、温情、旧时代 | 出租屋、客厅、回忆 |
| 日光 / 窗光 | 中性偏暖白（约 5600K） | 自然、真实、日常 | 都市写实、校园 |
| 阴天漫射天光 | 高色温冷白 | 沉重、失落、现实 | 悲伤、社会派 |
| 月光 / 冷蓝夜色 | 高色温冷蓝 | 疏离、孤独、危险 | 夜戏、对峙 |
| 荧光灯 / 屏幕光 | 冷白偏青绿 | 冰冷、体制、医院感 | 医院走廊、停车场、审讯 |

**色温锁定句：**

```text
主光始终来自画面左上方30°、色温5600K暖白
```

```text
色温全场固定：窗外冷蓝月光为冷侧，室内暖色台灯为暖侧，不允许中途改变色温或互换冷暖
```

**抽色保留单色（Selective Desaturation）**

用于觉醒 / 爆气 / 终结击的高光镜：

```text
画面瞬间抽色成黑白，唯独保留 {燃烧的金色斗气 / 剑身的暗红 / 眼中的猩红}
```

```text
the frame drains to monochrome except for {the burning golden aura / the dark red blade / the crimson in the eyes}
```

作用是在黑白画面里造出唯一的视觉焦点，冲击力远高于往画面上加特效。三条限制：

1. **一场戏只用一次**——用第二次，观众就把它读成滤镜故障，不再是高光。
2. **保留的色相只能有一个**（与「一镜一主特效」同源）；保留两种颜色，唯一焦点消失，画面塌回普通调色。
3. **它是瞬时叠加，不改变全片色调基准**：抽色结束必须回到本表为该题材指定的原色板。

### 5.7 色彩逻辑一致性（阵营 / 时空 / 情绪）

- 全片主色调是否稳定。
- 不同人物、阵营、场景是否有明确色彩逻辑。
- 回忆、现实、梦境、幻想是否用一致的色彩区分。
- 危险、温情、悬疑、喜剧等情绪色彩是否统一。
- 调色是否造成角色肤色、服装色、道具色前后不一致。

**时空色彩分离写法：**

```text
现实段：冷灰低饱和，硬光，8:1 大光比；回忆段：暖黄柔焦，柔光，2:1 小光比，轻微光晕。两段之间色彩差异必须一致复用，不允许中途互换。
```

**阵营色彩分离写法（配合群像站位）：**

```text
主阵营服装与光色统一在{暖色系}，对立阵营统一在{冷色系}，中立者保持低饱和灰调；同一角色跨镜头不改变其阵营色。
```
