# 运镜与画面风格速查库

> 来源：微信公众号「生活小事开心说」《52个AI视频提示词，运镜+风格一次拿全》(2026-08-19)。
> 本文按本项目的写法重新组织与改写，只保留每一式"写什么、何时用、哪一句不能省"，不照抄原文提示词。
> 用法：先定这一镜要观众感受什么，再从下表挑**一个**主运镜和**一种**画面风格拼成一句；
> 【主体】【场景】换成本镜的具体角色、服装、位置和动作。

## 一、选运镜的总规则

1. 一镜只放一个主运镜。旋转、俯冲、手持叠在一起，模型会哪个都拍不像；其余靠风格词补。
2. 每一式都有一句"防跑偏"的关键限定（下表最右列），省掉它模型就会按自己的习惯拍。
3. 运镜决定情绪：环绕偏梦境，俯冲偏冲击，手持偏临场，后拉偏孤独，固定偏调度与克制。
4. 主观形容词（高级感、氛围感、电影感）模型读不懂，换成具体的动作、光线、材质与配色。

## 二、24 个运镜，按用途分 6 组

| 组 | 运镜 | 写法要点 | 适用 | 不能省的限定 |
|---|---|---|---|---|
| 基础 | 旋转环绕 | 镜头绕主体慢转，主体基本不动，背景随之流动 | 梦境、闪回、情绪段 | 主体保持稳定，动的是镜头 |
| 基础 | 高点定格 | 动作冲到最高点瞬间凝固，碎片/衣摆悬停，镜头再绕半圈 | 动作高光 | 明写"在最高点凝固"，否则不会停 |
| 基础 | 延时流动 | 固定机位，云、光、人流被压缩时间加速 | 城市空镜、昼夜交替 | 机位与构图不动 |
| 基础 | 固定调度 | 全程不移动，靠人物进出画与前后景推进 | 文戏、对话、纪实 | 写明"镜头全程不移动" |
| 空间 | 广角建立 | 先交代完整环境，人物在画面里占比小 | 每场开场第一镜 | 人物别放大，环境是主角 |
| 空间 | 平行横移 | 与主体平行稳定横移，前中后景依次掠过 | 街景、走廊、层次空间 | 主体始终贴近画面中轴 |
| 空间 | 后拉留白 | 从近景缓慢后撤，人物越来越小、四周空白越来越大 | 告别、孤独、段落收束 | 节奏慢，人物几乎不动 |
| 空间 | 低位升起 | 从低处升起越过前景，逐步揭示整个场景 | 越级揭示、大场面 | 运动平稳连贯 |
| 冲击 | 推拉变焦 | 一边推近一边反向变焦，主体大小不变、背景被拉伸或压扁 | 惊变、顿悟、发现 | 写出"反向变焦、主体大小不变" |
| 冲击 | 第一视角 | 以人物眼睛进入场景，带步行起伏与手部前景 | 沉浸、探索 | 加"手部前景"提升真实感 |
| 冲击 | 微距特写 | 锁定材质最关键的一小块，背景大幅虚化 | 道具、皮肤、食物、证物 | 焦点锁定在关键区域 |
| 冲击 | 高空俯冲 | 从高处快速俯冲穿过云层/楼宇接近主体 | 动作开场、航拍 | 结尾"在主体附近稳定收住" |
| 叙事 | 前景遮挡转场 | 树叶、门框、路人掠过把画面盖住，顺势进入下一场 | 换场、时间跳跃 | 前后两段运动方向一致 |
| 叙事 | 凝固推近 | 动作顶点人物与环境一起定住，镜头仍在缓推或平移 | 子弹时间 | 凝固的是画面，镜头仍在动 |
| 叙事 | 穿越推进 | 沿街道/走廊一路前冲，两侧景物越掠越快 | 行进、时间流逝 | 主体行进路线稳住 |
| 叙事 | 逆光轮廓 | 主光在人物身后，只留轮廓与服装线条 | 剪影、黄昏情绪 | 压低面部细节，否则脸会被打亮 |
| 构图 | 对称中轴 | 借走廊、门洞、地面纹理拉出中轴，主体在正中 | 仪式、庄重、压迫 | 写"中轴线"比只写"对称"更有效 |
| 构图 | 过肩 | 前景人物肩部虚化，对焦对面人物 | 对手戏、对话 | 前景肩部必须虚化 |
| 构图 | 框架取景 | 门框、窗框、镜子做前景框，主体在框内 | 纵深、窥视感 | 前景框自然虚化 |
| 构图 | 轻微倾斜 | 地平线与建筑线条歪向一侧 | 不安、失控、悬疑 | 只写"轻微"，过度会晕 |
| 纪实 | 手持跟拍 | 贴着人物节奏跟走，保留呼吸起伏 | 纪实、临场、追逐前段 | "轻微晃动"与"不要剧烈抖动"两头都写 |
| 纪实 | 焦点转移 | 焦点从前景平滑移到后景的关键人物/信息 | 揭示、强调 | 切焦速度适中，不来回乱切 |
| 纪实 | 长焦压缩 | 拉近背景与主体距离，背景化成柔和光斑 | 街拍、夜景、人物剥离环境 | 主体与背景清楚分离 |
| 纪实 | 鱼眼贴脸 | 主体贴近镜头占满前景，画面边缘明显外弯 | 街头、潮流、夸张喜剧 | 写出"边缘弯曲变形" |

## 四、组合公式

`一个主运镜（怎么拍） + 一种画面风格（像什么） + 本镜主体与动作 + 对应的负面限定`

- 都市情绪：旋转环绕 + 霓虹雨夜 → 梦境感叠加疏离感。
- 产品或道具高能亮相：高空俯冲 + 黑金镜面/冷蓝科技 → 速度感叠加质感。
- 治愈收尾：后拉留白 + 明亮日常 → 留白叠加松弛。

## 五、避坑清单

1. 不写主观形容词，写可拍的动作、光线、材质、配色。
2. 【主体】必须具体到性别年龄、服装颜色、位置和正在做的事；只写"一个人"画面会随机发挥。
3. 一条提示词只保留一个主运镜。
4. 风格对应的负面限定要写：怀旧补"不要噪点、不要脏画面"，纪实补"不要剧烈抖动"，逆光补"不要面部过曝"。
5. 系列镜头锁定同一参考图（或同一种子），只换运镜和风格词，整段画面才统一。
