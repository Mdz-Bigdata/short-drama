# 提示词结构契约

选**一个**主契约，把占位符填满，删掉不相关的字段。素材 token（`@图片N`/`@视频N`/`@音频N`）保持平台界面上显示的原样，不要翻译。

| 场景 | 用哪个契约 |
|---|---|
| 有参考图/参考视频、要拍一整段戏（多镜连续） | §1 六段式 Full-Reference（主力） |
| 单镜快速出片 | §2 单镜标准契约 |
| 已有首帧图，要它动起来 | §3 图生视频 / 首帧契约 |
| 有首帧和尾帧，要中间的过程 | §4 首尾帧契约 |
| 纯文字起片，没有任何素材 | §5 文生视频契约 |
| 需要逐秒精确控制 | §6 时间轴契约 |
| 打戏 | §7 动作戏契约 |

---

## §1 六段式 Full-Reference 契约（主力）

每段 15–30 秒视频的提示词是一套结构化的六段式文档，而不是一句话。

| 段落 | 内容 | 作用 |
|---|---|---|
| `subject_definitions` | 角色与场景的锁定描述 | 规定哪些图片负责什么，全片不得漂移 |
| `summary` | 整段剧情概述 | 一句话定调：什么人在什么地方发生了什么 |
| `retention_analysis` | 不变量约束 | 人物不变量 / 场景不变量 / 风格不变量 / 绝对禁止项 |
| `detailed_description` | 逐镜头详细描述 | 机位、运镜、表演、对白、情绪节奏 |
| `overall_soundscape` | 环境声设计 | 雨声/脚步/环境底噪/对白/呼吸等声音层 |
| `non_diegetic_music` | 配乐设计 | BGM 进出点、情绪匹配、乐器选择 |

### 填空模板

```text
【subject_definitions】
整体设定为{时间/地点/戏份类型}，{题材氛围}，主色{主色}，辅色{辅色}，{动机光},{光比},{冷暖关系}。
将 @图片1 中的{场景描述}定义为 <场景1>；
将 @图片2 中的{角色A}定义为 <主体1>，音色为{音色描述}；
将 @图片3 中的{角色B}定义为 <主体2>，音色为{音色描述}。

【summary】
{主体}在{地点}{做了什么}，{结果或转折}。

【retention_analysis】
人物不变量：{面孔/发型/服装/配饰/伤痕/持有道具及其手别}全程不变。
场景不变量：{空间布局/光源数量与方向/关键陈设位置}全程不变。
风格不变量：{色彩分级/光比/镜头质感/胶片颗粒}全程不变。
绝对禁止项：{本段不允许出现的元素}。

【detailed_description】
镜头1：{运镜中文}（{运镜英文}），起幅：{首帧} → 落幅：{末帧}，
{可见动作与身体细节}，{具象微表情}；{光色与光比}；{环境物理反馈}。
镜头2：……（同上结构，且必须承接镜头1的落幅）
镜头3：……

【overall_soundscape】
{环境底噪层}，{动作音效层}，{人声/呼吸层}，{声音的强弱变化点}。

【non_diegetic_music】
{进点时间}起{乐器}{情绪}进入，{出点时间}{收/留白}；{是否与动作卡点}。
```

### 完整范例（3 镜 / 古装权谋夜戏）

> 这是本项目的标准写法样例，新提示词照此结构写。

```text

动机硬光，8:1大光比，冷暖分离。
将 @图片1 中的祭坛边柴堆引火区夜景定义为 <场景1>；
将 @图片2 中的裴无咎定义为 <主体1>，音色为偏低沉厚、冷得无情绪的三十五岁男声；
将 @图片3 中的沈昭雪定义为 <主体2>，音色为中低声区、偏冷带颗粒感的二十一岁女声。

镜头1：低角度仰拍缓慢升起（low angle hero shot, tilt up, worm's eye），
起幅：<主体1>袍角与脚边浇满灯油的干柴近景，火把焰头在画面边缘跳动 →
落幅：中景，<主体1>侧身立于柴堆旁，火把已凑近柴堆，
```

## §3 图生视频 / 首帧契约

```text
以 @图片1 为首帧，保持画面中人物的面孔、发型、服装、配饰与所处环境完全不变。
镜头从该画面开始：{运镜}，{景别变化}。
{主体}{动作，从静止自然启动}，{微表情变化}。
背景与光源保持 @图片1 的{光源方向/色温}不变，不要改变构图与陈设。
{质量锚点串}{稳定性与负面串}
```

**要点**：首帧图已经决定了一切外观，提示词只负责「让它动起来」；不要在提示词里重新描述一遍长相，那会引起漂移。

## §4 首尾帧契约

```text
以 @图片1 为首帧、@图片2 为尾帧。
中间过程：{主体}{从首帧状态到尾帧状态的连续动作过程}，动作自然连贯、符合物理惯性。
镜头：{运镜}，与动作同步。
过程中保持{人物外观/服装/道具/光源}不变，不要出现首尾帧之外的新元素、新人物、新场景。
{质量锚点串}{稳定性与负面串}
```

**要点**：首尾帧之间只允许一个连续动作。跨度太大（如"站着"→"倒地"→"起身"）必须拆成两段。

## §6 时间轴契约（逐秒控制）

当需要精确到秒时，把 `detailed_description` 换成时间戳剧本：

```text
【00:00-00:05】{阶段名}：{动作/物理指令}；{镜头}；{对白/音效}。
【00:05-00:10】{由上一段状态自然延续}：……
……
【00:25-00:30】{收束}：{动作因果与清晰结尾}。
```

规则：每一段的起始状态必须等于上一段的结束状态；不要在段内塞入两个不相关的动作。

## §7 动作戏契约

```text
{时长}秒{题材档}动作短片。{地点与环境}，{地面/天气等物理条件}。
写实电影质感，动作流畅、符合人体力学；避免血腥特写（该项无档位，恒定生效）。
题材档（三选一，全片统一，只保留选中的那一行）：
- 写实档：禁用超能力、禁用夸张慢动作拖尾。
- 古装武侠档：允许刀光气浪、剑气折射、轻功位移；仍禁能量球与法阵。
- 仙侠玄幻档：允许灵气环绕、剑气破空、能量冲击波、法阵光效；能量特效必须标方向{前推/上冲/下劈/爆散/环绕}，一镜只允许一种。

站位与方向（全段不变）：
{A}始终在画面左侧，面向右；{B}始终在画面右侧，面向左；两人距离{N}步。
攻击方向统一：{A}的攻击自左向右推进，{B}的攻击自右向左推进；
所有位移沿这条轴线发生，不跨越轴线，不左右对调。

人物：{A}是{打法特征}，{服装}，打法以{技术特点}为主；
{B}是{打法特征}，{服装}，以{技术特点}为主要进攻手段。

攻防规则：{谁}率先出手，{谁}先格挡或让开再行反制。
全片两人都要有主动出招、防御化解、格挡和反击，
任何一方不得连续挨打超过一个回合。
每个回合（约 3 镜、4–6 秒）完成一次进攻—化解—反击的完整轮转；15 秒段落 = 2 个完整回合 + 1 记终结击。

分段时间轴：
0-2秒 {开场对峙与架势}；
2-5秒 {A抢攻、B闪避并反制}；
5-8秒 {B贴身压制、A转守为攻}；
8-11秒 {互换攻防、节奏加快}；
11-13秒 {一方反扑逼退另一方}；
13-15秒 {抓住破绽一次制胜反击收尾}。

运镜与画面：全段按 全景建立 → 中景交手 → 近景/局部特写打击 → 全景交代结果 的顺序编排景别，
禁止全程单一景别；手持跟拍与固定中景交替，穿插两三个极短的面部特写捕捉眼神与呼吸；
全程让{武器/拳脚}、脚步、肌肉受力和衣料飘动保持清晰可见；
只在最后一击命中时用一瞬间慢镜头。
全程避免动作发虚、肢体扭曲、武器形变、镜头莫名切换。

光影与氛围：{主光方向与色温}，{明暗对比强度}，{题材色板种子}，
{环境粒子：尘土/雨幕/雪沫，只保留一类}。

音效提示：{金属撞击/钝击闷响/破空声/地面碎裂声/低频蓄音}，
对齐{形变第一帧/火花迸发瞬间}。

打击感五件套（每一次打击都必须写全五类，分摊在不同镜次，不要挤在同一镜）：
① 蓄力势能{重心下压/肌肉紧绷/关节蓄力/身体扭转}；
② 接触冲击{环形冲击波/火花/冲击帧/画面短震}；
③ 受击反馈{头部猛甩/身体弓形后弹/手臂上扬/步伐擦地}；
④ 环境破坏{碎石飞溅/尘土炸开/地面裂纹/断木横飞}；
⑤ 镜头反馈{撞击瞬间镜头剧烈震动/速度线爆发；短暂慢动作仅限终结击}。

画面稳定流畅，无闪烁跳帧，无五官变形，无肢体畸形，人物不换脸，光影统一，24fps。
```

**题材档与站位段的使用规则**：

- **题材档必须三选一，且全片统一**。混档会让同一段里既有"写实拳脚"又有"法阵光效"，模型判断不出能量特效该遵守哪套物理，直接糊成一团发光斑块。
- **血腥禁令不随档位变化，三档都恒定生效**（与 [performance-action.md](performance-action.md) §3.13 动作戏负面词与网关清洗一致）。
- 仙侠玄幻档的能量特效**必须标方向**（前推 / 上冲 / 下劈 / 爆散 / 环绕，写法见 [performance-action.md](performance-action.md) §3.10）。不标方向时模型默认渲染成原地静止的环绕光晕，打击感归零；**一镜写两种以上能量特效**会让两套粒子互抢主体权重，形变优先级打架，武器与手部一起变形。
- **正文里的「攻防规则」三行与 [performance-action.md](performance-action.md) §4.3 攻防轮转规则同源**，此处保留只是为了让契约能整段粘贴；**规则本身以 performance-action.md §4.3 攻防轮转规则为准，要改就只改那一处**，不要在本文件里单独调数值（回合镜数、4–6 秒、15 秒 = 2 回合 + 1 记终结击）。
- **站位与方向段要在每一镜的提示词里复述当镜适用的部分**，只在契约头写一次不够用：分段调用时每段是独立请求，模型看不到上一段的轴线声明，第二段就会左右对调（上一镜自左向右的出拳，下一镜从右边挡回来）。

**输出格式铁则：正文与工具配置严格分离**（本铁则适用于本文件全部契约，不限 §7）：

| 去向 | 内容 | 为什么 |
|---|---|---|
| **顶层字段 / 配置区**（禁止写进提示词正文） | `resolution`（分辨率）、`duration`（建议总时长）、`ratio`（宽高比 9:16 / 16:9）、`watermark`（水印开关）、运动幅度档位（motion strength）、一致性档位（consistency level）、`seed` | 这些是采样器参数，不是画面描述。模型在正文里读到它们只会困惑或直接忽略，白占 token，稀释正文的有效信息密度 |
| **提示词正文** | 画质与风格锚点（胶片质感、光比、色彩分级）、稳定性负面串、**帧率 24fps** | 前两类是可渲染的画面语义；**帧率 24fps 是唯一破例**——它同时是画面质感描述（24fps 电影感，防止被误判为升格高帧率），且是防崩坏后缀的固定成分，抽掉会让稳定性串缺一角 |

> **时长的边界**：正文首句 `{时长}秒{题材}短片` 是给模型定**叙事节奏**的定调句，保留；真正决定出片长度的是顶层 `duration`。两者必须写成同一个数，冲突时以顶层字段为准。除这一句外，正文不得再出现任何时长、画幅或分辨率的声明。

**交付时分两块，标题清晰区分**：

```text
【提示词正文】
（六段式或本节契约的完整正文，不含分辨率、画幅、时长、seed、档位参数）

【工具配置建议】
resolution: 720p
duration: 15
ratio: 9:16
watermark: false
motion_strength: {档位}
consistency: {档位}
seed: {固定值或留空}
```

**分段生成硬参数**（把上面的时间轴切开逐段调用时）：**每段时长 / 动作单元 / 禁止项 / 一致性四项硬参数见 [performance-action.md](performance-action.md) §4.1 拆镜原则**，本文件不重复；超了必崩，没有例外。

> **约束单位是一次打击（跨出招—受击—环境三镜链），不是一镜。** 五类必须在同一次打击里全部出现，但不得挤进同一镜——
> 出招镜担①、受击镜担②③、环境镜担④、⑤优先后期做。
> 详见 [performance-action.md](performance-action.md) §4.2 打击感五件套。

## 通用写法规则

### 起幅 / 落幅

每一镜都必须写清首帧和末帧：

```text
起幅：{画面内容 + 景别} → 落幅：{画面内容 + 景别}
```

下一镜的**起幅必须等于上一镜的落幅**，这是跨镜连贯的机械保证。

### 台词

```text
用{音色描述}，{语速与情绪}说道 {台词原文}
```

- 台词原文用 `{}` 花括号包裹，模型据此判断口型与配音内容。
- 音色写法：`偏低沉厚、冷得无情绪的三十五岁男声`、`中低声区、偏冷带颗粒感的二十一岁女声`。
- 语速情绪写法：`语速平缓、毫无起伏地`、`压着嗓子一字一句`、`声音发抖、尾音上扬`。
- 默认不出字幕，结尾负面串里已含 `保持无字幕`。
- 一条台词只绑一个说话人、一种语言，不要把多语言要求混进同一段。

### 声音层

用尖括号包一段声音设计，放在每镜画面描述之后：

```text
<{环境底噪}，{动作音效}，{人声/呼吸}，{强弱变化}>
```

### 素材绑定

```text
将 @图片N 中的{描述}定义为 <场景N> / <主体N>，音色为{音色描述}
```

定义一次之后，全片只用 `<主体1>` `<场景1>` 这样的代号引用，不要反复重述长相——重述是漂移的主要来源。

## 1. 六段式 Full-Reference 结构（产线主契约）

### 1.1 六段定义与硬顺序

六段**顺序固定、不得增删、不得合并、不得改名**。字段键用于程序侧序列化，中文标题用于提示词正文。

| # | 字段键 | 正文标题 | 作用（一句话） | 必填 | 建议篇幅 | 缺失时的典型事故 |
|---|---|---|---|---|---|---|
| 1 | `subject_definitions` | 【主体定义】 | 规定哪张图/哪段音频负责什么，全片不得漂移 | ✅ | 每个资产 1 行 | 换脸、双胞胎、素材污染、背景被参考图替换 |
| 2 | `summary` | 【剧情概述】 | 一句话定调：谁在哪做了什么，什么题材什么基调 | ✅ | 1–2 句 | 模型抓不到重点，画面沦为"会动的PPT" |
| 3 | `retention_analysis` | 【不变量约束】 | 人物/场景/风格三类不变量 + 绝对禁止项 | ✅ | 4 组 | 跨镜换装、光向跳变、色调漂移、道具消失 |
| 4 | `detailed_description` | 【逐镜头详细描述】 | 机位、运镜、表演、对白、情绪节奏、起幅落幅 | ✅ | 每镜 3–6 句 | 动作跳跃、循环静止、时间线压缩 |
| 5 | `overall_soundscape` | 【环境声设计】 | 环境底噪 / 动作音效 / 呼吸 / 对白的声音分层 | ✅ | 3–5 行 | 无声成片、音效与画面不对位、音乐混入人声层 |
| 6 | `non_diegetic_music` | 【配乐设计】 | BGM 进出点、情绪匹配、乐器编制 | ⭕（可声明"无配乐"） | 2–4 行 | 每镜音乐重启、音乐盖住台词、音乐与情绪反向 |

**硬规则：**

1. 第 1 段必须写在最前面。**越需要精准参考的素材（人脸大头照）位置越靠前**。
2. 第 3 段的不变量只写"跨镜必须一致"的东西；一次性的画面细节写进第 4 段，不要塞进不变量。
3. 第 4 段是唯一允许写动作和时间的段落；第 1/2/3 段**不写动作**。
4. 第 5 段与第 6 段必须分开写。禁止把 BGM 混进环境声段，也禁止用"背景音乐"描述音效。
5. 六段之间**不重复描述**。同一句约束只允许出现在一个段落里（不变量写在第 3 段，第 4 段只写变化量）。
6. 需要"绝对不许出现"的东西，全部集中到第 3 段的【绝对禁止】子块，不要在每镜末尾各挂一串负面词。

### 1.2 第 1 段 `subject_definitions`（主体定义）

**职责**：把素材 ID 变成有语义的标签，并声明每个标签的作用域与禁止迁移项。这是全片防漂移的第一道闸。

**必写字段：**

| 字段 | 写法 | 示例 |
|---|---|---|
| 素材编号 | `@图片N` / `@视频N` / `@音频N` | `@图片1` |
| 标签定义 | `将 @图片N 中的[2-3个稳定静态特征] 定义为 <主体N>` | `将 @图片1 中的短黑发、左眉浅疤、深蓝旧夹克 定义为 <主体1>` |
| 迁移什么 | 身份 / 妆造 / 场景 / 动作 / 运镜 / 音色 / 节奏 | `仅迁移面部特征` |
| 作用范围 | 全片 / 某角色 / 某时间段 / 某镜头 | `全片` / `08–14秒` / `仅镜头2` |
| 禁止迁移 | 原人物、原背景、水印、品牌、原音轨、辅助线 | `不要迁移 @视频1 中的人物、室内背景、字幕和原音轨` |
| 音色绑定 | `音色参考@音频N` / `语气和音色参考@视频N` | `<主体1> 的音色参考 @音频1，仅参考声线、年龄感与克制语气` |
| 帧位绑定 | `@图片N 作为首帧约束 / 尾帧约束` | `@图片2 作为尾帧约束` |

**填空模板（逐行复制）：**

```text
【主体定义】
将 @图片1 中的[2-3个稳定静态特征] 定义为 <主体1>（[角色名]）；<主体1> 的面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）。
将 @图片2 中的[2-3个稳定静态特征] 定义为 <主体2>（[角色名]）。
将 @图片3 中的[空间/材质/陈设特征] 定义为 <场景1>；不要迁移 @图片3 中的[人物/杂物]。
@视频1 仅参考[运镜轨迹/动作力学/剪辑节奏]，作用于[全片/X–Y秒]；不要迁移 @视频1 中的人物外貌、背景、字幕和原音轨。
@音频1 仅作为 <主体1> 的音色参考（声线、年龄感、语流、情绪），不是 BGM，不复制参考音频中的原句与背景噪声。
@音频2 作为全片 BGM，从 [00:XX] 进入；不要把 @音频1 混入音乐层。
@图片4 作为首帧约束；@图片5 作为尾帧约束。
身份优先级：面孔与发型以 @图片1 为准；服装版型只参考 @图片2；场景与光线以 @图片3 为准；发生冲突时人物身份与场景地理优先。
```

**正例 / 反例：**

| ❌ 错误 | ✅ 正确 | 原因 |
|---|---|---|
| `完全参考@视频1` | `参考 @视频1 的运镜速度与绕行轨迹，应用于 18–24 秒；不要迁移人物、背景、字幕和原音轨` | 引擎无法判断要迁移身份/场景/动作/运镜/音轨中的哪一项 |
| `@图片1跑向门口` | `<主体1>@图片1 跑向门口` 或 `@图片1 中的女子跑向门口` | 裸 `@图片N` 紧接动词触发数字粘连歧义 |
| `[asset-9f2c...] 站在左侧` | `<主体2> 站在画面左侧` | Asset ID 无语义，必须经 `@图片N` / `<主体N>` 桥接 |
| 上传人物三视图作人脸参考 | 拆成"大头照 + 全身照"两张 | 多视图易触发 ID 漂移与双胞胎 |

### 1.3 第 2 段 `summary`（剧情概述）

**职责**：一句话定调。让模型先知道"这是什么片、什么情绪、镜头的核心动作是什么"，再去读细节。

**公式：**

```text
[主体]在[地点]完成[事件]，[题材/风格]，[核心镜头语言]。
```

**填空模板：**

```text
【剧情概述】
[时长]秒[题材]短剧片段：<主体1> 在 <场景1> [完成的核心事件]，情绪由[起点情绪]走向[终点情绪]；[全片核心镜头语言，如"以慢推近景为主，收尾慢拉远"]。[视觉风格一句话]。
```

**写法规则：**

1. 只写**一件事**。出现"然后""接着""同时"就说明该拆镜或该拆批次。
2. 禁止文学化比喻与抽象概念。`个人成长`、`命运的重量`不可用；改写为可见动作。
3. 禁止省略主体。`生长、绽放`这种无主语句式，模型无法确定渲染对象。
4. 禁止空洞画质词（`masterpiece`、`最高画质`、`超清8K`），改用物理材质与光线描述。
5. 情绪必须写成"从 A 到 B"的曲线，不写单一静态形容词。

### 1.4 第 3 段 `retention_analysis`（不变量约束）

**职责**：声明四组不变量。第 4 段允许描述的只有"变化量"，凡是第 3 段列出的都**不许在任何镜头里改变**。

**四个子块（顺序固定）：**

```text
【不变量约束】
一、人物不变量：
[角色A]：同一张脸、同一五官比例、同一发际线与发型、同一服装版型/颜色/材质、同一体型与年龄感、同一标志性配饰；跨镜头锚点为[2-3个永远可见的独特标记]。
[角色B]：……
道具归属：[道具名]始终在[角色]的[左手/右手/口袋/桌面位置]，未经时间轴说明不得换手、消失或重复出现。

二、场景不变量：
同一空间布局与家具位置：[左侧…、右侧…、中间…、出入口…]；主光来自[方向]，色温[冷蓝/暖黄]，时间为[白天/夜晚]，天气为[…]；前中后景层次为[前景…/中景…/背景…]。
轴线：遵守 180 度轴线，[角色A]始终在画面左侧，[角色B]始终在画面右侧，视线方向一致。

三、风格不变量：
[视觉风格词，全片逐字一致，如"真实电影质感，实拍写真，photorealistic live-action cinematic film still"]，[色调公式，如"青橙电影色调 teal and orange"]，[焦段与景深，如"85mm 人像焦段，浅景深"]，[胶片/颗粒，如"Kodak Vision3 500T，film grain"]。
画质包：高清，细节丰富，电影质感，色彩自然，光影柔和。
稳定包：人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿。

四、绝对禁止：
不要跳切，不要时间跳跃，不要突然换姿势，不要瞬移，不要更换背景，不要换衣服，不要换发型，不要换脸，不要光线突变，不要阴影突变，不要跳轴，不要视线错位，不要道具消失，不要道具重复，不要动作接不上，不要情绪突变，不要随机换角度，不要空间断裂，不要闪烁，不要场景重置。
保持无字幕，避免生成任何文字或字幕；不要生成水印；不要生成 Logo。
视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻。
```

**不变量优先级（冲突时按此裁决）：**

```text
角色一致性 > 光影一致性 > 色调一致性 > 背景一致性 > 运动一致性
```

**兜底约束包挂载表：**

| 包名 | 何时必挂 | 内容 |
|---|---|---|
| 画质包 | 默认必挂 | `高清，细节丰富，电影质感，色彩自然，光影柔和` |
| 稳定包 | 默认必挂 | `人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿` |
| 水印/Logo 兜底 | 默认必挂 | `不要生成水印；不要生成 Logo` |
| 字幕兜底 | 非文字生成任务必挂 | `保持无字幕，避免生成任何文字或字幕` |
| 双胞胎兜底 | 多人/多主体场景必挂 | 见上方"绝对禁止"第三行 |
| 风格锚定 | 动漫/非写实场景必挂 | 显式写 `2D 日漫风格` / `3D 国风漫画` / `赛博朋克冷蓝紫色调` |
| 强方位约束 | 多人正面动态镜头必挂 | `左侧角色穿灰蓝色作训服…`＋固定机位 |
| 写实排卡 | 真人短剧必挂 | `绝非动画、绝非卡通、绝非3D渲染、绝非插画、绝非草图 (not anime, not cartoon, not 3d render, not cgi, not illustration, not sketch)` |

> **负面词纪律**：负面词要保护"本任务"。不要把一串固定负面词无差别贴到每一条提示词末尾；纯音轨编辑任务不需要"不要跳轴"，静止空镜不需要"不要多指"。

### 1.5 第 4 段 `detailed_description`（逐镜头详细描述）

**职责**：唯一描述"变化"的段落。每镜一段，内部字段顺序固定。

**单镜内部字段顺序（不可打乱）：**

```text
镜号 → 承接上一镜 → 景别 → 机位角度/焦段 → 运镜（1 种） → 起幅 → 表演动作（1 个小动作） → 可观察表情 → 对白 → 情绪节奏 → 落幅 → 交付下一镜
```

**填空模板：**

```text
【逐镜头详细描述】
镜头1（[起止秒或时长]）：直接承接[开场建立 / 上一镜最后一帧的什么状态]。[景别，如中近景 medium close-up]，[角度，如低角度仰拍 low angle]，[焦段，如 50mm]，[运镜，如缓慢推轨推进 slow dolly in，速度与情绪修饰]。
起幅：[画面开始时的准确静止状态——人物位置/朝向/视线/道具在哪只手/景别]。
表演：<主体1> [一个可完成的小动作，带肢体+幅度+速度+力度]，[动作过渡衔接，如"借着转身惯性顺势抬手"]。
表情：[眉/眼/嘴/下颌/呼吸/手部的可观察细节]。
对白：<主体1>（[语言]，[音色]，[情绪]，[语速]）说：{[台词原文]}。
情绪：从[情绪阶段A]推进到[情绪阶段B]，只推进一级。
落幅：[画面结束时的准确静止状态，与起幅有可见差异]。
交付：向下一镜交付[视线方向/动量方向/道具位置]。

镜头2（[起止秒]）：直接承接镜头1落幅的[具体状态]。……
```

**逐镜写作 8 条规则：**

1. **一镜一事**：每镜只推进一个小动作 + 一个情绪节拍。禁止"走路、打架、然后哭泣"塞进一镜。
2. **一镜一运镜**：单镜只指定 1 种运镜（推 / 拉 / 摇 / 移 / 固定 / 跟拍择一），禁止推拉摇移叠加。
3. **一帧一景别**：同一条提示词里不得既写 `extreme wide shot` 又写 `close-up on eyes`。
4. **构图词前置**：把景别和运镜写在句首（`Close-up shot of a handsome man...`），主体描述过长会抢走构图词权重。
5. **动作因果链**：准备 → 发力 → 接触 → 反应 → 恢复。禁止"一步到位"（`a man jumping from a bridge` → `a man leaning over the bridge railing, slowly tilting forward`）。
6. **情绪具象化**：禁写"愤怒/悲伤"，改写为面部肌肉与肢体（悲伤 → `肩膀微微颤抖、眼眶泛红、手指攥紧衣角`）。
7. **动作安全区按戏别分流**：
   - **文戏默认走动作安全区**：优先低缓连续小动作（缓慢回头、微风拂发、轻抿咖啡、微表情变化）；规避奔跑、拳脚交加、街舞、攀爬、多人复杂肢体接触。
   - **打戏不走安全区**，改走 §7 动作戏契约 + "出招-受击"三镜拆分（见 [performance-action.md](performance-action.md) 附 §3.4「出招-受击三镜拆分法」）。实体肢体接触仍**禁止同框生成**（同框接触帧会让两具身体的骨架互相吞并，穿模、多手多腿），按下一条第 8 点拆成正反打，对手用**虚化剪影 + 目标高度锚点**承载攻防语义；但动作本身按契约正常编排，**不做降级**。
8. **正反打分拍**：多人肢体交互（握手、拥抱、对打）不要写进同一镜，改用过肩正反打分别生成。

**拆镜示范（发现→反应→消化→决定→行动，每步单独成镜）：**

```text
❌ 她发现真相后崩溃离开。

✅ S01：她低头看到手机上的消息，身体僵住。
✅ S02：她缓慢抬眼看向对方，眼眶开始泛红。
✅ S03：她嘴唇抿紧，右手攥住手机，呼吸变重。
✅ S04：她没有说话，只是后退半步。
✅ S05：她转身，手机垂在右手，缓慢走出客厅。
```

### 1.6 第 5 段 `overall_soundscape`（环境声设计）

**职责**：声音的**画内层**。分四轨写，逐轨点名，禁止只写"有声音/无声音"。

| 声音层 | 写什么 | 禁止 |
|---|---|---|
| 环境底噪 (ambience) | 空间+材质+持续性，同一场戏共用同一底噪 | 抽象词"氛围音" |
| 动作音效 (foley) | 材质 + 力度 + 表面三维描述，并写对齐帧 | "打斗音效""脚步声" |
| 呼吸 / 体感 | 吸气、叹气、喘息、哽咽、心跳 | 与台词混写 |
| 对白 (dialogue) | 见 §5，绑定说话人/语言/音色/情绪 | 与 BGM 同段 |

**填空模板：**

```text
【环境声设计】
环境底噪：[空间+材质+持续声，如"密集雨点敲击玻璃 + 远处闷雷 + 雨水汇流"]，[空间声学定语，如"雨中浸泡 Rain-drenched with white noise bed"]，全场保持同一底噪，场景切换时交叉淡化。
动作音效：[X 秒/镜头N] [材质+力度+表面，如"高跟鞋踩在湿滑大理石上的清脆哒哒 Sharp heels clicking on wet marble floor"]，对齐[具体画面帧，如"鞋跟接触地面的那一帧"]。
呼吸与体感：[如"急促浅呼吸、说话前吸气"]，出现在[镜头N]。
对白轨：见【逐镜头详细描述】各镜对白行；口型与目标语言发音同步。
静音处理：[X–Y 秒] 只保留 [呼吸/雨声]，其余全部压低。（禁止写"无声音"）
```

**物理拟声对照（抽象 → 可执行）：**

| ❌ 抽象描述 | ✅ 物理拟声描述 |
|---|---|
| 悲伤的音乐 | 大提琴低沉缓慢的拉弦声 |
| 紧张的声音 | 心跳般的低频鼓点，逐渐加速 |
| 好听的风声 | 松林间穿过的呼啸风声 |
| 打斗音效 | 刀刃碰撞的金属铿锵声 |
| 走路声 | 重靴踩在干雪上的嘎吱声 `Crunching heavy boots on dry compacted snow` |
| 门声 | 锈铁门磨混凝土地面的刺耳刮擦 `Rusty metal door grinding on concrete floor` |

**音效对齐帧规则（动作戏）：**

| 动作 | 对齐哪一帧 | 混音要点 |
|---|---|---|
| 重拳/重腿命中 | 面部形变的**第一帧** | 切中高频、增强低频，产生钝击分量 |
| 金属兵器格挡 | 火花迸发的**那一瞬间** | 留 0.5s 高频余音颤鸣 |
| 挥舞/破风 | 加速前冲的**前 3 帧**（声音先于画面） | 为撞击做听觉蓄力 |
| 受击坠地 | 身体接触地面、爆起尘土的**那一帧** | 混合沙石碎裂与身体重击 |

> **产线默认策略**：若本项目走"只生成音效、后期铺乐"路线，每个批次开头必须写：`只生成音效，禁止生成音乐。禁止生成任何字幕。`，且第 6 段写 `本片段不生成配乐`。

### 1.10 六段式实例（15 秒，雨夜对峙）

```text
【主体定义】
将 @图片1 中的黑色长直发低马尾、白色针织衫、左手银色戒指 定义为 <主体1>（林夏）；面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）。

@音频1 仅作为 <主体1> 的音色参考（偏低沉、微沙哑、御姐感），不是 BGM，不复制参考音频中的原句与背景噪声。
身份优先级：面孔与发型以 @图片1 为准；服装只参考 @图片2；场景与光线以 @图片3 为准。

【剧情概述】
15秒都市虐恋片段：<主体1> 在 <场景1> 看清手机上的消息后强忍情绪转身离开，情绪由压抑平静走向沉默离开；以中景慢推起、近景慢推递进、慢拉远收束。真实电影质感实拍写真。

【不变量约束】
一、人物不变量：<主体1> 同一张脸、同一低马尾、同一白色针织衫与浅蓝牛仔裤、左手银色戒指全程可见；手机始终在右手，不得换手或消失。
二、场景不变量：沙发在画面左侧，落地窗在画面右侧，茶几在中间；主光为右侧窗外冷蓝月光，沙发后方一盏暖色台灯；夜晚，室内；前景茶几、中景人物、背景虚化城市霓虹；<主体1> 始终位于画面左侧，遵守180度轴线。
三、风格不变量：真实电影质感，实拍写真，photorealistic live-action cinematic film still；冷蓝为主的低饱和色调；85mm 人像焦段，浅景深；轻微 film grain。画质包：高清，细节丰富，电影质感，色彩自然，光影柔和。稳定包：人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿。
四、绝对禁止：不要跳切，不要瞬移，不要更换背景，不要换衣服，不要换发型，不要换脸，不要光线突变，不要跳轴，不要道具消失，不要情绪突变，不要闪烁；保持无字幕；不要生成水印；不要生成 Logo；绝非动画、绝非卡通、绝非3D渲染、绝非插画。

【逐镜头详细描述】
镜头1（0–5秒）：开场建立。中景 medium shot，平视 eye level，50mm，缓慢推轨推进 slow dolly in。
起幅：<主体1> 站在画面左侧靠近沙发，面朝画面右侧，手机亮屏握在右手，垂在腰侧。表演：她把手机缓慢抬到胸前，视线落到屏幕上，肩膀轻微下沉。表情：眉心轻轻收紧，嘴唇抿成一条线。对白：无。情绪：压抑平静 → 怀疑。落幅：手机停在右手胸前，视线锁在屏幕，身体静止。交付：向下一镜交付"手机在右手胸前、视线在屏幕"。

镜头2（5–10秒）：直接承接镜头1落幅的手机位置与视线。近景 close-up，平视，85mm，缓慢推轨推进 slow push in。
起幅：手机在右手胸前，视线落在屏幕，冷蓝光从画面右侧打在侧脸。表演：她从手机缓慢抬眼看向画外右侧，喉结轻微一动。表情：眼眶泛红，鼻翼微微颤动，右手指节收紧。对白：<主体1>（普通话，音色参考 @音频1 的低沉微沙哑，隐忍，语速偏慢，一字一顿、尾音发抖）说：{我【从来】没有……求过你。}。情绪：怀疑 → 被刺痛。落幅：视线停在画外右侧，眼中含泪未落，手机仍在右手。交付：向下一镜交付"画外右侧视线与未落的泪"。

镜头3（10–15秒）：直接承接镜头2落幅的视线与含泪状态。中景转全景，平视，35mm，缓慢拉远 slow dolly out。
```

## 2. 资产绑定语法

### 2.1 素材 Token 与配额

| Token | 含义 | 本平台适配器上限（MiniMax H3 / Seedance） | Seedance 2.5 官方手册上限 | 单文件限制 |
|---|---|---|---|---|
| `@图片1`…`@图片N` | 图片素材 | 9 | 30 | ≤30MB；jpeg/png/webp/bmp/tiff/gif；宽高 300–6000px；宽高比 0.4–2.5 |
| `@视频1`…`@视频N` | 视频素材 | 3 | 10 | ≤200MB；mp4/mov；单段 2–30s，合计 ≤30s；24–60fps |
| `@音频1`…`@音频N` | 音频素材 | 3 | 10 | ≤15MB；wav/mp3；单段与合计 ≤30s |

**规则：**

- 编号按**上传顺序**从 1 开始，必须与界面显示的 token 逐字一致，不翻译、不改写。
- 取**平台适配器上限与模型手册上限中的较小值**；不确定时按适配器上限（9/3/3）写。
- 素材不是越多越好：推荐 4–5 个（角色图 1–2 张〔大头照+全身照〕+ 场景图 1 + 运镜视频 1 + 音频 1），不建议用满上限。
- 超过 4 个参考人物时，先分组生图（每组 ≤4 人）再图生视频。
- 长图 / 九宫格素材必须先拆成单图再上传。

**稳定性区间（质量建议，非拒绝阈值）：**

| 场景 | 稳定区间 | 高风险区间 |
|---|---|---|
| 视频/音频提供的不同主体数 | 1–5 | 6–10 需多次尝试 |
| 主体参考视频时长 | 5–10s | 更长会降低稳定性 |
| 图片提供的不同主体数 | 1–8 | 9–12 需多次尝试 |
| 被编辑的源视频 | ≤20s | 更长会削弱编辑保留度 |

### 2.2 `<主体N>` / `<场景1>` 定义语法

**两种绑定写法，二选一：**

| 情形 | 写法 | 示例 |
|---|---|---|
| 未提前定义、单次使用 | `<主体N>@图片N` | `张红@图片1`、`<主体1>@图片1` |
| 多主体场景或需要全片复用 | 先定义再引用 | `将 @图片1 中的[2-3个稳定静态特征] 定义为 <主体1>`，之后全程写 `<主体1>` |

**扩展写法：**

```text
# 同一主体来自多张素材
将 @图片1 中的[面部特征]、@图片2 中的[服装与配饰] 定义为 <主体1>。

# 人脸参考策略（推荐）
<主体1> 的面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）。

# 场景定义
将 @图片3 中的简约木质宿舍 定义为 <场景1>。

# 首尾帧绑定
@图片4 作为首帧约束；@图片5 作为尾帧约束。

# 运镜锚定
运镜参考 @视频1 的中景推拉与轻微摇移。

# 音色绑定
<主体1> 的音色参考 @音频1；旁白音色参考 @视频1 中的男声。
```

**两条强制原则：**

| 原则 | 内容 | 反例 → 正例 |
|---|---|---|
| Asset ID 屏蔽原则 | 底层模型无法关联无语义 Asset ID，严禁把 `[asset-xxx]` 裸写进动作描述，必须经 `@图片N` / `<主体N>` 桥接 | `[asset-3f21] 走向门口` → `<主体1> 走向门口` |
| 断句防歧义原则 | `@图片N` 后紧接动词或方位词会触发数字粘连歧义，必须改写 | `@图片1跑向…` → `<主体1>@图片1 跑向…`；`@图片2位于…` → `@图片2 中的女生位于画面左侧` |

### 3.4 首尾帧模板

**适用条件（四条全满足才走首尾帧）：**

1. 合法首帧和尾帧都存在；
2. 尾状态是硬性剧情锚点（落座、转身完成、道具到位、门完全关闭）；
3. 首尾画面属于同一镜头且场景/角色差异可连续过渡；
4. 运行时模型档案确认支持首尾帧。

## 4. 起幅 / 落幅书写规范（start frame → end frame）

### 4.1 定义

| 术语 | 契约字段 | 定义 | 判定标准 |
|---|---|---|---|
| 起幅（start frame） | `start_state` / 首状态 | 镜头**第一帧**的静止画面 | 能被单帧截图完整描述，无动词进行时 |
| 落幅（end frame） | `end_state` / 尾状态 | 镜头**最后一帧**的静止画面 | 能被单帧截图完整描述，且与起幅有可见差异 |
| 承接（continuity_in） | `continuity_in` | 本镜起幅从上一镜落幅继承了什么 | 明确指向上一镜镜号与具体状态 |
| 交付（continuity_out） | `continuity_out` | 本镜落幅向下一镜交付什么 | 明确写出视线/动量/道具位置 |
| 交接状态 | handoff state | 落幅时仍在延续的动量与运镜 | 用于视频延长与跨镜衔接 |

### 4.2 十条书写规则

1. **起幅必须是静止画面**，写状态不写过程。`手机在右手胸前，视线落在屏幕` ✅；`她正在看手机并抬起头` ❌。
   > **动作戏例外**：打戏镜头的起幅**不写死姿态**。起幅要写**运动峰值的凝固瞬间**（`短刀正向要害推进中`、`脚刚离地`、`衣袂横拖出残影`），而不是"已完成收刀后的站姿"。原因：死姿态作起始帧，会让视频开场先把人物从静止"重新启动"一次，剪进时间线就是一次节奏断裂。
   > "静止画面"的本意是**构图可读、不糊**，不是**人物不动**——运动峰值同样是清晰单帧（如"空中下劈定格"），两者不冲突。
2. **起幅六要素齐全**：景别 / 人物位置 / 朝向 / 视线 / 道具归属（哪只手） / 主光方向。
3. **落幅与起幅必须有可见差异**。两者相同 = 触发循环或静止（模型会原地打转 2–3 秒重复动作）。
4. **落幅只允许一个新状态**：一个小动作 + 一级情绪。落幅出现两个新事实说明该拆镜。
5. **落幅必须声明道具的归属、所在手、空间位置和状态**，供下一镜 `continuity_in` 原样承接。
6. **落幅即下一镜起幅**。分镜表里 `S(n).end_state` 必须逐字等于 `S(n+1).start_state` 的可见部分。
7. **运镜也有起幅落幅**：写清机位起点、终点、方向、速度与叙事原因（如"中景起、近景落，慢推，把注意力移向人物的细微反应"）。
8. **运镜不改光**：摄影机移动时光源保持空间固定，落幅的主光方向与起幅一致。
9. **落幅仍有动量时必须写明动量**：`角色位于站台右侧、面向左前方、奔跑动量尚未停止；帆布包在左肩；车票仍在右手；镜头正向后移动`。
10. **禁止写"同上/同前/延续上一批次/场景不变/人物位置不变/继续刚才的对峙"**；每镜完整重写起幅，同场景后续镜头不得越写越短。

### 4.3 起幅/落幅字段模板

```text
起幅：[景别]，<主体N> 位于[画面位置]，面朝[方向]，视线落在[对象]，[道具]在[哪只手/哪个位置]，主光来自[方向]，[前景/背景层次]。
落幅：[景别（若运镜改变景别则写终点景别）]，<主体N> 位于[画面位置]，姿态为[…]，视线在[…]，[道具]在[…]，[新出现/消失的画面元素]。
交接状态：[动量方向与速度]、[镜头运动状态]、[光线状态]、[声音状态]。
承接：接 [上一镜号] 落幅的[具体状态]。
交付：向 [下一镜号] 交付[视线/动量/道具位置]。
```

### 4.4 落幅类型速查

| 落幅类型 | 适用 | 写法要点 | 是否适合首尾帧模式 |
|---|---|---|---|
| 动作完成型 | 落座、转身完成、门完全关闭 | 写"完成态"姿势与接触点 | ✅ 强烈推荐 |
| 道具到位型 | 道具交接、放下、收进口袋 | 写道具最终归属与手部空出 | ✅ |
| 视线交出型 | 为下一镜揭示对象铺垫 | 写视线方向 + 画外左/右 | ⭕ 首帧模式即可 |
| 离场/背影型 | 段落收束 | 写人物在画面中的比例与留白 | ⭕ |
| 情绪定格型 | 情绪最高点 | 写面部最终状态（泪未落/嘴角僵住） | ⭕ |
| 留白空镜型 | 结尾余味 | 写人物离开后画面剩下什么 | ✅ |

### 4.5 跨镜交接链示范

| 镜号 | 时间 | 承接上一镜 | 起幅 | 落幅 | 交付 |
|---|---|---|---|---|---|
| S01 | 0-3s | 开场建立 | A在左、B在右，两人静止，手机在茶几右上角 | 站位不变，A视线转向茶几 | 视线指向茶几 |
| S02 | 3-6s | 接S01站位与视线 | A仍在左侧，视线在茶几 | A低头看手机，右手靠近手机 | 右手位置 |
| S03 | 6-9s | 接S02低头状态 | A右手在手机上方 | 手机在A右手，屏幕亮 | 手机在右手 |
| S04 | 9-12s | 接S03手机在手 | 手机在右手胸前，视线在屏幕 | A抬头看B，眼眶泛红 | 视线指向B |
| S05 | 12-15s | 接S04强忍状态 | A面向B，泪未落 | A转身，手机垂在右手，背影入画 | 段落收束 |

### 4.6 起幅落幅禁止项

```text
不要写"同上/场景不变/人物位置不变"；不要让落幅与起幅完全相同；不要在一个落幅里同时完成两个新动作；不要在落幅里让道具换手、消失或凭空出现；不要因为运镜改变光源方向；不要让下一镜的起幅重置人物位置或姿态。
```

## 5. 对白写法

### 5.1 特殊字符规范（强制）

| 信息类型 | 符号 | 示例 |
|---|---|---|
| 背景音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` / `(soft piano melody)` |
| 音效 | `<>` | `<远处传来狗叫声>` / `<footsteps on wet pavement>` |
| 台词 | `{}` | `{你好，世界}`；小语种需标注语种 |
| 字幕 / 标题 | `【】` | `【第一章：启程】` |

> 四类符号**不可混用**。台词只能进 `{}`，写进 `<>` 会被当成音效处理；`（）`只承载音乐，不要用来写旁白。

### 5.2 台词行写法（平台正文）

> **台词行万能公式与逐字示例见 [performance-action.md](performance-action.md) §2.11 台词提示词模板**（`[角色] + [基础音色] + [情绪类型] + [强度/克制度] + [语速] + [生理表现] + [停顿/重音标记] + 台词文本`），本文件不重复，只给平台契约正文的落位写法。

**平台正文写法（推荐，绑定主体标签 + 花括号）：**

```text
<主体1>（[语言]，音色参考 @音频1 的[音色描述]，[情绪-强度]，[语速]，[生理表现]）说：{[台词原文]}。
```

**其他等价写法（按下游模型习惯二选一）：**

```text
台词（角色名，情绪标签）："台词内容"
台词（猴子，得意，四川口音）："幺妹儿，霸王别姬有得没得？"
```

### 5.3 语速（契约落位）

> **语速分级表（极慢 / 慢速 / 常速 / 偏快 / 极快，含字/分钟区间与提示词写法）以 [performance-action.md](performance-action.md) §2.3 语速分级表为唯一权威**，本文件不重复。
> 契约侧只需知道：语速词写在台词行的 `[语速]` 位（平台正文里是 `<主体N>（…，[语速]，…）说：{…}` 的第三个逗号段），且必须与 §5.9 的时长换算自洽——写了「语速极慢」就不能再按 0.3s/字 估镜头长度。
> 短剧默认基线 **270–320 字/分钟**（比传统影视快 20%–30%；TTS 语速档 0.9–1.0x，见 performance-action.md §2.3）。

### 5.4 情绪（契约落位）

> **情绪三层写法（情绪类型 / 强度·克制度 / 生理表现）、「平淡写法 vs 立体写法」对照与情绪声音词库，以 [performance-action.md](performance-action.md) §2.4 情绪三层写法为唯一权威**，本文件不重复。

契约级要求——三层必须落在台词行的括号段里，缺一层视为契约不合法：

| 层 | 写在哪个括号位 | 平台正文示例片段 |
|---|---|---|
| ① 情绪类型 | `[情绪-强度]` 段的前半 | `（普通话，音色参考 @音频1 的低沉沙哑，**愤怒**-隐忍，…）` |
| ② 强度/克制度 | `[情绪-强度]` 段的后半（用 `-` 连接） | `（…，愤怒-**隐忍**，…）` |
| ③ 生理表现 | `[生理表现]` 段（紧跟 `[语速]` 之后） | `（…，语速偏慢，**一字一顿、尾音发抖**）说：{…}` |

> 只写 `（愤怒）说：{…}` 属于缺 ②③ 两层，输出必然是"念稿感"；词条从 performance-action.md §2.4 的词库里取。

### 5.5 停顿、重音、语气词、呼吸

| 元素 | 标记法 | 示例 |
|---|---|---|
| 短停顿（≈0.3s） | 逗号 | `你到底，去哪了？` |
| 中停顿（0.5–1s） | `……` 或换行 | `算了……不重要了。` |
| 长停顿（>1s） | 显式标注 | `你……[停顿1秒]是不是早就知道了？` |
| 重音 | `【】` 包裹或引号强调 | `我从来【没有】怪过你。` |
| 语气词 | `啊、吧、呢、嘛、哈、哼、唉、嗯` | `唉……算了吧。` |
| 呼吸/体感 | `[吸气][叹气][冷笑一声]` | `[冷笑] 哼，你还真敢说。` |

### 5.6 说话形态（决定口型与画面关系）

| 形态 | 何时使用 | 写法 |
|---|---|---|
| 说 | 角色在画面中开口 | `角色名说：{原台词}` |
| 内心独白 | 心理活动，私密、更慢、更轻 | `角色名内心独白：{原台词}`，配 `内心独白、气声、放慢、贴近麦` |
| 画外音 | 镜头切到别人反应、空镜、道具特写、背影，或说话人不在画面 | `角色名画外音：{原台词}` |
| 旁白 | 全知视角，客观抽离 | `旁白画外音：{原台词}`，配 `旁白、沉稳、不带角色情绪` |

> 常见错误：把内心独白配成对白语气，显得用力过猛。内心戏要更轻、更慢、更贴。

### 5.7 音色、方言、多语言

| 需求 | 写法 |
|---|---|
| 音色参考音频 | `参考 @音频1 中的音色，生成…`；`音色参考@音频1，仅参考声线、年龄感、语流、情绪，不要把参考音频当作BGM` |
| 音色参考视频 | `语气和音色参考@视频1` / `旁白音色参考@视频1中的男声` |
| 音色还原不足 | `使用 @音频1 低厚温润带细碎颗粒感中年男声的音色说：{…}` |
| 四川话 | `用四川口音说：{…}` |
| 粤语 | `用粤语说：{…}` |
| 东北话 | `用东北口音说：{…}` |
| 台湾腔 | `用台湾腔说：{…}` |
| 多角色不同语言 | 各自台词行注明：`台词（角色A，用西班牙语，坚定）："…"` |
| 同一角色切换语言 | `先用中文说"…"，然后切换为英语继续说"…"` |
| 特殊音色风格 | `纪录片级低沉磁性旁白` / `脱口秀式的夸张语气` / `ASMR式轻柔低语` / `科普节目的专业解说音色` |

**中文发音兜底**：多音字 / 生僻字 / 形近字易读错，可改写为同音常用字（"螭龙山" → "吃龙山"），并在优化披露中说明；数字符号口语化（`3:00` → `三点`，`%` → `百分之`）。

### 5.8 字幕开关

| 需求 | 写法 |
|---|---|
| 不出字幕（产线默认） | `保持无字幕，避免生成任何文字或字幕` |
| 出目标语言字幕 | `字幕：仅显示目标语言字幕，准确文本为"…"` |
| 底部同步字幕 | `画面底部出现字幕，字幕内容为"…"，字幕需与音频节奏完全同步` |
| 标题卡 | `【第一章：启程】` |
| 气泡台词 | `<角色>说："…"，角色说话时周围出现气泡，气泡里写着台词` |
| 广告语 | `「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」` |

> 字幕开关必须与第 3 段"绝对禁止"一致：写了"保持无字幕"就不得再要求生成字幕文本。

### 5.9 台词时长换算（决定镜头长度）

| 阶段 | 换算规则 |
|---|---|
| 分镜脚本估算 | 台词镜头按平均语速估算，**每 10 字台词约 2 秒** |
| 视频批次编译（约束性） | 默认 **每汉字约 0.3 秒**；情绪重、语速慢、停顿明显时按 **每汉字约 0.35 秒** |
| 标点停顿 | 逗号、顿号、转折、迟疑、问句、感叹句、省略号额外预留停顿 |
| 长台词下限 | 超过 20 字重点检查，一般**不少于 6 秒**；情绪重或带动作时通常需要 **8 秒以上** |
| 超长台词 | 超过 30 字原则上不塞进单个短镜头，拆成说话镜头 / 反应镜头 / 细节镜头 / 正反打，用画外音承接 |
| 跨批拆分 | 台词导致批次超上限时，只可按原标点或自然语义节点拆到相邻批次，保持原文顺序，**不得改写、删减或新增** |
| 口型对齐 | 先量时长再配音；3 秒镜头的台词必须能在 3 秒内自然说完，不硬塞；重点词卡在面部特写/推镜时刻 |

### 5.10 对白场景模板（契约补充）

> **争吵/冲突、深情告白、悬念/反转、搞笑/沙雕四类基础场景模板见 [performance-action.md](performance-action.md) §2.11「场景化台词模板」**，本文件不重复。
> 下面三段是契约独有的多角色/多轨情形，performance-action.md 未覆盖。

**抢白/打断：**

```text
[A] 我早就说过这件事根本不——
[B-打断-音量压过A] 够了！我不想再听你解释！
```

**潜台词（表面 vs 真实）：**

```text
[表面平静-实则强忍崩溃] "挺好的，你过得好就行。"
（提示：语气刻意轻松，但尾音发紧、有一瞬间气息不稳）
```

**多角色多语言：**

```text
林澈（@图片1，普通话，低声克制）说：{别回头。}
米娅（@图片2，西班牙语，急促）说：{Sigue caminando.}
无字幕。
```

### 5.11 对白禁止项

```text
不要只给台词文本不给情绪与语速；不要全程一个语速；不要把内心独白写成对白语气；不要中英混用（专有名词除外）；不要改写、删减或新增剧本台词；不要让台词长度超出镜头时长；不要在同一段里同时要求"无字幕"和"生成字幕"；不要把音色参考音频当作 BGM。
```

## 6. 时长与节拍

### 6.1 模型时长契约

| 模型 | 单次生成上限 | 下限 | 时间戳写法 | 说明 |
|---|---:|---:|---|---|
| MiniMax H3 | **15s** | 4s | 按适配器约定的秒级时间轴 | 支持文本 / 首帧 / 尾帧 / 首尾帧 / 多图 / 多模态 |
| Seedance 2.0 | **15s** | 4s | **禁写绝对秒数**，用 `镜头1 / 镜头2 / 镜头3` | 对精确时间支持不稳定；顶层传 `resolution/duration/ratio/watermark`，正文必带 `style_caption` |
| Seedance 2.5 | **30s** | 4s | 支持 `0-5秒`、`[00.0-05.0s]`、`0:30-0:45`，官方示例用 24fps 帧锚点 | 标准生成 4–30s；超长模式 30–180s；延长源 ≤30s、新增 4–30s、结果 ≤60s |
| 未登记模型 | 保守 10s | 4s | 秒级 | 切碎只是多几个镜头，切长会让请求直接失败 |

**硬规则：**

1. **每个分镜必须能被所选模型一次生成出来**。镜头时长上限 = 该模型上限，不是固定 15。
2. 恰好 30 秒且需要精确逐秒控制时，走"标准生成 + 时间戳 30s"变体，不要盲目切成 15 秒碎片。
3. 31–60 秒且无可用源片时优先超长模式；有值得保留的源片时用视频延长。
4. 延长模式的"时长"指**新增区间**，不是最终总长。

### 6.2 逐秒时间轴写法规则

| 时长 | 时间粒度 | 写法 |
|---|---|---|
| 4–10s，单一动作 | 散文或 2–3 拍 | `0-X秒：…；X-N秒：…` |
| 11–30s，多事件 | 时间戳拍 | 每拍 3–5 秒，标注景别/运镜/动作/对白/音效 |
| 30–180s | 幕 + 时间戳序列 | 5–12 个序列，不要列几十个微镜头 |
| 延长 | 只写新增区间 | 从源片首/尾状态起写 |
| 编辑 | 写生效时段 + 保留清单 | `仅在 X-Y 秒生效` |

**每拍必须包含五项：**

```text
[起止时间]：[景别 + 角度 + 单一运镜]，[动作因果（准备→发力→接触→反应→恢复）]，[可观察表情]，[对白 {…} 或 无]，[音效及对齐帧]。
```

**动作时间戳引导公式（动作戏）：**

```text
[0:00-0:02] A charges forward aggressively; [0:02-duration] A swings a heavy right hook connecting with B's jaw.
```

> 原理：在提示词中显式带入秒级时段切片，可在扩散前几步把动作能量约束到对应帧区间，解决动作随机发生、无法卡点的问题。

### 6.3 时间预算（按叙事功能分配）

| 功能 | 典型占比 | 目的 |
|---|---:|---|
| 建立 | 10–15% | 建立人物、地点、目标与视觉语法 |
| 发展 | 25–35% | 因果动作与逐步升级的阻力 |
| 转折 | 10–20% | 改变认知、目标、关系或物理状态 |
| 高潮 | 20–30% | 最高视觉/情绪/信息负载 |
| 收束 | 10–20% | 展示后果、回收母题、形成真正的结尾 |

**密度规则：**

- 每 3–5 秒**至少一个**新动作或状态变化，否则触发循环/静止。
- 单个 5 秒窗口**不超过 2–3 个**不同动作，否则触发时间线压缩。
- 情绪转折与揭示等关键时刻，**至少给 3–5 秒**专属画面时间。

### 6.4 15 秒契约

**四段式节拍模型：**

```
⏰ 0s ──────────────── 3s ─────────────── 7s ────────────── 11s ────────────── 15s
   │  [第一切片：全景段]  │  [第二切片：中景段]  │ [第三切片：特写段]  │ [第四切片：收尾段]  │
   ▼                     ▼                     ▼                    ▼                    ▼
 交代场景与整体氛围    主角登场，启动动作    动作细节，情绪传递   动作收尾，悬念拉远/转场
```

| 时间 | 景别与运镜 | 内容 | 连续性重点 |
|---|---|---|---|
| 0–3s | 全景/大远景，`establishing wide shot` | 交代故事背景与空间 | 锁定空间、人物左右、道具位置 |
| 3–7s | 中景跟随，`medium shot, tracking follow` | 主角登场，启动动作 | 只让一个道具或一个动作启动 |
| 7–11s | 近景/局部特写，`close-up shot, shallow depth of field` | 冲突起燃或情绪聚焦 | 承接上一动作，表情轻微变化 |
| 11–15s | 拉远收束，`dolly out, high dynamic change` | 悬念收尾或平滑转场 | 动作从上一镜自然收束 |

**15 秒五拍连续性变体（对话/情绪戏）：**

| 时间 | 功能 | 镜头建议 |
|---|---|---|
| 0-3s | 建立场景和人物关系 | 全景或中景静止 |
| 3-6s | 触发事件 | 中景慢推 |
| 6-9s | 角色反应 | 近景或手部特写 |
| 9-12s | 情绪升级（只上升一级） | 大特写慢推 |
| 12-15s | 行动或悬念 | 慢拉远或背影镜头 |

**15 秒时间轴模板（可复制）：**

```text
【时间轴】
0-3秒：[大远景/全景 establishing wide shot]，[固定或缓慢横移]，交代[场景+天气+光源方向]，[人物在画面中的位置与比例]。音效：[环境底噪]。
3-7秒：[中景 medium shot]，[跟拍/慢推 单一运镜]，<主体1> [启动动作]，[表情]。对白：[{…} 或 无]。音效：[动作音效+对齐帧]。
7-11秒：[近景/特写 close-up]，[慢推 slow push in]，<主体1> [情绪聚焦的小动作]，[面部细节]。对白：{…}。音效：[呼吸/衣料]。
11-15秒：[中景转全景]，[慢拉远 slow dolly out]，<主体1> [收束动作]，落幅为[…]。音效：[环境音渐弱]。BGM：[00:11 收束，留1秒尾音]。
```

**五镜动作链（10 秒内拉满动作节奏）：**

| 镜 | 景别 | 时长 | 内容 |
|---|---|---:|---|
| 1 | 全景 Establishing Clash | 2–3s | 双方相对站位、体型差距、场景氛围 |
| 2 | 中景前冲 Medium Shot Charge | 1.5s | 爆发速度与前冲身法，低角度前冲 |
| 3 | 近景交锋 Close-up Attack | 1.5–2s | 招式线条，刀光气浪 |
| 4 | 特写重击 Extreme Close-up Impact | 1s | 接触形变、汗水飞散 |
| 5 | POV 受击反应 | 2s | 第一人称模糊+强震，看向胜者 |

### 6.7 镜头时长设计（指针）

> **按镜头类型的时长参考表与段落节奏表，以 [models-failures.md](models-failures.md) §一《镜头时长设计参考》/《段落节奏》为唯一权威**，本文件不重复。
> 那两张表给的是**成片剪辑时长（层③）**：**这些数字一律不填进请求**，不足 4 秒的镜头统一按 4 秒下单，多出来的素材在剪辑台裁掉（三层时长口径见 models-failures.md §1.1）。
> 本节 §6.1 的模型上下限才是**生成请求时长（层①）**，`duration` 必须落在 `[4, 模型上限]` 内，越界直接 400。

> 分镜脚本层单镜**不超过 10 秒**；视频批次层每批 **5–15 秒**（上限随模型），两层数字不冲突：批次由 1–N 个分镜镜头组合而成。

### 6.8 时长与节拍故障对照

| 症状 | 根因 | 修法 |
|---|---|---|
| 事件被压缩、动作赶、部分事件被跳过 | 单位时间事件过多；时间分配与动作物理时长不符 | 按时间预算表重排；每 5 秒窗口 ≤2–3 个动作；关键时刻至少 3–5 秒；延长总时长或删事件 |
| 角色原地循环 2–3 秒动作 / 完全静止 | 只写状态不写过程；落幅=起幅；时长远大于内容量 | 每拍必须有状态变化；把动作写成过程（`手从桌面缓慢滑向信封边缘，指尖停在封口处`）；长镜补微动作（呼吸、眼动、风、环境运动） |
| 运镜指令被忽略 | 构图词被冗长主体描述抢权重；机位在空间中不可实现 | 运镜写在一句话概述之后或每拍开头；检查 360° 环绕是否有足够空间；用中文运镜词避免审核误判 |
| 台词说不完/口型糊 | 台词字数超过镜头时长 | 按 0.3s/字复核；>20 字给 ≥6 秒；>30 字拆镜用画外音承接 |
| 30 秒被切成两段 15 秒后不连贯 | 误用旧的 15 秒强制切分规则 | 确认模型上限；Seedance 2.5 单次可到 30s，不要盲目切分 |

## 7. 契约合法性总校验（生成前 Gate）

- [ ] **模式匹配**：所选模式与意图、时长一致（首尾帧 / 多图 / 多模态 / 首帧 / 文生）。
- [ ] **时长合法**：镜头时长在 `[4, 模型上限]` 区间内；Seedance 2.0 未写绝对秒数。
- [ ] **时间戳合法**：有序、不重叠、覆盖目标区间。
- [ ] **素材合法**：每个 token 存在、有角色、有作用范围、有禁止迁移项；数量与时长未超限。
- [ ] **无裸 ID / 无粘连**：无 `[asset-xxx]`，无 `@图片N+动词`。
- [ ] **六段齐全**：顺序正确、无合并、无重复描述。
- [ ] **起幅落幅齐全**：每镜有起幅、落幅、承接、交付；落幅≠起幅；无"同上"。
- [ ] **一镜一运镜、一帧一景别、一镜一动作、一镜一情绪级**。
- [ ] **声音不打架**：对白 / BGM / 环境 / 音效 / 字幕 / 静音互不矛盾，且没有写"无声音"。
- [ ] **台词零改写**：原文一字不差；语言与音色绑定明确；时长匹配镜头。
- [ ] **不变量无冲突**：镜头语言、光影、风格、物理指令之间不矛盾。
- [ ] **指纹一致**：分镜图提示词与运镜提示词来自同一契约，`contract_fingerprint` 相同；不一致时禁止生成。
- [ ] **降级可见**：模型能力不匹配时显式降级或阻断，未支持的参考素材不被静默忽略。

> 校验不通过一律修正后重投。仅当"警告"描述的是使用者有意识的取舍时，才允许带警告出片。
