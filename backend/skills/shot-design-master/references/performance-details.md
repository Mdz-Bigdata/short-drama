## 二、身体动作层

### 2.1 核心原则

- 动作幅度控制在 60-80%，避免过度夸张导致面部变形
- 优先使用中景/半身镜头，减少面部细节暴露
- 每个镜头 2-4 秒，过长会积累表情误差

### 2.2 提示词模板

#### 基础站姿/坐姿对话

```
A [gender] character in [outfit], sitting at a [location],
[subtle body language], slight natural body sway,
breathing motion visible in shoulders,
shot from [camera angle], [lighting],
cinematic, 24fps, natural movement
```

#### 情绪化身体语言

| 情绪 | 身体动作提示词 |
|------|--------------|
| 紧张 | `fidgeting with hands, shifting weight between feet, shoulders slightly raised and tense` |
| 愤怒 | `leaning forward aggressively, clenched fists at sides, chest expanding with heavy breath` |
| 悲伤 | `shoulders slumped forward, head slightly bowed, arms wrapped around self` |
| 喜悦 | `open posture, slight bounce in movement, hands gesturing freely, chest lifted` |
| 惊讶 | `stepping back slightly, hands rising to chest level, spine straightening suddenly` |
| 思考 | `hand touching chin, head tilting to one side, eyes looking up-left, weight on one leg` |

#### 动态动作场景

```
[Character description], walking [speed/style] through [environment],
[specific gesture: adjusting collar / checking phone / brushing hair back],
natural arm swing, [emotional undertone],
tracking shot, shallow depth of field, 24fps
```

### 2.3 避坑要点

- ❌ 避免：`smiling face`, `happy expression`（让面部表情层处理）
- ✅ 使用：`relaxed posture suggesting contentment`（用体态暗示情绪）
- ❌ 避免：超过 5 秒的单一镜头
- ✅ 使用：2-3 秒分段生成，后期拼接

## 三、面部表情驱动层（LivePortrait）

### 3.1 核心原则

- 使用真人参考视频驱动，而非纯 AI 生成
- 表情强度控制在 0.6-0.8（满值会导致变形）
- 微表情过渡时间不少于 6 帧（0.25 秒 @24fps）

### 3.2 表情参考录制要点

```
录制规范：
- 光线：柔光正面，避免侧光阴影
- 角度：与 AI 生成角色的头部角度一致（±5°）
- 帧率：30fps 以上
- 时长：比目标片段多录 1-2 秒余量
- 表演：从中性表情开始，缓慢过渡到目标情绪
```

### 3.3 情绪微表情分解

#### 自然微笑（非僵硬笑容）

```
分解帧序列（24fps）：
帧 1-6:   中性 → 嘴角微微上扬（2mm）
帧 7-12:  眼轮匝肌收缩（鱼尾纹出现）+ 颧骨轻微上提
帧 13-18: 嘴角继续上扬 + 眼睛微眯（真笑标志：Duchenne smile）
帧 19-24: 保持，加入轻微头部倾斜（3-5°）
```

#### 各情绪面部肌肉动作

| 情绪 | 眉毛 | 眼睛 | 嘴部 | 辅助动作 |
|------|------|------|------|---------|
| 惊讶 | 上扬、分开 | 睁大、瞳孔放大 | 张开、下巴下落 | 头部微后仰 |
| 恐惧 | 上扬、靠拢 | 睁大、上眼白可见 | 微张、嘴角下拉 | 颈部后缩 |
| 厌恶 | 内侧下压 | 微眯 | 上唇上提、鼻翼皱起 | 头微偏转 |
| 愤怒 | 下压、靠拢 | 瞪视、眼睑紧绷 | 抿紧或咬牙、下颌前突 | 鼻孔微张 |
| 悲伤 | 内侧上扬 | 眼睑下垂、泪膜感 | 嘴角下拉、下唇微颤 | 头微低 |
| 轻蔑 | 单侧微挑 | 微眯（单侧） | 单侧嘴角上扬 | 下巴微抬 |

### 3.4 LivePortrait 参数建议

```yaml
# LivePortrait 驱动参数
expression_intensity: 0.7      # 表情强度（0.5-0.8 为自然区间）
lip_ratio: 0.0                 # 嘴型由口型层单独控制，此处归零
head_pose_blend: 0.3           # 头部姿态跟随（不宜过高）
eye_blink_rate: 0.15           # 眨眼频率（每秒约3-4次正常）
smooth_factor: 0.85            # 帧间平滑（越高越平滑，但会损失细节）
face_mask_erode: 5             # 面部遮罩收缩像素（避免边缘伪影）
```

## 四、口型同步层（Wav2Lip / MuseTalk）

### 4.1 工具对比

| 特性 | Wav2Lip | MuseTalk |
|------|---------|----------|
| 精度 | 中等 | 较高 |
| 速度 | 快 | 中等 |
| 中文支持 | 一般 | 较好 |
| 面部保真 | 下颌区域可能模糊 | 保真度更高 |
| 适用场景 | 快速预览/低成本 | 最终成片 |

### 4.2 音频预处理

```bash
# 音频降噪 + 标准化（提升口型精度）
ffmpeg -i input.wav -af "highpass=f=80,lowpass=f=8000,dynaudnorm" clean.wav

# 如使用 TTS，推荐参数
- 语速：0.9-1.0x（过快口型跟不上）
- 情绪：与画面情绪匹配
- 停顿：句间留 0.3-0.5s 自然停顿
```

### 4.3 MuseTalk 配置建议

```yaml
# MuseTalk 参数
fps: 24
face_det_batch_size: 8
audio_feature: "hubert"        # 中文效果更好
mouth_open_ratio: 1.2          # 嘴部张开比例（中文发音需要略大）
smooth_expression: true
batch_size: 4
```

### 4.4 口型自然度提升技巧

- 台词设计避免连续爆破音（b/p/d/t），容易产生口型跳变
- 在句末添加轻微闭口动作（0.2s），避免嘴部突然定格
- 对话间隙保持嘴唇自然闭合而非完全静止（添加微小呼吸动作）

## 五、关键帧插值技术

### 5.1 表情关键帧设计

```
场景示例：角色从平静 → 震惊 → 愤怒（共3秒，72帧@24fps）

关键帧布局：
┌────────┬────────────┬────────────┬────────────┬────────┐
│ K1(0f) │  K2(18f)   │  K3(36f)   │  K4(54f)   │K5(72f) │
│ 平静    │ 微疑惑     │ 瞳孔放大    │  眉头紧锁   │ 愤怒   │
│ 中性    │ 眉微皱     │ 嘴微张      │  牙关咬紧   │ 怒视   │
└────────┴────────────┴────────────┴────────────┴────────┘

插值规则：
- K1→K2：ease-in（缓起），情绪酝酿
- K2→K3：linear（线性），反应瞬间
- K3→K4：ease-out（缓停），情绪沉淀
- K4→K5：ease-in-out（缓入缓出），最终定格
```

### 5.2 插帧工具与参数

#### RIFE / FILM 插帧

```bash
# RIFE 2x 插帧（24fps → 48fps，用于平滑表情过渡）
python inference_video.py \
  --input face_sequence/ \
  --output interpolated/ \
  --exp 1 \              # 2^1 = 2x 插帧
  --scale 1.0 \
  --ensemble             # 集成模式，质量更高
```

#### 关键帧生成策略

```
方法 A：多次生成取最佳帧
1. 同一提示词生成 5-10 次
2. 逐帧筛选表情最自然的帧
3. 组合关键帧序列
4. 用 RIFE/FILM 插值补充中间帧

方法 B：渐进式提示词
1. 第一段：纯中性表情（锚定基准）
2. 第二段：25% 目标情绪
3. 第三段：50% 目标情绪
4. 第四段：75% 目标情绪
5. 第五段：100% 目标情绪
→ 拼接后自然过渡
```

### 5.3 表情过渡曲线

```
自然表情变化遵循的时间规律：

微表情（involuntary）：0.04-0.2s（1-5帧）
常规表情变化：0.5-1.0s（12-24帧）
情绪氛围转换：1.0-3.0s（24-72帧）

❌ 错误：2帧内从笑变哭（机械感）
✅ 正确：先笑容消退(8帧) → 中性过渡(4帧) → 悲伤浮现(12帧)
```

## 六、后期微调

### 6.1 DaVinci Resolve 面部修复

```
修复流程：
1. 节点1：面部追踪（Tracker → Face）
2. 节点2：柔化（Midtones 降低对比度 5-10%，减少AI生硬感）
3. 节点3：眼部提亮（Power Window 圈选眼白区域，+0.1 曝光）
4. 节点4：肤色统一（Qualifier 选取皮肤色域，微调色温一致性）
5. 节点5：锐度（仅眼部+唇部区域加锐 0.2-0.3）
```

### 6.2 After Effects 表情修补

```
逐帧修补方案（用于关键特写镜头）：
1. 导入 AI 生成序列帧
2. 使用 Content-Aware Fill 修复表情断裂帧
3. Puppet Warp 微调嘴角/眉毛位置
4. 时间重映射（Time Remap）拉伸/压缩过渡时间
5. 添加 Camera Shake（0.5-1px）模拟真实手持感
```

### 6.3 通用后期增强

```
让 AI 视频更真实的后期处理清单：

□ 添加微量胶片颗粒（Grain, 2-5%）
□ 轻微镜头畸变（Lens Distortion, 1-2%）
□ 景深模拟（面部锐利，背景微糊）
□ 色彩分级（参考真实影视调色，避免AI过饱和感）
□ 呼吸灯效果（曝光 ±0.02 缓慢波动，模拟活体）
□ 微量运动模糊（Motion Blur, 180° shutter）
□ 音频环境声底（房间噪声 -40dB，避免"真空感"）
```

## 七、分镜与镜头语言（规避表情问题）

### 7.1 镜头类型选择策略

```
表情自然度 vs 景别关系：

远景(ELS)  ██████████ 100% 安全（看不到表情）
全景(LS)   ████████░░  80% 安全
中景(MS)   ██████░░░░  60% 安全 ← 推荐主力景别
近景(CU)   ████░░░░░░  40% 需要精修
特写(ECU)  ██░░░░░░░░  20% 必须精修或真人驱动
```

### 7.2 对话场景分镜模板

```
双人对话（规避表情僵硬方案）：

镜头1：说话者A 中景正面（2s）— 表情驱动
镜头2：听话者B 侧面/过肩（1.5s）— 仅需微动
镜头3：双人中景（2s）— 表情细节不突出
镜头4：说话者A 手部/道具特写（1s）— 无面部
镜头5：B的反应 中景（2s）— 表情驱动

原则：说话时给镜头，听话时切走或用侧面
```

### 7.3 遮挡与转场技巧

```
当表情无法解决时的替代方案：

- 角色低头/侧脸：手捂脸、低头沉思、转身
- 光影遮挡：逆光剪影、百叶窗光影、烟雾
- 道具遮挡：杯子、手机、书本、帽檐
- 画面切换：insert 镜头（手部动作、环境细节）
- 运动模糊：角色快速转头时自然模糊 1-2 帧
```

## 八、完整制作流程 Checklist

```
□ Step 1：剧本分镜 — 标注每个镜头的情绪关键词和景别（竖屏按 9:16 构图，详见十三章）
□ Step 2：角色一致性 — 锁定参考图 + seed + 角色锚定块（详见第十章）
□ Step 3：声音设计 — TTS/克隆/真人配音，输出干声对白（详见第十一章）
□ Step 4：身体动作生成 — Kling/Runway（含手部规避，不含面部表情指令）
□ Step 5：手部/肢体检查 — 排查多指/穿模，必要时藏手或重绘（详见第十二章）
□ Step 6：面部表情录制 — 真人参考视频（逐镜头）
□ Step 7：表情驱动 — LivePortrait 合成面部
□ Step 8：口型同步 — MuseTalk/Wav2Lip 匹配第三步音频
□ Step 9：关键帧审查 — 逐帧检查表情断裂点 + 角色一致性比对
□ Step 10：插帧平滑 — RIFE 补充过渡帧
□ Step 11：后期调色 — DaVinci Resolve 统一色调（含肤色/发色一致性校正）
□ Step 12：音效混合 — 环境声 + 对话 + 配乐（卡点对齐爽点）
□ Step 13：竖屏字幕花字 — 安全区内排版，白字黑边（详见 13.4）
□ Step 14：全片审看 — 重点关注面部特写 + 手部 + 角色一致性
□ Step 15：导出 — H.265, 1080×1920, 24fps, 高码率
```

## 九、常见问题速查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 笑容像面具 | 缺少眼部参与 | 确保眼轮匝肌收缩（鱼尾纹） |
| 表情突变 | 关键帧间缺少过渡 | 添加中间情绪帧，用 ease-in-out |
| 面部边缘闪烁 | 遮罩贴合度差 | 增加 face_mask_erode，feather 边缘 |
| 说话时面部僵硬 | 口型层覆盖了表情 | 分层合成：先表情后口型，口型仅影响下半脸 |
| 眨眼不自然 | 频率过低或过于规律 | 添加随机眨眼（每 2-6 秒一次，非等间距） |
| 皮肤蜡感 | AI 过度平滑 | 后期添加皮肤纹理/颗粒 |
| 眼神空洞 | 瞳孔无高光/无追踪 | 后期添加眼部高光点，或在参考中加入视线引导 |
| 跨镜头脸变了 | 纯文字生成、无锚定 | image-to-video 首帧锚定 + 固定 seed + 角色锚定块（十章） |
| 双人串脸 | 角色区分度低 | 差异化设计 + 分别锚定 + 多用单人镜头（10.5） |
| 手指畸形/多指 | 手部自由度高 | 藏手/持物/控幅 + 负向提示词，特写走局部重绘（十二章） |
| 接触镜头穿模 | 交接瞬间同框 | 分镜拆解，避开交接瞬间，侧/背面藏手臂（12.4） |
| 同角色音色变了 | 换了音色/模型 | 锁定音色 ID 或克隆模型全程复用（11.4） |
| 配音机械僵硬 | TTS 匀速无情绪 | 按情绪标注语速/停顿/重音（11.2） |
| 竖屏人物被切 | 横屏裁切而成 | 分镜阶段即按 9:16 设计，景别上移（13.6） |
| 完播率低 | 开场慢热 | 前 3 秒即抛冲突/悬念，去片头 logo（13.2） |

## 十、角色一致性体系

> 解决跨镜头人物**脸漂移 / 服装变化 / 串脸**——AI 短剧第一大难题
> 原则：一致性是"地基"，必须在身体动作生成（第二章）之前锁定

### 10.1 一致性的三个层级

```
层级1：面孔一致性（最难，优先级最高）
   └─ 脸型、五官比例、瞳色、肤色、标志特征（痣/疤/酒窝）

层级2：服装道具一致性
   └─ 服装款式/颜色、发型、配饰、随身道具

层级3：体型气质一致性
   └─ 身高比例、体态、年龄感、整体气场
```

> 崩坏概率：层级1 >> 层级2 > 层级3。镜头越近、时长越长，漂移越明显。

### 10.2 参考图锁定规范

```
角色参考图（character reference）制作规范：
- 三视图：正面 + 45°侧 + 90°正侧（同一光照、同一人物）
- 表情：中性基准（不带情绪，避免锁定到特定表情）
- 光照：柔光正面、无强阴影（便于后续重打光）
- 分辨率：≥ 1024×1024，五官清晰无模糊
- 背景：纯色/灰底（避免背景干扰人物特征提取）
- 数量：主角 3-5 张多角度，配角至少 1 张正面
```

### 10.3 种子与 Face ID 锁定

```
锁定手段（按一致性强度排序）：

强 ┌─ 首帧参考（image-to-video）★推荐主力
   │    用锁定好的角色图作为视频首帧驱动，
   │    一致性远高于纯文字生成（text-to-video）
   │
   ├─ 角色 LoRA / face embedding
   │    对同一角色训练专属模型，跨镜头复用
   │
   ├─ 固定种子（fixed seed）
   │    同一 seed + 同一提示词，减少随机漂移
   │
弱 └─ 纯提示词描述
        仅靠文字描述外貌，漂移最严重，不可单独依赖
```

- ❌ 避免：每个镜头用纯 text-to-video 重新生成人物
- ✅ 使用：image-to-video，首帧锚定同一张角色参考图
- ✅ 使用：固定 seed 作为辅助，叠加角色描述锚定块

### 10.4 角色描述锚定块（Character Sheet）

为每个角色建立**固定描述块**，复制粘贴到所有镜头提示词的人物部分，逐字不改：

```
[角色A 锚定块 — 全程复用]
A 28-year-old woman, oval face, almond-shaped dark brown eyes,
straight black shoulder-length hair with center part,
small mole below left eye, fair skin,
wearing a beige trench coat over white shirt,
slim build, 168cm proportion
```

#### 必锁定字段表

| 字段 | 必须锁定的内容 | 示例 |
|------|--------------|------|
| 脸型 | 脸型形状 | `oval face` / `square jaw` |
| 眼睛 | 形状 + 瞳色 | `almond-shaped dark brown eyes` |
| 发型 | 长度 + 颜色 + 分缝 | `black shoulder-length hair, center part` |
| 肤色 | 明确色调 | `fair skin` / `tan skin` |
| 标志特征 | 痣/疤/酒窝/雀斑 | `small mole below left eye` |
| 服装 | 款式 + 颜色 | `beige trench coat over white shirt` |
| 体型 | 身材 + 比例 | `slim build, 168cm proportion` |

### 10.5 多角色场景区分（防串脸）

```
双人/多人同框防串脸方案：

1. 分别锚定：每个角色独立锚定块，明确空间位置
   "[角色A锚定块] on the left, [角色B锚定块] on the right"

2. 差异化设计：主角间在发色/脸型/服装色上拉开区分度
   （避免两个角色都是黑长直，AI 易混淆）

3. 视线/站位绑定：明确谁面向谁，避免错位
   "A facing B, B looking down"

4. 优先分镜规避：能单人镜头解决的对话，不强行同框
   （呼应 7.2 对话分镜模板：说话给镜头，听话切走）
```

### 10.6 一致性校验与兜底修复

```
逐镜头校验清单：
□ 五官比例与参考图一致（重点：眼距、鼻型、唇形）
□ 瞳色/肤色无偏移
□ 发型长度/分缝一致
□ 标志特征（痣/疤）位置正确
□ 服装颜色/款式连续
□ 体型比例一致（无忽胖忽瘦）

兜底修复（生成无法满足时）：
- 换脸（face swap）：用统一参考脸覆盖漂移帧
- 局部重绘（inpaint）：仅重绘漂移的五官区域
- 调色统一：肤色/发色偏移用 DaVinci 校正（呼应 6.1）
```

### 10.7 避坑要点

- ❌ 避免：靠"美女"这类模糊词描述人物（每次生成都不同）
- ✅ 使用：具体到字段的锚定块，全程逐字复用
- ❌ 避免：先生成动作再考虑一致性（漂移已发生，只能靠后期硬救）
- ✅ 使用：开拍前先锁定参考图 + seed，把一致性做在源头
- ❌ 避免：特写镜头堆叠（脸部细节暴露最多，漂移最致命）——呼应 7.1 景别策略

## 十一、配音与声音设计

> 补足"声音本身怎么做"——第四章只讲了音频预处理，此章讲声音的生成与设计
> 输出物：干净、情绪匹配、角色一致的对白音频，供第四章口型层驱动

### 11.1 声音方案选型对比

| 方案 | 自然度 | 成本 | 角色一致性 | 适用场景 |
|------|-------|------|-----------|---------|
| 真人配音 | 最高 | 高（人力/录音） | 高（同一演员） | 高质量成片、情绪戏 |
| TTS 合成 | 中-高 | 低 | 中（音色库固定） | 快速量产、旁白 |
| 声音克隆 | 高 | 中 | 高（克隆锁定） | 角色专属音色、批量 |

> 推荐组合：主角用**声音克隆**锁定专属音色，旁白/配角用 **TTS**，关键情绪戏用**真人配音**。

### 11.2 TTS 情绪标注与参数

```
TTS 生成参数（呼应 4.2）：
- 语速：0.9-1.0x（过快口型跟不上）
- 音高：按角色设定固定（男声/女声/年龄感）
- 停顿：句间 0.3-0.5s，段落间 0.6-0.8s
- 情绪：与画面情绪匹配（见下表）

情绪标注写法（SSML 风格，按工具支持调整）：
平静：<prosody rate="1.0" pitch="0">...</prosody>
愤怒：<prosody rate="1.1" pitch="+2st" volume="loud">...</prosody>
悲伤：<prosody rate="0.85" pitch="-2st" volume="soft">...</prosody>
紧张：<prosody rate="1.05"> ...<break time="0.2s"/>... </prosody>
```

| 情绪 | 语速 | 音高 | 音量 | 停顿特征 |
|------|------|------|------|---------|
| 平静 | 1.0x | 基准 | 中 | 规律停顿 |
| 愤怒 | 1.1x | 偏高 | 大 | 短促、少停顿 |
| 悲伤 | 0.85x | 偏低 | 小 | 长停顿、句末拖音 |
| 紧张 | 1.05x | 略高 | 中 | 不规则碎停顿 |
| 喜悦 | 1.05x | 偏高 | 中-大 | 轻快、起伏大 |

### 11.3 声音克隆要点

```
克隆样本规范：
- 时长：干净样本 ≥ 3-5 分钟（越多越稳）
- 内容：覆盖多种语调（陈述/疑问/感叹）
- 录音：安静环境，单一说话人，无背景音乐
- 降噪：克隆前先降噪 + 标准化（复用 4.2 的 ffmpeg 命令）
- 采样率：≥ 44.1kHz / 16bit
```

### 11.4 角色音色跨镜头一致性

```
防"音色漂移"：
□ 同一角色全程用同一克隆模型 / 同一 TTS 音色 ID
□ 锁定相同的音高/语速基准（仅按情绪微调，不换音色）
□ 分集制作时记录音色配置，避免重开项目时参数丢失
□ 多角色：音色差异化（音高/音色拉开，呼应 10.5 防串脸思路）
```

### 11.5 对白节奏与呼吸感

```
让对白"像活人说话"：
- 句末换气：长句中段插入 0.15-0.2s 微停顿（模拟换气）
- 呼吸声：情绪戏可保留轻微吸气声（增强真实感）
- 避免机械匀速：重点词放慢/加重，次要词带过
- 对话留白：角色之间留 0.3-0.5s 反应间隙（呼应 4.4）
- 与口型衔接：句末轻微闭口 0.2s，避免嘴部定格（呼应 4.4）
```

### 11.6 与口型同步层对接清单

```
交付给第四章（口型层）前确认：
□ 格式：WAV（无损，优于 MP3）
□ 采样率：与 MuseTalk/Wav2Lip 要求一致（通常 16kHz/44.1kHz）
□ 声道：单声道（对白），口型检测更稳
□ 已降噪 + 标准化（highpass/lowpass/dynaudnorm）
□ 时长与目标画面片段对齐（音频不长于画面）
□ 中文优先 hubert 特征（呼应 4.3 配置）
```

### 11.7 避坑要点

- ❌ 避免：TTS 默认匀速朗读（机械感重，口型也呆板）
- ✅ 使用：按情绪标注语速/停顿/重音
- ❌ 避免：同一角色不同集换音色（观众立刻出戏）
- ✅ 使用：锁定音色 ID / 克隆模型全程复用
- ❌ 避免：带背景音乐的音频直接做口型（干扰检测）——先做干声口型，后期再混音乐

## 十二、手部与肢体细节

> AI 出片最易暴露的崩坏点：多指/粘连/扭曲。原则——**能藏则藏，要拍则控**

### 12.1 手部崩坏根因与规避

```
根因：手部姿态自由度极高，训练数据中手的形态最复杂
→ AI 易生成 6 指/断指/粘连/反关节

规避策略（优先级从高到低）：
1. 藏手     ── 手插兜、背手、持物遮挡、出画框
2. 控幅     ── 手部动作幅度小、慢，减少崩坏窗口
3. 远景     ── 中景以上，手部不占画面焦点（呼应 7.1）
4. 短时     ── 手部特写 ≤ 1s，减少崩坏累积
5. 精修兜底 ── 实在要特写，走 12.6 局部重绘
```

### 12.2 手部正向 + 负向提示词

```
正向提示（明确手部状态）：
"hands resting naturally on the table, fingers relaxed and separated,
 five fingers clearly defined, anatomically correct hands"

负向提示（negative prompt，规避崩坏）：
"extra fingers, fused fingers, missing fingers, deformed hands,
 mutated hands, malformed hands, too many fingers, distorted fingers"
```

- ❌ 避免：复杂手势特写（比心/数手指/精细动作）
- ✅ 使用：自然放松的简单手部状态

### 12.3 道具交互稳定生成

```
拿道具（杯子/手机/书）的稳定方案：
- 道具体积越大越稳（拿书 > 拿手机 > 拿笔）
- 明确交互动词："holding a cup with both hands"（双手更稳）
- 道具遮挡指缝：用道具自然挡住容易崩的指间区域
- 静态持物 > 动态操作（"holding phone" 优于 "typing on phone"）
- 呼应 7.3：道具本身也是遮挡表情/手部的好工具
```

### 12.4 肢体接触场景难点

```
双人接触（拥抱/握手/递物）易穿模、手部错位：

握手   → 用中景、手部交握处可后期微修；避免特写
拥抱   → 从背后/侧面拍，藏住交叠的手臂（避免穿模暴露）
递物   → 分两镜：A递出（手部出画）+ B接住（道具已在手）
         避免"交接瞬间"同框（最易穿模）
搀扶   → 接触点用衣物/遮挡处理，避免手指嵌入身体
```

### 12.5 走位与肢体连贯

```
防穿模/飘移：
- 走位幅度控制在 60-80%（呼应 2.1）
- 避免角色与道具/墙体过近（易穿模）
- 转身/快速移动时，1-2 帧运动模糊掩盖瞬态崩坏（呼应 7.3）
- 多人走位：错开前后景深，避免肢体重叠区
```

### 12.6 手部局部后期修复

```
特写手部必须救时：
1. inpaint 局部重绘：仅框选手部区域重新生成（保留其余画面）
2. AE Puppet Warp：微调手指位置/数量（呼应 6.2）
3. 替换帧：从多次生成中挑手部正常的帧，插值补全（呼应 5.2 方法A）
4. 遮挡补救：后期叠加道具/光影遮住崩坏手部
```

### 12.7 避坑要点

- ❌ 避免：手部精细动作特写（崩坏率最高）
- ✅ 使用：藏手 / 持物 / 控幅 / 远景四件套
- ❌ 避免：双人接触瞬间同框（穿模重灾区）
- ✅ 使用：分镜拆解接触动作，避开交接瞬间
- ✅ 必加：所有人物镜头都带手部负向提示词

## 十三、竖屏短剧适配

> 9:16 平台（抖音/快手/ReelShort 类）落地规范
> 原则：构图、节奏、字幕都要为"竖屏 + 强留人"重新设计，不能套横屏惯性

### 13.1 9:16 构图规范

```
竖屏画面分区（1080×1920）：
┌─────────────┐  ← 顶部安全区（避开平台 UI/头像）约 200px
│   ░░░░░░░   │
│             │
│   人物主体   │  ← 人物面部建议落在上 1/3 黄金区
│  (上1/3区)   │
│             │
│             │
│   躯干/动作  │  ← 中部留给身体动作
│             │
│   ▓▓▓▓▓▓▓   │  ← 字幕区（底部上方，避免压在最底）
│  字幕安全区  │
└─────────────┘  ← 底部安全区（避开点赞/评论 UI）约 250px

要点：
- 人物面部占画面宽度 50-70%（竖屏比横屏更"怼脸"）
- 重要信息不放最顶/最底（被平台 UI 遮挡）
```

### 13.2 开场钩子节奏模板（前 3 秒留人）

```
黄金前 3 秒结构：

0.0-0.5s  ── 强视觉/冲突画面（不要片头/logo）
0.5-1.5s  ── 抛出悬念或冲突点（一句话钩子台词）
1.5-3.0s  ── 强化情绪，给"必须看下去"的理由

❌ 避免：开场铺垫环境/慢热叙事（前3秒流失率最高）
✅ 使用：开场即冲突/反转/悬念（如"你居然是…"戛然而止）
```

### 13.3 单集时长与卡点节奏

```
竖屏短剧节奏规律：
- 单集时长：60-120s（平台主流）
- 爽点密度：每 15-20s 一个小高潮/反转
- 镜头时长：竖屏更碎，单镜 1.5-3s（呼应 2.1）
- 结尾钩子：每集结尾留悬念（促完播/追更）

卡点：情绪高潮 / 反转点 与 BGM 鼓点对齐（增强爽感）
```

### 13.4 字幕与花字规范

```
字幕规范：
- 位置：底部安全区上方（约画面下 1/4，不贴最底）
- 字号：占画面宽度，单行不超过 14-16 字
- 样式：白字 + 黑色描边/底纹（任何背景都清晰）
- 时长：与配音同步，单句停留 ≥ 1s（够读完）

花字（强调字）：
- 关键反转/情绪词用花字放大、变色
- 不超过画面 2 处，避免杂乱
```

### 13.5 平台规格表

| 参数 | 推荐值 |
|------|-------|
| 分辨率 | 1080×1920（9:16） |
| 帧率 | 24-30fps |
| 编码 | H.264/H.265，高码率 |
| 单集时长 | 60-120s |
| 封面 | 9:16 竖图，含冲突画面 + 标题文字 |
| 音频 | 响度标准化（避免忽大忽小） |

### 13.6 竖屏分镜调整

```
破除横屏构图惯性：
- 景别上移：横屏的"中景"在竖屏要更近（怼脸感）
- 弃用大横向构图：左右大全景在竖屏被裁，改纵向构图
- 纵向调度：人物前后景深走位（替代横屏的左右走位）
- 单人优先：竖屏窄，双人同框易拥挤，多用单人正反打
  （呼应 7.2 对话分镜 + 10.5 多角色区分）
- 手部/道具特写竖排：纵向画面适合手部由下往上的动作
```

### 13.7 避坑要点

- ❌ 避免：横屏拍完裁成竖屏（构图被破坏、人物被切）
- ✅ 使用：从分镜阶段就按 9:16 设计构图
- ❌ 避免：开场慢热、放片头 logo（前 3 秒流失）
- ✅ 使用：开场即钩子，3 秒内抛冲突
- ❌ 避免：字幕压在底部 UI 区被遮挡
- ✅ 使用：字幕落在底部安全区上方，白字黑边
