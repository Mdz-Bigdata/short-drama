# 四重锁与镜头交接：连续镜头的状态传递

> 来源：微信公众号「生活小事开心说」《AI短剧连续镜头一致性控制：四重系统》(2026-10-14)；
> 「阿金玩AI」《Seedance 2.0 故事板总串镜？这 5 个设置》(2026-09-17)。
> 本文按本项目流水线改写：角色锁对应设定集身份锚点，场景锁对应场景圣经，
> 道具/动作锁对应 ShotMotionContract 的 start_state / end_state / continuity_in / continuity_out。

## 一、核心观念：五十个镜头是五十次状态交接

连续镜头不是让模型记住五十张图，而是每一镜都**接过上一镜留下的状态、交出本镜结束时的状态**。
观众认人、认地方、认东西，靠的是四件事同时不变：角色、场景、道具、动作方向。任何一件跳变都会出戏。

## 二、四把锁：先建底稿，再拍第一镜

不要从第一镜直接开拍。先把四份底稿写好，每一镜的提示词开头原样粘贴，再写这一镜的变化。

| 锁 | 固定不变的部分 | 允许随剧情变化的部分 |
|---|---|---|
| 角色锁 | 骨相轮廓、年龄感、发式发色、服装版型与颜色、配饰位置、身高体态 | 神情、视线、姿态、动作、情绪 |
| 场景锁 | 地点身份、建筑结构、门窗位置、道路方向、陈设摆放、主光方向 | 天气、时段、灯光强弱 |
| 道具锁 | 编号、外形、材质颜色、尺寸、磨损程度 | 位置、持有者、使用状态（必须逐镜记录） |
| 动作锁 | 人物运动方向、摄影机所在的轴线一侧 | 本镜执行的那一个动作阶段 |

道具状态表每行：`编号 | 名称 | 外形 | 材质颜色 | 尺寸 | 磨损 | 当前位置 | 持有者 | 使用状态`，每镜更新后三列。

## 三、镜头状态卡（每镜生成前填写）

`镜头编号 | 人物位置 | 身体朝向 | 头部朝向 | 左手状态 | 右手状态 | 视线方向 | 道具位置 | 情绪 | 环境状态 | 结束状态`

结束状态就是下一镜的开始状态。写不出结束状态的镜头，下一镜一定接不上。

## 四、连续性总表与检查点

- 一张总表管全片：`镜头 | 人物状态 | 场景状态 | 道具状态 | 动作状态 | 结束状态 | 检查点`。
- **每 5–8 镜设一个检查点**：在检查点对照角色锁、场景锁、道具状态表逐项核对，发现漂移立即在这一段内修，
  不要拖到全片做完再返工。
- 分段管理：一个检查点区间就是一个可独立验收的段落。

## 五、动作连贯三原则

1. **三段式**：任何动作拆成"准备 → 执行 → 结束"，一镜只处理一个阶段或一个核心动作。
   "走过去、推门、进店、回头"是四个动作，写成一镜，模型会省掉一步或把几步揉成一团。
2. **方向锁与 180° 轴线**：人物运动方向在相邻镜头里保持一致，摄影机留在轴线同一侧，不突然反向。
3. **镜头克制**：一镜一个核心动作配一种运镜，不在同一镜里叠加复杂运镜与多个动作。

## 六、故事板交给视频模型时的五条设置

1. **故事板只管顺序与构图**：用黑白简稿交代景别、机位、人物位置和动作顺序，不画成精修插画；
   提示词里写明故事板只决定镜头顺序、人物位置和动作方向，**成片不显示故事板边框、格子、编号和草稿线条**，
   画风由风格描述决定。
2. **固定信息写一次，镜头里只写变化**：角色外观、服装、场景、整体风格放在开头一次写清；
   各镜只写"这一镜做什么"，便于检查哪里变了。
3. **每张参考图只负责一件事**：如"图1 定镜头顺序与构图、不决定身份；图2 定主角脸型发型服装；
   图3 定场景与光线方向；图4 定关键道具外形"。上传后检查有没有两张图对同一件事给出冲突要求，先消冲突再生成。
4. **一镜一个主要动作，并写出结束状态**：`镜头N | 起止秒数 | 景别机位 | 承接上一镜的什么 | 这一镜做什么 | 结束时留下什么`。
5. **续拍以实际最后一帧为起点**：计划中的结束状态不等于模型真的生成的状态。续拍前先看已验收视频的最后一帧，
   确认四件事——人物在哪、朝哪个方向运动、道具处于什么状态、光从哪边来——再从这个真实状态写下一段。
   剧情真的换了时空（雨夜街道到第二天办公室），就写成新场景的新镜头，不强求无缝续拍。

## 七、先跑通一条小样

第一条只做 15 秒、3 个镜头，只验收三件事：主角有没有变脸、场景有没有跳变、三个动作是否按顺序完成。
动作还接不上就先减到两镜。小样通过后再加人物互动、复杂运镜和更长剧情。

## 八、失败后一次只改一项

| 现象 | 下一次优先调整 |
|---|---|
| 成片带出故事板格子或线条 | 明确故事板只控制构图与顺序，排除边框、编号与线稿画风 |
| 几个镜头被合成一个 | 加清镜头编号与时间段，必要时先减少镜头数 |
| 主角变脸或换衣服 | 检查角色参考图是否清晰，并写明它只负责身份与服装 |
| 关键动作被跳过 | 每镜只留一个主要动作，写清动作结束状态 |
| 场景或光线突变 | 重新核对场景参考图与各镜光线描述是否一致 |
| 下一段接不上 | 对照上一段**实际**最后一帧，重写续拍起点 |

## 九、连续分镜生产表：十二字段与剪辑点

> 来源：公众号「生活小事开心说」2026-09《镜头一多就乱套？一张表管住 50 个镜头》
> (https://mp.weixin.qq.com/s/dLisJ57T55gtgA1c60K2PA)，是第三节"镜头状态卡"的生产化版本。按本项目重写。

同一张表同时做三件事：记录连续性、承接提示词、兼任剪辑清单。每一镜都要能回答五问——负责什么剧情、从什么状态开始、
在镜头里改变了什么、具体怎么拍、把什么交给下一镜；缺一问就是断点。

按生产顺序从左到右建列：

| 字段 | 填什么 |
|---|---|
| 镜号 | 统一编号如 `EP01-S01`，永不重排 |
| 剧情功能 | 这一镜在故事里承担的任务，一句话 |
| 人物 / 场景 / 道具 | 只写资产锁的编号，不在这里重写描述 |
| 上一镜结束状态 | 本镜的起始输入，**从上一行原句复制** |
| Shot State | 位置、朝向、视线、双手、道具、情绪、环境七项 |
| 本镜核心动作 | 只写一个主要动作 |
| 首帧描述 | 静止画面的构图与状态，用来定住开场(生图提示词) |
| 动作描述 | 从起手到收尾的动作过程、运镜与情绪变化(生视频提示词) |
| 台词与声音 | 对白、旁白、环境音、音效分层写 |
| 本镜结束状态 | 交给下一行——整张表的传动轴 |
| 时长 | 3–8 秒，超过 8 秒动作容易散 |
| 生成状态 | 未生成 / 已生成 / 待修复 / 已通过 |

进剪辑再加两列：**剪辑点**(在哪个动作或声音上切，切在动作起势处两镜才顺) 和 **连续性检查**(逐镜打勾)。
本项目里，首帧描述对应分镜图提示词，动作描述对应视频提示词的 picture / end state 段，
`shot_motion_contract` 的 end state 就是这里的"本镜结束状态"。

两处最容易写崩：

- **状态写成形容词**。"有点紧张"模型接不住；写可见事实——下巴微收、左肩略高、双手虚握在身侧、视线固定在前方积水上。
- **一镜塞多个动作**。"抬头、转身、拔刀、冲过去"要拆成：抬头锁定来人 → 左手按柄 → 右手贴柄重心后移 → 抽刀出鞘 → 上前半步对峙，
  五镜各一个动作，每镜的结束状态自动成为下一镜的第一句。

开拍前六条自检：状态链闭合(每镜起始状态能在上一镜结束状态里找到原句)；资产引用统一(三处都写编号，没有一处重新描述)；
动作单一；状态可见(没有情绪形容词)；道具交代(关键道具每镜都写位置与状态)；剪辑点明确(落在动作起势或声音节点)。
