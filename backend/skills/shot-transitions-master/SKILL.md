# 镜头衔接规约（Storyboard Artist / Editor）

本规约描述系统如何决定「第 N 格怎样变成第 N+1 格」。运行时实现见
`backend/app/core/shot_transitions.py`，本文件是规约正文，不被执行。
站位、轴线与机位本身由 `spatial-stage-master` 决定；本规约只管相邻两镜之间。

六个维度不是六道互不相干的关卡：一刀切点往往同时由几条规则决定，
规划时按下文「转场决策顺序」取第一条成立的，检查时六个维度各自独立报告。

## 一、切点规划（每一刀都有一份）

| 字段 | 含义 |
|------|------|
| 转场方式 | 硬切 / 叠化 / 淡入淡出 / 匹配剪辑 |
| 衔接手法 | 开场、顺接、正反打、视线匹配、切回反应、动作匹配、图形匹配、时间流逝、回忆、章节转换、场景转换 |
| 带过去的东西 | 视线、动作、形状、光线……观众借以跨过这一刀的线索 |
| 动势衔接 | 静接静 / 动接动 / 动接静 / 静接动 |
| 景别变化 | 推近或拉开几级（大远景 0 … 大特写 8） |
| 机位方向变化 | 有空间方案时量出的度数 |
| 出剪 / 入剪 | 上一镜在切点做什么、这一镜从哪里接 |

分镜面板的「入剪 / 出剪 / 起始状态 / 结束状态」与镜头的「承接 / 交付」由切点规划写出，
不再是整场九格共用的固定措辞。每一镜记录「切入本镜」的方式，成片合成时照它选择转场。

## 二、转场决策顺序

1. **一集的第一镜**：渐显进入（淡入淡出）。其余场次的第一镜承接同一集上一场的最后一镜，按下面 2–10 条判定。
2. **回忆 / 梦境**：进入或离开回忆、闪回、梦境——叠化，色调与现实区分。
3. **大跨度时间**：「三年后」「数月之后」「多年以后」——淡出到黑再淡入，给观众换章的停顿。
4. **时间流逝**：「次日」「片刻之后」「良久」，或前后镜的时段不同（白天 / 黄昏 / 夜晚）——叠化。
5. **换场景**（场次或地点变了）：
   - 前后画面有同形之物（瞳孔 ↔ 圆月、剑身 ↔ 立柱、烛火 ↔ 篝火）——匹配剪辑；
   - 人物出门 / 离开，下一场同一人物出现——硬切，以出场动作接起两个空间；
   - 两个场景冷暖色调相反——叠化，光色渐变；
   - 其余——硬切，由声音先行或环境线索（门、窗、道路）承接。
6. **视线匹配**：人物看向画外，下一镜是主观镜头、物件或另一个人——先给视线，再给所见。
7. **切回反应**：主观 / 物件 / 空镜之后回到人物——给出所见之物带来的反应。
8. **动作匹配**：两镜描写同一动作的不同阶段（伸手 → 握住、拔剑 → 出鞘、起身 → 站起），且是同一人物——
   在动作进行到一半时切出，下一镜从动作后半段接入。
9. **正反打**：两个单人镜头拍不同的人——机位留在轴线同一侧，视线方向相对。
10. **顺接**：同一场景内的其余情况——硬切，承接姿态、朝向与道具归属。

转场时长：硬切、匹配剪辑 0 秒；叠化约 0.5 秒；淡入淡出约 0.8 秒。
叠化与淡入淡出两侧画面必须稳住：运动镜头先落幅再转场，转场完成后再起幅运动。

## 三、六个维度的检查

| 维度 | 检查 | 级别 | 判定 |
|------|------|------|------|
| 视觉 | 景别递进 | 提示 | 同一场景相邻两镜景别跨度超过 4 级（如大远景 → 大特写）；冲击 / 反转镜、物件与主观镜头除外 |
| 视觉 | 30 度原则 | 提示 | 同一组人物、景别相差不超过一级、机位方向变化不足 30°（需空间方案） |
| 视觉 | 视线闭环 | 提示 | 主观镜头前没有发出视线的人；或「人物看向画外 → 所见」之后切到了别人，没有回到看的人 |
| 运动 | 动势方向 | 提示 | 相邻两个运动镜头方向相反（推接拉、升接降、左摇接右摇） |
| 逻辑 | 人物不瞬移 | 提示 | 同一场景硬切两侧，上一镜结束时可见的人物到这一镜开始时位置相差超过 0.8 米（需空间方案；叠化 / 淡入淡出表示时间过去，不算） |
| 逻辑 | 先因后果 | 提示 | 前一镜已出现结果（中箭、血溅、门应声而开），后一镜才出现原因（放箭、挥刀、敲门）；悬念 / 冲击 / 反转镜除外 |
| 匹配 | 光色连续 | 提示 | 同一场景硬切两侧的光线时段不同，或冷暖色调相反 |
| 节奏 | 时长张弛 | 提示 | 五镜以上全部同一时长；或打斗、冲击等快节奏镜头时长远超本场中位数 |
| 节奏 | 情绪过渡 | 提示 | 悲伤 / 恐惧与喜剧情绪直接相接，中间没有缓冲镜头 |

180 度轴线由空间方案判定（越轴为错误级，拦在第 5 阶段之前），此处不重复。
全部检查进入分镜提示词详情的连续性自检列表，每条都说明涉及哪几镜、怎么改。

## 四、分镜表作者须知（写入分镜表提示词）

- 相邻镜景别逐级变化，远景不直接跳特写（冲击 / 反转镜除外）。
- 连续拍同一人物时，景别拉开两级以上或机位方向变化 30 度以上。
- 人物看向画外，下一镜给其所见（主观或物件），再切回该人物的反应。
- 动作在进行中切出，下一镜接同一动作的后半段；先因后果。
- 运动镜头接运动镜头方向一致，接固定镜头前先落幅。
- 动作戏用短镜头、情绪戏留长镜头，时长要有长短变化；悲喜之间留缓冲镜头。
- 同场景直接硬切；时间流逝与回忆用叠化；章节或大跨度时间用淡入淡出；画面同形时用匹配剪辑。

## 五、成片合成

每一刀先过连续性质检（越轴等判不过的切点直接拦下，不会因为换成叠化而放行），
再按切点规划选择合成转场：硬切 → hard_cut，匹配剪辑 → match_cut，叠化 → crossfade，淡入淡出 → dip_to_black。
旧任务没有切点规划时沿用质检自己的选择。

## 六、灵活运用

规则是默认值，不是禁令。景别跳跃、情绪撞击、越过常规的切点都可以是有意为之——
把镜头标为冲击 / 反转 / 悬念镜，或人工确认提示级告警即可。
