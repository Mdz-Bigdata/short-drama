# 接镜思路与接不上的诊断

## 一、先问为什么切

下一镜要带来新信息：新动作、新表情、新关系。景别、角度、内容都差不多的两镜，切过去只是换了个机位，并成一镜更好。
先定这一切要让观众跟住什么（动作、线索、时间变化、没说完的话），再定在哪一刻切。

## 二、六类关系

| 关系 | 接法 | 要核对的 |
|---|---|---|
| 接动作 | 同一动作换景别；相似动作连两场戏 | 动作阶段、速度、用手、重心。后镜从略往后的阶段接，不重演。跨场呼应不表示两场同时发生，要靠情节说明 |
| 接图形 | 圆接圆、斜线接斜线 | 中心位置、大小、边缘、明暗；不为凑形状删剧情 |
| 借遮挡 | 近物遮满；摄影机掠过墙面 | 切点处要遮满，半张脸藏不住背景。摄影机运动和前景滑动方向分开写 |
| 留参照 | 同物换境；同景换时 | 列清要保留的特征，别把穿帮当变化。物件为何在此要有交代 |
| 错开声画 | J-cut 下场声音先到；L-cut 上场声音留下 | 只在剪辑阶段做，不写进视频提示词；听得清声音来自哪里 |
| 顺着看与走 | 视线引导；方向延续 | 谁在看、看向哪里；方向要变就交代转身或全景 |

## 三、生成前写清

把「前镜切出的状态」和「后镜接入的状态」分开写：主体位置与大小、运动方向、动作阶段、道具状态。
它们可以在片段中间，不一定是文件的首尾帧；切点前后留余量。同一连续镜头切段时才要求首帧等于上一段尾帧。

## 四、接不上时查什么

动静能接，问题是能量有没有来由和落点：一声响动可以带起快摇，慢说话后突然高速横摇就不行。
运动除了方向还要比速度、加速度、轨迹、面积和谁在动。眼睛的落点也要交接：主体跨屏，观众会漏掉后一镜开头。
光的方向和软硬后期改不回来。救的顺序：重新找切的理由 → 先接注意力 → 用声音过桥 → 插反应或空镜 → 技术匹配 → 最后才考虑设计型转场。

## 五、运镜跟着戏走

建立用摇或固定，推进用缓推缓移，冲突用手持或快推，释放用缓拉或固定。慢推是悬念，快推是震惊。
一场戏全程固定机位连起来像幻灯片。

## 六、首尾帧过渡

八种走法：运镜、景别、光影、动作延续、风格演变、时间流逝、色彩、空间穿越。
两张图比例必须相同，跨度别太大，风格保持一致。
