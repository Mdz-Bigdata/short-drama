# 镜头组与连镜对表：站位、道具、组合禁忌

> **本项目覆盖规则**：不用硬切——原文「90% 用无技巧硬切」
> 在本项目一律改为动作 / 视线 / 形状匹配的顺接，切点写在动作进行中。

## 一、为什么会"连镜断裂"

每一段视频都是一次独立生成，模型不记得上一段谁站哪、手里拿着什么、光从哪来。
靠更长的提示词解决不了，要把**空间和道具状态变成结构化、可引用的数据**，每一镜都从同一份基准出发。

## 二、站位锁定

1. **空间基准**：每场戏先定地标(家具、出入口)、光源(方向、色温)、人物初始站位与朝向、固定机位。
   本项目由空间调度(`spatial_stage`)量出，场地参考图作为基准帧挂到这场戏的每一镜。
   换房间、空间关系大变(台阶上→平地)、新人物入场，都要新建基准。
2. **镜间衔接锁**：相邻镜头继承上一镜结束时的人物位置、姿态、手部落点、持物、道具落点和视线方向。
   剧本没写「她走到桌子右边」，人就不能自己换边。本项目写在运镜契约的 start_state / end_state 与 `[空间锚]`。
3. **人物锚点不能无因变化**：机位可以随便换，人物状态不能跳——蹲到站、桌前到门口，中间必须有可见的动作过程。

## 三、道具稳定

每个跨镜道具保持三件事连续：**归属**(谁拿着、放在哪)、**朝向**(哪面朝镜头、开口方向)、**状态**(完好/损坏、干/湿、开/合、亮/灭)。
变化必须有镜头里看得见的动作(放下、递交、打开)。没有对应动作的变化都是穿帮。
状态表每镜一行：`镜头 | 道具 | 持有者 | 位置 | 朝向 | 状态`，即本项目 `[道具锁]` 与四重锁的道具状态表。

**冻结关键帧只写起点**：分镜首帧只画这一镜开始那一瞬能看见的东西；道具到结尾才出现的状态写进结束状态，
不写进首帧——同一张图里出现两个位置，模型会犹豫。

## 四、镜头组：一组镜头讲完一件小事

| 组合 | 结构 | 用途 |
|---|---|---|
| 递进 | 全景 → 中景 → 特写 | 先交代环境，再看动作，最后强调细节；最常用 |
| 循环 | 全 → 中 → 特 → 中 → 全 | 完整呈现一件事的起止 |
| 反向递进 | 特写 → 中景 → 全景 | 先用细节制造悬念，再揭示全貌；开场钩子、情绪收尾 |
| 并列 | 同级景别并列 | 多细节展示，不讲顺序 |
| 对比 | 大景别直接接大特写 | 强烈反差，慎用 |

衔接手法(本项目全部写成顺接，不硬切)：**动作匹配**(上一镜动作后半段接下一镜前半段，切在动作中间)、
**视线匹配**(看向画外 → 接他看见的东西)、**形状/色彩匹配**、**逻辑顺接**(因果、时间、空间)、**空镜缓冲**(换场、情绪留白)。

## 五、组合禁忌(常规叙事)

1. 同景别同角度跳接——两镜之间机位至少差 30° 或景别至少差一级。
2. 无理由跳级景别——全景直接接大特写，中间要有过渡。
3. 越轴——全程在 180° 轴线同一侧；要过轴先给一个中性镜头或可见的绕轴运动。
4. 动接静、静接动无过渡——运动镜头落幅停稳再接固定镜头，或固定镜头起幅后再起动。
5. 运镜方向对冲——左摇接右摇、推接拉，观众会晕。
6. 情绪反向——同一组里景别、角度、运镜的情绪倾向互相打架。
7. 堆砌运镜与转场——每镜一个主运镜，转场只在换场、情绪转折处用。

时长参考(剪辑节奏，非单段视频时长)：景别越大停留越久——全景 2–4 秒、中景 1.5–2.5、近景 1–2、特写 0.5–1.5。
本项目一段视频至少 4 秒，所以这条用来分配**一段多镜头视频里各镜的占比**，不是用来切短片段。

## 六、生成前对表(五查)

1. **站位**：同一角色在相邻镜头里的左/中/右、朝向一致。
2. **视线**：A 看 B 的镜头里视线方向对着 B 的位置；正反打两人视线对得上。
3. **道具**：持有者、位置、朝向、状态与上一镜衔接，没有凭空出现、消失或换手。
4. **动作**：上一镜的动作终点 = 下一镜的动作起点。
5. **光线**：同一场戏色温、光源方向、阴影方向统一(见《首尾帧衔接》的光线词固定)。

本项目第 4 阶段在生图之前自动做一遍对表：分镜表被退回(占位内容、入镜角色列与画面不符、点到未出场的人)
或光色相反、景别跳级、运镜对冲这三条没过，就把原因原样交回分镜表作者改一版再定稿；改完仍不过就用问题最少
的那一版。实现：`app/core/storyboard_revision.py`。
