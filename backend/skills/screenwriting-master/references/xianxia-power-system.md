# 修仙 / 武侠力量体系：写剧本时的设定底板

修仙、武侠剧最常见的失分不是打得不好看，是力量体系前后不一：前一集金丹碾压筑基，后一集筑基随手反杀；丹药吃了就涨，代价从不兑现。
这一页给一套通行的阶梯和写法，开篇定好，全剧照着走。

## 一、写法规则（先读）

1. **一部剧只用一套阶梯**：境界、功法品级、丹药品阶在第一次出现时说清，之后每次提到都对得上。改设定只能是剧情（发现上古传承、破境），不能是笔误。
2. **胜负挂在阶梯上**：同阶看功法品级与克制，跨阶要有付出（燃血、焚脉丹、借阵、借地利、对方旧伤）。跨一阶可以，跨两阶必须在前文埋好代价或底牌。
3. **每门功法、每颗丹药都带代价**：反噬、禁忌、限制、后遗症是现成的冲突。主角用了禁术，后面几集必须兑现代价（经脉受损、心魔、寿元、被天道排斥）。
4. **品级要让观众看见**：同一招，玄级与天级在画面上的尺度不同（见下文「品级与画面尺度」）。台词里报出品级，画面上给出差距。
5. **术法名字就是视觉说明书**：名字里「指、掌、拳、印、剑」定了招式的形，「吞、囚、封、镇、焚、炼」定了它对人做什么，「魔、血、雷、冰、鸿蒙、大荒」定了颜色和质感。起名时就想好它在镜头里长什么样。
6. **反派功法自带剧情**：邪功速成、代价大、被正道克制。写反派时把「他为什么练邪功」「代价何时爆发」当作伏笔用。

## 二、修仙境界（通用阶梯）

炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升（地仙 / 天仙 / 金仙）

- 低阶（炼气、筑基）：灵气入体、御使低阶法器，打斗以近身和符箓为主。
- 中阶（金丹、元婴）：真元外放成形，飞剑、法宝、法相开始出现；元婴可离体逃生。
- 高阶（化神以上）：引动天地法则，一招改换天象；渡劫必引雷劫。

## 三、功法品级与画面尺度

凡级 < 黄级 < 玄级 < 地级 < 天级 < 仙级 < 大道级

| 品级 | 作用 | 画面尺度 |
| --- | --- | --- |
| 凡级 | 强身健体，不动灵气 | 纯肉身动作，无光效 |
| 黄级 | 引气入体，吸纳稀薄灵气 | 贴身薄光、气流，范围一臂之内 |
| 玄级 | 凝气旋，灵气可外放 | 光效离体数米，可打出成形的气劲 |
| 地级 | 真元液化，可御法器 | 覆盖一间屋、一座院，法器拖出光轨 |
| 天级 | 生道韵，引天地大势 | 天色、云层、地面随之变化，范围以百米计 |
| 仙级 | 沟通法则 | 天地异象，山河被压出痕迹 |
| 大道级 | 改写局部规则 | 时间、空间、重力失常，只给主角或上古传承 |

## 四、功法流派（每一派自带冲突）

- **正统道门**：温和、根基稳、不易走火入魔，克制心魔；进境慢。适合正道宗门弟子，冲突来自「慢」与「规矩」。
  - 入门引气诀（黄级）、清心稳脉的中阶心法（地级）、九转扩丹田的镇派道经（天级）、阴阳双修渡劫心经（仙级）。
- **魔修邪道**：吞噬他人精血、灵气、亡魂速成；代价是心性暴戾、心魔深重、断修即自损、渡劫雷劫加倍、被天道排斥。适合反派与黑化主角。
- **体修**：淬皮肉筋骨，借地脉之力改造肉身；同阶肉身硬撼法器，重伤可借灵气复原。打戏以力量、硬碰硬、地面开裂为主。
- **丹修医道**：感知药性、提纯药力、徒手疗伤、以真元化解丹毒。冲突来自救谁、丹毒、丹雷。

## 五、武侠内功（江湖体系）

境界：锻体 → 气血 → 通脉 → 内息 → 罡气 → 宗师 → 大宗师 → 天人

- **正派内功**：绵长养身的固本功；内力纯白、克制阴毒的浩然之气；至阳至刚、驱寒疗伤但易心火过旺的纯阳功。
- **邪派毒功**：带麻痹剧毒、触之经脉溃烂的阴毒功；吸人内力速成、晚年经脉崩碎的化功大法；冻结气血、中者僵冷的寒煞功。
- **医家内功**：疏通经脉、化解寻常毒素、配合针灸药浴。
- 武侠的内力**不画成发光能量体**：靠衣袂、尘土、器物、对手身体的受力来显力（见特效指南「内力外放」）。

## 六、丹药与药材

- **品阶**：一至九阶，1–3 阶对应炼气、筑基，4–6 阶对应金丹、元婴，7–9 阶对应化神至渡劫。每颗再分次品、正品、精品、无暇；无暇丹带丹纹、无丹毒。
- **常用类别**：破境丹（一生只首枚有效、根基虚浮者伤经脉、引心魔）、疗伤保命丹（止血生肌、修复内腑、护住元神吊命）、洗髓丹（排凡胎杂质、提纯灵根）、清心丹（压心魔、渡劫必备）、延寿丹、秘丹毒丹（侵蚀元神、短期暴涨修为事后经脉尽断）。
- **炼丹流程**：选药 → 提纯 → 入炉控火 → 凝丹 → 渡丹雷 → 封丹。高阶丹必引丹雷，这是现成的奇观戏。
- **丹毒**：低品丹残留丹毒，久服阻塞经脉、损伤灵根——「乱吃丹的人后面要还」。
- **丹师等级**：丹徒、丹士、丹师、丹王、丹尊、丹圣。
- **药材年份**：十年凡草 → 百年宝药 → 千年灵药 → 万年王药 → 十万年圣药 → 百万年神药。武侠药材分凡药、珍药、奇药（雪莲、灵芝一类）。
- **武侠医毒**：外敷金疮药、固本大还丹、续断经脉的膏药；入口化血的剧毒、慢慢废掉内力的蛊、寒气入髓的毒；解毒丹、纯阳解煞丸。手段有望气诊脉、内力针灸、药浴拔毒、接骨续筋；毒术有淬毒兵刃、迷香、蛊虫、以内力种下的寒毒禁制。苗疆、五毒一派用蛊（迷魂、噬血、控心、续命）。

## 七、灵根

- 五行灵根：金、木、水、火、土；变异灵根：雷、冰、风、暗。
- 品级：杂灵根（多系混杂，最慢）→ 下品 → 中品 → 上品 → 天灵根（单系纯净，速度翻倍）→ 先天异灵根（主角专属）。
- 废柴逆袭的标准起点是杂灵根或无灵根；翻身靠洗髓、传承、异灵根觉醒，每一步都要在剧情里付出代价。
- 灵根决定术法的颜色与质感：火灵根的术法是火，雷灵根是紫电，冰灵根是霜晶。同一个人前后一致。
