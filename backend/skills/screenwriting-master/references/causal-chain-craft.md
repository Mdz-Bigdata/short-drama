# 因果链：把「然后」换成「所以」

事件多不等于剧情在走。几件事只是按时间排在一起，删掉中间哪一件后面都照样成立，那是排列，不是推进。
剧情要的是：因为 A，才有 B；B 逼人物做了一个选择，选择又引出 C。

## 一、节点之间先连「所以」

写完一串节点，挨个用「因为……所以……」连一遍：

- 连得上：前一件事改变了后一件事发生的条件。
- 连不上、只能用「然后」「同一天」「正好」接：这两件事之间缺一个原因，补原因，或者删掉其中一件。
- 怎么连都勉强：问题在前面已经写下的事，不在后面缺情节。先别加人物、加意外。

## 二、因果有强弱，弱的不值得写长

「下雨→淋湿→感冒→去医院」也是因果，但人物只是在挨着，没有选择、没有关系变化、没有利益冲突。
每个节点写完问一句：它改变了什么？至少改一样——

1. 目标：原本够得着的变远了，或者目标本身变了。
2. 关系：信任的人开始怀疑，敌人不得不合作。
3. 认知：发现一直相信的事是错的。
4. 处境：安全的地方不能再待，手里的资源没了。

四样都没变的节点，要么删，要么并进别的节点；只有承担氛围、关系养成、信息交代时才留，并且写短。

## 三、关键节点让人物的选择参与进来

天灾、意外、别人的算计可以开局，但每集的转折点要由人物自己的选择触发：他本可以不救、不说、不交出来，他偏这么做了，于是要付代价。

检查方法：把主角换成一个性格完全相反的人，这件事还会这样发生吗？不会，说明人物和剧情咬上了；会，说明他只是被推着走。

两种写法的差别：「得到秘籍所以被追杀」是遭遇；「选择相信师父、为找证据闯禁地，所以被认作叛徒」是选择的后果，而且每条退路都有代价（逃 = 放弃调查，交出 = 背叛师父，继续 = 可能失去一切）。

## 四、中段不散：支线都要改变主角接近目标的方式

开篇的矛盾解决了、新的还没立起来时，最容易一集一个新敌人、一个新秘密、一个新人物。每条支线写之前问：它让主角离主线目标更近、更远，还是让目标变复杂？

比武、结交、感情线都可以写，只要它们是主线的手段或代价：为了接近仇人的手下才去比武；比武认识的人恰好知道旧案；救下的人是仇人的女儿。中段要做的是让已有的矛盾生长，而不是换新的矛盾。

## 五、写完一场过三问

1. 这件事为什么非发生不可？要找到具体的触发点（利益冲突、隐瞒、价值观分歧爆发），不能是「这里需要一场戏」。
2. 它改变了什么？按第二节的四样对。
3. 这个变化引出什么后果？顺着追：失去朋友 → 没了情报来源 → 只能找旧敌 → 旧敌开出难以接受的条件。前一个节点留下的问题，就是下一个节点的起点，不必另造反派和巧合。

## 六、删中间那场试一试

连续三场 A → B → C，把 B 删掉：A 和 C 照样接得上、人物决定照样说得通，B 就要重写——让它给出新信息或改掉人物的判断，使 C 只能因为 B 才发生。
只用于推剧情的场次；情绪缓冲、关系养成、氛围场不按这条删。

## 七、落到短剧

- 每集的节点之间是「所以」；集与集之间，上一集的选择留下的后果是下一集的起点（和钩子兑现咬合）。
- 爽点前面要有主角自己做过的选择或埋过的手段，赢得有来由；虐点要是他的选择带来的代价，不是作者降下的霉运。
- 主角每做一个重要选择，后面的剧情里都要能找到它留下的痕迹。
