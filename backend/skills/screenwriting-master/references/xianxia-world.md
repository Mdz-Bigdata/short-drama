# 修仙世界的人情物理：妖兽、称谓礼数、宗门服饰、坊市与灵石

力量体系定「谁强」，设定谱给「有什么」，这一页管「这个世界里的人怎么说话、穿什么、拿什么买东西、山里有什么」。
写对了，观众一听一看就知道这是修仙世界；写错了（修士互称「先生」、外门弟子穿长老的袍子），出戏。

## 一、妖兽与灵兽

- **品阶**：一阶至九阶，大致对应修士炼气至渡劫；高阶妖兽能化形成人，化形后仍留一处破绽（竖瞳、兽耳、鳞片、尾巴）。
- **妖丹（内丹）**：妖兽的修为凝在妖丹里，杀妖取丹是修士的生计，也是结仇的起点（杀了小的，大的来报仇）。
- **常见种类与画面**：
  - 狼、虎、豹类：成群出没、体型比寻常大一倍、眼泛幽光。
  - 蛇、蛟类：鳞片反光、竖瞳；蛟有角无爪或角未成，化龙要渡劫。
  - 鸟类（鹏、鹤、雀）：翼展遮天，羽毛带属性光（火羽、雷羽）。
  - 龟、蟾类：甲壳上长着苔藓与碑文，常年不动，像一座小山。
  - 狐类：多尾（尾越多修为越高），擅幻术。
  - 上古凶兽：只在秘境、封印下出现，一现身天地变色。
- **妖兽材料**：妖丹（修为所在，炼丹、炼器、直接吸收）、精血（炼体、觉醒血脉、画高阶符；越纯越浓，高阶妖兽精血带金色）、兽骨兽角（炼器）、鳞甲兽皮（炼防具）、羽毛（炼飞行法器）、毒囊（炼毒）。取材料的过程本身就是戏：斩杀、剥取、被母兽追杀。
- **吸收精血**：服下或浸泡，血气冲入经脉，皮肤下青筋暴起、泛出兽纹，眼里闪过兽瞳；扛不住就被兽性反噬，失去理智。
- **灵兽契约**：主仆契（灵兽受制）、平等契（同生共死）；契约成时额头或手心浮出契印。灵兽平时装在灵兽袋里。
- **写法**：妖兽的强弱用对比交代（一爪拍碎巨石、炼气弟子被吓瘫）；高阶妖兽要有智慧和动机，不是会走的经验值。

## 二、称谓与礼数

- **修士之间**：道友（平辈）、前辈 / 晚辈（差一个大境界以上）、师兄 / 师姐 / 师弟 / 师妹（同门）、师尊 / 师父（拜师）、师叔 / 师伯（师父的同门）。
- **自称**：贫道（道士）、贫僧（和尚）、本座（宗主、魔头、高阶修士，傲慢）、老夫 / 老身（年高者）、在下（谦称）、晚辈。
- **对上位者**：宗主、掌门、太上长老、老祖；魔道称尊主、魔尊；世家称家主、老祖宗。
- **礼**：道门稽首（左手抱右拳、举至眉心微躬）、佛门合十、平辈拱手；拜师行三叩九拜；跪是大礼，修士膝下有尊严，跪人就是戏。
- **说话的分寸**：境界压人时对方喘不过气、开口发颤；高阶对低阶可以不回答；直呼高阶名讳是冒犯（立刻有人出手）。
- **常用词**：闭关、出关、突破、渡劫、陨落（死）、坐化（老死）、夺舍、道心、因果、机缘、灵根、走火入魔。不用「先生、老板、警察、手机」这类现代词。

## 三、宗门服饰按身份

- **按层级分颜色**（全剧固定一套，开篇定好）：杂役粗布灰衣；外门弟子青灰道袍；内门弟子青色或白色道袍、袖口一道宗门纹；真传弟子白袍金边或银边、绣宗门图腾；执事深色袍；长老紫袍或玄色袍、腰悬令牌；宗主（掌门）袍上绣完整宗门图腾、头戴玉冠。
- **按宗门分风格**：剑宗（窄袖利落、背剑）、丹宗（宽袍、腰挂药囊）、佛门（僧衣袈裟）、魔门（黑红、暗纹、面具或兜帽）、世家（华服锦缎、家徽）、散修（杂色旅装、斗笠）。
- **身份的小物件**：宗门令牌 / 身份玉牌（腰间）、储物袋、佩剑或法宝、发冠与发簪（境界越高越简，也越贵）。
- 服装是角色的一部分：同一个人升了层级就换了袍子，这一换就是一场戏（被授真传袍、被剥去道袍逐出师门）。

## 四、坊市、拍卖与灵石

- **灵石**：下品、中品、上品、极品，大致百换一；是货币，也是修炼和布阵的能源。穷修士一块下品灵石掰着用。
- **坊市**：修士的集市，摊位卖丹药、符箓、法器、妖兽材料、来路不明的残卷；坊市里禁止动手（有坐镇的高手），出了坊市才动手——现成的「门口截杀」。
- **拍卖会**：包厢里坐着大人物（只露声音或剪影），压轴品引来几方竞价；主角拿出一件东西震住全场，或者一句「我出双倍」——拍下之后被盯上是固定接法。
- **交易的戏**：捡漏（别人看不上的残卷是至宝）、被坑（买到假丹）、以物易物（妖丹换功法）、赊账与人情。
- **画面**：坊市是一条长街，两侧摊位挂着写字的幡子，空中偶有飞剑掠过；拍卖场是阶梯看台加一圈包厢，中央高台上的东西用光幕罩着。
