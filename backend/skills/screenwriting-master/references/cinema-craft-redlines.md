# 电影级编剧红线与 S 级三冲击

> 来源：SkillHub「星云AI编剧大师」(@user_9b400410/screenwriting-master v1.0.2，MIT；原创 @山音《山音超级编剧大师》，二创 @星云)。
> 山音原版已整体收录在 `shanyin-screenwriting-master`；本文只补二创版新增、且本项目流水线能直接执行的部分，
> 用本项目的话重写，不复制原文。

## 一、写作红线（最高优先级，交稿前逐条自检）

绝对不写：

- 心理描写："他意识到""她心里涌起"——摄影机拍不到。
- 括号里的潜台词注释："（其实在掩饰紧张）"。
- 说教旁白、解释剧情的台词、强行催泪的独白。
- 机械连接词堆出来的 AI 腔（"然而""与此同时""不禁"连用）。
- 任何画面和声音里都不存在的东西。

必须做到：

- 台词口语化，**每个角色有自己的语言指纹**：用词、句长、口头禅、回避什么话题，换掉名字也认得出是谁在说。
- 用动作代替解释，动作本身就是潜台词。
- 对话像冰山，只露一角；真正的意思留在没说出口的部分。
- 张力靠对手戏推动，不靠旁白和解说。

## 二、S 级三冲击

每一集都要在三个维度各有一次顶点时刻，写分集账本时就标出它落在哪个故事节点：

| 维度 | 判断标准 |
|---|---|
| 情绪冲击 | 观众心口被撞一下的瞬间：揭穿、背叛、失去、迟到的认可 |
| 视觉冲击 | 值得截图、能做海报的一帧：构图、光线、动作在此刻同时到顶 |
| 场景冲击 | 情境本身罕见或极端，但因果必须成立；不合逻辑的强情节宁可不要 |

三次顶点不要挤在同一场：情绪顶点通常在集尾钩子前，视觉顶点交给分镜放大，场景顶点决定本集的核心设定。

## 三、人物链

`Want（主动追求的目标） → Need（自己没意识到的缺口） → Ghost（过去的伤） → Lie（因伤而信的错念） → Flaw（错念外化的行为毛病）`

短剧集数少，Ghost 不必演出来，但编剧必须知道；Lie 在中段被戳破，Flaw 在高潮前被迫面对。
主要关系设计成**不对称**：一方知道得多、一方要得多、一方地位高——不对称才有戏。

## 四、先建世界，再切截面

角色带着前史走进第一场戏，世界在故事开始前已经运行很久。顺序：破题 → 梗概 → 人物 → 前史与世界观 →
结构大纲 → 场景拆解 → 场景写作 → 剧本医生验收。前四步建世界，后四步从最有张力的截面切进去。

## 五、剧集连续性：四张追踪表

每集写完更新一次，跨集写作时随稿附上：

| 表 | 记录 |
|---|---|
| 角色状态 | 每个角色此刻的处境、关系、伤势、所持物、已知信息 |
| 暗线进度 | 每条暗线推进到哪一步、下一步在哪集触发 |
| 埋种回调 | 每个伏笔埋在哪集哪场、计划在哪集回收、是否已回收 |
| 已公开信息 | 观众此刻已经知道什么——防止重复交代，也防止角色说出观众还不该知道的事 |

## 六、交付与边界

- 新产出另存新版本（v2、v3…），不覆盖前作——与本项目的剧本版本菜单一致。
- 亲密内容只用于明确成年角色，以距离、呼吸、视线落点呈现；不涉及未成年人与露骨描写。
- 脏话可以推动冲突，紧跟【做消音处理】。
- 对外部作品只做结构转化与重新表达，不大段复制受保护的台词与场面。
- 地方戏、手艺、民俗等文化符号服务人物与叙事，不做布景板式堆砌。
