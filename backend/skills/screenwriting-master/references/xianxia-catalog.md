# 修仙设定谱：功法、术法、丹药、宗门、法宝道具、秘境、符箓、阵法、传承

和「修仙 / 武侠力量体系」配套：那一页定阶梯和规则，这一页给可以直接拿来用的条目。名字都是示例，可以照着结构另起；
起名时记住：结尾的字定它是什么（指、掌、印、诀、丹、钟、鼎），名字里的字定颜色、作用和尺度（雷、焚、吞、囚、鸿蒙、九幽）。

## 二、术法神通的类型（写进戏里时各有各的看点）

- **攻伐**：指、掌、拳、剑、刀、印、斩——看点是蓄力成形和打中后的作用。
- **防御**：护体光罩、金钟、玄甲、结界——看点是被打出裂纹、裂纹蔓延、碎开那一下。
- **遁术身法**：化光遁走、缩地成寸、残影步——看点是一闪之后人已在别处，原地留残影。
- **神识**：神识扫过（无形波纹）、神识压制（对手跪下、地面下陷）、搜魂——看点在受者身上。
- **控制封印**：锁链、光牢、定身符、封印——看点是挣扎与合拢。
- **召唤法相**：身后浮出巨大法相、灵兽、剑灵——看点是尺度对比，人很小。
- **领域**：一片空间改了颜色和规则（时间放慢、重力翻倍、万物结霜）——看点是边界和边界内外的差别。
- **禁术**：燃血、燃寿、自爆金丹——必须当场写出代价（白发、吐血、修为倒退）。

- 丹药的画面三要素：**颜色**（按药性）、**丹纹**（品相越高纹越多越清晰，无暇丹自带光纹）、**丹香**（开瓶时化成一缕薄雾）。
- 出炉异象按品阶升级：低阶只有丹香，中阶丹光冲出炉口，高阶引丹雷、天现异象。

## 四、宗门

- **类型**：剑宗（以剑入道）、丹宗（炼丹济世，富而弱）、器宗（炼器，与剑宗往来）、阵宗（守山阵法最强）、符宗、佛门、魔门、修仙世家（血脉传承、讲嫡庶）、散修联盟、妖族部落。
- **资源与规矩**：贡献点换功法丹药、洞府按身份分配、秘境名额靠宗门大比；门规严（同门相残、私传功法、叛门者废修为）。
- **现成冲突**：外门考核、宗门大比、长老派系之争、真传之位、叛徒与卧底、宗门被围、灭门复仇、正魔大战。
- **地点与画面**：山门（巨大牌坊、石阶万级、云海）、主殿（高阔、金顶、香火）、藏经阁（层层书架、玉简发微光、禁制光幕）、丹房（丹炉居中、药柜满墙、地火）、器堂（锻炉、铁砧、火星）、演武场 / 比武台（青石擂台、四周看台）、洞府（依山开凿、石门、灵泉、蒲团）、后山禁地（雾、封印碑、残阵）、灵田药园、传送阵台、护山大阵（平时不可见，开启时光幕笼罩全山）。

## 五、法宝、兵器与道具

- **法宝品阶**（画面随品阶升级）：法器（无光，靠真元催动）→ 灵器（微光）→ 宝器（流光、有纹路）→ 灵宝（有灵性，能自行护主）→ 仙器（器灵成形，开口说话）→ 神器 / 先天至宝（一现世天地异象）。
- **攻伐类**：飞剑（本命剑，可藏于丹田、出鞘化光）、刀、枪、鞭、扇（扇出风刃）、琴（音波）、笔（凌空书符）、拂尘、念珠。
- **镇压防御类**：钟（罩人、钟声震魂）、鼎（镇压、炼化）、镜（照出原形、反射术法）、塔（收人入塔）、印（从天压下）、珠（定风、避水）、葫芦（收人、喷火）、旗 / 幡（招魂、布阵）、伞（挡雨挡雷）、梭（飞行）。
- **辅助道具**：储物袋 / 储物戒（随手取物，取物时一闪）、传音符 / 传讯玉符、玉简（贴额读取，额头发光）、阵盘、阵旗、傀儡、灵兽袋、丹炉、灵石（下品 / 中品 / 上品 / 极品，是货币也是修炼资源）。
- **符箓**：黄符（低阶）、蓝符、紫符、金符（高阶）；用时夹在两指、真元一催即燃，烧成灰前术法已出。
- **认主与祭炼**：滴血认主（血珠渗入、法宝一震发光）、本命法宝温养于丹田、器灵认主后可与主人对话；法宝被毁，主人受反噬（吐血）。
- 写法宝时说清三件事：**谁的、什么品阶、怎么用**；同一件法宝全剧外观不变，损坏后照写裂痕。

## 六、秘境

- **类型**：上古洞天（大能坐化处，留传承与禁制）、遗迹（宗门覆灭留下的废墟）、小世界（自成天地，时间流速不同）、古战场（残兵、怨魂、杀意不散）、天坑地宫、雷池（淬体）、火山熔窟（异火）、极寒冰原、血海魔渊、仙人墓。
- **开启规则**：几十年一开、修为上限（防止老怪进入）、名额靠宗门大比或拍卖、入口在时限后关闭（来不及出来就困在里面）。这些都是现成的倒计时。
- **里面有什么**：传承（考验心性或资质）、天材地宝（守护妖兽）、残阵禁制、前人尸骨与遗书、其他宗门的弟子（夺宝、杀人越货）。
- **写法**：进入前交代规则和时限；里面每一步都要有选择（救人还是夺宝、信谁）；出口前给最大的反转（同伴背刺、传承认主、秘境崩塌）。
- **画面**：天色异常（紫天、双月、永昼）、漂浮的山石与断桥、巨大的古代遗骸或石像、空气里飘着光点或灰烬、入口是一道光门或空间裂隙；秘境崩塌时天空碎裂、地面下陷。

## 七、符箓

- **品阶**：黄符（低阶）→ 蓝符 → 紫符 → 金符（高阶）→ 本命符 / 天符（以精血或道韵绘成，可封入一击之力）。
- **种类**：攻击符（火球、雷击、冰锥、风刃）、防御符（金光罩、土墙）、辅助符（神行、轻身、隐匿、净尘）、控制符（定身、缚灵）、封印符（贴上即封、镇妖）、替身符（受致命一击时碎符替死）、传讯符（化作光鸟飞走）、破禁符（破阵、开禁制）。
- **制符**：符纸（黄纸、兽皮、玉片）+ 朱砂或妖兽血 + 符笔；画符须一气呵成，断笔即废，高阶符画到最后一笔时符纸自燃或发光。
- **用法与画面**：两指夹符，真元一催即燃，符文脱纸化光；贴身的符（护身、替身）平时贴在衣内，触发时从衣里透光；成叠的符一撒，漫天黄纸同时燃起。
- **戏剧用途**：底牌（一张保命符翻盘）、伏笔（谁送的符、符是真是假）、代价（高阶符一次性、制作要耗寿元或精血）。

## 八、阵法

- **种类**：杀阵（阵内刀光剑气纵横）、困阵（出不去、走回原地）、幻阵（看见最怕的东西、心魔）、守护阵（护山大阵、光幕罩住全山）、聚灵阵（灵气汇成漩涡，修炼加速）、传送阵（光柱冲天、人影一淡即逝）、封印阵（镇压妖魔，阵破则大凶出世）、血祭阵（以活人为祭，魔道常用）。
- **组成**：阵眼（阵的核心，破了阵就破）、阵基 / 阵旗 / 阵盘（布阵的器物）、灵石（阵的能源，灵石耗尽阵就停）、阵纹（铺在地上或刻在石上）。
- **破阵**：找到阵眼一击破之；强攻（以力破阵，阵越大越难）；耗尽灵石；以阵破阵；阵法师推演生门死门。
- **写法**：先让观众看见阵（阵纹亮起、光幕升起），再写困在里面的人怎么试、怎么错、怎么找到破绽；破阵那一下要有声音和碎裂。
- **画面**：阵纹从脚下向外铺开、一圈圈亮起；光幕成半球或立方罩住；阵眼是最亮的一点；阵破时光幕像玻璃一样裂开、碎片化光散去。

## 九、传承

- **形式**：玉简传承（贴额读取，额头发光，几息之间学会一门功法）、残魂传承（大能残魂现身，亲自指点或要求一件事）、灌顶（大能以神识直接灌入修为与感悟，受者浑身发光、痛苦难当）、石碑 / 壁画悟道（盯着碑文或壁画入定数日，碑上的字或画活过来）、血脉传承（血脉觉醒时脑中涌入先祖记忆）、法宝器灵传承（器灵认主后讲出功法）、梦中传承（反复梦见同一场景，一点点学会）。
- **考验**：几乎所有传承都有考验——心性（幻境里面对最想要的东西）、资质（灵根、体质）、毅力（爬阶、承受威压）、选择（救人还是取宝）、因果（接了传承就接了前人的仇家）。
- **代价与因果**：接传承常要答应残魂一件事（报仇、寻人、守护一族）；前人的仇家会认出这门功法；强行接受超出修为的传承会经脉受损。
- **写法**：传承是剧情的大转折，不是奖励发放。写清：为什么是主角（资质、心性、机缘、血脉）、考验怎么过（用前文埋下的品质过关）、接了之后背上什么。一部剧里大传承两三次就够，多了就廉价。
- **画面**：光点从玉简 / 石碑 / 残魂涌入眉心；受者悬空盘坐、周身经脉一条条亮起；残魂是半透明的老者或女子，说话时声音带回响；悟道时四周时间像慢了下来，落叶悬在半空。
