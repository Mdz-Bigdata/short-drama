# AI 影视剧 / 短剧台词语速与情绪提示词总结

> 面向 AI 配音、TTS、数字人口播、AI 短剧/漫剧生成场景的台词控制提示词手册。
> 适用工具：ElevenLabs、Minimax(海螺)、豆包/火山语音、CosyVoice、GPT-SoVITS、Fish Audio、剪映/即梦、可灵、Runway 等。

---

## 一、核心原则

1. **一句台词 = 文本 + 语速 + 情绪 + 停顿 + 重音**，缺一不可。只给文本，AI 会输出"念稿"式的平淡声音。
2. **情绪要具体、可执行**，避免抽象词。不要只写"生气"，而写"压抑的愤怒，声音发抖但音量克制"。
3. **语速服务于情绪与节奏**，不是独立参数。紧张=快，悲伤=慢，是情绪驱动语速。
4. **短剧节奏比影视快 20%–30%**。短视频用户耐心低，台词要"密、爽、钩子前置"。
5. **口语化优先**，书面语是 AI 配音的天敌。多用短句、语气词、断句。

## 二、语速控制

### 2.1 语速分级参考（中文普通话）

| 等级 | 字/分钟 | 适用场景 | 提示词写法 |
|---|---|---|---|
| 极慢 | 120–180 | 临终、回忆、旁白煽情、悬念铺垫 | `语速极慢，字字停顿，带哽咽感` |
| 慢速 | 180–240 | 悲伤、深情、思考、庄重宣告 | `语速放缓，情绪沉重` |
| 常速 | 240–300 | 日常对话、叙述、口播 | `正常语速，自然流畅` |
| 偏快 | 300–360 | 争吵、催促、兴奋、爽点爆发 | `语速加快，情绪上扬` |
| 极快 | 360+ | 慌乱、逃跑、连珠炮质问、搞笑 | `语速极快，急促连贯不换气` |

> 短剧默认基线建议 **270–320 字/分钟**，比传统影视快。

### 2.2 语速提示词模板

```
[语速：偏快][情绪：焦急] 你到底去哪了？我找了你一整晚！
[语速：慢][情绪：疲惫] 算了……不重要了。
```

### 2.3 语速动态变化（同一句内变速）

高级技巧：一句话里语速有起伏才自然。

```
前半句平稳，后半句突然加快带质问语气：
"我本来什么都不想说的——可你居然连这个都骗我？！"
```

## 三、情绪控制

### 3.1 情绪要拆成"三层"来写

写情绪时，同时描述这三层，AI 输出才立体：

1. **情绪类型**：喜、怒、哀、惧、惊、厌、爱
2. **强度/克制度**：爆发 vs 压抑（同样是怒，摔门大吼 ≠ 咬牙冷笑）
3. **生理表现**：颤抖、哽咽、冷笑、气音、鼻音、喘息

**示例对比：**

| 平淡写法（差） | 立体写法（好） |
|---|---|
| 生气地说 | 压抑的愤怒，音量不高但一字一顿，尾音发冷 |
| 开心地说 | 抑制不住的雀跃，语速偏快，带笑音，句尾上扬 |
| 难过 | 强忍哭腔，声音发闷，中途有一次吸气停顿 |

### 3.2 常用情绪提示词库

**正向情绪**
- 温柔：`气声、轻柔、语调平缓、句尾下沉`
- 喜悦：`语调上扬、带笑意、语速轻快`
- 兴奋：`高音量、语速快、语气亢奋、句末拔高`
- 深情/告白：`低沉磁性、放慢、真诚、微微气音`

**负向情绪**
- 悲伤：`哽咽、颤音、语速慢、有停顿、鼻音重`
- 愤怒（爆发）：`高音量、咬字重、语速快、破音`
- 愤怒（隐忍）：`低音量、冷、一字一顿、尾音发抖`
- 恐惧：`气息不稳、语速忽快忽慢、颤抖、音调偏高`
- 委屈：`带哭腔、音量小、语调下坠、撒娇式尾音`
- 冷漠/嘲讽：`平淡、冷笑、拉长音、阴阳怪气`

**中性/叙事**
- 旁白：`沉稳、客观、中速、清晰`
- 悬念铺垫：`压低声音、放慢、制造停顿`

### 3.3 情绪转折（一句话内情绪切换）

短剧爽点常靠情绪反转，提示词要标出转折点：

```
[前：委屈低声] 我以为你会懂我……
[转折-突然冷下来] 现在看来，是我想多了。
```

## 四、停顿、重音与语气词

### 4.1 停顿标记

- 短停顿（0.3s 左右）：用逗号或 `,`
- 中停顿（0.5–1s）：用 `……` 或换行
- 长停顿/留白（>1s）：显式标注 `[停顿1秒]`

```
你……[停顿]是不是早就知道了？
```

### 4.2 重音标注

给关键词加重音，突出台词信息核心：

```
是"你"让我变成这样的。   ← "你"重读
我从来【没有】怪过你。   ← 【】内重读
```

### 4.3 语气词与呼吸

口语真实感来源。适度加入：`啊、吧、呢、嘛、哈、哼、唉、嗯`
呼吸声：`[吸气][叹气][冷笑一声]`

```
[叹气] 唉……算了吧。
[冷笑] 哼，你还真敢说。
```

## 五、角色声线一致性

### 5.1 角色声音设定卡（生成前先定义）

每个角色开拍前固定一份声线卡，全剧复用，避免同一人前后声音漂移：

```
角色：林夏
性别/年龄：女，25 岁
音色：偏低沉、微沙哑、御姐感
基础语速：常速偏慢
口头禅/习惯：句尾爱拖长音
情绪基调：外冷内热，克制
```

### 5.2 多角色对话注意

- 明确标注说话人：`[林夏]……` `[陈default]……`
- 不同角色语速/音调要有区分度，否则观众分不清谁在说
- 对话节奏：你来我往的台词，回复间隔要短（短剧"快"）

## 六、场景化提示词模板

### 6.1 争吵/冲突戏

```
[角色A-愤怒爆发-语速快-高音量] 你凭什么替我做决定？！
[角色B-隐忍-语速慢-低音量-尾音抖] 我……是为了你好。
[角色A-冷笑-拉长音] 为我好？呵。
```

### 6.2 深情告白戏

```
[男主-低沉深情-放慢-气声][停顿]
"这些年……我一直在等你回头。[停顿1秒] 现在，我不等了——我要追上去。"
```

### 6.3 悬念/反转戏

```
[旁白-压低-放慢-制造紧张] 没有人知道，那天晚上，房间里……还有第三个人。
```

### 6.4 搞笑/沙雕戏

```
[语速极快-夸张-破音] 啊啊啊我不管我不管，今天必须给我道歉！！！
```

## 七、常见问题与避坑清单

| 问题 | 原因 | 解决 |
|---|---|---|
| 配音像念稿、没感情 | 只给了文本 | 每句补情绪+语速+重音 |
| 语速忽快忽慢不稳 | 未设基础语速 | 先定角色基础语速再局部调整 |
| 情绪转折生硬 | 未标转折点 | 显式标注 [转折] 位置 |
| 长句一口气念完憋气 | 缺停顿标记 | 长句拆分 + 加 …… 停顿 |
| 数字/英文/多音字读错 | 文本歧义 | 改写为口语：如"3"写"三"，标注多音字 |
| 角色声音前后不一致 | 未固定声线 | 建立角色声音设定卡全剧复用 |
| 情绪太满、用力过猛 | 全程高强度 | 情绪要有起伏，留克制段落做对比 |
| 尾音吞字/含糊 | 语速过快 | 关键台词降速，句尾清晰收音 |

## 八、提示词万能公式

```
[角色] + [基础音色] + [此句情绪类型] + [情绪强度/克制度] + [语速] + [生理表现] + [停顿/重音标记] + 台词文本
```

**完整示例：**

```
[林夏][低沉沙哑][愤怒-隐忍][语速偏慢][一字一顿、尾音发抖]
"我【从来】没有……求过你。"
```

## 九、不同平台适配备注

- **ElevenLabs**：情绪靠文本语境 + Stability/Style 参数；标点强烈影响语气，善用 `...`、`—`、`!`。
- **Minimax / 火山 / CosyVoice**：多支持情绪标签或语速/语调数值参数，可直接传 `emotion`、`speed`。
- **GPT-SoVITS / Fish Audio**：靠参考音频定音色，情绪靠参考样本 + 文本标点。
- **视频端（即梦/可灵/Runway）**：口型对齐要求台词时长匹配画面，语速需配合镜头节奏。

> 通用做法：先用"文本+标点+情绪描述"把台词写扎实，再用平台数值参数微调，两者叠加效果最好。

## 十、对话台词专项（多角色互动）

单句台词看情绪，对话看**关系与节奏**。以下针对"你来我往"的对白场景。

### 10.1 对话节奏三要素

1. **接话速度**：情绪越激烈，接话越快（几乎抢话）；沉默、犹豫时留白拉长。
2. **语速对比**：对话双方语速要有差异，制造张力（一个急一个稳＝压迫感）。
3. **音量落差**：一方拔高、另一方压低，比双方都吼更有戏剧性。

```
[A-质问-语速快-音量高] 那天晚上你到底在哪？
[B-停顿0.5秒-低声-语速慢] ……你为什么突然问这个。
[A-抢话-更快] 别回避！回答我！
```

### 10.2 潜台词（言外之意）

台词表面一个意思，情绪传递另一个意思，才有层次。提示词要标"表面 vs 真实"：

```
[表面平静-实则强忍崩溃] "挺好的，你过得好就行。"
（提示：语气刻意轻松，但尾音发紧、有一瞬间气息不稳）
```

### 10.3 抢白 / 打断 / 重叠

真实吵架不会你一句我一句轮流讲。标注打断点：

```
[A] 我早就说过这件事根本不——
[B-打断-音量压过A] 够了！我不想再听你解释！
```

### 10.4 独白 vs 对白 vs 旁白（三种口吻要分开）

| 类型 | 对象感 | 语气特征 | 提示写法 |
|---|---|---|---|
| 对白 | 对着另一个角色 | 有互动、有攻防 | `对话感、语气有指向` |
| 独白/内心 OS | 对自己/观众 | 私密、放松、更慢 | `内心独白、气声、放慢、贴近麦` |
| 旁白 | 全知视角 | 客观、抽离 | `旁白、沉稳、不带角色情绪` |

> 常见错误：把内心独白配成对白语气，显得"用力过猛"。内心戏要更轻、更慢、更贴。

### 10.5 情绪递进（多轮对话的情绪爬坡）

一场戏的情绪应该是曲线，不是一条直线。规划整场的情绪走向：

```
起：平静试探 → 承：暗流涌动 → 转：情绪爆发 → 合：爆发后的疲惫/释然
```

对应语速：中速 → 略快 → 极快高音量 → 骤降转慢。

## 十一、声音表演细节（进阶）

### 11.1 微表情式声音处理

- **欲言又止**：`说半句停住，[停顿]，改口`
- **哭着说话**：`带哭腔但坚持把话说完，中间有抽气`
- **笑着说狠话**：`语气轻笑，内容却冷，反差感`
- **疲惫叹息式**：`每句话前先叹气，语速慢，尾音往下掉`
- **咬牙切齿**：`音量不大但咬字极重，气从牙缝出`

### 11.2 呼吸设计

呼吸是"真人感"的关键，不同状态呼吸不同：

| 状态 | 呼吸提示 |
|---|---|
| 平静 | 自然，不标注 |
| 紧张/恐惧 | `急促浅呼吸、说话前吸气` |
| 剧烈运动后 | `喘息明显、说话断续、上气不接下气` |
| 悲伤压抑 | `深吸一口气再开口、中途哽住` |
| 亲密耳语 | `气声重、贴麦、几乎没有换气声` |

### 11.3 音调曲线（升调 / 降调 / 平调）

- **疑问、期待、撒娇** → 句尾升调
- **陈述、失望、决绝** → 句尾降调
- **冷漠、机械、克制** → 全句平调

```
"你真的……要走吗？"    ← 尾音升调，带不舍
"那就……这样吧。"      ← 尾音降调，认命
```

## 十二、按题材的台词风格速查（短剧常见类型）

| 题材 | 台词特征 | 语速基调 | 情绪关键词 |
|---|---|---|---|
| 甜宠 | 撒娇、心动、拌嘴 | 轻快 | 娇羞、宠溺、雀跃、脸红气声 |
| 复仇/逆袭 | 打脸、宣言、反转 | 偏快，爽点处骤停重音 | 隐忍→爆发、冷笑、居高临下 |
| 悬疑/惊悚 | 试探、留白、信息差 | 慢，多停顿 | 压低、气息不稳、阴冷 |
| 虐恋/悲情 | 误会、诀别、独白 | 慢 | 哽咽、颤音、克制的崩溃 |
| 家庭伦理 | 争执、劝和、说教 | 中速 | 无奈、愤懑、语重心长 |
| 搞笑/无厘头 | 吐槽、夸张、反差 | 极快 | 夸张、破音、阴阳怪气 |

## 十三、台词文本改写规范（送给 AI 前的预处理）

AI 配音质量一半取决于文本本身。送稿前先做这些改写：

1. **书面语 → 口语**：`因为…所以…` → `就因为这样，我才…`
2. **长句拆短**：一句不超过 20–25 字，超了就断句或加停顿。
3. **数字/符号口语化**：`3:00` → `三点`，`%` → `百分之`，`&` → `和`。
4. **多音字标注**：`还(hái)钱` / `重(chóng)来` 有歧义时注音或换词。
5. **英文缩写展开或注音**：`CEO` → 视情况保留或写"总裁"。
6. **补语气词接口**：干巴巴的句子加 `啊/吧/呢` 增自然度（勿滥用）。
7. **敏感谐音规避**：某些词 TTS 易读错或平台屏蔽，提前换同义词。

## 十四、口型对齐（AI 数字人 / 视频短剧专用）

当台词要配画面口型时，语速不只是表演，更是**时长约束**：

- **先量时长，再配音**：一个镜头 3 秒，台词就得能在 3 秒内自然说完，不能硬塞。
- **口型帧率匹配**：语速过快会导致口型跟不上、糊嘴；过慢会有"停顿脸"。
- **重点词卡在画面重点帧**：情绪爆发的词，尽量对齐面部特写/推镜时刻。
- **静默留口型**：角色不说话时也要有微表情/呼吸，别让脸僵住。

```
[镜头3秒-中速-口型清晰] "我，不会走。"   （3字一顿，卡满3秒，配坚定表情）
```

## 十五、成片前台词质检清单（Checklist）

配音生成后，逐条核对：

- [ ] 每句是否有明确情绪，而非"念稿"？
- [ ] 语速是否随情绪起伏，而非全程一个速度？
- [ ] 多角色声音是否可区分（音色/语速/音调有差异）？
- [ ] 同一角色全剧声线是否一致？
- [ ] 关键台词（爽点/转折/金句）重音是否突出？
- [ ] 长句是否有换气停顿，没有憋气感？
- [ ] 多音字、数字、英文是否读对？
- [ ] 情绪转折处衔接是否自然，不生硬？
- [ ] 是否有"情绪太满"的段落需要留白对比？
- [ ] （视频）台词时长是否匹配镜头与口型？
