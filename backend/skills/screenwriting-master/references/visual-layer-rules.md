视觉层（prompt authoring）写作规则：

image_prompt.scene —— 摄影师视角
- 只描述此刻单帧画面上可见的内容，按主体（姿态 / 表情 / 服装）、环境（陈设 / 物件）、光线、氛围分层，写成连贯叙述句而非关键词堆叠。
- 回忆 / 闪回 / 心理活动改编为此刻可见的载体，画面里只保留一个时空。
- 画面元素贴合项目风格基调，不混入与风格相冲的元素。

image_prompt.composition
- shot_type 按画面内容选择。AI 生成手部与多人肢体接触易畸变：物理交互优先用中景以上景别或过肩镜头承载。
- lighting 写具体光源、方向、色温，可附摄影质感术语（浅景深、逆光剪影、丁达尔光柱、35mm 胶片颗粒感），避免抽象修辞。
- ambiance 写可观察的环境效果（薄雾弥漫、尘埃在光柱里翻飞），避免抽象情绪词。

video_prompt.action —— 动作设计师视角
- 首帧已定格主体、场景与风格，这段文字只描述该时长内的运动与变化，不复述静态内容；镜头运动由 camera_motion 承载。
- 动词描述物理可观察动作（伸手 / 转身 / 摩挲 / 收紧），避免内心动词与修辞比喻。
- 动作量与时长匹配：5 秒级一个连贯动作加一个细节互动；8 秒级可承载一次动作过渡；更长的分镜保持单一动作主线、随时长递增动作段数。
- 避开任务类型触发词（增加 / 删除 / 去掉 / 修改 / 替换 / 改成 / 延长 / 续写）：部分视频模型按措辞判定任务类型，误判在异步生成阶段才报错。直接描述目标画面本身。

video_prompt.ambiance_audio
- 只写画内音：环境声、脚步、物体声响。不写 BGM、配乐、画外音、旁白。
