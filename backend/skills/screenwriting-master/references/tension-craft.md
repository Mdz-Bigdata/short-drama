# 紧张感：控制观众的预期

危险堆得再大，观众不一定紧张。紧张来自预期：观众知道有事要发生，却不知道何时、以何种方式发生。所以写紧张戏，要设计的是观众**什么时候知道、等多久、怎么兑现**。

## 一、信息差：让观众先知道

1. **先给观众一条反常信息**：下毒的人刚换过茶盏；师兄说「师父闭关」，上一场观众却看见师父的命灯灭了。可以是全部真相，也可以只是一角——观众不必知道是谁，只要知道人物的判断是错的。
2. **人物照旧行事**：他端起茶、整理衣冠、照原计划赴约。平常的动作在观众眼里全成了倒计时。
3. **一步步靠近**：反常一处处冒头，直到人物不得不面对。

埋下的反常要可信、要兑现。回回虚惊，观众就不再当真。

同一件事，信息分给谁，出来的是三种戏，动笔前先选定：

| 谁先知道 | 观众的感受 | 怎么写 |
| --- | --- | --- |
| 观众先知道 | 替人物捏汗：他什么时候发现 | 上面三步 |
| 人物先知道 | 好奇：他看见了什么 | 先写人物的反应（脸色一变、手停在半空、目光钉在一处），他看到的东西先不给 |
| 同时知道 | 一瞬间的冲击 | 跟着人物的手或视线一起看到；留给揭底那一下，不连着用 |

反应本身就是信息：一个眼神、一次停顿交代得了的，不让人物张嘴说出来。

## 二、延迟兑现：确认了危险，先别让它发生

紧张最浓的是「危险已确认、结果未兑现」那一段。

- 先让观众明白在等什么——性质都说不清的危险只制造困惑。
- 用会变化的细节拖住它：门外的影子从一个变成两个；更漏滴到最后几滴；对方的手从袖口缩回去了。每个细节都要让观众对危险重新下一次判断，不是单纯拖时间。
- 在期待最高时兑现，或给出一个合理的新走向。铺垫到底什么都没有，观众会觉得被耍。

## 三、揭底：一层一层给

大秘密不是藏到最后一次倒出来，是排好给出的顺序：

1. **先让人觉得不对**：一个和处境不相称的细节（被逐出师门的人深夜叩门，浑身是伤，说话却格外客气）。
2. **把注意力引过去**：他执意要进后院，径直走向那口封了多年的井。
3. **分几步给看**：先是井壁上的暗门，再是门后的石阶，再是石阶尽头有人住过的痕迹。
4. **先给处境，后给解释**：先看见那地方什么样、人过成什么样，原因放到最后。
5. **最后一层让前面全对上**：答案一出，前面看不懂的举动（为什么急着进门、为什么熟门熟路）都有了着落；每揭一层，留下一个更深的问题。

## 四、有张有弛：一直高压就没有高压

| 阶段 | 作用 |
| --- | --- |
| 缓冲 | 人物暂时安全，整理信息、处理关系 |
| 预警 | 一个细节暗示新危险 |
| 逼近 | 反常越来越明显，人物开始行动 |
| 爆发 | 危险发生，积攒的期待兑现 |

缓冲不等于危险解除。人物松一口气、恢复一点行动，但危险还在不在没有人说得准，观众只是从极怕落到一直不安；把话说死（「屋里没人」），这口气就泄了。

爆发之后要有缓冲，但缓冲不是停下：主角逃出追杀，躲进破庙生火、给伤口上药——门外传来的却是自己人的暗号，而这个暗号只有已经死去的人知道。刚到手的安全被一条新信息打碎，落差本身就是紧张。

与集首钩子的关系：短剧前 3 秒照样要强钩子；这里管的是钩子之后——不是每个节点都顶在最高压。先让人物以为过关，再用新信息掀翻，往往比一直加码更狠。

## 五、落到分镜

「夜里回到住处，屋里有人」：

- **平铺**：推门，看见黑衣人，拔剑就打。危险一出现就爆发，观众没来得及期待。
- **调过节奏**：推门，屋里黑着；他摸到桌边点灯——灯芯是温的。他停住，手从火折子移到剑柄；窗纸上一道影子一晃不见；他慢慢退向门口——门在身后自己合上了。

多出来的是三步：一个物件制造反常；人物尝试应对，观众担心他来不来得及；危险打断他的应对。

拆格时：观众已察觉、结果未定的那几格放慢，拆成几个短分镜，每格只给一个变化的细节；日常段落快写。察觉之后再铺陈设和心理，紧张一样会散。

## 六、动笔前问四句，写完问三句

动笔前：这一场人物知道什么？观众知道什么？还藏着什么没给？打算在哪一刻、用哪个动作揭开？

情绪跟着信息走：每给一条新信息，观众对局势的判断变一次，情绪才起落一次。情绪上不去，先查信息给得对不对，不靠加配乐、加表情。

写完：

1. 观众此刻**具体**在担心什么？（不是「很危险」，而是「他会被认出来」）
2. 观众在**等**什么发生？
3. 这段有没有用新信息**改变**观众的预期？（不是要不停反转，而是让下一秒有新判断）

三句答得出，紧张就有了落点。
