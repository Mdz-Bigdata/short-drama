# 爽点谱系与主角强弱两段弧

> 来源：故事创作训练营《短剧剧本写作：21个必备爽点》为主，参考新星蜕变Novaryx《电影高张力镜头语言》、晨阳写作社《短剧剧本怎么写》。
> 只收方法，用本项目的话重写，不复制原文与案例。压抑→爆点→释放三段式、压弹簧、高潮四要点见《场次工艺与对白技法》，本文不重复。
> 适用：主角要赢的戏（逆袭、复仇、修仙玄幻、权谋、都市异能、战神赘婿）。甜宠、家庭、正剧只取第一节第 2 条「不按套路」。

## 一、三条爽感底线

1. **杀伐果断，横推无敌**：敌我一旦定下，主角出手就是终局，斩草除根，不留反扑的口子。反派跪地哭诉、拿旧情求饶，主角不心软、不放走；
   短剧观众不接受原谅与和解，要看坏人付账。赢了不解释、不训话，一个动作一句话收场。强大之后对手一层比一层硬，主角一路碾过去，
   悬念不放在"赢不赢"，放在"怎么赢、赢得多轻、谁被震住、下一个是谁"。
2. **故事性强，不按套路**：每个爽点都要有因，回头看观众觉得"他本来就该赢"，不是作者开挂。解围用的道具、一句话、一份人情，前面埋过，
   不凭空变出来。反派坏得有逻辑、有自己的算盘，不降智送分。观众以为要怎么打脸时，换一种同样解气、但没想到的赢法；
   相邻两集不用同一种爽法（从第三节谱系里换）。每次赢都改变主角处境，或引出更大的敌人，不原地重复打脸。
3. **弱时苟，强时杀**：主角有由弱到强的成长线时，按第二节分两段写。

## 二、主角强弱两段弧

**弱小时：凡人流 · 智谋型 · 苟道流**
- 没有碾压的本钱就不正面硬拼：藏住底牌、示弱、避开打不过的仗，活下来是第一目标。
- 赢靠脑子：信息差、借势借刀、让对手的贪心和傲慢替自己干活、设局让对手自己跳坑。观众爽的是"算赢了"，不是"打赢了"。
- 每一步有代价：伤、钱、人情、暴露的风险。凡人流的可信来自代价。
- 苟不是怂：观众必须看得见他在谋划（一个记下的细节、一句旁人听不懂的话、提前做好的准备）。忍是为了出手，忍下的每一笔账都记着。
- 不给天降金手指：机缘靠前面的选择换来。

**强大后：杀伐果断，横推**
- 实力跨过门槛要落在具体的一集（突破、身份翻开、靠山倒戈、布的局收网），让观众知道"从这一集起他不用再忍了"。
- 跨过门槛后行为翻转：以前避开的仗主动去打，以前记下的账一笔笔清算，出手即终局。
- 底色不变：弱时的谨慎和强时的狠是同一个人，都是不给敌人机会。强了也不浪、不轻敌，不为一时痛快留后患。
- 强后的戏不能只剩碾压：用更大的局、更高层的敌人、主角在乎的人被威胁，给横推找新的阻力。

## 三、爽点谱系（换着用，别连用同一种）

| 爽法 | 要点 |
|---|---|
| 逆袭 | 所有人押对手赢，主角做成了；先把这件事的难度演足 |
| 反转打脸 | 让事实替主角说话：嫌弃变巴结、拿大佬压人而大佬就是主角、被当面嘲讽的"破烂"其实是宝 |
| 身份被识破 | 主角低调，身份是旁人从蛛丝马迹里认出来的，不是自己亮的 |
| 扮猪吃虎 | 主角主动装弱、故意露怯，等对手底牌出尽再一击 |
| 耍猴遛狗 | 对手自以为布好了网，每一步其实都顺着主角的引导在走 |
| 大智近妖 | 对手以为在下棋，其实是棋子；输了还不知道输在哪一步 |
| 报仇雪恨 | 仇要结得深；清算一层层来，让仇人看着自己的东西被一样样拿走 |
| 绝处逢生 | 绝境要真绝；出路是前面埋好的后手，揭开时观众恍然 |
| 极限反杀 | 实力差摆在明面上，主角藏着的那一手翻过来 |
| 力挽狂澜 | 众人乱成一团，主角一个人稳住局面，看不起他的人被迫认 |
| 打小引老 | 收拾了小的，反派的靠山不报仇，反来招揽主角 |
| 佛系赢家 | 别人抢破头的东西主角不在乎却轻松拿下；是站在顶上才淡定，不是面瘫 |
| 杀伐果断 | 赢了之后怎么做：彻底清算，反派求饶也不放 |

弱时多用：扮猪吃虎、耍猴遛狗、大智近妖、绝处逢生、报仇雪恨的布局段。强时多用：杀伐果断、极限反杀、力挽狂澜、反转打脸、佛系赢家。

## 四、爽点画面：静多动少，一下爆开

- 爆发之前长时间压住：机位锁住不动，人物被门框、阴影框住，观众等着爆，画面按住不爆。
- 爆点只给一瞬：长静 → 极短的爆发 → 立刻收住回到静止。杀伐的狠在快和干净，不在多打几下。
- 爆完给反应：围观者僵住、反派变脸、关键人物的一个眼神，一两个镜头就够。

## 五、自检

1. 这集的爽法和上一集是不是同一种？是就换。
2. 主角赢的那一手，前面埋过没有？
3. 反派这次是不是降智送分？
4. 弱时：主角在算计，还是只在挨打？观众看得见他在谋划吗？
5. 强时：出手是不是终局？有没有放走该收拾的人？
6. 赢完之后，主角的处境变了没有，下一个更大的对手露头没有？
