## 一、剧本与内容层面

### 1. 剧本结构设计

**黄金3秒法则**
- 开头3秒必须制造冲突或悬念
- 不要用铺垫、旁白、空镜头开场
- 直接进入事件核心

**钩子设计（每集结尾）**
- 每集最后5秒必须设置悬念
- 让观众产生"下一集会怎样"的冲动
- 常见钩子：身份揭露一半、反转前奏、危险逼近

**节奏控制**
- 每15-30秒一个情绪转折
- 避免长对话、长独白
- 信息密度要高，每句话都要推动剧情

**结构模板（单集1-3分钟）**

```
0-3秒:   钩子/冲突开场
3-20秒:  建立情境
20-50秒: 矛盾升级/转折
50-70秒: 高潮/反转
70-90秒: 情绪释放 + 下集悬念
```

### 2. 对话设计

```
注意事项:
- 短句为主（每句不超过15字）
- 避免书面化表达
- 台词要有情绪张力
- 每句话都有信息量或情感推进
- 潜台词比直白更有力

反面案例: "我觉得我们之间的关系可能需要重新审视一下"
正面案例: "我们...结束了"
```

### 3. 角色设计要点

```
核心原则:
- 主角必须有明确的欲望和阻碍
- 配角存在的意义是推动主角弧光
- 每个角色的说话方式要有辨识度
- AI短剧角色不宜超过4-5人（控制一致性成本）

AI特别注意:
- 角色外形要有强辨识度（便于AI保持一致性）
- 避免双胞胎、长相接近的角色
- 服装颜色差异要大（AI更容易区分）
- 发型要有标志性特征
```

### 4. 题材选择注意

```
适合AI制作的题材:
✓ 对话密集型（减少复杂动作）
✓ 场景固定/较少（降低场景一致性难度）
✓ 角色数量少（2-4人最佳）
✓ 静态情绪张力大于动态动作

不适合AI制作的题材（当前技术）:
✗ 大量打斗/追逐/动作场景
✗ 群戏（10人以上同框）
✗ 复杂手部特写（写字、弹琴）
✗ 需要精确物理交互（倒水、开门细节）
```

## 二、视觉与画面层面

### 1. 风格一致性

```
核心规则:
- 全片统一一个视觉风格，不要中途切换
- 确定色调后锁定LUT/调色参数
- 同一角色在不同镜头中外观一致
- 同一场景的布局和光影保持稳定

执行方法:
- 建立视觉风格指南文档
- 每个角色制作Character Sheet
- 每个场景制作Scene Sheet
- 使用统一的AI模型和参数
```

### 2. 画面质量控制

```
检查清单:
□ 无AI伪影（多余手指、融合错误、肢体变形）
□ 面部自然（无扭曲、无不对称）
□ 文字清晰可读（如果画面中有文字）
□ 边缘清晰无锯齿
□ 光影物理正确（阴影方向一致）
□ 无明显帧间闪烁
□ 分辨率达标（至少1080p）
```

### 3. 镜头语言

```
AI短剧常用镜头:
- 特写（面部表情）— 叙事表现力最强，但 AI 技术风险最高，必须真人驱动/逐帧精修，不可裸生成（基准见 README §4）
- 中景（半身对话）— 较稳定，推荐主力景别
- 近景（胸部以上）— 常用于对话

慎用镜头:
- 全景/远景 — 人物细节易丢失
- 跟拍/运动镜头 — AI运动控制不稳定
- 手部特写 — AI手部生成仍是弱项
- 多人同框全身 — 比例和位置易出错
```

### 4. 构图注意

```
竖屏短剧（9:16）:
- 主体放在画面中上部（手机自然视线区）
- 下方1/5留给字幕区
- 避免重要信息放在画面边缘
- 特写和近景是最佳选择

横屏短剧（16:9）:
- 遵循三分法
- 对话场景注意视线方向留白
- 利用前景增加层次
```

## 三、AI技术层面

### 1. 模型选择与管理

```
关键原则:
- 全片使用同一个基础模型（不要中途换模型）
- LoRA权重固定记录
- 生成参数建立标准模板
- 每次生成记录Seed值（便于复现和微调）

常见错误:
✗ 不同镜头用不同模型生成
✗ 随意更换LoRA或权重
✗ 不记录生成参数
✗ 使用默认随机Seed
```

### 2. Prompt管理

```
结构化Prompt模板:

[固定部分 — 全片不变]
风格: cinematic, film grain, warm tones, 35mm lens...
质量: masterpiece, best quality, highly detailed...
负面: deformed, ugly, extra fingers, blurry...

[角色部分 — 同角色不变]
角色描述: young chinese woman, long black hair...
服装描述: white dress, silver necklace...

[可变部分 — 每镜头调整]
动作: standing, looking at door, surprised expression
镜头: medium shot, eye level, slightly low angle
光线: afternoon sunlight from right window

管理建议:
- 建立Prompt库（按角色、场景分类）
- 使用变量替换而非每次重写
- 记录哪些Prompt产出了最佳效果
```

### 3. 生成策略

```
批次生成原则:
- 同一场景的镜头集中生成（保持模型状态一致）
- 每个镜头生成3-5个备选
- 优先选择与相邻镜头最一致的版本
- 先生成关键帧/锚定帧，再生成其余镜头

质量vs数量:
- 宁可花时间生成高质量少量素材
- 不要用大量低质量素材凑数
- 一个好镜头 > 十个将就的镜头
```

### 4. 当前AI技术局限（需规避）

```
已知弱项:
- 手部生成（手指数量、姿态）
- 文字生成（画面中的文字常出错）
- 物理交互（拿杯子、握手等精确动作）
- 时间一致性（长视频帧间稳定性）
- 多人场景（人物数量和身份混乱）
- 复杂动作（跑步、打斗的自然性）

规避策略:
- 尽量用中景以上避免手部特写
- 画面中的文字用后期叠加
- 复杂交互动作用切镜头暗示
- 单人或双人镜头为主
- 动作场景用快切+音效弥补
```

## 四、声音与配音层面

### 1. 配音质量

```
注意事项:
- 同一角色全片使用同一个AI声音模型
- 情绪表达要与画面匹配
- 语速适配画面节奏
- 避免AI配音的机械感（添加呼吸音、停顿）
- 不同角色的声音要有明显区分

技术要点:
- 采样率至少44.1kHz
- 录制/生成环境保持一致（混响参数统一）
- 情绪标注要精确（不是"开心"而是"压抑的笑"）
```

### 2. 口型同步

```
问题: AI生成的视频口型与配音不完全匹配

解决方案:
- 使用支持口型驱动的工具（如HeyGen、Sync Labs）
- 生成视频时就输入最终台词
- 后期用口型同步工具（Wav2Lip）修正
- 适当用中景/侧面镜头减少口型可见度
```

### 3. 音效设计

```
必备音效层:
1. 环境音（底噪）— 全程铺设
2. 动作音效 — 脚步、开门、物品碰撞
3. 情绪音效 — 心跳、呼吸加速、钟表滴答
4. UI音效 — 手机提示音、消息声

注意:
- 每个场景的环境音要一致（不能一会有雨声一会没有）
- 音效要与画面动作对齐
- 不要过度使用音效（宁少勿多）
```

### 4. 背景音乐

```
原则:
- 音乐跨镜头连续播放（不要每个镜头重新开始）
- 音乐情绪与剧情情绪匹配
- 避免音乐抢台词（对话时降低音乐音量）
- 高潮处音乐助推情绪
- 转场处音乐提供衔接感

AI音乐生成注意:
- 同一场景用同一首曲子
- 生成时指定情绪、节奏、乐器
- 确保音乐时长覆盖场景需要
- 注意版权问题（确认AI生成音乐的商用许可）
```

## 五、剪辑与后期层面

### 1. 剪辑节奏

```
短剧节奏公式:
- 竖屏短剧: 平均2-4秒/镜头
- 横屏短剧: 平均3-6秒/镜头
- 对话场景: 跟随台词节奏切换
- 高潮场景: 1-2秒快切
- 情绪场景: 5-8秒长镜头

避免:
- 节奏过于平均（没有起伏）
- 无意义的长停顿
- 切镜头太频繁让人眩晕
```

### 2. 转场使用

```
原则: 转场是为了叙事服务，不是炫技

推荐:
- 同场景: 硬切为主
- 换场景: 遮挡转场或短暂黑屏
- 时间流逝: 淡入淡出
- 情绪高潮: 闪白/运动模糊

避免:
- 滥用花哨转场（星形擦除、百叶窗等）
- 每个镜头都加转场
- 转场时间过长影响节奏
```

### 3. 字幕设计

```
竖屏短剧字幕:
- 位置: 画面下方1/5处
- 字号: 适中（手机上清晰可读）
- 背景: 半透明底条或描边
- 颜色: 白色为主，重点词用黄色/红色
- 动画: 逐字显现或整句弹出

注意:
- 字幕与配音严格同步
- 不要遮挡关键画面元素
- 错别字零容忍
- 长句分行显示
```

### 4. 特效与包装

```
适度使用:
- 文字特效（强调关键信息）
- 表情/贴纸（喜剧场景）
- 画面缩放/震动（情绪强调）
- 滤镜切换（回忆/幻想场景）

避免:
- 过度使用特效分散注意力
- 特效风格与整体调性不符
- 低质量特效拉低整体品质
```

## 六、平台规则与审核层面

### 1. 内容红线

```
绝对禁止:
✗ 色情/软色情内容
✗ 血腥暴力（写实的）
✗ 涉政/敏感时事
✗ 宗教冒犯
✗ 未成年人不当内容
✗ 诱导危险行为
✗ 虚假信息/伪新闻

灰色地带（需谨慎）:
△ 擦边暗示（平台标准不一）
△ 封建迷信（看呈现方式）
△ 家庭暴力（看处理角度）
△ 吸烟饮酒（看呈现频次）
```

### 2. 各平台差异

```
抖音:
- 竖屏优先（9:16）
- 内容审核严格
- 偏爱强情绪、快节奏
- 付费短剧需申请资质

快手:
- 竖屏为主
- 下沉市场用户多
- 家庭/乡村题材受欢迎
- 审核相对宽松但有底线

微信视频号:
- 横竖屏均可
- 用户偏成熟
- 品质感要求较高
- 社交传播逻辑

B站:
- 横屏为主
- 年轻用户
- 弹幕互动
- 内容品质门槛高

海外（ReelShort/ShortTV等）:
- 竖屏9:16
- 英文为主
- 尺度相对宽松
- 付费解锁模式成熟
```

### 3. AI内容标识

```
趋势:
- 越来越多平台要求标注AI生成内容
- 部分平台限制纯AI生成内容的推荐权重
- 未来可能需要声明AI使用比例

建议:
- 了解目标平台的AI内容政策
- 必要时添加AI生成标识
- 保留原始素材和生成记录（备查）
- 关注政策动态及时调整
```

## 七、商业与运营层面

### 1. 变现模式选择

```
付费解锁模式:
- 免费播放前5-10集 → 后续付费
- 关键节点设付费墙（高潮前）
- 定价参考: 单集0.5-2元，全集9.9-39.9元

广告变现:
- 剧情中植入品牌
- 贴片广告
- 信息流广告分成

IP授权:
- 热门短剧改编长剧/电影
- 周边衍生品
- 游戏/小说改编
```

### 2. 成本控制

```
AI短剧成本构成:
- AI工具订阅/API费用: 30-40%
- 配音（AI语音）: 10-15%
- 后期制作（剪辑、调色）: 20-25%
- 音乐音效: 5-10%
- 运营推广: 15-25%

控制建议:
- 建立可复用的资产库（角色模型、场景、音效）
- 批量生成降低单镜头成本
- 标准化工作流减少返工
- 用AI工具替代人工后期（调色、字幕）
```

### 3. 数据关注指标

```
核心指标:
- 完播率（最重要）— 目标>40%
- 3秒留存率 — 目标>70%
- 下一集点击率 — 目标>30%
- 付费转化率 — 目标>5%
- 分享率 — 衡量传播力

优化方向:
- 完播率低 → 节奏太慢/内容无聊
- 3秒留存低 → 开头不够吸引人
- 下集点击低 → 结尾钩子不够强
- 付费转化低 → 付费墙位置不对/定价过高
```

### 4. 投流与推广

```
冷启动策略:
- 前3集做成独立短视频投放测试
- 找到数据最好的"钩子片段"
- 用钩子片段做投放素材引导付费

投流注意:
- 素材与正片质量一致（不要诱导性素材）
- A/B测试不同钩子点
- 关注ROI而非单纯曝光量
- 不同平台需要不同投放策略
```

## 八、团队协作与流程管理

### 1. AI短剧最小团队配置

```
最小可行团队（1-3人）:
- 编剧/导演（1人）: 剧本+分镜+整体把控
- AI制作（1人）: 生成+后期+调色
- 运营（1人）: 发布+投流+数据分析

进阶团队（5-8人）:
- 制片人（1人）: 项目管理、预算
- 编剧（1-2人）: 剧本创作
- AI美术（1-2人）: 视觉设计+AI生成
- 后期（1人）: 剪辑+调色+音频
- 运营（1-2人）: 多平台运营+投流
```

### 2. 生产流程标准化

```
标准周期（60集短剧）:

第1周: 剧本创作（大纲+前20集剧本）
第2周: 视觉开发（角色设计+场景设计+风格确定）
第3周: AI生成（前30集素材生成）
第4周: AI生成（后30集素材生成）
第5周: 后期制作（剪辑+调色+配音+音效）
第6周: 审核修改+发布准备

总计: 6周完成60集（传统拍摄需3-6个月）
```

### 3. 版本管理

```
命名规范:
项目名_集数_镜号_版本号
例: 霸总爱上我_EP03_S02C05_v3

必须记录:
- 每个镜头的AI生成参数
- 使用的模型和LoRA版本
- Prompt完整内容
- 选用的是第几个生成版本
- 后期调整记录
```

## 九、法律与版权层面

### 1. AI生成内容版权

```
当前状况（持续变化中）:
- 各国对AI生成内容的版权归属尚无统一规定
- 中国: 有法院判例支持AI生成内容受著作权保护（需有人类创作性参与）
- 美国: 纯AI生成不受版权保护，但有人类参与的可以

建议:
- 保留完整的创作过程记录（Prompt、参数、选择过程）
- 证明人类的创造性参与（选择、编排、修改）
- 关注所在地区最新法规
```

### 2. 肖像权风险

```
风险点:
- AI生成的人脸可能与真实人物相似
- 使用真人照片训练LoRA可能侵权
- 数字人克隆需获得授权

规避:
- 不要基于名人照片生成角色
- 训练LoRA使用自有/授权素材
- 生成后检查是否与知名人物相似
- 保留授权协议
```

### 3. 素材版权

```
需确认版权的素材:
- AI模型本身的商用许可
- 训练数据的合规性
- 背景音乐（即使AI生成也要确认许可）
- 音效素材来源
- 参考图的使用范围

安全做法:
- 使用明确允许商用的AI模型
- AI生成音乐确认平台的商用条款
- 建立素材来源追溯表
```

## 十、质量把控清单

### 单集质量检查

```markdown
## 质量检查表 — 第___集

### 内容
- [ ] 开头3秒有吸引力
- [ ] 剧情推进无废镜头
- [ ] 对话自然不生硬
- [ ] 情绪节奏有起伏
- [ ] 结尾有有效钩子
- [ ] 无逻辑硬伤

### 视觉
```

## 十一、常见失败原因总结

| 失败类型 | 具体表现 | 预防方法 |
|----------|----------|----------|
| 剧本平淡 | 无冲突、无悬念、节奏慢 | 每15秒设一个转折点 |
| 视觉不一致 | 角色变脸、场景乱跳 | 严格执行连续性方案 |
| AI感太重 | 动作僵硬、表情不自然 | 用剪辑和音效弥补 |
| 音画不同步 | 口型对不上、音效延迟 | 用口型同步工具修正 |
| 节奏拖沓 | 观众看到一半就划走 | 控制每镜时长+快切 |
| 质量参差 | 有的镜头好有的差 | 统一标准，差的重新生成 |
| 技术追求过度 | 花大量时间追求完美单镜头 | 先完成再完美，整体优于局部 |
| 忽视声音 | 只关注画面不管声音 | 声音占体验的50%以上 |
| 不了解平台 | 内容与平台调性不匹配 | 先研究平台爆款再创作 |
| 没有数据思维 | 凭感觉创作不看数据 | 用数据指导迭代优化 |
