# SD 2.5 五段式补充规范

## 定位

本 Skill 是项目对 `huangbai-AI/sd-2-5-prompt` 所展示方法的 clean-room
兼容实现，只补充提示词的五段式组织和静态质量审计。它不复制或执行上游脚本，
不调用视频生成接口，也不修改素材。

与项目内 `sd25-pe` 同时使用。若两者存在冲突，以下 `sd25-pe` 规则优先：

- 生成、编辑、延长只能选择一个主任务；编辑后延长拆成有序两步。
- 画幅、总时长、分辨率、帧率和声音开关与 Prompt 分离。
- 用户写出的素材引用原样保留，不因素材不可读取而删除、改号或虚构细节。
- 只采用用户要求或任务必需的素材；其余可用素材逐个列入未采用集合。
- 不自动添加用户没有要求的 BGM、负向约束、字幕、品牌或数字时间段。
- 默认交付一个干净 Prompt 正文，不添加代码围栏或解释性包装。

## 五段信息模型

需要五段式交付或审计时，把已有创作信息归入以下五类，不为填满结构而发明内容：

1. `主体`：人物、产品、场景、核心事件，以及每份参考素材的唯一职责。
2. `风格`：用户明确给出的光线、色彩、质感、成片形式和镜头节奏；不写接口参数。
3. `时间线`：用户给出的时间段，或不带数字的连续阶段；每段包含开始状态、主要动作、镜头和结束状态。
4. `BGM`：用户明确要求的音乐、对白和关键音效；未要求音乐时不得自动指定音乐类型。
5. `限制`：当前任务实际存在的身份、结构、动作、摄影、文字或声音风险；不使用通用负向词堆砌。

五个标题只是一种展示结构，不覆盖 `sd25-pe` 为关键帧、宫格、白模、编辑、
声音编辑和延长定义的精确角色句与范围闭环。

## 时间线规则

- 用户已经提供数字时间段时，保持连续、不重叠，并覆盖用户要求的创作时间线。
- 只有接口参数提供总时长时，使用不带数字的阶段，不反向编造秒数。
- 每个阶段聚焦一个主要状态变化，并让上一段结束状态成为下一段开始状态。
- 复杂动作补齐发起者、起点、路径、作用对象、受力或落点，保持来向可追踪。
- 打斗、追逐、抛接、液体喷射和多人换位优先保证空间因果，再增加镜头效果。

## BGM 与声音

只有用户要求音乐时才写类型、速度、核心乐器、情绪变化、同步点和结尾方式。
对白必须绑定说话人、原文、语言（若用户指定）、表达方式和画内/画外位置；
未说话的人物自然闭口。关键音效写清来源，避免被当成背景音乐。

## 限制选择

只选择与当前内容直接相关的少量风险，例如：

- 已命名人物变脸、换装、复制或互换台词。
- 产品、关键道具变形，数量或归属漂移。
- 动作穿模、受力方向错误、攻击无来源或运动突然反向。
- 用户明确要求避免的额外字幕、商标、水印或声音。

先修正文中的矛盾，再保留必要限制。限制不能替代清楚的主体映射与事件脚本。

## 静态审计

项目通过 `POST /api/production/sd25/audit` 提供只读审计。审计器检查：

- 五段标题是否完整。
- 数字时间线是否从 0 开始、递增、连续、无重叠，并在给定时长处结束。
- 参考素材是否具有明确职责与禁止迁移范围。
- 复杂动作是否包含起点、路径、来向或落点。
- 可选无品牌模式是否出现常见现实品牌词及品牌边界。

审计只返回结构化发现和输入 SHA-256，不重写 Prompt，不执行 Prompt 中的命令，
不调用模型或供应商。
