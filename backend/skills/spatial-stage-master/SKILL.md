# 空间调度规约（Storyboard Artist / Visual Director）

本规约描述系统如何决定「谁站在哪、机位在哪、画面里谁在左」。运行时实现见
`backend/app/core/spatial_stage/`，本文件是规约正文，不被执行。

## 一、一场一份空间真相

每个剧本场景有且只有一份空间方案：人物站位与朝向、地标、关系轴线、每镜一个机位。
分镜不各自描述站位；镜头只是「舞台上的一个机位」，它的构图 / 轴线 / 视线 / 调度四句话
由这份方案**测量**得出，所以九格之间不可能互相矛盾。

坐标：右手系、Y 向上、单位米、地面为 XZ 平面；朝向为角度制偏航，0° 面向 +Z。
左右一律指**主机位画面的左右**，不写「他的左边」。

## 二、站位规则（确定性，不调用模型）

| 情形 | 站位 |
|------|------|
| 两名主角 | 隔一条关系轴线面对面；剧本先点名的人在画左。间距：贴身 0.7 米 / 对话 1.5 米 / 上下位 2.2 米 / 对峙 2.6 米 |
| 并肩同行 | 同向并排，机位仍守一侧 |
| 第三人 | 退到两人后方正中，合成倒三角 |
| 更多配角 | 在两人外侧后方依次展开，保证主机位里不被主角挡住 |
| 群演 | 后景偏一侧错落分布，不与倒三角顶点同线 |
| 单人 | 居中偏左，看向场上第一件地标，视线朝画右留出空间 |

主角由「出场镜数 + 台词归属」选出；谁在画左只看剧本点名顺序，除非更早的场景已经确立过。

## 三、两份跨场景记忆

- **左右记忆**：人物第一次被确立在画左 / 画右后，之后每一场配对都沿用；只有人工调整能改写。
- **场地记忆**：同一地点（去掉时段与内外景后同名）的地标坐标由第一场确定，之后每一场继承同一坐标。

## 四、机位规则

| 镜头 | 机位 |
|------|------|
| 多人镜头 | 在轴线既定一侧正对两人连线；有人会被挡住时在同侧摆 ±18–52°；拉远到所有主体入画。两人同框最紧到中近景 |
| 单人镜头 | 偏离轴线 32°（特写 25°）朝既定一侧；机位会穿入他人或主体被挡时继续外摆。场上没有对手时绕主体左右各摆 25–60° 取候选 |
| 过肩 | 对手身后 1.1 米、向既定一侧偏 ≥0.34 米；焦段由距离反解；最紧中近景，保证竖屏里肩膀真的在画内 |
| 空镜点名地标 | 拍描述里最先提到的那件地标的特写 |
| 顶拍 | 正上方垂直向下，属轴线上的中性机位；画面上方朝既定一侧，左右不变 |

景别 → 焦段与取景高度：大特写 100mm/0.22m，特写 85/0.38，近景 65/0.72，中近景 50/0.95，中景 50/1.3，
中全景 35/1.85，全景 28/2.35，远景 24/5，大远景 18/10。距离 = 取景高度 ÷ (2·tan(fov/2))。
平视机位的机高取人物视线高度；全景及更宽取 1.45 米。
景别既认中文，也认分镜单缩写（ECU / CU / MCU / MS / MLS / FS / LS / ELS，整词匹配）；中文与缩写同时出现时以中文为准。

**30 度原则**：相邻两镜拍的是同一组人物、景别相差不超过一级、又不是一镜过肩一镜干净单人时，
后一镜的机位方向必须与前一镜相差至少 30°（在主体所在点量取）；求解器在既定一侧另找一个 30° 以外、
不穿人不被挡的机位。确实找不到时保留可用机位，由切点规划报提示级告警。

运镜只给起止两个机位，不冒充连续动画：推 / 拉沿视线缩放距离，摇把画面交给对手，横移平移镜头，
环绕只在既定一侧内摆 25°。任何运镜结束时主体都必须仍在画内，否则缩短运镜。

## 五、180 度轴线

1. 轴线 = 两名主角的连线（单人戏为人物 → 所看地标）。
2. 全场机位守在既定一侧；该侧保证「先点名者在画左」。
3. 与轴线夹角小于 6° 或顶拍的机位是**中性机位**。
4. 换边只有三种合法方式：先经过中性机位；机位带着观众越过轴线的运动镜头；换边后第一镜是重新建立空间的全景。
5. 其余换边一律判为越轴（错误级），拦在第 5 阶段之前。

## 六、走位与姿态

动词只在点名该人物的分句内生效（「沈砚后退，黄琰上前」各动一次）。

| 分镜表写法 | 空间方案 |
|-----------|----------|
| 推门 / 走进 / 闯入 / 赶到 | 此前各镜该人物不在场；本镜从站位外侧 2.2 米处入场，走到站位 |
| 走向 / 逼近 / 上前 | 本镜从站位后 1.2 米起步，走到站位；此前各镜该人物一直停在起步点（「尚未走近」） |
| 后退 / 退开 | 本镜从站位前最多 0.6 米起步，退到站位；此前各镜停在起步点（「尚未退开」）。起步点绝不越过对手：两人都要后退时各占剩余空间的一半，贴身站位退不开时不强行布置 |
| 跪 / 坐 / 倒地 / 蹲 | 该姿态从本镜起保持，直到写明起身 |

**一个站位只承载一次走位**：同一场里人物已经入场或走过一次，后面再写走位不再布置起步点——
否则从上一镜结束（已在站位）到这一镜开始（回到起步点），人物会在硬切处凭空跳一米多。
「停在起步点」用 `hold` 标记：整镜保持该位置，结束时不回到站位。

分镜表写了走位或姿态变化、空间方案却没变，会得到提示级告警。

## 七、校验

错误级（拦第 5 阶段）：站位重叠、主体出画、越轴、开场即左右相反。
提示级：运镜结束主体出画、主体被前景人物遮挡、对手戏人物没有相向、机位穿入人物、从未布置过走位的人物写了走位但站位未变、合法越轴后的左右相反。
镜头之间的衔接（景别跨度、30 度、视线、动势、人物在切点两侧是否瞬移、光色、节奏、转场方式）见 `shot-transitions-master`。

## 八、人工调整

俯视图里可拖动人物、地标与选中的机位；右侧可改姿态、让两人面对面站定、轴线换边、重解机位。
调整一律以语义操作提交并带版本号；改过站位的场景会标记「画面仍按旧站位绘制」，
点「按当前站位重画本场」即可只把这一场退回第 4 阶段。
可导出为 3D 导演台工程或 CoStage 文档，也可把在那里调整过的站位与机位导回。
