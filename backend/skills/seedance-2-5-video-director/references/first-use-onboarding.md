# Seedance 2.5 视频导演安装与使用引导

## 输出规则

仅在安装器或运行环境明确说明 Skill 刚完成安装，或用户主动索要帮助、安装指导、教程、输入模板或示例时展示。不要因为新开对话、当前对话第一次调用或缺少跨会话状态而自动展示。若展示后仍有实际任务，立即继续处理原请求，不要求用户重新发送。

## 学习指导

```text
【Seedance 2.5 视频导演｜使用指导】

这个 Skill 的工作是把视频创意、人物参考图、已有视频、音频、分镜图或旧提示词，整理成适合 Dreamina／即梦 Seedance 2.5 的视频脚本、导演方案、诊断结果或可复制提示词。

它只负责策划和编写文本，不会自动提交生成任务、消耗积分或声称已经生成视频。

开始前只要确认五件事：
1. 想做什么：新视频、续写、编辑、转场、白模渲染或分镜动画；
2. 总时长和画幅：例如15秒、16:9；
3. 素材角色：每张图片、视频和音频分别控制谁、什么动作或什么声音；
4. 故事变化：从第一帧到最后一帧发生什么；
5. 输出形式：完整导演方案、只要提示词、只要脚本、只诊断或按原结构修改。

常用主模式：
- 4–30秒普通新视频：basic-multimodal；
- 精确30秒时间轴：timestamp-30s；
- 30–180秒长视频：long-video；
- 在原视频之前或之后增加内容：video-extension；
- 删除、替换或修改原视频局部：video-edit；
- 白模动作或场景渲染：clay-renderer；
- 连接两段原视频：seamless-transition；
- 把多格分镜依次做成镜头：multi-grid-storyboard。

人物参考图默认锁定完整可见人物，包括身份、脸、发型、体型、服装、鞋子和配饰。除非你明确说“只参考脸”或允许重新造型，否则不会自行换衣服。

续写必须说清新增片段位于原片之前还是之后；“向前续写”和“向后续写”容易产生歧义，Skill会先确认边界。

写真人表演时，优先描述人物为何反应、听见后的停顿、自然动作和残留情绪，不机械罗列眉毛、眼睛、鼻子和嘴的逐项变化。
```

## 最小输入模板

```text
使用 $seedance-2-5-video-director。

任务：<新视频 / 续写 / 编辑 / 转场 / 白模渲染 / 分镜动画>
时长与画幅：<例如15秒，16:9>
素材：<例如 @Image 1 是完整人物参考；@Video 1 只参考动作>
故事：<开始状态 → 主要变化 → 最终状态>
声音：<对白、环境声、BGM、是否需要字幕>
输出：<完整方案 / 只要提示词 / 只要脚本 / 只诊断 / 按原结构修改>
```

## 学习示例

### 示例一：人物参考图生成新视频

```text
使用 $seedance-2-5-video-director。

任务：生成20秒、16:9的第三人称情感短片。
素材：@Image 1 是女主完整人物参考，严格保持脸、发型、体型和原服装；不要继承图片背景。
故事：女主在雨停后的公交站等人，对方始终没来；她看完手机消息，收起伞独自离开。
声音：只有城市环境声和一句自然对白，无字幕，无BGM。
输出：完整导演方案和最终提示词。
```

学习重点：完整人物参考不等于只参考脸；时间轴必须给等待、理解消息和离开留出真实表演时间。

### 示例二：原视频之后续写

```text
使用 $seedance-2-5-video-director。

任务：在 @Video 1 原片之后追加5秒。
新增剧情：承接原片最后一帧的人物步伐、朝向、机位和环境声；人物停下，回头看向身后的门，门内灯光熄灭。
保护：原视频内容完全不变，不重置站位，不新增无关人物。
输出：只要最终提示词。
```

学习重点：明确“原片之后”和“最后一帧”，避免续写方向歧义。

### 示例三：诊断矛盾提示词

```text
使用 $seedance-2-5-video-director。

只诊断下面提示词，不要重写：
“一镜到底，固定机位，同时切换正反打；人物始终距离镜头两米，但最后脸部填满画面。”
```

学习重点：一镜到底与正反打冲突；固定距离与脸部填满画面冲突。诊断模式只说明问题，不擅自改写成另一个故事。

### 示例四：视频编辑

```text
使用 $seedance-2-5-video-director。

任务：编辑 @Video 1。
在5–8秒，仅把红色方框内的蓝色杯子替换为白色花瓶；人物、动作、桌面其他物品、背景、机位、原声和其余时间保持不变。
输出：只要最终提示词。
```

学习重点：编辑任务要同时写清时间、位置、目标、操作和不允许变化的元素。
